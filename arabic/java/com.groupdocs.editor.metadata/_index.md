المساحة الاسمية **com.groupdocs.editor.metadata** توفر الفئات لوصف خصائص المستند الأساسية اعتمادًا على نوع المستند.



## الفئات

| فئة | الوصف |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | يمثل بيانات تعريفية لوثيقة كتاب إلكتروني واحدة |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | يمثل بيانات تعريفية لوثيقة بريد إلكتروني واحدة بأي تنسيق بريد إلكتروني مدعوم |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | يمثل بيانات تعريفية لوثيقة ذات تنسيق تخطيط ثابت مثل PDF أو XPS |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | يمثل بيانات تعريفية لوثيقة ماركداون واحدة |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | يمثل بيانات تعريفية لوثيقة عرض تقديمي واحدة |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | يمثل بيانات تعريفية لوثيقة جدول بيانات واحدة |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | يمثل بيانات تعريفية لوثيقة نصية واحدة مثل XML أو HTML أو نص عادي (TXT) |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | يمثل بيانات تعريفية لوثيقة معالجة كلمات واحدة |
