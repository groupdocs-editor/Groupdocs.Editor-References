## Length.Unit enumeration

جميع وحدات الطول المدعومة

```csharp
public enum Unit
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Unitless | `0` | بدون وحدة - لا توجد وحدة طول معرفة. القيمة الافتراضية. |
| Px | `1` | بكسل. نسبة إلى جهاز العرض. لعرض الشاشة، عادةً بكسل جهاز واحد (نقطة) من الشاشة. |
| Em | `2` | إيم. تمثل هذه الوحدة حجم الخط المحسوب للعنصر. |
| Ex | `3` | Ex (طول-x). تمثل هذه الوحدة الارتفاع السيني لخط العنصر. في الخطوط التي تحتوي على الحرف 'x'، يكون هذا عادةً ارتفاع الأحرف الصغيرة في الخط؛ 1ex ≈ 0.5em في العديد من الخطوط. |
| Cm | `4` | سم. سنتيمتر واحد (10 مليمترات). |
| Mm | `5` | مم. مليمتر واحد. |
| In | `6` | In. بوصة واحدة (2.54 سنتيمتر). |
| Pt | `7` | Pt. النقطة الواحدة هي 1/72 من البوصة أو 0.353 مم. |
| Pc | `8` | Pc. بيكا واحدة (12 نقطة). |
| Ch | `9` | Ch. هذه الوحدة تمثل العرض، أو بدقة أكبر مقياس التقدم، للرمز '0' (صفر، رمز يونيكود U+0030) في خط العنصر. |
| Rem | `10` | Rem. هذه الوحدة تمثل حجم الخط للعنصر الجذر (مثال: حجم الخط لعنصر &lt;html&gt;). عند استخدامها على حجم الخط لهذا العنصر الجذر، تمثل قيمته الأولية. |
| Vw | `11` | Vw - عرض نافذة العرض. 1/100 من عرض نافذة العرض. |
| Vh | `12` | Vh - ارتفاع نافذة العرض. 1/100 من ارتفاع نافذة العرض. |
| Vmin | `13` | Vmin. 1/100 من القيمة الدنيا بين ارتفاع وعرض نافذة العرض. |
| Vmax | `14` | Vmax. 1/100 من القيمة القصوى بين ارتفاع وعرض نافذة العرض. |
| Percent | `15` | القيمة نسبية إلى قيمة ثابتة (خارجية)، وهي تعتمد على السياق. 1% = 1/100 من القيمة الخارجية. |
