## IImage interface

نوع بيانات CSS للصورة يمثل صورة ثنائية الأبعاد

```csharp
public interface IImage
```

### ملاحظات

https://developer.mozilla.org/en-US/docs/Web/CSS/image مرجع CSS يعلن عن 4 أنواع من الصور التي يمكن التعامل معها: 1. الصور ذات الأبعاد الداخلية (حجم طبيعي) وبالتالي نسبة عرض إلى ارتفاع ثابتة، وهذا يشمل جميع الصور النقطية. 2. الصور ذات أبعاد داخلية متعددة، موجودة بإصدارات متعددة داخل ملف واحد، وهذا يشمل ملفات ICON (*.ico). قد يكون هذا أيضًا TIFF، لأنها تدعم صورًا متعددة داخل ملف واحد، إلا أن تنسيق TIFF غير مدعوم على الويب. 3. الصور التي لا تملك أبعاد داخلية ولكن لها نسبة عرض إلى ارتفاع داخلية بين عرضها وارتفاعها. وهذا يشمل جميع الصور المتجهة، SVG أولاً. 4. الصور التي لا تملك أبعاد داخلية ولا نسبة عرض إلى ارتفاع داخلية. وهذا يشمل جميع التدرجات.
