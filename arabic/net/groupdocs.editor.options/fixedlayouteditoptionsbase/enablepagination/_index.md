## FixedLayoutEditOptionsBase.EnablePagination property

يسمح بتمكين (true) أو تعطيل (false) الترقيم في مستند HTML الناتج. افتراضيًا يكون معطلًا (false).

```csharp
public bool EnablePagination { get; set; }
```

### ملاحظات

المستندات ذات التنسيق الثابت (PDF و XPS على وجه الخصوص) هي في جوهرها مُقسَّمة إلى صفحات بدقة، ومحتواها له تخطيط ثابت ومقسم إلى صفحات. ولكن HTML القابل للتحرير الناتج يمكن تمثيله إما في عرض بدون صفحات أو عرض بصفحات.
