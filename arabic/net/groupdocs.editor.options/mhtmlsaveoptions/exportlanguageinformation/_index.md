## MhtmlSaveOptions.ExportLanguageInformation property

يحدد ما إذا كان سيتم تصدير معلومات اللغة إلى MHTML. القيمة الافتراضية هي `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### ملاحظات

عند ضبط هذه الخاصية على `true`، يقوم GroupDocs.Editor بإصدار سمة HTML `lang` على عناصر المستند التي تحدد اللغة. قد يكون ذلك ضرورياً للحفاظ على الدلالات المتعلقة باللغة.
