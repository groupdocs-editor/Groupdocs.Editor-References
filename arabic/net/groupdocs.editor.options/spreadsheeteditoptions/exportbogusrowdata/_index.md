## SpreadsheetEditOptions.ExportBogusRowData property

عند التفعيل، يحتوي جدول HTML في المستند HTML المُنتج على صف سفلي مخفي فارغ بارتفاع صفر وخلايا فارغة، حيث يتم تحديد العرض فقط. يحتوي هذا الصف على قيم عرض دقيقة لكل عمود ويُحسّن التحويل العكسي من HTML إلى Spreadsheet. بشكل افتراضي مُفعَّل (`true`).

```csharp
public bool ExportBogusRowData { get; set; }
```
