## XmlEditOptions.FixIncorrectStructure property

يسمح بتمكين أو تعطيل الآلية لإصلاح بنية XML التالفة. يكون معطلًا بشكل افتراضي (false).

public bool FixIncorrectStructure { get; set; }

### ملاحظات
