تحتوي على فئات وواجهات تتعلق بإدارة ومعالجة حقول النماذج داخل المستندات. توفر هذه المساحة وظائف للعمل مع أنواع مختلفة من حقول النماذج، مثل حقول النص، ومربعات الاختيار، والقوائم المنسدلة، وما إلى ذلك، مما يسمح للمستخدمين بالتفاعل مع حقول النماذج وتعديلها برمجيًا.

## الفئات

| فئة | الوصف |
| --- | --- |
| [CheckBoxForm](./checkboxform) | يمثل حقل نموذج يعرض مربع اختيار. |
| [CurrentDateFormField](./currentdateformfield) | يمثل حقل نموذج يعرض التاريخ الحالي. |
| [CurrentTimeFormField](./currenttimeformfield) | يمثل حقل نموذج يعرض الوقت الحالي. |
| [DateFormField](./dateformfield) | يمثل حقل نموذج يعرض تاريخًا. |
| [DropDownFormField](./dropdownformfield) | يمثل حقل نموذج يعرض قائمة منسدلة. |
| [FormFieldCollection](./formfieldcollection) | يمثل مجموعة من حقول النماذج. |
| [HelpText](./helptext) | يمثل نص المساعدة لحقل نموذج. |
| [InvalidFormField](./invalidformfield) | يمثل تحديث أسماء حقول النماذج غير الصالحة أثناء عملية [`FixInvalidFormFieldNames`](../groupdocs.editor/formfieldmanager/fixinvalidformfieldnames). |
| [NumberFormField](./numberformfield) | يمثل حقل نموذج يقبل إدخال رقم. |
| [TextFormField](./textformfield) | يمثل حقل نموذج يقبل إدخال نص. |
