المساحة الاسمية **com.groupdocs.editor.formats** توفر الواجهات والفئات التي تصف صيغ المستندات المدعومة.



## الفئات

| فئة | الوصف |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | يحتوي على جميع تنسيقات eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | يحتوي على جميع تنسيقات البريد الإلكتروني. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | يحتوي على جميع تنسيقات التخطيط الثابت (المعروفة أيضًا باسم "fixed-page")، والتي تشمل PDF و XPS (هذا لا يشمل الصور النقطية). |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | يمثل عائلات التنسيقات المختلفة المتاحة في النظام. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | يحتوي على جميع تنسيقات العروض التقديمية. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | يحتوي على جميع تنسيقات جداول البيانات الثنائية وXML والنصية (باستثناء جميع التنسيقات النصية القائمة على الفواصل مثل CSV وTSV والفواصل المنقوطة وغيرها)، التي يمكن حفظ المصنف فيها. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | يحتوي على جميع التنسيقات النصية (المعتمدة على النص)، بما في ذلك العلامات (XML، HTML) وغيرها. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | يحتوي على جميع تنسيقات معالجة الكلمات. |
