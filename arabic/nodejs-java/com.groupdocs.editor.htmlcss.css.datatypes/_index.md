المساحة الاسمية **com.groupdocs.editor.htmlcss.css.datatypes** توفر الفئات التي تمثل أنواع بيانات CSS.



## الفئات

| فئة | الوصف |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | يمثل قيمة لون واحدة بصيغة ARGB مع محولات ومسلسلات. |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | يحتوي على جميع \"الألوان المعروفة\" التي لها اسم فريد ثابت وقيمة في معيار CSS. |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | يمثل قيمة طول CSS بأي وحدة مدعومة، بما في ذلك النسبة المئوية والنوع بدون وحدة. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | جميع وحدات الطول المدعومة |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | يمثل نوع بيانات CSS \"نسبة\"، والذي يُستخدم لوصف نسب الأبعاد في استعلامات الوسائط وللصور النقطية عن طريق تحديد النسبة بين قيمتين بلا وحدة تُسمى \"البسط\" و\"المقام\". |
