المساحة الاسمية **com.groupdocs.editor.htmlcss.exceptions** توفر الاستثناءات التي تُرمى عند محاولة فتح أو تحميل أو حفظ أو معالجة أي محتوى بطريقة أخرى.



## الفئات

| فئة | الوصف |
| --- | --- |
| [InvalidFontFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidfontformatexception) | الاستثناء الذي يُرمى عند محاولة فتح أو تحميل أو حفظ أو معالجة محتوى ما بطريقة ما، والذي يُفترض أنه خط بتنسيق مدعوم (معروف)، لكنه في الواقع خط بتنسيق غير مدعوم أو غير متوقع أو ليس خطًا على الإطلاق. |
| [InvalidImageFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | الاستثناء الذي يُرمى عند محاولة فتح أو تحميل أو حفظ أو معالجة محتوى ما بطريقة ما، والذي يُفترض أنه صورة (نقطية أو متجهة)، لكنه في الواقع صورة من نوع غير متوقع أو ليست صورة على الإطلاق. |
