المساحة الاسمية **com.groupdocs.editor.htmlcss.resources** توفر الفئات التي تمثل جميع أنواع موارد HTML.



## الفئات

| فئة | الوصف |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | طرق ثابتة مساعدة لاكتشاف أنواع الموارد (التنسيقات). |

## الواجهات

| واجهة | الوصف |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | يوسع الواجهة القياسية IDisposable، ويسمح بالحصول على الحالة الحالية لكائن والاشتراك في حدث التخلص. |
| [IHtmlResource](../com.groupdocs.editor.htmlcss.resources/ihtmlresource) | يمثل نسخة واحدة من مورد HTML غير المعروف (صورة نقطية أو متجهة، ورقة أنماط، خط، مورد نصي (CSS، XML) إلخ). |
| [IResourceType](../com.groupdocs.editor.htmlcss.resources/iresourcetype) | يمثل نسخة واحدة من نوع/تنسيق المورد غير المعروف (صورة، خط، نص). |
