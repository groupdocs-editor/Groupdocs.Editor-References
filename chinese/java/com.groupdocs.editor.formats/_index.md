**com.groupdocs.editor.formats** 命名空间提供描述受支持文档格式的接口和类。



## 类

| 类 | 描述 |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | 封装所有电子书格式。 |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | 封装所有电子邮件格式。 |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | 封装所有固定布局（亦称 "fixed-page"）格式，包括 PDF 和 XPS（不包括光栅图像） |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | 表示系统中可用的不同格式族。 |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | 封装所有演示文稿格式。 |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | 封装所有二进制、XML 和文本电子表格格式（不包括所有使用分隔符的文本格式，如 CSV、TSV、分号分隔等），可用于保存工作簿。 |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | 封装所有文本（基于文本）格式，包括标记语言（XML、HTML）等。 |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | 封装所有文字处理格式。 |
