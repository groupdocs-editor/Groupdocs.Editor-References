**com.groupdocs.editor.htmlcss.css.datatypes** 命名空间提供表示 CSS 数据类型的类。



## 类

| 类 | 描述 |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | 表示 ARGB 格式的单个颜色值，包含转换器和序列化器。 |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | 包含所有在 CSS 标准中具有固定唯一名称和值的“已知颜色”。 |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | 表示任何支持单位的 CSS 长度值，包括百分比和无单位类型。 |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | 所有支持的长度单位 |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | 表示一种 “ratio” CSS 数据类型，用于在媒体查询中描述宽高比，以及通过表示称为 “numerator” 和 “denominator” 的两个无单位值之间的比例来用于栅格图像。 |
