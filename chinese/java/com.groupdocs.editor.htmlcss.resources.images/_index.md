**com.groupdocs.editor.htmlcss.resources.images** 命名空间提供一般情况下表示所有类型图像资源的类。



## 类

| 类 | 描述 |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | 表示一个光栅矩形图像在任意单位下的线性尺寸（宽度和高度）。 |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | 表示一种可支持的图像类型（格式），支持光栅和矢量格式。 |

## 接口

| 接口 | 描述 |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Image CSS 数据类型表示二维图像。 |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | 表示任何类型的图像资源，无论是光栅还是矢量。 |
