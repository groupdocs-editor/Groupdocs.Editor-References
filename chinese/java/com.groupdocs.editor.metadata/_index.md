**com.groupdocs.editor.metadata** 命名空间提供用于描述基于文档类型的基本文档属性的类。



## 类

| 类 | 描述 |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | 表示一本电子书文档的元数据 |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | 表示任意受支持电子邮件格式的电子邮件文档的元数据 |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | 表示具有固定布局格式（如 PDF 或 XPS）的文档的元数据 |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | 表示 Markdown 文档的元数据 |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | 表示演示文稿文档的元数据 |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | 表示电子表格文档的元数据 |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | 表示诸如 XML、HTML 或纯文本（TXT）等文本文档的元数据 |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | 表示文字处理文档的元数据 |
