## IImage interface

图像 CSS 数据类型表示二维图像。

### 备注

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS 参考声明了四种可处理的图像类型：1. 具有固有尺寸（自然大小）且因此固定宽高比的图像，包括所有光栅图像。2. 具有多个固有尺寸，存在于单个文件的多个版本中的图像，包括 ICON（*.ico）文件。这也可能是 TIFF，因为它们支持单文件内的多图像，但 TIFF 格式在网页中不受支持。3. 没有固有尺寸但具有宽高之间固有宽高比的图像。这包括所有矢量图像，首先是 SVG。4. 既没有固有尺寸，也没有固有宽高比的图像。这包括所有渐变。
