## EbookDocumentInfo.PageCount property

返回 MOBI 或 AZW3 时的页数，或 ePub 时的章节数。

```csharp
public int PageCount { get; }
```

### 备注

电子书文档通常没有固定页数，因此没有页数。对于 ePub 可以计算章节数量。然而，MOBI 和 AZW3 格式也没有章节，因此该数字是根据设置为纵向 A4 的标准页面尺寸计算的。
