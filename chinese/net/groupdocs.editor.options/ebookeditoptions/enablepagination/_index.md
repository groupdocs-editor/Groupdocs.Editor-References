## EbookEditOptions.EnablePagination property

允许在生成的 HTML 文档中启用或禁用分页。默认情况下为禁用 (`false`).

```csharp
public bool EnablePagination { get; set; }
```

### 备注

本质上，大多数电子书格式内部都是类似 Office Open XML 的流式格式，内容是连续的并划分为章节而非页面。然而，它包含一些页面特定的信息，如页码、脚注、页眉/页脚等。一些电子书阅读器会将电子书内容拆分为页面，而其他（尤其是移动端）则不会。此选项允许控制在编辑时电子书内容在 HTML/CSS 中的呈现方式——浮动视图 (`false`) 或分页视图 (`true`)。
