## EbookSaveOptions.SplitHeadingLevel property

指定拆分电子书文件的标题最大层级。默认值为 `2`。将其设置为 `0` 将禁用拆分，所有电子书内容将合并为生成文件中的单一包。

```csharp
public int SplitHeadingLevel { get; set; }
```

### 备注

当此属性设置为 1 到 9 之间的值时，文档将在使用 **Heading 1**、**Heading 2** , **Heading 3** 等样式的段落处进行拆分，直至指定的标题级别。

默认情况下，只有 **Heading 1** 和 **Heading 2** 段落会导致文档拆分。将此属性设置为零（或小于零）将导致文档根本不会在标题段落处拆分。
