## FontEmbeddingOptions enumeration

字体嵌入选项控制应将哪些字体资源嵌入输出的 WordProcessing 或 PDF 文档中

```csharp
public enum FontEmbeddingOptions
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| NotEmbed | `0` | 不嵌入任何来自 EditableDocument 或系统的字体资源。默认值。 |
| EmbedAll | `1` | 分析来自输入 EditableDocument 的文档内容，查找所有使用的字体并将其嵌入到输出的 WordProcessing 或 PDF 文档中。首先，GroupDocs.Editor 会从 EditableDocument 内的字体资源获取字体。如果这些字体不足或缺失，则 GroupDocs.Editor 会从操作系统获取字体。 |
| EmbedWithoutSystem | `2` | 与 EmbedAll 完全相同，但排除那些被操作系统视为系统字体的字体 |

### 备注

字体嵌入选项在文档保存期间（从中间的 EditableDocument 转换为输出的 WordProcessing 或 PDF 格式）应用，此枚举作为属性包含在 WordProcessingSaveOptions 和 PdfSaveOptions 中，使用时应从这些属性获取
