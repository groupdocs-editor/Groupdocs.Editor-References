## FontExtractionOptions enumeration

字体提取选项控制应提取哪些字体以及从何处提取

```csharp
public enum FontExtractionOptions
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| NotExtract | `0` | 既不从文档也不从系统提取任何字体资源。默认值。 |
| ExtractAllEmbedded | `1` | 提取输入 Word 文档中嵌入的所有字体资源，无论它们是自定义的还是系统的。 |
| ExtractEmbeddedWithoutSystem | `2` | 仅提取那些嵌入的自定义字体资源（非系统字体） |
| ExtractAll | `3` | 尝试提取输入 WordProcessing 文档中使用的所有字体，包括系统字体。 |
