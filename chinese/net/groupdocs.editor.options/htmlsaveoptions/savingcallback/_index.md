## HtmlSaveOptions.SavingCallback property

接口，必须由最终用户实现，以保存所有外部 HTML 资源。此属性 **must** 不能为 `null`，否则 GroupDocs.Editor 在将 [`EditableDocument`](../../../groupdocs.editor/editabledocument) 保存为 HTML 格式时将抛出异常。

```csharp
public IHtmlSavingCallback SavingCallback { get; set; }
```

### 备注

如果 [`EmbedStylesheetsIntoMarkup`](../embedstylesheetsintomarkup) 属性的值设置为 `true`，所有样式表将嵌入到 HTML 标记中，因此它们不会传递给此保存回调。
