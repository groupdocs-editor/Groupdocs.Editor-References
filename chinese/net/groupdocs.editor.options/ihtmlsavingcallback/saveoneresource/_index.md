## IHtmlSavingCallback.SaveOneResource method

实例方法，在调用 [`Save`](../../../groupdocs.editor/editabledocument/save) 方法期间触发，必须由最终用户实现，以获取并保存提供的 HTML 资源，然后返回该资源的链接给调用者。

```csharp
public string SaveOneResource(IHtmlResource resource)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 资源 | IHtmlResource | 任何类型的 HTML 资源（图像和字体，如果样式表未嵌入在 HTML 标记中，也可能包括样式表），由 GroupDocs.Editor 传递给此接口的用户自定义实现，由用户获取，用户可以执行任何必要的操作，如保存、发送、转换等。GroupDocs.Editor 永不向此方法传递 `null` HTML 资源。 |

### 返回值

对资源的链接（引用），在 *resource* 参数中获取，用户必须提供给 GroupDocs.Editor，以便 GroupDocs.Editor 将此链接放入 HTML 标记中。

### 备注

GroupDocs.Editor 期望此方法的用户自定义实现不会在执行期间抛出异常。然而，当异常发生时，GroupDocs.Editor 将把 [`FilenameWithExtension`](../../../groupdocs.editor.htmlcss.resources/ihtmlresource/filenamewithextension) 属性的值写入 HTML 标记中。
