## MarkdownSaveOptions.ExportImagesAsBase64 property

指定是否将图像以 Base64 格式保存到输出文件。默认值为 `false`。

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### 备注

当此属性设置为 `true` 时，图像数据将直接导出到图像元素 ![]() 中，不会创建单独的文件。如果此属性为 `true`，其优先级高于 [`ImagesFolder`](../imagesfolder) 属性。
