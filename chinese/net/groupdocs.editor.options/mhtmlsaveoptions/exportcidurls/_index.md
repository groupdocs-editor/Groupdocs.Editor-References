## MhtmlSaveOptions.ExportCidUrls property

指定是否使用 CID（Content-ID）URL 来引用包含在 MHTML 文档中的资源（图像、字体、CSS）。默认值为 `false`。

```csharp
public bool ExportCidUrls { get; set; }
```

### 备注

默认情况下，MHTML 文档中的资源通过文件名引用（例如 "image.png"），并与 MIME 部分的 "Content-Location" 头匹配。此选项启用另一种方法，将资源文件的引用写为 CID（Content-ID）URL（例如 "cid:image.png"），并与 "Content-ID" 头匹配。

理论上，两种引用方式应该没有区别，且任意一种都应在任何浏览器或邮件客户端中正常工作。然而在实际使用中，某些客户端无法通过文件名获取资源。如果您的浏览器或邮件客户端拒绝加载 MTHML 文档中包含的资源（图片不显示或 CSS 样式未加载），请尝试使用 CID URL 导出文档。
