## PageRange structure

封装一个页范围，可具有开放或闭合的边界。默认情况下为“完全开放”——包括所有现有页。页码从 1 开始，而不是从 0 开始。

public struct PageRange : IEquatable<PageRange>

| [EndNumber](../../groupdocs.editor.options/pagerange/endnumber) { get; } | 排他结束页码，即此页面范围持续到该页并在该页之前结束。如果为 0，则页面范围一直延伸到文档结束。 |
