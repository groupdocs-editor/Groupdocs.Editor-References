## PdfSaveOptions.Password property

密码，将作为用户密码应用于生成的 PDF 文档，打开时需要。如果为 NULL 或为空，则文档不使用密码。否则，文档将使用 RC4（密钥长度 128 位）加密。默认是 NULL —— 不使用密码。
