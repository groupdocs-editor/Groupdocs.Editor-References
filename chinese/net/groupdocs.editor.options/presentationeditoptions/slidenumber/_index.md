## PresentationEditOptions.SlideNumber property

允许指定应打开进行编辑的幻灯片编号

```csharp
public int SlideNumber { get; set; }
```

### 备注

幻灯片编号是从零开始的索引，允许指定并选择演示文稿中要编辑的特定幻灯片。如果小于 0，则选择第一张幻灯片（等同于 SlideNumber = 0）。如果大于演示文稿中所有幻灯片的数量，则选择最后一张幻灯片。如果输入的演示文稿仅包含单张幻灯片，则此选项将被忽略，且该单张幻灯片将被编辑。如果尝试打开隐藏的幻灯片进行编辑，而 [`ShowHiddenSlides`](../showhiddenslides) 选项设置为 'false'，则会抛出异常。
