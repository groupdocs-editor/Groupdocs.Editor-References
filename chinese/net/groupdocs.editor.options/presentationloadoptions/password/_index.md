## PresentationLoadOptions.Password property

允许指定、修改和获取用于打开 Presentation 文档的密码（如果文档已加密）。将其设置为 NULL 或空字符串即可移除密码。

```csharp
public string Password { get; set; }
```

### 备注

默认情况下，此属性的值为 NULL——未设置密码。如果输入的 Presentation 文档受密码保护，则密码是必需的，未指定或无效密码会抛出异常。如果输入的 Presentation 文档未受密码保护，但设置了密码，则会被忽略。
