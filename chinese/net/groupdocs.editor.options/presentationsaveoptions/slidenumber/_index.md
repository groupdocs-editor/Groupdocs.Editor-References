## PresentationSaveOptions.SlideNumber property

允许将编辑后的幻灯片插入到现有演示文稿中，而不是创建仅包含单张幻灯片的新演示文稿（默认行为）。幻灯片编号是演示文稿中幻灯片的从 1 开始的编号，加载自 Editor 类。如果为 0（默认值），则创建仅包含单个编辑幻灯片的新演示文稿。如果大于或小于零，并且 Editor 类中已加载有效的演示文稿，则存储在输入 EditableDocument 实例中的编辑幻灯片将被插入到该演示文稿中。

```csharp
public int SlideNumber { get; set; }
```

### 备注

SlideNumber 整数属性，如果不处于默认状态（保留值 '0'），则表示幻灯片编号，从 1 开始，而不是从零开始，其最大值为演示文稿中所有现有幻灯片的数量。然而，如果指定的值大于所有幻灯片的数量，GroupDocs.Editor 将调整为最后一张幻灯片。负数值也被允许，用于从末尾计数。例如，"-1" 表示演示文稿的最后一张幻灯片，"-2" 表示倒数第二张，依此类推。与正数值类似，当负数幻灯片编号超过给定演示文稿的总幻灯片数时，它将被调整为第一张幻灯片。[`InsertAsNewSlide`](../insertasnewslide) 布尔属性与此属性紧密关联。

### 示例

给定的演示文稿有 5 张幻灯片：SlideNumber = 0; — 忽略给定的演示文稿，创建一个新演示文稿并将编辑后的幻灯片放入其中。SlideNumber = 1; — 用编辑后的幻灯片替换第一张幻灯片。SlideNumber = 2; — 用编辑后的幻灯片替换第二张幻灯片。SlideNumber = 5; — 用编辑后的幻灯片替换最后（第 5）张幻灯片。SlideNumber = 6; — 用编辑后的幻灯片替换最后（第 5）张幻灯片，因为 6 大于 5，已被调整。SlideNumber = -1; — 用编辑后的幻灯片替换最后（第 5）张幻灯片，因为 "-1" 表示 "最后一张现有幻灯片"。SlideNumber = -2; — 用编辑后的幻灯片替换第 4 张幻灯片。SlideNumber = -3; — 用编辑后的幻灯片替换第 3 张幻灯片。SlideNumber = -4; — 用编辑后的幻灯片替换第 2 张幻灯片。SlideNumber = -5; — 用编辑后的幻灯片替换第一张幻灯片。SlideNumber = -6; — 用编辑后的幻灯片替换第一张幻灯片，因为 "-6" 大于 5，已被调整。
