## PresentationSaveOptions.SlideNumbersToDelete property

允许指定一个包含要在保存时从演示文稿中删除的幻灯片的 1 基编号数组，以便在编辑幻灯片被插入到现有演示文稿的情况下使用

```csharp
public int[] SlideNumbersToDelete { get; set; }
```

### 备注

当编辑后的幻灯片不是保存为新的单幻灯片演示文稿（默认行为），而是保存到现有演示文稿中（使用 [`SlideNumber`](../slidenumber) 属性）时，也可以通过在此数组中指定其编号来删除该演示文稿中的某些特定幻灯片。

默认情况下此数组为 `null` —— 不会删除任何幻灯片。但是，当此数组非空且包含至少一个有效的幻灯片编号时，在使用编辑幻灯片内容生成输出 Presentation 文档后，指定编号的幻灯片将在写入输出流或文件之前从演示文稿中删除。

此数组中的幻灯片编号为 1 基，而非 0 基，无效的编号（小于 1 或大于幻灯片总数）将被忽略。
