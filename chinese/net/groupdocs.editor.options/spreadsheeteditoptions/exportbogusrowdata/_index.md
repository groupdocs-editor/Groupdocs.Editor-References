## SpreadsheetEditOptions.ExportBogusRowData property

启用后，生成的 HTML 文档中的 HTML 表格会包含一个底部隐藏的空行，行高为零且单元格为空，仅指定宽度。该空行的单元格包含每列的精确宽度值，可提升从 HTML 到电子表格的逆向转换。默认情况下该选项为启用 (`true).

public bool ExportBogusRowData { get; set; }
