## SpreadsheetEditOptions.MergeEmptyAdjacentCells property

启用后，输入电子表格文档中相邻的空水平单元格将在可编辑的 HTML 文档中合并为一个单元格，并带有相应的 `colspan` 属性。默认情况下为禁用 (`false).

```csharp
public bool MergeEmptyAdjacentCells { get; set; }
```

### 备注

默认情况下，GroupDocs.Editor 会通过保留每个单元格，将输入 Spreadsheet 文档中的表格转换为输出的 HTML 文档。然而，Spreadsheet 文档可能很稀疏——可能包含大量空白区域，其中许多单元格为空。启用此选项后，会将这些空单元格合并为一个在 `TD` 元素中具有 `colspan` 属性的单元格，从而显著减少生成的 HTML 标记的大小。
