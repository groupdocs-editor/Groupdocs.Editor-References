## SpreadsheetEditOptions.WorksheetIndex property

允许指定输入电子表格文档中工作表（标签）的 0 基索引，以决定应转换为 HTML 的工作表（参见备注）。

```csharp
public int WorksheetIndex { get; set; }
```

### 备注

大多数 Spreadsheet 文档支持标签的概念，即它们可以拥有多个标签。另一方面，HTML 格式不支持此类结构。因此，GroupDocs.Editor 在转换为 HTML 时只能处理输入文档的一个特定标签，此选项用于指定该标签。标签索引为 0 基，负值被禁止。如果指定的索引超出所有标签的数量，将抛出异常。如果输入 Spreadsheet 文档仅包含一个标签，则此选项将被忽略。默认值为 0（第一个标签）。
