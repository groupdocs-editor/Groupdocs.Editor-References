| 名称 | 描述 |

| [InsertAsNewWorksheet](../../groupdocs.editor.options/spreadsheetsaveoptions/insertasnewworksheet) { get; set; } | 布尔标志，指定编辑后的工作表是应在原始电子表格中由 [`WorksheetNumber`](./worksheetnumber) 属性指定的位置替换现有工作表，还是应插入到现有工作表与前一个工作表之间而不替换其内容。默认值为 false——将替换现有工作表。如果 [`WorksheetNumber`](./worksheetnumber) 属性的值设为 '0'，则此属性被忽略。 |
| [OutputFormat](../../groupdocs.editor.options/spreadsheetsaveoptions/outputformat) { get; set; } | 允许指定用于保存文档的 Spreadsheet 格式 |

| [WorksheetNumber](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumber) { get; set; } | 允许将已编辑的工作表插入现有电子表格的副本中，而不是创建一个新的单工作表电子表格（默认行为）。WorksheetNumber 是电子表格中工作表的基于 1 的编号，电子表格在 Editor 类中加载。如果为 0（默认值），将创建仅包含单个已编辑工作表的新电子表格。如果大于或小于零，并且在 Editor 类中加载了有效的电子表格，则由输入 EditableDocument 实例表示的已编辑工作表将插入该电子表格中。 |
| [WorksheetNumbersToDelete](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete) { get; set; } | 允许指定一个包含工作表基于 1 的编号的数组，这些工作表将在保存期间从电子表格中删除，以防已编辑的工作表被插入到现有电子表格中。 |
| [WorksheetProtection](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetprotection) { get; set; } | 允许为输出的 Spreadsheet 文档启用工作表保护。默认值为 NULL——不应用保护。并非所有格式都支持工作表保护。 |
