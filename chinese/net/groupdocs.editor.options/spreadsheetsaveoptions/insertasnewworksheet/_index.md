## SpreadsheetSaveOptions.InsertAsNewWorksheet property

布尔标志，指定编辑的工作表是应在原始电子表格中由[`WorksheetNumber`](../worksheetnumber)属性指定的位置替换现有工作表，还是应插入到现有工作表与前一个工作表之间而不替换其内容。默认情况下为 false — 现有工作表将被替换。如果[`WorksheetNumber`](../worksheetnumber)属性的值设为 '0'，则此属性被忽略。

```csharp
public bool InsertAsNewWorksheet { get; set; }
```

### 备注

默认情况下工作表会被替换。这意味着如果给定的电子表格有5个工作表，并且[`WorksheetNumber`](../worksheetnumber)=4，则第4个工作表将被新的编辑工作表替换，而电子表格中工作表的总数（5）保持不变。然而，如果此属性的值设置为 true，则新的编辑工作表将作为第4个工作表插入，所有后续工作表将向后移动：“old” 第4个工作表变为第5个，第5个变为第6个，电子表格中工作表的总数将增加一个，变为6。
