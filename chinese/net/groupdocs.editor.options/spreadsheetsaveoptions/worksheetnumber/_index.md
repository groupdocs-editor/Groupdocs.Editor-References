## SpreadsheetSaveOptions.WorksheetNumber property

允许将已编辑的工作表插入现有电子表格的副本中，而不是创建一个新的单工作表电子表格（默认行为）。WorksheetNumber 是电子表格中工作表的基于 1 的编号，电子表格在 Editor 类中加载。如果为 0（默认值），将创建仅包含单个已编辑工作表的新电子表格。如果大于或小于零，并且在 Editor 类中加载了有效的电子表格，则由输入 EditableDocument 实例表示的已编辑工作表将插入该电子表格中。

```csharp
public int WorksheetNumber { get; set; }
```

### 备注

WorksheetNumber 整数属性，如果不在默认状态（保留值 '0'），则表示工作表编号，从 1 开始，而不是从零开始，其最大值为演示文稿中所有现有幻灯片的数量。然而，如果指定的值大于所有幻灯片的数量，GroupDocs.Editor 将调整为最后一个工作表。负数值也被允许，并从末尾计数工作表。例如，\"-1\" 表示电子表格中的最后一个工作表，\"-2\" — 倒数第二个，依此类推。与正数值类似，当负工作表编号超过给定电子表格的工作表总数时，它将被调整为第一个工作表。[`InsertAsNewWorksheet`](../insertasnewworksheet) 布尔属性与此紧密关联。

### 示例

给定的电子表格有 5 个工作表：WorksheetNumber = 0; — 忽略给定的电子表格，创建新电子表格并将编辑的工作表放入其中。WorksheetNumber = 1; — 用编辑的工作表替换第一个工作表。WorksheetNumber = 2; — 用编辑的工作表替换第二个工作表。WorksheetNumber = 5; — 用编辑的工作表替换最后（第 5）个工作表。WorksheetNumber = 6; — 用编辑的工作表替换最后（第 5）个工作表，因为 6 大于 5，已被调整。WorksheetNumber = -1; — 用编辑的工作表替换最后（第 5）个工作表，因为 \"-1\" 意味着 \"最后一个现有的\"。WorksheetNumber = -2; — 用编辑的工作表替换第 4 个工作表。WorksheetNumber = -3; — 用编辑的工作表替换第 3 个工作表。WorksheetNumber = -4; — 用编辑的工作表替换第 2 个工作表。WorksheetNumber = -5; — 用编辑的工作表替换第一个工作表。WorksheetNumber = -6; — 用编辑的工作表替换第一个工作表，因为 \"-6\" 大于 5，已被调整。
