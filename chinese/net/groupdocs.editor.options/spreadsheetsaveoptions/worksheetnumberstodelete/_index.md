## SpreadsheetSaveOptions.WorksheetNumbersToDelete property

允许指定一个包含工作表基于 1 的编号的数组，这些工作表将在保存期间从电子表格中删除，以防已编辑的工作表被插入到现有电子表格中。

```csharp
public int[] WorksheetNumbersToDelete { get; set; }
```

### 备注

当编辑的工作表不是保存为新的单工作表电子表格（默认行为），而是使用[`WorksheetNumber`](../worksheetnumber)属性保存到现有电子表格时，也可以通过在此数组中指定其编号来删除该电子表格中的特定工作表。

默认情况下此数组为 `null` — 不会删除任何工作表。但是，当此数组非 null 且非空，并且至少包含一个有效的工作表编号时，在生成包含编辑工作表内容的输出电子表格文档后，指定编号的工作表将在写入其内容到输出流或文件之前被删除。

此数组中的工作表编号为 1 基，而非 0 基，低于 1 或超过工作表总数的无效编号将被忽略。
