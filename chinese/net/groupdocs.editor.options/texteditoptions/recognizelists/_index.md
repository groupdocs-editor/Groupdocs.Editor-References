## TextEditOptions.RecognizeLists property

允许指定在从纯文本格式导入文档时如何识别编号列表项。默认值为 true。

```csharp
public bool RecognizeLists { get; set; }
```

### 备注

如果此选项设置为 false，列表识别算法会检测列表段落，当列表编号以点、右括号或项目符号（如 "•"、"*"、"-" 或 "o"）结尾时。如果此选项设置为 true，空格也会用作列表编号分隔符：用于阿拉伯式编号（1.、1.1.2.）的列表识别算法同时使用空格和点（"."）符号。
