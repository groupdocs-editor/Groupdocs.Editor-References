## WordProcessingEditOptions.ExtractOnlyUsedFont property

获取或设置一个值，指示是否仅提取文档文本内容中使用的字体资源。

```csharp
public bool ExtractOnlyUsedFont { get; set; }
```

### Property Value

`true` 如果需要仅提取文档文本内容中使用的字体资源；否则为 `false`。默认值为 `false`。

### 备注

并非 WordProcessing 文档中使用的所有字体都 100% 直接使用（应用于某些文本）。可能出现字体在文档中被引用甚至嵌入，但未应用于任何文本的情况。例如，某些字体可能附加到某个样式上，但该样式未应用于任何文本部分。此选项控制如何处理此类情况。
