## WordProcessingEditOptions.InputControlsClassName property

允许指定一个类名，该类名将放置在每个表示输入 WordProcessing 文档中某字段的 HTML 元素的 'class' 属性中。默认值为 NULL——不应用 'class' 属性。

```csharp
public string InputControlsClassName { get; set; }
```

### 备注

几乎所有来自 WordProcessing 格式系列的格式都包含字段——特定的文档实体，允许从用户获取输入数据。字段种类繁多：文本框、复选框、下拉框、列表、按钮、日期/时间选择器等。所有这些字段都会被转换为最合适的 HTML 结构和元素，并在输入文档中存在时保留用户输入的数据。在特定使用场景下，只需要在客户端收集已输入的数据，而不是编辑整个文档内容。为此，需要以某种方式标识输入控件，以便在客户端获取它们及其数据。此属性允许指定一个类名，该类名将应用于 HTML 标记中的每个输入控件，以便客户端代码能够遍历 HTML 文档结构并收集数据。
