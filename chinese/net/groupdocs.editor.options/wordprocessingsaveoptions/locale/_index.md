## WordProcessingSaveOptions.Locale property

允许为 WordProcessing 文档设置覆盖默认区域设置（语言），该设置将在文档创建期间应用。如果未指定（默认值），MS Word（或其他程序）将根据其自身设置或其他因素检测（或选择）文档的区域设置。

```csharp
public CultureInfo Locale { get; set; }
```

### 备注

此选项会强制将指定的语言区域应用于文档中所有文本。如果文档包含使用不同语言编写的不同文本部分，请勿使用此选项。
