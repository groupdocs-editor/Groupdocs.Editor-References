## XmlEditOptions.FixIncorrectStructure property

允许启用或禁用修复损坏的 XML 结构的机制。默认情况下已禁用（false）。

```csharp
public bool FixIncorrectStructure { get; set; }
```

### 备注

默认情况下，只接受正确有效且结构良好的 XML 文档。当启用此选项时，GroupDocs.Editor 将尝试在可能的情况下修复损坏的 XML 结构。
