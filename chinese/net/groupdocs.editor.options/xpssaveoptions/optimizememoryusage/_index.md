## XpsSaveOptions.OptimizeMemoryUsage property

在从 HTML 生成文档期间启用内存优化机制，这会以降低性能为代价减少内存使用。将此选项设置为 true 可以在生成大型文档时显著降低内存消耗，但会导致保存时间变慢。默认值为 false（为获得更好性能而禁用内存优化）。

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
