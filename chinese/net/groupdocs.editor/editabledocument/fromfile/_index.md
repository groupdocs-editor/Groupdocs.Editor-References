## EditableDocument.FromFile method

静态工厂，用于从 HTML 文件创建 EditableDocument 实例，文件通过 *.html 文件本身的路径以及包含链接资源的文件夹指定

```csharp
public static EditableDocument FromFile(string htmlFilePath, string resourceFolderPath)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| htmlFilePath | String | 字符串，包含 HTML 文件的完整路径。不能为空，必须是有效的文件路径，且文件本身必须存在。 |
| resourceFolderPath | String | 可选的 HTML 资源文件夹路径。如果为 NULL、无效或该文件夹不存在，编辑器将自行通过分析 HTML 标记尝试查找此文件夹。 |

### 返回值

新的非空 EditableDocument 实例

### 异常

| 异常 | 条件 |
| --- | --- |
| ArgumentException | HTML 文件路径和/或资源文件夹路径无效。 |
| FileNotFoundException | 未找到指定的 HTML 文件。 |
