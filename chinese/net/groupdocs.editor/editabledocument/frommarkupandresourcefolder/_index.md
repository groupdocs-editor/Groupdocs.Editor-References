## EditableDocument.FromMarkupAndResourceFolder method

静态工厂，用于从指定的 HTML 标记以及位于由完整路径指定的文件夹中的资源创建 EditableDocument 实例

```csharp
public static EditableDocument FromMarkupAndResourceFolder(string newHtmlContent, 
    string resourceFolderPath)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| newHtmlContent | String | 字符串，包含应解析的原始 HTML 标记。不能为空、为 NULL 或无效。 |
| resourceFolderPath | String | 资源文件夹的必填路径。该文件夹中的所有样式表都会被使用。不能为空或为 NULL，且该文件夹必须存在。 |

### 返回值

新的非空 EditableDocument 实例

### 备注

当 HTML 文档内容以字符串形式呈现，但所有资源位于某个文件夹中，且 HTML 标记中的这些资源链接通常无效或缺失时，此静态工厂非常有用。调用此方法时，它会扫描指定文件夹并自动将所有找到的样式表应用到文档中。当从不同的 HTML 编辑器获取内容时，此方法尤为有用，因为这些编辑器通常会截断文档元数据等信息。
