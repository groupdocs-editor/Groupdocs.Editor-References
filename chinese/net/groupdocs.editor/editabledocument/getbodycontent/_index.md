## GetBodyContent() {#getbodycontent}

以字符串形式返回 HTML 文档的主体（打开和关闭 BODY 标签之间的内部内容，不包括这些标签）。

```csharp
public string GetBodyContent()
```

### 返回值

字符串，包含 HTML 文档的主体内容（不含 opening 和 closing BODY 标记）

### 备注

大多数 WYSIWYG 编辑器通常只操作文档 BODY 的内部内容，无法正确处理来自 HEAD 块的元信息。此方法专为此类情况设计。此重载不允许调整外部资源请求的 URI。

## GetBodyContent(string) {#getbodycontent_1}

以字符串形式返回 HTML 文档的主体（打开和关闭 BODY 标签之间的内部内容，不包括这些标签），其中指向外部资源的链接包含带占位符的指定模板。

```csharp
public string GetBodyContent(string externalImagesTemplate)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| externalImagesTemplate | String | 通过此参数可以指定一个带有单个占位符的字符串模板，该模板将应用于所有 IMG 元素中外部图像的链接，并出现在生成的 HTML 字符串中。如果为 NULL 或为空，则不会添加模板，生成的 HTML 标记中将仅保留纯文件名。如果模板无效，则会被视为前缀，文件名将被连接到其末尾。 |

### 返回值

字符串，包含 HTML 文档的主体内容（不含 opening 和 closing BODY 标记），其中的链接已调整为指向外部图像

### 备注

大多数所见即所得编辑器通常只处理文档 BODY 的内部内容，无法正确处理来自 HEAD 块的元信息。此方法专为此类情况设计。此重载允许调整外部资源请求的 URI。
