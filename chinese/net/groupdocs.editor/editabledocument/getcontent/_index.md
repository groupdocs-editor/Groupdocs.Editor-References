## GetContent(string, string) {#getcontent_1}

以字符串形式返回 HTML 文档的整体内容，其中指向外部资源的链接包含带占位符的指定模板。

```csharp
public string GetContent(string externalImagesTemplate, string externalCssTemplate)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| externalImagesTemplate | String | 通过此参数可以指定一个带有单个占位符的字符串模板，该模板将应用于所有 IMG 元素中外部图像的链接，并出现在生成的 HTML 字符串中。如果为 NULL 或为空，则不会添加模板，生成的 HTML 标记中将仅保留纯文件名。如果模板无效，则会被视为前缀，文件名将被连接到其末尾。 |
| externalCssTemplate | String | 通过此参数可以指定一个带有一个占位符的字符串模板，该模板将被添加到结果 HTML 字符串中所有 LINK 元素指向的外部样式表链接上。如果为 NULL 或为空，则不会添加模板，结果 HTML 标记中将仅保留纯文件名。如果模板无效，则会被视为前缀，文件名将被拼接到其末尾。 |

### 返回值

字符串，包含已调整外部资源链接的 HTML 文档内容
