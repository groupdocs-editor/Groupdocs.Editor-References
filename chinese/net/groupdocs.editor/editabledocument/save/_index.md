## Save(TextWriter, HtmlSaveOptions) {#save}

将此 [`EditableDocument`](../../editabledocument) 的内容保存为 HTML 文档到指定的文本写入器，同时第二个 options 参数允许自定义保存过程并指定资源保存回调。

```csharp
public void Save(TextWriter htmlMarkup, HtmlSaveOptions saveOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| htmlMarkup | TextWriter | 文本写入器的实现，HTML 标记将写入其中。不能为空。 |
| saveOptions | HtmlSaveOptions | HTML 保存选项，控制保存过程：HTML 标记的存储方式（标签名称、引号类型）以及 CSS 和其他资源（如图像或字体）的保存位置和方式。用户应在 [`SavingCallback`](../../../groupdocs.editor.options/htmlsaveoptions/savingcallback) 属性中指定接口的实现类，以控制资源的保存方式以及在 HTML 标记中的引用方式。 |

### 异常

| 异常 | 条件 |
| --- | --- |
| ArgumentNullException | 指定的任意参数或 *saveOptions* 中的 `SavingCallback` 属性为 `null`。 |
