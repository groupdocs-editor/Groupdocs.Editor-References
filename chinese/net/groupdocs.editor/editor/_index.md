## Editor class

主类，封装了转换方法。Editor 类提供用于加载、编辑和保存所有支持格式文档的方法。它是可释放的，因此请使用 `using` 指令或通过调用 `Dispose()` 方法手动释放其资源。文档加载通过构造函数完成。文档编辑通过 `Edit` 方法，编辑后保存回生成的文档通过 `Save` 方法。

### 备注

Editor 类应视为 GroupDocs.Editor 的入口点和根对象。所有操作均通过此类执行。使用 Editor 类完成完整文档编辑流程的典型步骤如下：

1. 通过构造函数将文档加载到 Editor 实例中。
2. 可选地，使用 [`GetDocumentInfo`](./getdocumentinfo) 方法检测文档类型。
3. 调用 [`Edit`](./edit) 方法打开文档进行编辑，并从中获取 [`EditableDocument`](../editabledocument) 类的实例。
4. 在客户端使用任意所见即所得的 HTML 编辑器编辑文档内容。
5. 从已编辑的文档内容创建一个新的 [`EditableDocument`](../editabledocument) 实例。
6. 通过调用 [`Save`](./save) 方法将已编辑的文档保存为某种输出格式。
7. 通过 'using' 操作符或手动方式释放 Editor 类的实例。
