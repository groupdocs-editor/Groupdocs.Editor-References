## Edit(IEditOptions) {#edit_1}

使用指定的格式特定选项打开先前加载的文档进行编辑，通过生成并返回 '[`EditableDocument`](../../editabledocument)' 类的实例，该实例随后包含用于生成 HTML 标记和相关资源的方法。

```csharp
public EditableDocument Edit(IEditOptions editOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| editOptions | IEditOptions | 格式特定的文档选项，允许调优转换过程。可以为 NULL——在这种情况下，GroupDocs.Editor 会检测先前加载文档的格式并应用该格式的默认选项。不应与先前应用的加载选项冲突。 |

### 返回值

‘[`EditableDocument`](../../editabledocument)’ 类的实例，封装了以中间格式呈现的整个输入文档及其所有资源。如果此方法成功完成，永不返回 NULL。

### 备注

当原始输入文档通过构造函数加载到 'Editor' 实例时，此方法通过将文档转换为中间格式并封装在 'EditableDocument' 类的实例中，允许打开文档进行编辑。由此方法返回的 '[`EditableDocument`](../../editabledocument)' 包含生成 HTML 标记及相应资源（如图像、字体和样式表）所需的所有方法和属性，适用于后续传递到任何所见即所得 HTML 编辑器的各种配置。此重载获取针对特定族格式的编辑选项。**了解更多**
