## Editor.FormFieldManager property

提供对文档中表单字段管理功能的访问。

```csharp
public FormFieldManager FormFieldManager { get; }
```

### 返回值

一个用于管理文档中表单字段的 `FormFieldManager` 实例。

### 备注

`FormFieldManager` 属性创建一个 `FormFieldManager` 类的新实例，允许访问用于管理文档中表单字段的方法和属性。表单字段是文档中的交互式元素，可捕获用户输入或触发操作。`FormFieldManager` 实例提供多种表单字段操作的方法，包括检查无效表单字段、更新表单字段数据以及修复命名问题。它还便于检索表单字段名称及其关联数据。此属性对于以编程方式交互和操作表单字段非常有用，可实现表单字段验证、同步和自定义等任务。
