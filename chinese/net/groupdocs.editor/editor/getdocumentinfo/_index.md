## Editor.GetDocumentInfo method

返回已加载到此 'Editor' 实例的文档的元数据。

```csharp
public IDocumentInfo GetDocumentInfo(string password)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| password | String | 用户可以为文档指定密码（如果该文档已使用密码加密）。可以为 NULL 或空字符串，等同于未提供密码。对于不支持密码保护的文档格式，此参数将被忽略。如果文档已加密且未在此参数中指定密码，但在创建此 [`Editor`](../../editor) 实例时的加载选项中已指定密码，则将使用该密码。 |

### 返回值

[`IDocumentInfo`](../../../groupdocs.editor.metadata/idocumentinfo) 接口的特定格式继承者，指示检测到的格式及其特定元数据；如果文档未被识别为支持的格式或已损坏，则为 NULL。

### 异常

| 异常 | 条件 |
| --- | --- |
| ObjectDisposedException | 当调用 "GetDocumentInfo" 时 Editor 实例已被释放，则抛出此异常。 |
| [PasswordRequiredException](../../passwordrequiredexception) | 当加载的文档受密码保护，但在参数 "*password*" 中以及创建实例时的加载选项中均未指定密码时抛出。 |
| [IncorrectPasswordException](../../incorrectpasswordexception) | 当加载的文档受密码保护，已指定密码但密码不正确时抛出。 |
| InvalidOperationException | 当发生未知性质的意外错误时抛出 |

### 备注

当不清楚输入文档的格式、是否受密码保护以及包含多少页/工作表/幻灯片时，GetDocumentInfo 方法非常有用。基于 GetDocumentInfo 返回的此元数据，可以正确调整主处理流水线的加载和编辑选项。

GetDocumentInfo 方法始终返回完整数据，不受试用模式影响，其使用不会扣除已消耗的字节或积分。
