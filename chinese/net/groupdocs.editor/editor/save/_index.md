## Save(EditableDocument, Stream, ISaveOptions) {#save_2}

将指定的已编辑文档（表示为 '[`EditableDocument`](../../editabledocument)' 实例）转换为指定格式的结果文档，并将其内容保存到指定的流中。

```csharp
public void Save(EditableDocument inputDocument, Stream outputDocument, ISaveOptions saveOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| inputDocument | EditableDocument | 输入文档的版本，该文档在所见即所得 HTML 编辑器中被编辑并存储为 '[`EditableDocument`](../../editabledocument)' 类的实例，应转换为某特定格式的输出文档。不能为空或已释放。 |
| outputDocument | Stream | 输出流，用于记录生成文档的内容。不得为 null、已释放，且必须支持写入。 |
| saveOptions | ISaveOptions | 文档保存选项，用于定义生成文档的格式，以及通用和特定格式的保存选项。不得为 null。 |

## Save(Stream, WordProcessingSaveOptions) {#save_1}

将修改后的原始文档（例如 [`FormFieldManager`](../formfieldmanager)）转换为指定格式的生成文档，并将其内容保存到提供的流中。

```csharp
public Stream Save(Stream outputDocument, WordProcessingSaveOptions saveOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| outputDocument | Stream | 用于保存输出文档的流。该流应可写且定位在文档内容的起始位置。不得为 null。 |
| saveOptions | WordProcessingSaveOptions | 文档保存选项，定义生成文档的格式以及通用和特定格式的保存选项。不得为 null。 |

### 返回值

包含已保存文档内容的流。

### 备注

如果 *outputDocument* 或 *saveOptions* 为 null，将抛出 ArgumentNullException。如果待保存的文档缺失，也将抛出 ArgumentNullException。


| 参数 | 类型 | 描述 |
| --- | --- | --- |
| outputDocument | Stream | 用于保存文档内容的流。该流不能为空。 |
