## FormFieldManager.FixInvalidFormFieldNames method

通过应用指定的更新或自动生成唯一名称来修复文档中无效的表单字段名称。

```csharp
public void FixInvalidFormFieldNames(IEnumerable<InvalidFormField> updateInvalidFormFieldNames)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| updateInvalidFormFieldNames | IEnumerable`1 | 一个用于无效表单字段名称的更新集合。每个更新包含表单字段的原始名称及其对应的新名称。如果留空，无效表单字段名称将自动重命名以确保唯一性。 |

### 备注

`FixInvalidFormFieldNames` 方法通过应用 *updateInvalidFormFieldNames* 集合中指定的更新，或在集合为空时自动生成唯一名称，来解决文档中表单字段的命名冲突或不一致问题。当某些表单字段名称无效或与文档中的其他元素冲突且需要纠正以确保正常功能时，此方法非常有用。 ; ;
