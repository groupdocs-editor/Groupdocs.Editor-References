## FormFieldManager.HasInvalidFormFields method

检查文档是否包含任何无效的表单字段。

```csharp
public bool HasInvalidFormFields()
```

### 返回值

`true` 表示文档包含一个或多个无效表单字段；否则为 `false`。

### 备注

`HasInvalidFormFields` 方法扫描文档内容，以确定是否包含任何名称无效的表单字段。如果表单字段与其他表单字段重复唯一标识符且没有关联的唯一书签名称，则视为无效。这些书签名称用作每个表单字段的标识符。此方法可快速检查文档是否需要进一步检查和潜在的表单字段名称校正。 ; ; ;
