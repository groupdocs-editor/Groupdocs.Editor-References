## 类

| 类 | 描述 |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | 表示字体大小，作为特殊单位或长度值，指定字体的大小（历史上是大写字母 "M" 的宽度）。 |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | 定义字体应如何使用其 font-family 中的普通、斜体或倾斜体进行样式设置。 |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | Font-weight 属性设置字体的粗细（或加粗程度）。 |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | 表示文本装饰线的类型：下划线（underscore）、上划线和删除线（strikethrough）。 |
