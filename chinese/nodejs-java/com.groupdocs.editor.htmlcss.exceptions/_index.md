该 **com.groupdocs.editor.htmlcss.exceptions** 命名空间提供在尝试打开、加载、保存或以其他方式处理某些内容时抛出的异常。



## 类

| 类 | 描述 |
| --- | --- |
| [InvalidFontFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidfontformatexception) | 当尝试打开、加载、保存或以其他方式处理某些内容时抛出的异常，该内容原本被认为是受支持（已知）格式的字体，但实际上是不受支持或意外格式的字体，或根本不是字体。 |
| [InvalidImageFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | 当尝试打开、加载、保存或以其他方式处理某些内容时抛出的异常，该内容原本被认为是图像（光栅或矢量），但实际上是意外类型的图像，或根本不是图像。 |
