该 **com.groupdocs.editor.metadata** 命名空间提供用于描述取决于文档类型的基本文档属性的类。



## 类

| 类 | 描述 |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | 表示一本电子书文档的元数据 |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | 表示任意受支持电子邮件格式的电子邮件文档的元数据 |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | 表示具有固定布局格式（如 PDF 或 XPS）的文档的元数据 |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | 表示一个 Markdown 文档的元数据 |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | 表示一个演示文稿文档的元数据 |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | 表示一个电子表格文档的元数据 |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | 表示像 XML、HTML 或纯文本（TXT）这样的文本文档的元数据 |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | 表示一个文字处理文档的元数据 |

| 接口 | 描述 |
| --- | --- |
