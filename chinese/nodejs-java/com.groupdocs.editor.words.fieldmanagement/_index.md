**com.groupdocs.editor.words.fieldmanagement** 命名空间包含与文档中表单字段的管理和操作相关的类和接口。该命名空间提供对各种表单字段（如文本字段、复选框、下拉列表等）的功能，允许用户以编程方式交互和修改表单字段。



## 类

| 类 | 描述 |
| --- | --- |
| [CheckBoxForm](../com.groupdocs.editor.words.fieldmanagement/checkboxform) | 表示显示复选框的表单字段。 |
| [CurrentDateFormField](../com.groupdocs.editor.words.fieldmanagement/currentdateformfield) | 表示显示当前日期的表单字段。 |
| [CurrentTimeFormField](../com.groupdocs.editor.words.fieldmanagement/currenttimeformfield) | 表示显示当前时间的表单字段。 |
| [DateFormField](../com.groupdocs.editor.words.fieldmanagement/dateformfield) | 表示显示日期的表单字段。 |
| [DropDownFormField](../com.groupdocs.editor.words.fieldmanagement/dropdownformfield) | 表示显示下拉列表的表单字段。 |
| [FormFieldCollection](../com.groupdocs.editor.words.fieldmanagement/formfieldcollection) | 表示表单字段的集合。 |
| [FormFieldType](../com.groupdocs.editor.words.fieldmanagement/formfieldtype) | 指定表单字段的类型。 |
| [HelpText](../com.groupdocs.editor.words.fieldmanagement/helptext) | 表示表单字段的帮助文本。 |
| [InvalidFormField](../com.groupdocs.editor.words.fieldmanagement/invalidformfield) | 表示在 FormFieldManager.FixInvalidFormFieldNames 操作期间对无效表单字段名称的更新。 |
| [NumberFormField](../com.groupdocs.editor.words.fieldmanagement/numberformfield) | 表示接受数字输入的表单字段。 |
| [TextFormField](../com.groupdocs.editor.words.fieldmanagement/textformfield) | 表示接受文本输入的表单字段。 |
