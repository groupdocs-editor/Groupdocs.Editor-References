Le **com.groupdocs.editor.formats** espace de noms fournit des interfaces et des classes qui décrivent les formats de documents pris en charge.



## Classes

| Classe | Description |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Encapsule tous les formats eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Encapsule tous les formats d'e‑mail. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Encapsule tous les formats à mise en page fixe (également appelés "fixed-page") qui incluent PDF et XPS (cela n'inclut pas les images raster) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Représente les différentes familles de formats disponibles dans le système. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Encapsule tous les formats de présentation. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Encapsule tous les formats de feuille de calcul binaires, XML et textuels (excluant tous les formats textuels basés sur des délimiteurs avec séparateur comme CSV, TSV, séparés par des points-virgules, etc.), dans lesquels le classeur peut être enregistré. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Encapsule tous les formats textuels (basés sur du texte), y compris le balisage (XML, HTML) et d'autres. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Encapsule tous les formats de traitement de texte. |
