Le **com.groupdocs.editor.htmlcss.resources.images** espace de noms fournit des classes qui représentent les ressources d’images de tous types en général.



## Classes

| Classe | Description |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Représente les dimensions linéaires (largeur et hauteur) d'une image raster rectangulaire en unité arbitraire. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Représente un type d'image pris en charge (format), prend en charge les formats raster et vectoriel. |

## Interfaces

| Interface | Description |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Le type de données CSS Image représente une image bidimensionnelle. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Représente une ressource d'image de tout type, raster ou vectorielle. |
