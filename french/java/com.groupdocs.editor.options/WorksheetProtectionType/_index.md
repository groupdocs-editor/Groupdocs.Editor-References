Représente les types de protection des feuilles de calcul (onglet) Spreadsheet.

## Champs

| Champ | Description |
| --- | --- |
|  | [None](#None) | La protection n'est pas appliquée (valeur par défaut) |
|
|  | [All](#All) | L'utilisateur ne peut rien modifier sur la feuille de calcul |
|
|  | [Contents](#Contents) | L'utilisateur ne peut pas saisir de données dans la feuille de calcul |
|
|  | [Objects](#Objects) | L'utilisateur ne peut pas modifier les objets de dessin |
|
|  | [Scenarios](#Scenarios) | L'utilisateur ne peut pas modifier les scénarios enregistrés |

|  | [Structure](#Structure) | L'utilisateur ne peut pas modifier la structure |

|  | [Window](#Window) | L'utilisateur ne peut pas modifier la fenêtre |
