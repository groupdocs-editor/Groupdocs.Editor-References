## Length.GetUnitFromName method

Tente d'analyser le nom d'unité spécifié et renvoie la valeur correspondante d'une énumération Unit. Renvoie Unit.Unitless si aucune unité appropriée n'est trouvée.

```csharp
public static Unit GetUnitFromName(string unitName)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| unitName | String | Chaîne, qui représente le nom d'une unité |

### Valeur de retour

Valeur de l'énumération Unit dans tous les cas, Unit.Unitless lorsqu'aucune unité appropriée n'est trouvée
