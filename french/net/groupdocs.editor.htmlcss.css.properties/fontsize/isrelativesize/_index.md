## FontSize.IsRelativeSize property

Indique si cette taille de police est définie avec une taille relative sous forme de mot‑clé. La police sera plus grande ou plus petite par rapport à la taille de police de l'élément parent, approximativement selon le ratio utilisé pour séparer les mots‑clés de taille absolue.

public bool IsRelativeSize { get; }
