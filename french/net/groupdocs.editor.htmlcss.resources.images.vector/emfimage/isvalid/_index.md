## IsValid(Stream) {#isvalid}

Checks whether specified stream is a valid EMF image

```csharp
public static bool IsValid(Stream binaryContent)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| binaryContent | Stream | Flux d'octets d'entrée. Ne peut pas être NULL, doit prendre en charge la lecture et le déplacement. |

### Valeur de retour

Vrai si le flux spécifié contient une image EMF valide, faux sinon.
