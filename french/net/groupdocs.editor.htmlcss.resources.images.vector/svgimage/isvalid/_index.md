## SvgImage.IsValid method

Performs a surface check whether specified textual XML-compliant content represents a SVG image

```csharp
public static bool IsValid(string content)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| contenu | String | Contenu XML d'une image SVG sous forme de texte simple, pas un contenu encodé en base64. |

### Valeur de retour

Vrai si la chaîne spécifiée peut être considérée comme un SVG valide à première vue, faux si ce n'est certainement pas un SVG.
