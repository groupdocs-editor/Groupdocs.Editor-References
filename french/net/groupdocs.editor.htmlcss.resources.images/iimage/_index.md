## IImage interface

Le type de données CSS Image représente une image bidimensionnelle.

```csharp
public interface IImage
```

### Remarques

https://developer.mozilla.org/en-US/docs/Web/CSS/image la référence CSS déclare 4 types d'images qui peuvent être gérés : 1. Images avec des dimensions intrinsèques (une taille naturelle) et donc un ratio d'aspect fixe, ce qui inclut toutes les images raster. 2. Images avec plusieurs dimensions intrinsèques, existant en plusieurs versions dans un même fichier, ce qui inclut les fichiers ICON (*.ico). Cela peut également être le TIFF, car ils supportent plusieurs images dans un fichier, cependant le format TIFF n'est pas supporté sur le web. 3. Images sans dimensions intrinsèques mais avec un ratio d'aspect intrinsèque entre sa largeur et sa hauteur. Cela inclut toutes les images vectorielles, SVG en premier lieu. 4. Images sans dimensions intrinsèques, ni ratio d'aspect intrinsèque. Cela inclut tous les dégradés.
