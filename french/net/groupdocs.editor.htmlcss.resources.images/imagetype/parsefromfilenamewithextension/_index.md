## ImageType.ParseFromFilenameWithExtension method

Renvoie la valeur ImageType, qui est équivalente à l'extension de nom de fichier, extraite du nom de fichier spécifié

```csharp
public static ImageType ParseFromFilenameWithExtension(string filename)
```

| Paramètre | Type | Description |
