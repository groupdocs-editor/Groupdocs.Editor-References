## TagRenderingCase enumeration

Représente différents types de sérialisation des noms de balises HTML

```csharp
public enum TagRenderingCase
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| LowerCase | `0` | all-lower - toutes les lettres du nom de balise seront sérialisées en minuscules |
| UpperCase | `1` | ALL-CAPITAL - toutes les lettres du nom de balise seront sérialisées en MAJUSCULES |
| FirstLetterUpperCase | `2` | La première lettre du nom de balise sera sérialisée en majuscule, tandis que toutes les autres - en minuscule. |
