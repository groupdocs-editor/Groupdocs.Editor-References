## IDocumentInfo.IsEncrypted property

Indique si le fichier spécifique est chiffré et nécessite un mot de passe pour l'ouverture. Pour les types de documents qui ne peuvent pas être chiffrés (comme tous les documents texte), cela doit toujours renvoyer 'false'.
