## IDocumentInfo.PageCount property

Dans le type implémentant, il faut renvoyer le nombre (nombre) de pages ou d'autres entités similaires dépendant du format (onglets, diapositives, etc.). Pour les familles de types qui n'ont rien de similaire (comme les documents texte simples ou XML), il faut renvoyer 1.

public int PageCount { get; }
