## MarkdownDocumentInfo.PageCount property

Renvoie le nombre de pages. Les documents Markdown n'ont généralement pas de pages fixes et donc de nombre de pages, ainsi ce nombre est calculé à partir de la taille de page standard définie sur A4 en orientation portrait.
