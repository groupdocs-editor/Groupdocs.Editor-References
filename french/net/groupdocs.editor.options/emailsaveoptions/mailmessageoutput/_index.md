## EmailSaveOptions.MailMessageOutput property

Permet de contrôler quelles parties du message électronique doivent être transférées vers le document e‑mail de sortie, qui sera généré et enregistré avec la méthode [`Save`](../../../groupdocs.editor/editor/save).

public MailMessageOutput MailMessageOutput { get; set; }

### Property Value
