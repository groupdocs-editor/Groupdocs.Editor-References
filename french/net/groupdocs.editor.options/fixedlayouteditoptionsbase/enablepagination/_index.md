## FixedLayoutEditOptionsBase.EnablePagination property

Permet d'activer (true) ou de désactiver (false) la pagination dans le document HTML résultant. Par défaut, elle est désactivée (false).

```csharp
public bool EnablePagination { get; set; }
```

### Remarques

Les documents au format mise en page fixe (PDF et XPS en particulier) sont, par essence, strictement paginés, leur contenu a une mise en page fixe et est divisé en pages. Cependant, le HTML modifiable résultant peut être présenté soit en vue sans page, soit en vue paginée.
