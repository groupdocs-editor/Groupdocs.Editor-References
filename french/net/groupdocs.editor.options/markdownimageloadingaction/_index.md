## MarkdownImageLoadingAction enumeration

Définit le mode de chargement des images lors de l'ouverture du fichier au format Markdown pour l'édition

```csharp
public enum MarkdownImageLoadingAction
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Default | `0` | GroupDocs.Editor chargera cette ressource comme d'habitude |
| Skip | `1` | GroupDocs.Editor ignorera le chargement de cette image |
| UserProvided | `2` | GroupDocs.Editor utilisera le tableau d'octets fourni par l'utilisateur dans [`SetData`](../markdownimageloadargs/setdata) comme données d'image |
