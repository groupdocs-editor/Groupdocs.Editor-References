## MarkdownSaveOptions.ImagesFolder property

Spécifie le dossier physique où les images sont enregistrées lors de l'exportation d'un document au format Markdown. La valeur par défaut est null.

```csharp
public string ImagesFolder { get; set; }
```

### Remarques

Si ni le `ImagesFolder` ni [`ExportImagesAsBase64`](../exportimagesasbase64) ne sont spécifiés par l'utilisateur, alors GroupDocs.Editor tentera de déterminer le `ImagesFolder` lui-même et l'appliquera en cas de succès
