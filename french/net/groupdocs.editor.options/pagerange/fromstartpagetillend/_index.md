## PageRange.FromStartPageTillEnd method

Crée une plage de pages qui commence au numéro de page spécifié et se poursuit jusqu'à la fin du document

```csharp
public static PageRange FromStartPageTillEnd(ushort startPageNumber)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| startPageNumber | UInt16 | Numéro de page à partir duquel la plage de pages commence, de manière inclusive. Les numéros de page sont indexés à partir de 1, ils doivent donc être strictement supérieurs à zéro |

### Valeur de retour

Nouvelle instance PageRange
