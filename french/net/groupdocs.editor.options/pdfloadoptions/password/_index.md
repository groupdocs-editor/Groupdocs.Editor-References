## PdfLoadOptions.Password property

Permet de spécifier, modifier et obtenir le mot de passe qui sera utilisé pour ouvrir un document PDF, s'il est chiffré. Définissez-le sur NULL ou une chaîne vide afin de ne pas utiliser le mot de passe (valeur par défaut).
