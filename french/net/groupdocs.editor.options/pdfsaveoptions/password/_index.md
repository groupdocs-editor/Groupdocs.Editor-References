## PdfSaveOptions.Password property

Mot de passe qui sera appliqué au document PDF généré comme mot de passe utilisateur, requis pour l'ouverture. Si NULL ou vide, aucun mot de passe ne sera appliqué au document. Sinon, le document sera chiffré avec RC4 (longueur de clé de 128 bits). Par défaut, c'est NULL — le mot de passe n'est pas appliqué.
