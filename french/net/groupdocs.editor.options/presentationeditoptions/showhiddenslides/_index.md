## PresentationEditOptions.ShowHiddenSlides property

Spécifie si les diapositives masquées doivent être incluses ou non. Par défaut, c'est false - les diapositives masquées ne sont pas affichées et une exception sera levée lors de leur tentative d'édition.

public bool ShowHiddenSlides { get; set; }
