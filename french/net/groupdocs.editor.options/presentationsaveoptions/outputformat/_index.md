## PresentationSaveOptions.OutputFormat property

Permet de spécifier un format Presentation qui sera utilisé pour enregistrer le document

```csharp
public PresentationFormats OutputFormat { get; set; }
```

### Remarques

Le format de sortie est généralement défini dans le constructeur de cette classe, car il est obligatoire. Cette propriété permet d'obtenir ou de modifier le format de sortie ultérieurement, lorsque une instance de la classe [`PresentationSaveOptions`](../../presentationsaveoptions) a déjà été créée.
