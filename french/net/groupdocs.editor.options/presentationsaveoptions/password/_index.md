## PresentationSaveOptions.Password property

Permet de spécifier, modifier et obtenir le mot de passe qui sera utilisé pour coder le document Presentation résultant. Par défaut, c'est NULL — le mot de passe ne sera pas défini. Définissez-le sur NULL ou une chaîne vide pour supprimer le mot de passe, s'il avait été défini auparavant.

```csharp
public string Password { get; set; }
```
