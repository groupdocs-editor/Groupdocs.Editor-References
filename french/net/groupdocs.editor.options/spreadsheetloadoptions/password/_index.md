## SpreadsheetLoadOptions.Password property

Permet de spécifier, modifier et obtenir le mot de passe qui sera utilisé pour ouvrir le document Spreadsheet, s'il est chiffré. Définissez-le sur NULL ou une chaîne vide afin de ne pas utiliser de mot de passe (valeur par défaut).

```csharp
public string Password { get; set; }
```
