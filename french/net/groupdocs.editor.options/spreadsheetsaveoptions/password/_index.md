## SpreadsheetSaveOptions.Password property

Permet de spécifier, modifier, obtenir ou supprimer un mot de passe qui sera utilisé pour chiffrer le document Spreadsheet généré, si ce format de document prend en charge la protection par mot de passe. Spécifiez NULL ou une chaîne vide pour supprimer (nettoyer) le mot de passe.
