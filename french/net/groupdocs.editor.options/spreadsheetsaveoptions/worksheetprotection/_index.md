## SpreadsheetSaveOptions.WorksheetProtection property

Permet d'activer la protection d'une feuille pour le document Spreadsheet de sortie. NULL par défaut – la protection n'est pas appliquée. Tous les formats ne prennent pas en charge la protection d'une feuille.

public WorksheetProtection WorksheetProtection { get; set; }
