## TextLeadingSpacesOptions enumeration

Contient les options disponibles pour la gestion des espaces en début de ligne lors de l'ouverture d'un document texte brut (TXT)

```csharp
public enum TextLeadingSpacesOptions
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| ConvertToIndent | `0` | Convertir un ou plusieurs espaces consécutifs en retrait à gauche. Valeur par défaut. |
| Preserve | `1` | Transmettre tous les espaces de début à la sortie HTML "tel quel", sans les modifier |
| Trim | `2` | Supprimer (tronquer) complètement tous les espaces de début |
