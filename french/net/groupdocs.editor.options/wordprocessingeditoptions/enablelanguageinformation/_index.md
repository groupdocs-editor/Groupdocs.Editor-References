## WordProcessingEditOptions.EnableLanguageInformation property

Spécifie si les informations de langue sont exportées dans le balisage HTML sous forme d'attributs HTML 'lang'. Cette option peut être utile pour la conversion aller-retour des documents multilingues. Par défaut, elle est désactivée (false).

public bool EnableLanguageInformation { get; set; }
