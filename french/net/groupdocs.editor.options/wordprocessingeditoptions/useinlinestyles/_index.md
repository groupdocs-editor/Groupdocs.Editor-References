## WordProcessingEditOptions.UseInlineStyles property

Contrôle l'endroit où stocker les données de style et de mise en forme du document WordProcessing d'entrée : dans une feuille de style externe (`false`) ou sous forme de styles en ligne dans le balisage HTML (`true`). Par défaut, les styles externes sont utilisés (`false`).

public bool UseInlineStyles { get; set; }
