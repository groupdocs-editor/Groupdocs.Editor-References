## WordProcessingLoadOptions.Password property

Permet de spécifier, modifier et obtenir le mot de passe qui sera utilisé pour ouvrir le document WordProcessing, s’il est chiffré. Définissez-le sur NULL ou une chaîne vide afin de ne pas utiliser de mot de passe (valeur par défaut).

public string Password { get; set; }
