## WordProcessingProtectionType enumeration

Représente tous les types de protection disponibles du document WordProcessing

```csharp
public enum WordProcessingProtectionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| NoProtection | `0` | Le document n'est pas protégé. Valeur par défaut. |
| AllowOnlyRevisions | `1` | L'utilisateur ne peut ajouter que des marques de révision au document |
| AllowOnlyComments | `2` | L'utilisateur ne peut modifier que les commentaires dans le document |
| AllowOnlyFormFields | `3` | L'utilisateur ne peut saisir que des données dans les champs de formulaire du document |
| ReadOnly | `4` | Aucune modification n'est autorisée sur le document |
