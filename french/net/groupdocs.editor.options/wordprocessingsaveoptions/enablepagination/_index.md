## WordProcessingSaveOptions.EnablePagination property

Permet d'activer ou de désactiver la pagination qui sera utilisée lors de l'enregistrement du document WordProcessing. Si le document original a été ouvert et modifié en mode pagination, cette option doit également être activée. Désactivée par défaut.

```csharp
public bool EnablePagination { get; set; }
```
