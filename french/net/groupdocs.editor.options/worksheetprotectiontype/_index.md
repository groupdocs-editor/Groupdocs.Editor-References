## WorksheetProtectionType enumeration

Représente les types de protection des feuilles de calcul (onglet) Spreadsheet

```csharp
public enum WorksheetProtectionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | La protection n'est pas appliquée (valeur par défaut) |
| All | `1` | L'utilisateur ne peut rien modifier sur la feuille de calcul |
| Contents | `2` | L'utilisateur ne peut pas saisir de données dans la feuille de calcul |
| Objects | `3` | L'utilisateur ne peut pas modifier les objets de dessin |
| Scenarios | `4` | L'utilisateur ne peut pas modifier les scénarios enregistrés |
| Structure | `5` | L'utilisateur ne peut pas modifier la structure |
| Window | `6` | L'utilisateur ne peut pas modifier la fenêtre |
