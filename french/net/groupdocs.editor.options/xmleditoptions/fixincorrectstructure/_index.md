## XmlEditOptions.FixIncorrectStructure property

Permet d'activer ou de désactiver le mécanisme de correction d'une structure XML corrompue. Désactivé par défaut (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Remarques

Par défaut, seuls les documents XML correctement formés et valides sont acceptés. Lorsque cette option est activée, GroupDocs.Editor tentera de corriger la structure XML corrompue si possible.
