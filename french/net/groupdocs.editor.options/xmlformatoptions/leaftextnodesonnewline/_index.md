## XmlFormatOptions.LeafTextNodesOnNewline property

Lorsqu'elle est activée, les nœuds texte feuilles (contenu textuel à l'intérieur des éléments XML, qui n'ont pas d'enfants) seront rendus sur une nouvelle ligne avec une indentation gauche plus grande. Par défaut, elle est désactivée (false) — les nœuds texte feuilles sont placés sur la même ligne que leurs parents, sans nouvelle indentation.

public bool LeafTextNodesOnNewline { get; set; }
