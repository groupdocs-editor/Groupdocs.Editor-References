## Editor.Dispose method

Libère cette instance d'Editor, afin qu'elle libère toutes les ressources internes et devienne indisponible pour une utilisation ultérieure.

```csharp
public void Dispose()
```

### Remarques

Après l’invocation de cette méthode, appeler toutes les autres méthodes de cette instance lèvera une ObjectDisposedException. Il est sûr d’appeler cette méthode plusieurs fois — tous les appels suivants sont ignorés.
