## FormFieldManager.UpdateFormFiled method

Met à jour les champs de formulaire dans le document en fonction de la collection de champs de formulaire fournie.

```csharp
public void UpdateFormFiled(FormFieldCollection formFieldCollection)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| formFieldCollection | FormFieldCollection | La collection de champs de formulaire contenant les mises à jour à appliquer au document. |

### Remarques

La méthode `UpdateFormFiled` met à jour les champs de formulaire dans le document en fonction de la *formFieldCollection* fournie. Chaque champ de formulaire de la collection correspond à un champ de formulaire du document, et les mises à jour spécifiées dans la collection sont appliquées en conséquence. Cette méthode est utile pour synchroniser les données des champs de formulaire entre le document et une source externe, telle qu'une interface utilisateur ou une base de données.
