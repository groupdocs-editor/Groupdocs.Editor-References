## InvalidFormatException class

L'exception qui est levée lorsque l'utilisateur tente d'ouvrir un document avec des options spécifiques au format qui sont incompatibles avec le format du document original.

```csharp
public sealed class InvalidFormatException : Exception
```

### Remarques

Par exemple, cette exception sera levée si l'on tente d'ouvrir un document de feuille de calcul avec des options de document de traitement de texte.
