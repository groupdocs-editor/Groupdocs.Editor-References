Le namespace **com.groupdocs.editor.htmlcss.css.datatypes** fournit des classes qui représentent les types de données CSS.



## Classes

| Classe | Description |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Représente une valeur de couleur au format ARGB avec des convertisseurs et des sérialiseurs |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Contient toutes les « couleurs connues », qui ont un nom et une valeur uniques fixes dans la norme CSS |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Représente une valeur de longueur CSS dans n'importe quelle unité prise en charge, y compris le pourcentage et le type sans unité. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Toutes les unités de longueur prises en charge |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Représente un type de données CSS « ratio », qui est utilisé pour décrire les rapports d'aspect dans les requêtes média et pour les images raster en indiquant la proportion entre deux valeurs sans unité appelées « numérateur » et « dénominateur ». |
