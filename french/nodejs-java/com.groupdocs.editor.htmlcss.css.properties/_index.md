## Classes

| Classe | Description |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Représente une taille de police comme une unité spéciale ou une valeur de longueur, qui spécifie la taille de la police (historique la largeur du caractère majuscule "M"). |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Définit comment la police doit être stylisée avec : une version normale, italique ou oblique provenant de sa famille de polices. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | La propriété font-weight définit le poids (ou l'épaisseur) de la police. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Représente les types de ligne de décoration du texte : souligné (underscore), surligné et barré (strikethrough). |
