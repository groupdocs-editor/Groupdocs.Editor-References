Le namespace **com.groupdocs.editor.htmlcss.exceptions** fournit des exceptions qui sont levées lorsqu’on essaie d’ouvrir, de charger, d’enregistrer ou de traiter d’une autre manière du contenu.



## Classes

| Classe | Description |
| --- | --- |
| [InvalidFontFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidfontformatexception) | L'exception qui est levée lorsqu'on essaie d'ouvrir, charger, enregistrer ou traiter d'une manière quelconque du contenu, qui est supposé être une police d'un format pris en charge (connu), mais qui est en réalité une police d'un format non pris en charge ou inattendu, ou qui n'est pas du tout une police. |
| [InvalidImageFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | L'exception qui est levée lorsqu'on essaie d'ouvrir, charger, enregistrer ou traiter d'une manière quelconque du contenu, qui est supposé être une image (raster ou vectorielle), mais qui est en réalité une image d'un type inattendu ou qui n'est pas du tout une image. |
