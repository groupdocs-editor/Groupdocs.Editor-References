Le namespace **com.groupdocs.editor.metadata** fournit des classes pour décrire les propriétés de base des documents selon le type de document.



## Classes

| Classe | Description |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Représente les métadonnées d'un document EBook |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Représente les métadonnées d'un document email de tout format email pris en charge |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Représente les métadonnées d'un document au format mise en page fixe comme PDF ou XPS |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Représente les métadonnées d'un document Markdown |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Représente les métadonnées d'un document Presentation |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Représente les métadonnées d'un document Spreadsheet |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Représente les métadonnées d'un document textuel comme XML, HTML ou texte brut (TXT) |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Représente les métadonnées d'un document WordProcessing |

## Interfaces

| Interface | Description |
| --- | --- |
| [IDocumentInfo](../com.groupdocs.editor.metadata/idocumentinfo) | Interface commune pour tous les wrappers de métadonnées de fichiers |
