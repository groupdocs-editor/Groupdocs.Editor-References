Der **com.groupdocs.editor.htmlcss.resources.images.raster** Namespace stellt Klassen bereit, die ausschließlich Raster‑Bildressourcen repräsentieren.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [BmpImage](../com.groupdocs.editor.htmlcss.resources.images.raster/bmpimage) | Stellt ein Bild im BMP (BitMap Picture)-Format mit seinen Metadaten und zusätzlichen Methoden dar. |
| [GifImage](../com.groupdocs.editor.htmlcss.resources.images.raster/gifimage) | Stellt ein Bild im GIF (Graphics Interchange Format)-Format mit seinen Metadaten und zusätzlichen Methoden dar. |
| [IconImage](../com.groupdocs.editor.htmlcss.resources.images.raster/iconimage) | Stellt ein Bild im ICON-Format mit seinen Metadaten und zusätzlichen Methoden dar. |
| [JpegImage](../com.groupdocs.editor.htmlcss.resources.images.raster/jpegimage) | Stellt ein Bild im JPEG (Joint Photographic Experts Group)-Format mit seinen Metadaten und zusätzlichen Methoden dar. |
| [PngImage](../com.groupdocs.editor.htmlcss.resources.images.raster/pngimage) | Stellt ein Bild im PNG (Portable Network Graphics)-Format mit seinen Metadaten und zusätzlichen Methoden dar. |
| [RasterImageResourceBase](../com.groupdocs.editor.htmlcss.resources.images.raster/rasterimageresourcebase) | Basisklasse für jedes unterstützte Rasterbild mit festem Namen, Abmessungen, Seitenverhältnis, Typ, Größe und Inhalt. |
| [TiffImage](../com.groupdocs.editor.htmlcss.resources.images.raster/tiffimage) | Stellt ein Bild im TIFF (Tagged Image File Format)-Format mit seinen Metadaten und zusätzlichen Methoden dar. |
