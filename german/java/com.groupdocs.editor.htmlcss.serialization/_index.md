| --- | --- |
| [QuoteType](../com.groupdocs.editor.htmlcss.serialization/quotetype) | Stellt Anführungszeichen dar – einfaches Anführungszeichen (') und doppeltes Anführungszeichen (\") |
| [TagRenderingCase](../com.groupdocs.editor.htmlcss.serialization/tagrenderingcase) | Stellt verschiedene Arten der Serialisierung von HTML-Tag-Namen dar. |
