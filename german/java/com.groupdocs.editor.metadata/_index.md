Der **com.groupdocs.editor.metadata** Namespace stellt Klassen zur Beschreibung grundlegender Dokumenteigenschaften bereit, die vom Dokumenttyp abhängen.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Stellt Metadaten eines E‑Book‑Dokuments dar |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Stellt Metadaten eines E‑Mail‑Dokuments in einem beliebigen unterstützten E‑Mail‑Format dar. |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Stellt Metadaten eines Dokuments mit festem Layoutformat wie PDF oder XPS dar. |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Stellt Metadaten eines Markdown‑Dokuments dar. |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Stellt Metadaten eines Präsentationsdokuments dar. |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Stellt Metadaten eines Tabellenkalkulationsdokuments dar. |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Stellt Metadaten eines textuellen Dokuments wie XML, HTML oder Klartext (TXT) dar. |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Stellt Metadaten eines Textverarbeitungsdokuments dar. |
