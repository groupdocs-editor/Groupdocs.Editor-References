|  | [Cc](#Cc) | Verarbeite alle CC-Empfänger der E-Mail-Nachricht |
|
|  | [Bcc](#Bcc) | Verarbeite alle BCC-Empfänger der E-Mail-Nachricht |
|
|  | [From](#From) | Verarbeite den Absender der E-Mail-Nachricht |
|
|  | [Attachments](#Attachments) | Verarbeite alle Anhänge der E-Mail-Nachricht |
|
|  | [Metadata](#Metadata) | Verarbeite alle anderen technischen Metadaten (Sensitivität, Priorität, Kodierung, MIME, X-Mailer usw.) |
|
|  | [Common](#Common) | Gemeinsame Ausgabe – Body mit allen wichtigsten Metadaten |
|
|  | [All](#All) | Vollständige Ausgabe – Body mit allen Metadaten |
