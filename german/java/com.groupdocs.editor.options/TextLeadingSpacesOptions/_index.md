Enthält verfügbare Optionen zur Behandlung von führenden Leerzeichen beim Öffnen von einfachem.
Textdatei (TXT)

## Felder

| Feld | Beschreibung |
| --- | --- |

|
|  | [Preserve](#Preserve) | Gibt alle führenden Leerzeichen an das Ausgabe‑HTML "as is" weiter, ohne sie zu verändern. |
|
|  | [Trim](#Trim) | Entfernt (schneidet) alle führenden Leerzeichen vollständig. |
|

```

### Preserve {#Preserve}
```
public static final int Preserve
