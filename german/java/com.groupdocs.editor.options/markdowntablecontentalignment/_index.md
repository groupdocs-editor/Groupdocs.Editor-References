Ermöglicht die Angabe der Ausrichtung des Tabelleninhalts, die verwendet wird, wenn
in das Markdown-Format exportiert wird.

## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [Auto](#Auto) | Die Ausrichtung wird aus dem ersten Absatz in der entsprechenden |
Tabellenspalte übernommen.
|
|  | [Left](#Left) | Der Inhalt von Tabellen wird linksbündig ausgerichtet. |
|
|  | [Center](#Center) | Der Inhalt von Tabellen wird zentriert ausgerichtet. |
|
|  | [Right](#Right) | Der Inhalt von Tabellen wird rechtsbündig ausgerichtet. |
|
