Der **com.groupdocs.editor.words.fieldmanagement** Namespace enthält Klassen und Schnittstellen, die sich auf die Verwaltung und Manipulation von Formularfeldern in Dokumenten beziehen. Dieser Namespace bietet Funktionen, um mit verschiedenen Arten von Formularfeldern zu arbeiten, wie Textfelder, Kontrollkästchen, Dropdown-Listen usw., und ermöglicht es Benutzern, Formularfelder programmgesteuert zu interagieren und zu ändern.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CheckBoxForm](../com.groupdocs.editor.words.fieldmanagement/checkboxform) | Stellt ein Formularfeld dar, das ein Kontrollkästchen anzeigt. |
| [CurrentDateFormField](../com.groupdocs.editor.words.fieldmanagement/currentdateformfield) | Stellt ein Formularfeld dar, das das aktuelle Datum anzeigt. |
| [CurrentTimeFormField](../com.groupdocs.editor.words.fieldmanagement/currenttimeformfield) | Stellt ein Formularfeld dar, das die aktuelle Uhrzeit anzeigt. |
| [DateFormField](../com.groupdocs.editor.words.fieldmanagement/dateformfield) | Stellt ein Formularfeld dar, das ein Datum anzeigt. |
| [DropDownFormField](../com.groupdocs.editor.words.fieldmanagement/dropdownformfield) | Stellt ein Formularfeld dar, das eine Dropdown-Liste anzeigt. |
| [FormFieldCollection](../com.groupdocs.editor.words.fieldmanagement/formfieldcollection) | Stellt eine Sammlung von Formularfeldern dar. |
| [FormFieldType](../com.groupdocs.editor.words.fieldmanagement/formfieldtype) | Gibt den Typ des Formularfelds an. |
| [HelpText](../com.groupdocs.editor.words.fieldmanagement/helptext) | Stellt Hilfetext für ein Formularfeld dar. |
| [InvalidFormField](../com.groupdocs.editor.words.fieldmanagement/invalidformfield) | Stellt die Aktualisierung ungültiger Formularfeldnamen während des Vorgangs FormFieldManager.FixInvalidFormFieldNames dar. |
| [NumberFormField](../com.groupdocs.editor.words.fieldmanagement/numberformfield) | Stellt ein Formularfeld dar, das eine Zahleneingabe akzeptiert. |
| [TextFormField](../com.groupdocs.editor.words.fieldmanagement/textformfield) | Stellt ein Formularfeld dar, das Texteingaben akzeptiert. |
