## FormatFamilyBase.GetHashCode method

Gibt einen Hashcode für das aktuelle Objekt zurück.


### Rückgabewert

Ein Hashcode für das aktuelle Objekt, geeignet für die Verwendung in Hash‑Algorithmen und Datenstrukturen wie einer Hashtabelle.

### Hinweise

Diese Methode überschreibt GetHashCode. Der Hashcode wird unter Verwendung der Eigenschaften `Id` und `Name` des Objekts berechnet. Der `unchecked`‑Kontext erlaubt Überlauf, was im Kontext einer Hashcode‑Berechnung akzeptabel ist.
