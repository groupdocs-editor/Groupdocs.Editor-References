## FontStyle.Italic field

Wählt eine Schrift, die als kursiv klassifiziert ist. Wenn keine kursive Variante der Schrift verfügbar ist, wird stattdessen eine schräg klassifizierte verwendet. Wenn keine von beiden verfügbar ist, wird der Stil künstlich simuliert.
