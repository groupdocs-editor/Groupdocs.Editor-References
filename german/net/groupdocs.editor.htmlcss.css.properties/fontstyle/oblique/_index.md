## FontStyle.Oblique field

Wählt eine Schrift, die als schräg klassifiziert ist. Wenn keine schräge Variante der Schrift verfügbar ist, wird stattdessen eine kursiv klassifizierte verwendet. Wenn keine von beiden verfügbar ist, wird der Stil künstlich simuliert.
