## IImage interface

Der Bild‑CSS‑Datentyp stellt ein zweidimensionales Bild dar.

```csharp
public interface IImage
```

### Hinweise

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS-Referenz definiert 4 Bildtypen, die verarbeitet werden können: 1. Bilder mit intrinsischen Abmessungen (einer natürlichen Größe) und damit festem Seitenverhältnis, die alle Rasterbilder umfassen. 2. Bilder mit mehreren intrinsischen Abmessungen, die in mehreren Versionen innerhalb einer einzigen Datei existieren, darunter ICON (*.ico)-Dateien. Das können auch TIFFs sein, da sie mehrere Bilder in einer Datei unterstützen, jedoch wird das TIFF-Format im Web nicht unterstützt. 3. Bilder ohne intrinsische Abmessungen, aber mit einem intrinsischen Seitenverhältnis zwischen Breite und Höhe. Dies umfasst alle Vektorbilder, vor allem SVG. 4. Bilder ohne intrinsische Abmessungen und ohne intrinsisches Seitenverhältnis. Dies umfasst alle Verläufe.
