## ResourceTypeDetector.TryDetectResource method

Versucht, einen Eingabestream zu analysieren und erstellt daraus eine der unterstützbaren HTML-Ressourcen, wobei ein angegebener angenommener Typ berücksichtigt wird, sofern er nicht null ist

```csharp
public static IHtmlResource TryDetectResource(Stream inputResourceStream, string name, 
    IResourceType assumptiveFormat)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| inputResourceStream | Stream | Eingabestream, der vermutlich eine HTML-Ressource enthält. Wenn ungültig, wird eine Ausnahme ausgelöst. |
| name | String | Ressourcenname, der bei Erfolg für die erstellte und zurückgegebene Ressource verwendet wird. Darf nicht NULL, leer oder nur Leerzeichen sein. |
| assumptiveFormat | IResourceType | Angenommenes Format der Eingabe‑HTML‑Ressource, das für die bestmögliche Leistung nützlich ist. Wenn völlig unbekannt, verwenden Sie den NULL‑Wert. Kann inkorrekt sein, was die Leistung nur verschlechtern wird. |

### Rückgabewert

Instanz, die das Interface 'IHtmlResource' implementiert und bei Erfolg eine der unterstützten HTML‑Ressourcen darstellt, oder bei Fehler NULL.
