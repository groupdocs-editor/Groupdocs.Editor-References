## explicit operator {#op_explicit_1}

Wandelt ein bestimmtes Char in das entsprechende [`QuoteType`](../../quotetype) um, wirft eine Ausnahme, wenn die Umwandlung ungültig ist.

```csharp
public static explicit operator QuoteType(char character)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Zeichen | Char | Ein einzelnes Anführungszeichen (U+0027 APOSTROPHE) oder ein doppeltes Anführungszeichen (U+0022 QUOTATION MARK) Zeichen. Es wird eine Ausnahme ausgelöst, wenn ein anderes Zeichen angegeben wird. |

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentOutOfRangeException | Das angegebene Char ist weder ein Anführungszeichen noch ein Apostroph. |
