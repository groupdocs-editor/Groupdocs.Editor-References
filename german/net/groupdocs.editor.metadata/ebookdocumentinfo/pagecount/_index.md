## EbookDocumentInfo.PageCount property

Gibt die Anzahl der Seiten im Fall von MOBI oder AZW3 bzw. die Anzahl der Kapitel im Fall von ePub zurück.

```csharp
public int PageCount { get; }
```

### Hinweise

e‑Book‑Dokumente haben normalerweise keine festen Seiten und damit keine Seitenzahl. Im Fall von ePub ist es möglich, die Anzahl der Kapitel zu berechnen. Die Formate MOBI und AZW3 besitzen jedoch ebenfalls keine Kapitel, sodass diese Zahl aus der Standard‑Seitengröße A4 im Hochformat berechnet wird.
