## IDocumentInfo.IsEncrypted property

Gibt an, ob eine bestimmte Datei verschlüsselt ist und ein Passwort zum Öffnen benötigt. Für Dokumenttypen, die nicht verschlüsselt werden können (wie alle textbasierten), sollte immer 'false' zurückgegeben werden.
