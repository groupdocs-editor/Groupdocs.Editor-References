## DelimitedTextEditOptions.OptimizeMemoryUsage property

Aktiviert Speicheroptimierungsmechanismen während der Verarbeitung von Eingabedokumenten, die in einigen Sonderfällen die Leistung beeinträchtigen können, aber andererseits den Speicherverbrauch reduzieren. Nützlich bei der Verarbeitung riesiger Dokumente und bei Auftreten einer OutOfMemoryException. Standard ist `false` (Speicheroptimierung ist zum Zweck einer besseren Leistung deaktiviert).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
