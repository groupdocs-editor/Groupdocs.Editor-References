## EbookSaveOptions.SplitHeadingLevel property

Gibt die maximale Überschriftenebene an, bei der die E‑Book‑Datei aufgeteilt wird. Standardwert ist `2`. Wird sie auf `0` gesetzt, wird das Aufteilen deaktiviert, sodass der gesamte Inhalt des E‑Books in ein einziges Paket innerhalb der resultierenden Datei integriert wird.

```csharp
public int SplitHeadingLevel { get; set; }
```

### Hinweise

Wenn diese Eigenschaft auf einen Wert von 1 bis 9 gesetzt wird, wird das Dokument an Absätzen aufgeteilt, die mit den Stilen **Heading 1**, **Heading 2**, **Heading 3** usw. formatiert sind, bis zur angegebenen Überschriftenebene.

Standardmäßig führen nur **Heading 1**- und **Heading 2**-Absätze dazu, dass das Dokument aufgeteilt wird. Wird diese Eigenschaft auf Null (oder einen kleineren Wert als Null) gesetzt, wird das Dokument überhaupt nicht an Überschriftenabsätzen aufgeteilt.
