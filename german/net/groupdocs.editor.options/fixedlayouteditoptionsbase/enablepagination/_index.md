## FixedLayoutEditOptionsBase.EnablePagination property

Ermöglicht das Aktivieren (true) oder Deaktivieren (false) der Seitennummerierung im resultierenden HTML‑Dokument. Standardmäßig ist sie deaktiviert (false).

```csharp
public bool EnablePagination { get; set; }
```

### Hinweise

Dokumente im Fixed‑Layout‑Format (insbesondere PDF und XPS) sind im Wesentlichen streng paginiert, ihr Inhalt hat ein festes Layout und ist auf Seiten aufgeteilt. Das resultierende editierbare HTML kann jedoch entweder in einer pageless‑ oder paginal‑Ansicht dargestellt werden.
