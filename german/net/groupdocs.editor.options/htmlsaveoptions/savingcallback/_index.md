## HtmlSaveOptions.SavingCallback property

Schnittstelle, die vom Endbenutzer implementiert werden muss, um alle externen HTML‑Ressourcen zu speichern. Diese Eigenschaft **must** nicht `null` sein, sonst wirft GroupDocs.Editor eine Ausnahme beim Speichern von [`EditableDocument`](../../../groupdocs.editor/editabledocument) in das HTML‑Format.

```csharp
public IHtmlSavingCallback SavingCallback { get; set; }
```

### Hinweise

Wenn der Wert der Eigenschaft [`EmbedStylesheetsIntoMarkup`](../embedstylesheetsintomarkup) auf `true` gesetzt ist, werden alle Stylesheets in das HTML‑Markup eingebettet und daher nicht an diesen Speicher‑Callback übergeben.
