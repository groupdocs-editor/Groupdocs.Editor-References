## IHtmlSavingCallback.SaveOneResource method

Instanzmethode, die beim Aufruf der [`Save`](../../../groupdocs.editor/editabledocument/save)‑Methode ausgelöst wird und vom Endbenutzer implementiert werden muss, um die bereitgestellte HTML‑Ressource zu erhalten, zu speichern und anschließend einen Link zu dieser Ressource an den Aufrufer zurückzugeben.

```csharp
public string SaveOneResource(IHtmlResource resource)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| resource | IHtmlResource | HTML‑Ressource beliebiger Art (Bilder und Schriftarten, ggf. Stylesheets, wenn sie nicht in das HTML‑Markup eingebettet sind), die von GroupDocs.Editor an die benutzerdefinierte Implementierung dieser Schnittstelle übergeben wird, vom Benutzer erhalten wird und der Benutzer beliebige notwendige Vorgänge wie Speichern, Senden, Konvertieren usw. durchführen kann. GroupDocs.Editor wird niemals eine `null` HTML‑Ressource an diese Methode übergeben. |

### Rückgabewert

Ein Link (Referenz) zur Ressource, der im Parameter *resource* erhalten wird und den der Benutzer GroupDocs.Editor bereitstellen muss, damit GroupDocs.Editor diesen Link in das HTML‑Markup einfügt.

### Hinweise

GroupDocs.Editor erwartet, dass die benutzerdefinierte Implementierung dieser Methode während der Ausführung keine Ausnahme wirft. Tritt jedoch eine Ausnahme auf, schreibt GroupDocs.Editor den Wert der [`FilenameWithExtension`](../../../groupdocs.editor.htmlcss.resources/ihtmlresource/filenamewithextension)-Eigenschaft in das HTML-Markup.
