## MarkdownSaveOptions.ExportImagesAsBase64 property

Gibt an, ob Bilder im Base64‑Format in die Ausgabedatei gespeichert werden. Standardwert ist `false`.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### Hinweise

Wenn diese Eigenschaft auf `true` gesetzt wird, werden Bilddaten direkt in die Bildelemente ![]() exportiert und separate Dateien werden nicht erstellt. Diese Eigenschaft hat, wenn sie auf `true` gesetzt ist, eine höhere Priorität als die Eigenschaft [`ImagesFolder`](../imagesfolder).
