## MhtmlSaveOptions.ExportLanguageInformation property

Gibt an, ob Sprachinformationen nach MHTML exportiert werden sollen. Standardwert ist `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### Hinweise

Wenn diese Eigenschaft auf `true` gesetzt ist, gibt der GroupDocs.Editor das HTML-Attribut `lang` bei den Dokumentelementen aus, die die Sprache angeben. Dies kann erforderlich sein, um sprachbezogene Semantik zu erhalten.
