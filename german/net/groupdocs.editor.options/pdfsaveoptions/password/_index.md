## PdfSaveOptions.Password property

Passwort, das auf das erzeugte PDF-Dokument als Benutzerpasswort angewendet wird und zum Öffnen erforderlich ist. Wenn NULL oder leer, wird kein Passwort auf das Dokument angewendet. Andernfalls wird das Dokument mit RC4 (Schlüssellänge von 128 Bit) verschlüsselt. Standardmäßig ist NULL — Passwort wird nicht angewendet.
