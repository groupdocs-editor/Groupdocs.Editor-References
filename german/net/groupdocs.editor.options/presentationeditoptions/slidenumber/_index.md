## PresentationEditOptions.SlideNumber property

Ermöglicht die Angabe der Foliennummern, die zum Bearbeiten geöffnet werden sollen


### Hinweise

Foliennummer ist ein nullbasierter Index einer Folie, der es ermöglicht, eine bestimmte Folie aus einer Präsentation zum Bearbeiten anzugeben und auszuwählen. Ist sie kleiner als 0, wird die erste Folie ausgewählt (wie SlideNumber = 0). Ist sie größer als die Anzahl aller Folien in der Präsentation, wird die letzte Folie ausgewählt. Enthält die Eingabepäsentation nur eine einzelne Folie, wird diese Option ignoriert und diese einzelne Folie wird bearbeitet. Wird versucht, eine versteckte Folie zum Bearbeiten zu öffnen, während die [`ShowHiddenSlides`](../showhiddenslides) Option auf 'false' gesetzt ist, wird eine Ausnahme ausgelöst.
