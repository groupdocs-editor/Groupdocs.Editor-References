## PresentationLoadOptions.Password property

Ermöglicht das Angeben, Ändern und Abrufen des Passworts, das zum Öffnen des Präsentationsdokuments verwendet wird, falls es verschlüsselt ist. Auf NULL oder leere Zeichenfolge setzen, um das Passwort zu entfernen.

```csharp
public string Password { get; set; }
```

### Hinweise

Standardmäßig hat diese Eigenschaft den Wert NULL – das Passwort ist nicht gesetzt. Wenn das Eingabe‑Presentation‑Dokument passwortgeschützt ist, ist das Passwort zwingend erforderlich und es wird eine Ausnahme ausgelöst, wenn das Passwort nicht angegeben oder ungültig ist. Wenn das Eingabe‑Presentation‑Dokument NICHT passwortgeschützt ist, das Passwort jedoch gesetzt ist, wird es ignoriert.
