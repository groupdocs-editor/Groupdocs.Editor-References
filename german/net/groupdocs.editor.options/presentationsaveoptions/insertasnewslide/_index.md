## PresentationSaveOptions.InsertAsNewSlide property

Boolesches Flag, das angibt, ob die bearbeitete Folie die vorhandene Folie in der Originalpräsentation an der durch die [`SlideNumber`](../slidenumber)-Eigenschaft angegebenen Position ersetzen soll oder zwischen der vorhandenen Folie und der vorherigen eingefügt werden soll, ohne deren Inhalt zu ersetzen. Standardmäßig ist `false` — die vorhandene Folie wird ersetzt. Diese Eigenschaft wird ignoriert, wenn der Wert der [`SlideNumber`](../slidenumber)-Eigenschaft auf `'0'` gesetzt ist.

```csharp
public bool InsertAsNewSlide { get; set; }
```

### Hinweise

Standardmäßig wird die Folie ersetzt. Das bedeutet, dass wenn die gegebene Präsentation 5 Folien hat und [`SlideNumber`](../slidenumber)=4, dann die 4. Folie durch die neue bearbeitete Folie ersetzt wird, während die Gesamtzahl der Folien in der Präsentation (5) unverändert bleibt. Wird jedoch der Wert dieser Eigenschaft auf true gesetzt, wird die neue bearbeitete Folie als 4. Folie eingefügt und alle nachfolgenden Folien werden ans Ende verschoben: Die \"alte\" 4. Folie wird zur 5., und die 5. wird zur 6., und die Gesamtzahl der Folien in der Präsentation wird um eins erhöht und beträgt 6.
