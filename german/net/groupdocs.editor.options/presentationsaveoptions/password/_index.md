## PresentationSaveOptions.Password property

Ermöglicht das Festlegen, Ändern und Abrufen des Passworts, das zum Kodieren des resultierenden Präsentationsdokuments verwendet wird. Standardmäßig ist NULL - Passwort wird nicht gesetzt. Setzen Sie es auf NULL oder einen leeren String, um das Passwort zu entfernen, falls es zuvor gesetzt wurde.
