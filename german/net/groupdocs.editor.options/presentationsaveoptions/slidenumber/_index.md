## PresentationSaveOptions.SlideNumber property

Ermöglicht das Einfügen einer bearbeiteten Folie in eine vorhandene Präsentation anstelle der Erstellung einer neuen Einzelfolien‑Präsentation (Standardverhalten). Die Foliennummer ist eine 1‑basierte Nummer einer Folie in der Präsentation, die in der Editor‑Klasse geladen wurde. Ist sie 0 (Standardwert), wird die neue Präsentation mit einer einzelnen bearbeiteten Folie erstellt. Ist sie größer oder kleiner als null und es gibt eine gültige Präsentation, die in der Editor‑Klasse geladen ist, wird die bearbeitete Folie, die in der Eingabe‑EditableDocument‑Instanz gespeichert ist, in diese Präsentation eingefügt.

```csharp
public int SlideNumber { get; set; }
```

### Hinweise

SlideNumber‑Ganzzahl‑Eigenschaft, wenn sie nicht im Standardzustand (reservierter Wert '0') ist, stellt sie eine Foliennummer dar, beginnend bei 1, nicht bei null, und ihr Maximalwert entspricht der Anzahl aller vorhandenen Folien in einer Präsentation. Wenn jedoch der angegebene Wert größer ist als die Gesamtzahl der Folien, passt GroupDocs.Editor ihn an, um die letzte Folie zu markieren. Negative Werte sind ebenfalls zulässig und zählen die Folien vom Ende rückwärts. Zum Beispiel bedeutet '-1' die letzte Folie einer Präsentation, '-2' die vorletzte usw. Wie bei positiven Werten wird, wenn die negative Foliennummer die Gesamtzahl der Folien in der angegebenen Präsentation überschreitet, sie auf die erste Folie angepasst. Die [`InsertAsNewSlide`](../insertasnewslide)-Boolesche‑Eigenschaft ist eng mit dieser verknüpft.

### Beispiele

SlideNumber = 1; — ersetzen Sie die erste Folie durch die bearbeitete SlideNumber = 2; — ersetzen Sie die zweite Folie durch die bearbeitete SlideNumber = 5; — ersetzen Sie die letzte (5.) Folie durch die bearbeitete SlideNumber = 6; — ersetzen Sie die letzte (5.) Folie durch die bearbeitete, weil 6 größer als 5 ist und daher angepasst wird SlideNumber = -1; — ersetzen Sie die letzte (5.) Folie durch die bearbeitete, weil "-1" "letzte vorhandene" bedeutet SlideNumber = -2; — ersetzen Sie die 4. Folie durch die bearbeitete SlideNumber = -3; — ersetzen Sie die 3. Folie durch die bearbeitete SlideNumber = -4; — ersetzen Sie die 2. Folie durch die bearbeitete SlideNumber = -5; — ersetzen Sie die erste Folie durch die bearbeitete SlideNumber = -6; — ersetzen Sie die erste Folie durch die bearbeitete, weil "-6" größer als 5 ist und daher angepasst wird
