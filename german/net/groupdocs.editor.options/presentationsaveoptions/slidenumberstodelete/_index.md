## PresentationSaveOptions.SlideNumbersToDelete property

Ermöglicht die Angabe eines Arrays mit 1‑basierten Foliennummern, die beim Speichern der Präsentation gelöscht werden sollen, falls die bearbeitete Folie in eine vorhandene Präsentation eingefügt wird

```csharp
public int[] SlideNumbersToDelete { get; set; }
```

### Hinweise

Wenn die bearbeitete Folie nicht als neue Einzelfolien‑Präsentation gespeichert wird (Standardverhalten), sondern stattdessen in eine bestehende Präsentation (unter Verwendung der [`SlideNumber`](../slidenumber)-Eigenschaft) gespeichert wird, ist es ebenfalls möglich, bestimmte Folien aus dieser Präsentation zu löschen, indem man deren Nummern in diesem Array angibt.

Standardmäßig ist dieses Array `null` — es werden keine Folien gelöscht. Wenn das Array jedoch nicht null und nicht leer ist und mindestens eine gültige Foliennummer enthält, werden nach der Erzeugung des Ausgabedokuments der Präsentation mit dem Inhalt der bearbeiteten Folie die Folien mit den angegebenen Nummern unmittelbar vor dem Schreiben des Inhalts in den Ausgabestream oder die Datei aus der Präsentation gelöscht.

Foliennummern in diesem Array sind 1‑basiert, nicht 0‑basiert; ungültige Nummern (kleiner als 1 oder größer als die Gesamtzahl der Folien) werden ignoriert.
