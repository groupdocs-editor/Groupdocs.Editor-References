## SpreadsheetEditOptions.ExcludeHiddenWorksheets property

Ermöglicht das Ausschließen versteckter Arbeitsblätter im Eingabe‑Spreadsheet‑Dokument, sodass sie vollständig ignoriert werden. Standard ist false – versteckte Arbeitsblätter sind verfügbar und werden wie üblich verarbeitet.

```csharp
public bool ExcludeHiddenWorksheets { get; set; }
```

### Hinweise

Mehrere binäre Spreadsheet‑Formate (wie XLSX) unterstützen das Konzept versteckter Arbeitsblätter (Tabs). Ein Dokument eines solchen Formats, das mehr als ein Arbeitsblatt enthält, kann zusätzliche versteckte Arbeitsblätter besitzen. Standardmäßig sind solche versteckten Arbeitsblätter für die Verarbeitung verfügbar, aber mit dieser Option können sie ignoriert werden, als wären sie nicht vorhanden. Wenn diese Option aktiviert ist, können Sie kein verstecktes Arbeitsblatt mit der '[`WorksheetIndex`](../worksheetindex)'‑Eigenschaft auswählen.
