## SpreadsheetEditOptions.ExportBogusRowData property

Wenn aktiviert, enthält die HTML‑Tabelle im erzeugten HTML‑Dokument eine leere, unten versteckte Zeile mit null Höhe und leeren Zellen, bei denen nur die Breite angegeben ist. Diese Zeile mit leeren Zellen enthält genaue Breitenwerte für jede Spalte und verbessert die Rückkonvertierung von HTML zu Spreadsheet. Standardmäßig ist sie aktiviert (`true`).

public bool ExportBogusRowData { get; set; }
