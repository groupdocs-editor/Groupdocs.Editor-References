## SpreadsheetEditOptions.MergeEmptyAdjacentCells property

Wenn aktiviert, werden die leeren benachbarten horizontalen Zellen aus dem Eingabe‑Spreadsheet‑Dokument im editierbaren HTML‑Dokument als zu einer einzigen Zelle mit dem entsprechenden `colspan`‑Attribut zusammengefasst. Standardmäßig ist sie deaktiviert (`false`).

```csharp
public bool MergeEmptyAdjacentCells { get; set; }
```

### Hinweise

Standardmäßig konvertiert GroupDocs.Editor eine Tabelle aus dem Eingabe‑Spreadsheet‑Dokument in das Ausgabe‑HTML‑Dokument, indem jede Zelle erhalten bleibt. Allerdings können Spreadsheet‑Dokumente spärlich sein – sie können große Mengen an "leeren Bereichen" enthalten, in denen viele Zellen leer sind. Diese Option fügt, wenn sie aktiviert ist, solche leeren Zellen zu einer Zelle mit dem `colspan`‑Attribut im `TD`‑Element zusammen und kann so die Größe des erzeugten HTML‑Markups erheblich reduzieren.
