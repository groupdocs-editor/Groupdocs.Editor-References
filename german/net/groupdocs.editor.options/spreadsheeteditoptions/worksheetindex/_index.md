## SpreadsheetEditOptions.WorksheetIndex property

Ermöglicht die Angabe des nullbasierten Index des Arbeitsblatts (Tabs) des Eingabe‑Spreadsheet‑Dokuments, das in HTML konvertiert werden soll (siehe Anmerkungen).

```csharp
public int WorksheetIndex { get; set; }
```

### Hinweise

Die meisten Spreadsheet‑Dokumente unterstützen das Konzept von Tabs, d. h. sie können mehrere Tabs haben. Andererseits unterstützt das HTML‑Format eine solche Struktur nicht. Deshalb kann GroupDocs.Editor nur einen bestimmten Tab des Eingabedokuments in HTML konvertieren, und diese Option ermöglicht die Angabe dieses Tabs. Der Tab‑Index ist 0‑basiert, negative Werte sind verboten. Wird ein Index angegeben, der die Anzahl aller Tabs überschreitet, wird eine Ausnahme ausgelöst. Enthält das Eingabe‑Spreadsheet‑Dokument nur einen Tab, wird diese Option ignoriert. Der Standardwert ist 0 (erster Tab).
