## SpreadsheetLoadOptions.OptimizeMemoryUsage property

Aktiviert Speicheroptimierungs‑Mechanismen während der Verarbeitung von Eingabedokumenten, die in einigen speziellen Fällen die Leistung verringern können, aber andererseits den Speicherverbrauch senken. Nützlich beim Verarbeiten riesiger Dokumente und bei Auftreten einer OutOfMemoryException. Standard ist false (Speicheroptimierung ist zum Zweck einer besseren Leistung deaktiviert).

public bool OptimizeMemoryUsage { get; set; }
