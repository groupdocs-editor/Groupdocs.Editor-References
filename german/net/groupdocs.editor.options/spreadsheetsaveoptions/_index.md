Geben Sie NULL oder einen leeren String an, um das Passwort zu entfernen (zu bereinigen). |
| [WorksheetNumber](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumber) { get; set; } | Ermöglicht das Einfügen eines bearbeiteten Arbeitsblatts in eine Kopie einer bestehenden Tabellenkalkulation anstelle der Erstellung einer neuen einblattigen Tabellenkalkulation (Standardverhalten). WorksheetNumber ist eine 1-basierte Nummer eines Arbeitsblatts in der Tabellenkalkulation, die in der Editor class geladen wurde. Ist sie 0 (Standardwert), wird die neue Tabellenkalkulation mit einem einzelnen bearbeiteten Arbeitsblatt erstellt. Ist sie größer oder kleiner als null und es gibt eine gültige Tabellenkalkulation, die in der Editor class geladen ist, wird das bearbeitete Arbeitsblatt, das durch die Eingabe-Instanz EditableDocument repräsentiert wird, in diese Tabellenkalkulation eingefügt. |

| [WorksheetProtection](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetprotection) { get; set; } | Ermöglicht das Aktivieren eines Arbeitsblattschutzes für das ausgegebene Spreadsheet‑Dokument.
