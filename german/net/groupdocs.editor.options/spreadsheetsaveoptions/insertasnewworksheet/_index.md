## SpreadsheetSaveOptions.InsertAsNewWorksheet property

Boolesches Flag, das angibt, ob das bearbeitete Arbeitsblatt das vorhandene Arbeitsblatt im ursprünglichen Tabellenblatt an der durch die [`WorksheetNumber`](../worksheetnumber)-Eigenschaft angegebenen Position ersetzen soll, oder ob es zwischen dem vorhandenen Arbeitsblatt und dem vorherigen eingefügt werden soll, ohne dessen Inhalt zu ersetzen. Standardmäßig ist es false — das vorhandene Arbeitsblatt wird ersetzt. Diese Eigenschaft wird ignoriert, wenn der Wert der [`WorksheetNumber`](../worksheetnumber)-Eigenschaft auf '0' gesetzt ist.

```csharp
public bool InsertAsNewWorksheet { get; set; }
```

### Hinweise

Standardmäßig wird das Arbeitsblatt ersetzt. Das bedeutet, dass wenn die gegebene Tabellenkalkulation 5 Arbeitsblätter hat und [`WorksheetNumber`](../worksheetnumber)=4, dann das 4. Arbeitsblatt durch das neue bearbeitete Arbeitsblatt ersetzt wird, während die Gesamtzahl der Arbeitsblätter in der Tabellenkalkulation (5) unverändert bleibt. Wird jedoch der Wert dieser Eigenschaft auf true gesetzt, wird das neue bearbeitete Arbeitsblatt als 4. Arbeitsblatt eingefügt, und alle nachfolgenden Arbeitsblätter werden ans Ende verschoben: Das \"alte\" 4. Arbeitsblatt wird zum 5., und das 5. wird zum 6., und die Gesamtzahl der Arbeitsblätter in der Tabellenkalkulation wird um eins erhöht und beträgt 6.
