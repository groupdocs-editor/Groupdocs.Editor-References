## SpreadsheetSaveOptions.WorksheetNumber property

Ermöglicht das Einfügen eines bearbeiteten Arbeitsblatts in eine Kopie einer bestehenden Tabellenkalkulation anstelle der Erstellung einer neuen einblattigen Tabellenkalkulation (Standardverhalten). WorksheetNumber ist eine 1-basierte Nummer eines Arbeitsblatts in der Tabellenkalkulation, die in der Editor class geladen wurde. Ist sie 0 (Standardwert), wird die neue Tabellenkalkulation mit einem einzelnen bearbeiteten Arbeitsblatt erstellt. Ist sie größer oder kleiner als null und es gibt eine gültige Tabellenkalkulation, die in der Editor class geladen ist, wird das bearbeitete Arbeitsblatt, das durch die Eingabe-Instanz EditableDocument repräsentiert wird, in diese Tabellenkalkulation eingefügt.

```csharp
public int WorksheetNumber { get; set; }
```

### Hinweise

WorksheetNumber ist eine ganzzahlige Eigenschaft; wenn sie nicht im Standardzustand (reservierter Wert '0') ist, stellt sie eine Arbeitsblattnummer dar, beginnend bei 1, nicht bei null, und ihr Maximalwert entspricht der Anzahl aller vorhandenen Folien in einer Präsentation. Wenn jedoch der angegebene Wert größer ist als die Anzahl aller Folien, wird GroupDocs.Editor ihn anpassen, um das letzte Arbeitsblatt zu markieren. Negative Werte sind ebenfalls zulässig und zählen die Arbeitsblätter von hinten. Zum Beispiel impliziert „-1“ das letzte Arbeitsblatt in einer Tabelle, „-2“ das vorletzte usw. Wie bei positiven Werten wird, wenn die negative Arbeitsblattnummer die Gesamtzahl der Arbeitsblätter in der angegebenen Tabelle überschreitet, sie auf das erste Arbeitsblatt angepasst. Die [`InsertAsNewWorksheet`](../insertasnewworksheet) boolesche Eigenschaft ist eng mit dieser verknüpft.

### Beispiele

Gegebene Tabelle hat 5 Arbeitsblätter: WorksheetNumber = 0; — die gegebene Tabelle ignorieren, eine neue Tabelle erstellen und das bearbeitete Arbeitsblatt dort einfügen. WorksheetNumber = 1; — das erste Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = 2; — das zweite Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = 5; — das letzte (5.) Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = 6; — das letzte (5.) Arbeitsblatt durch das bearbeitete ersetzen, weil 6 größer als 5 ist und daher angepasst wird. WorksheetNumber = -1; — das letzte (5.) Arbeitsblatt durch das bearbeitete ersetzen, weil „-1“ „letztes vorhandenes“ bedeutet. WorksheetNumber = -2; — das 4. Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = -3; — das 3. Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = -4; — das 2. Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = -5; — das erste Arbeitsblatt durch das bearbeitete ersetzen. WorksheetNumber = -6; — das erste Arbeitsblatt durch das bearbeitete ersetzen, weil „-6“ größer als 5 ist und daher angepasst wird.
