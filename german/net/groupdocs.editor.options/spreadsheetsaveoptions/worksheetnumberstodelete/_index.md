## SpreadsheetSaveOptions.WorksheetNumbersToDelete property

Ermöglicht die Angabe eines Arrays mit 1‑basierten Nummern von Arbeitsblättern, die beim Speichern der Tabellenkalkulation gelöscht werden sollen, falls das bearbeitete Arbeitsblatt in eine bestehende Tabellenkalkulation eingefügt wird.

```csharp
public int[] WorksheetNumbersToDelete { get; set; }
```

### Hinweise

Wenn das bearbeitete Arbeitsblatt nicht als neue ein‑Arbeitsblatt‑Tabelle gespeichert wird (Standardverhalten), sondern stattdessen in eine bestehende Tabelle (unter Verwendung der [`WorksheetNumber`](../worksheetnumber)-Eigenschaft) gespeichert wird, ist es ebenfalls möglich, bestimmte Arbeitsblätter aus dieser Tabelle zu löschen, indem deren Nummern in diesem Array angegeben werden.

Standardmäßig ist dieses Array `null` — es werden keine Arbeitsblätter gelöscht. Wenn das Array jedoch nicht null und nicht leer ist und mindestens eine gültige Arbeitsblatt‑Nummer enthält, werden nach der Erstellung des Ausgabedokumentes der Tabelle mit dem Inhalt des bearbeiteten Arbeitsblatts die Arbeitsblätter mit den angegebenen Nummern aus der Tabelle gelöscht, kurz bevor ihr Inhalt in den Ausgabestream oder die Datei geschrieben wird.

Arbeitsblatt‑Nummern in diesem Array sind 1‑basiert, nicht 0‑basiert; ungültige Nummern (kleiner als 1 oder größer als die Gesamtzahl der Arbeitsblätter) werden ignoriert.
