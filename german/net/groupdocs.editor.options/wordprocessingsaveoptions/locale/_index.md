## WordProcessingSaveOptions.Locale property

Ermöglicht das Überschreiben der Standard‑Locale (Sprache) für das WordProcessing‑Dokument, die bei dessen Erstellung angewendet wird. Wenn sie nicht angegeben ist (Standardwert), erkennt (oder wählt) MS Word (oder ein anderes Programm) die Dokument‑Locale anhand seiner eigenen Einstellungen oder anderer Faktoren.

```csharp
public CultureInfo Locale { get; set; }
```

### Hinweise

Diese Option wendet die angegebene Gebietssprache zwingend auf den gesamten Text im Dokument an. Nicht verwenden, wenn das Dokument verschiedene Textteile enthält, die in unterschiedlichen Sprachen geschrieben sind.
