## WordProcessingSaveOptions.LocaleFarEast property

Ermöglicht das Überschreiben der Locale (Sprache) für das WordProcessing‑Dokument für ostasiatischen Text, die bei dessen Erstellung angewendet wird. Wenn sie nicht angegeben ist (Standardwert), erkennt (oder wählt) MS Word (oder ein anderes Programm) die ostasiatische Locale des Dokuments anhand seiner eigenen Einstellungen oder anderer Faktoren.

```csharp
public CultureInfo LocaleFarEast { get; set; }
```

### Hinweise

Diese Option wendet die angegebene Gebietssprache zwingend auf den gesamten ostasiatischen Text im Dokument an. Nicht verwenden, wenn das Dokument verschiedene Textteile enthält, die in unterschiedlichen Sprachen geschrieben sind.
