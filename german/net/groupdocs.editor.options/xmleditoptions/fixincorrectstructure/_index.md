## XmlEditOptions.FixIncorrectStructure property

Ermöglicht das Aktivieren oder Deaktivieren des Mechanismus zur Korrektur einer beschädigten XML-Struktur. Standardmäßig ist deaktiviert (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Hinweise

Standardmäßig sind nur korrekte, gültige, wohlgeformte XML-Dokumente zulässig. Wenn diese Option aktiviert ist, versucht GroupDocs.Editor, beschädigte XML-Strukturen nach Möglichkeit zu reparieren.
