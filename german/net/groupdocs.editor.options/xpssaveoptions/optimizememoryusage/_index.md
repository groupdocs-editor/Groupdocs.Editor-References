## XpsSaveOptions.OptimizeMemoryUsage property

Aktiviert Speicheroptimierungsmechanismen während der Dokumenterstellung aus HTML, die die Leistung zugunsten einer verringerten Speichernutzung beeinträchtigen. Das Setzen dieser Option auf true kann den Speicherverbrauch bei der Erstellung großer Dokumente erheblich reduzieren, allerdings auf Kosten einer langsameren Speicherzeit. Standard ist false (Speicheroptimierung ist deaktiviert, um eine bessere Leistung zu erzielen).

public bool OptimizeMemoryUsage { get; set; }
