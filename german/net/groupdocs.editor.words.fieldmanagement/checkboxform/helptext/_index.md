## CheckBoxForm.HelpText property

Liest oder setzt den Hilfetext, der dem Formularfeld zugeordnet ist, die Quelle des Textes, der in einem Meldungsfeld angezeigt wird, wenn ein Formularfeld den Fokus hat und der Benutzer F1 drückt.

```csharp
public HelpText HelpText { get; set; }
```

### Hinweise

Wenn auf `false` gesetzt, wird der Hilfetext nicht angewendet.
