## EditableDocument.FromFile method

Statische Fabrik, die eine Instanz von EditableDocument aus einer HTML‑Datei erstellt, die durch einen Pfad zur *.html‑Datei selbst und einen Ordner mit verknüpften Ressourcen angegeben ist.

```csharp
public static EditableDocument FromFile(string htmlFilePath, string resourceFolderPath)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| htmlFilePath | String | String, der einen vollständigen Pfad zur HTML-Datei enthält. Darf nicht null sein, sollte ein gültiger Dateipfad sein und die Datei selbst muss existieren. |
| resourceFolderPath | String | Optionaler Pfad zum Ordner mit HTML-Ressourcen. Wenn NULL, ungültig oder der Ordner nicht existiert, versucht der Editor, diesen Ordner selbst zu finden, indem er das HTML-Markup analysiert. |

### Rückgabewert

Neue nicht-null Instanz von EditableDocument

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentException | HTML-Dateipfad und/oder der Pfad zum Ressourcenordner ist/sind ungültig. |
| FileNotFoundException | Die angegebene HTML-Datei kann nicht gefunden werden. |
