## GetContent&lt;TStream&gt;(TStream, Encoding) {#getcontent_2}

Gibt den gesamten Inhalt des HTML-Dokuments als Byte-Stream zurück, indem dieser Inhalt in den angegebenen Stream mit der angegebenen Textkodierung geschrieben wird.

```csharp
public TStream GetContent<TStream>(TStream storage, Encoding encoding)
    where TStream : Stream
```

| Parameter | Beschreibung |
| --- | --- |
| TStream | Beliebige Implementierung des Streams |
| Speicher | Nicht-null-Byte-Stream, der Schreiben unterstützt |
| Kodierung | Nicht-null-Textkodierung, die beim Schreiben von Textinhalt in den angegebenen *storage* angewendet werden sollte |

### Rückgabewert

Instanz des angegebenen *storage*

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentNullException | Einige Eingabeparameter sind null |
| ArgumentException | Der angegebene Stream ist nicht schreibbar |

## GetContent(string, string) {#getcontent_1}

Gibt den gesamten Inhalt des HTML-Dokuments als Zeichenkette zurück, wobei Links zu externen Ressourcen das angegebene Template mit Platzhaltern enthalten.

```csharp
public string GetContent(string externalImagesTemplate, string externalCssTemplate)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| externalImagesTemplate | String | Über diesen Parameter kann eine Zeichenkettenvorlage mit einem Platzhalter angegeben werden, die auf die Links zu allen externen Bildern in IMG-Elementen angewendet wird, die im resultierenden HTML-String vorkommen. Ist die Vorlage NULL oder leer, wird sie nicht hinzugefügt und es erscheinen nur reine Dateinamen im resultierenden HTML-Markup. Ist die Vorlage ungültig, wird sie als Präfix behandelt, sodass die Dateinamen an ihr Ende angehängt werden. |
| externalCssTemplate | String | Über diesen Parameter kann ein Zeichenketten-Template mit einem Platzhalter angegeben werden, das zu den Links aller externen Stylesheets in LINK-Elementen hinzugefügt wird, die im resultierenden HTML-String enthalten sein werden. Wenn NULL oder leer, wird das Template nicht hinzugefügt und reine Dateinamen werden im resultierenden HTML-Markup vorhanden sein. Ist das Template ungültig, wird es als Präfix behandelt, sodass Dateinamen an dessen Ende angehängt werden. |

### Rückgabewert

Zeichenkette, die den Inhalt des HTML-Dokuments mit Links enthält, angepasst an die externen Ressourcen
