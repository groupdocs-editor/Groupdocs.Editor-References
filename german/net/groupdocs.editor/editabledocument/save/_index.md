## Save(string, string) {#save_2}

Speichert dieses HTML-Dokument in die Datei am angegebenen Pfad, wobei das HTML-Markup gespeichert wird, und in den zugehörigen Ordner mit Ressourcen, der sich am angegebenen Pfad befindet.

```csharp
public void Save(string htmlFilePath, string resourcesFolderPath)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| htmlFilePath | String | Vollständiger Pfad zur Datei, in der das HTML-Markup gespeichert wird. Darf nicht NULL oder leer sein. Die Datei wird erstellt oder überschrieben, falls sie existiert. |
| resourcesFolderPath | String | Vollständiger Pfad zum zugehörigen Ordner, in dem alle zugehörigen Ressourcen gespeichert werden. Wenn NULL oder leer, wird der Ordner automatisch im selben Verzeichnis wie die *.html-Datei erstellt. Wenn angegeben und nicht vorhanden, wird er erstellt. |

## Save(TextWriter, HtmlSaveOptions) {#save}

Speichert den Inhalt dieses [`EditableDocument`](../../editabledocument) als HTML-Dokument in den angegebenen TextWriter, wobei der zweite Optionsparameter das Anpassen des Speicherverfahrens und das Festlegen des Ressourcen‑Speicher‑Callbacks ermöglicht.

```csharp
public void Save(TextWriter htmlMarkup, HtmlSaveOptions saveOptions)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| htmlMarkup | TextWriter | Implementierung des TextWriters, in den das HTML-Markup geschrieben wird. Darf nicht null sein. |
| saveOptions | HtmlSaveOptions | HTML‑Speicheroptionen, die das Speicherverfahren steuern: wie das HTML‑Markup gespeichert wird (Tag‑Namen, Anführungszeichen‑Typen) und wie und wo CSS sowie andere Ressourcen wie Bilder oder Schriftarten gespeichert werden. Der Benutzer sollte den Implementierer der Schnittstelle in der [`SavingCallback`](../../../groupdocs.editor.options/htmlsaveoptions/savingcallback)-Eigenschaft angeben, um zu kontrollieren, wie Ressourcen gespeichert und im HTML‑Markup referenziert werden. |

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentNullException | Einige der angegebenen Argumente oder die `SavingCallback`‑Eigenschaft in *saveOptions* sind `null`. |
