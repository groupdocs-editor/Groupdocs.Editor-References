## Editor.FormFieldManager property

Bietet Zugriff auf Funktionen zur Verwaltung von Formularfeldern im Dokument.

```csharp
public FormFieldManager FormFieldManager { get; }
```

### Rückgabewert

Eine `FormFieldManager`-Instanz zur Verwaltung von Formularfeldern im Dokument.

### Hinweise

Die `FormFieldManager`-Eigenschaft erstellt eine neue Instanz der `FormFieldManager`-Klasse, die Zugriff auf Methoden und Eigenschaften zur Verwaltung von Formularfeldern im Dokument ermöglicht. Formularfelder sind interaktive Elemente im Dokument, die Benutzereingaben erfassen oder Aktionen auslösen können. Die `FormFieldManager`-Instanz stellt Methoden für verschiedene Formularfeld‑Operationen bereit, einschließlich der Prüfung auf ungültige Formularfelder, der Aktualisierung von Formularfelddaten und der Behebung von Namensproblemen. Sie erleichtert zudem das Abrufen von Formularfeldnamen und deren zugehörigen Daten. Diese Eigenschaft ist nützlich, um programmgesteuert mit Formularfeldern zu interagieren und sie zu manipulieren, wodurch Aufgaben wie Formularfeldvalidierung, Synchronisation und Anpassung ermöglicht werden.
