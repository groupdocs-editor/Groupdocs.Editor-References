## InvalidFormatException class

Die Ausnahme, die ausgelöst wird, wenn ein Benutzer versucht, ein Dokument mit formatbezogenen Optionen zu öffnen, die mit dem ursprünglichen Dokumentformat inkompatibel sind.

```csharp
public sealed class InvalidFormatException : Exception
```

### Hinweise

Zum Beispiel wird diese Ausnahme ausgelöst, wenn versucht wird, ein Tabellenkalkulationsdokument mit Optionen für ein Textverarbeitungsdokument zu öffnen.
