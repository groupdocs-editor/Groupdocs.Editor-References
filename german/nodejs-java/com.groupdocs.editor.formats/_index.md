Der **com.groupdocs.editor.formats** Namespace stellt Schnittstellen und Klassen bereit, die unterstützte Dokumentformate beschreiben.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Kapselt alle eBook‑Formate. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Kapselt alle E‑Mail‑Formate. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Kapselt alle Fixed‑Layout‑Formate (auch bekannt als "fixed-page"), die PDF und XPS umfassen (Rasterbilder sind nicht enthalten). |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Stellt die verschiedenen im System verfügbaren Formatfamilien dar. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Kapselt alle Präsentationsformate. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Kapselt alle binären, XML‑ und textbasierten Tabellenkalkulationsformate (ausgenommen alle textbasierten, durch Trennzeichen getrennten Formate wie CSV, TSV, semikolongetrennt usw.), in denen die Arbeitsmappe gespeichert werden kann. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Kapselt alle textbasierten Formate, einschließlich Markup (XML, HTML) und anderer. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Kapselt alle Textverarbeitungsformate. |
