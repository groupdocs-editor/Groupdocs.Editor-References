Der **com.groupdocs.editor.htmlcss.css.datatypes** Namespace stellt Klassen bereit, die CSS‑Datentypen repräsentieren.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Stellt einen Farbwert im ARGB-Format mit Konvertern und Serialisierern dar. |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Enthält alle \"bekannten Farben\", die einen festen eindeutigen Namen und Wert im CSS-Standard haben. |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Stellt einen CSS-Längenwert in jeder unterstützten Einheit dar, einschließlich Prozent- und einheitenloser Typen. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Alle unterstützten Längeneinheiten |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Stellt einen \"Verhältnis\"-CSS-Datentyp dar, der zur Beschreibung von Seitenverhältnissen in Media Queries und für Rasterbilder verwendet wird, indem er das Verhältnis zwischen zwei einheitenlosen Werten namens \"Zähler\" und \"Nenner\" angibt. |
