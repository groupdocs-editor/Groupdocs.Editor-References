## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Stellt eine Schriftgröße als spezielle Einheit oder Längenwert dar, der die Größe der Schrift (historisch die Breite des Großbuchstabens \"M\") angibt. |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Definiert, wie die Schrift mit einer normalen, kursiven oder schrägen Variante aus ihrer Schriftfamilie gestaltet werden soll. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | Die Font-weight-Eigenschaft legt das Gewicht (oder die Fettigkeit) der Schrift fest. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Stellt Typen der Textdekorationslinie dar: Unterstreichung (Unterstrich), Oberstreichung und Durchstreichung (Strikethrough). |
