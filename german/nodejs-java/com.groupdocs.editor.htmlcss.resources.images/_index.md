Der **com.groupdocs.editor.htmlcss.resources.images** Namespace stellt Klassen bereit, die Bild‑Ressourcen aller Arten im Allgemeinen repräsentieren.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Stellt die linearen Abmessungen (Breite und Höhe) eines rasterförmigen Rechteckbildes in beliebiger Einheit dar. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Stellt einen unterstützbaren Bildtyp (Format) dar, unterstützt sowohl Raster- als auch Vektorformate. |

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Der Bild‑CSS‑Datentyp repräsentiert ein zweidimensionales Bild. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Stellt eine Bildressource beliebigen Typs, Raster oder Vektor, dar. |
