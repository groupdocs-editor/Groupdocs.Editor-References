Der **com.groupdocs.editor.htmlcss.resources** Namespace stellt Klassen bereit, die alle Arten von HTML‑Ressourcen repräsentieren.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | Statische Hilfsmethoden zum Erkennen von Ressourcentypen (Formaten). |

## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | Erweitert das standardmäßige IDisposable‑Interface, ermöglicht das Abrufen des aktuellen Zustands eines Objekts und das Abonnieren des Dispose‑Ereignisses. |
| [IHtmlResource](../com.groupdocs.editor.htmlcss.resources/ihtmlresource) | Stellt eine Instanz einer unbekannten HTML‑Ressource dar (Raster‑ oder Vektor‑Bild, Stylesheet, Schriftart, Textressource (CSS, XML) usw.). |
| [IResourceType](../com.groupdocs.editor.htmlcss.resources/iresourcetype) | Stellt eine Instanz eines unbekannten Ressourcentyps/Formats dar (Bild, Schriftart, Text). |
