Der **com.groupdocs.editor.htmlcss.serialization** Namespace stellt Typen bereit, die für die Feinabstimmung des Serialisierungsprozesses von HTML‑ und CSS‑Markup verantwortlich sind.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [QuoteType](../com.groupdocs.editor.htmlcss.serialization/quotetype) | Stellt Anführungszeichen dar – einfaches Anführungszeichen (') und doppeltes Anführungszeichen (\"). |
| [TagRenderingCase](../com.groupdocs.editor.htmlcss.serialization/tagrenderingcase) | Stellt verschiedene Arten der Serialisierung der HTML-Tag-Namen dar. |
