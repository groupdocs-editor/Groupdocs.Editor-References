Enthält verfügbare Optionen für die Behandlung von führenden Leerzeichen beim Öffnen einer einfachen
Textdokument (TXT)

## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [ConvertToIndent](#ConvertToIndent) | Konvertiere ein oder mehrere aufeinanderfolgende Leerzeichen in den linken Einzug. |
|
|  | [Preserve](#Preserve) | Gib alle führenden Leerzeichen an das Ausgabe‑HTML "as is" weiter, ohne sie zu verändern |
|
|  | [Trim](#Trim) | Entferne (abschneiden) alle führenden Leerzeichen vollständig |
|
