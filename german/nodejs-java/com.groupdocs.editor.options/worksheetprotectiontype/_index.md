## Felder

| Feld | Beschreibung |
| --- | --- |

|  | [Contents](#Contents) | Benutzer kann keine Daten im Tabellenblatt eingeben |

|
|  | [Scenarios](#Scenarios) | Benutzer kann gespeicherte Szenarien nicht ändern |

|  | [Structure](#Structure) | Benutzer kann die Struktur nicht ändern |
