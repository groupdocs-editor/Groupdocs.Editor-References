Der **com.groupdocs.editor** Namespace ist ein Root‑Namespace, der Klassen zum Bearbeiten mehrerer Dokumentformate in Ihren Java‑Anwendungen bereitstellt.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Zwischendokument, das Inhalte vor und nach der Bearbeitung enthält. |
| [Editor](../com.groupdocs.editor/editor) | Hauptklasse, die Konvertierungsmethoden kapselt. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | Die Ausnahme, die ausgelöst wird, wenn ein Benutzer versucht, ein Dokument zu öffnen, das mit X509Certificates verschlüsselt wurde. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | Die Ausnahme, die ausgelöst wird, wenn das angegebene Passwort falsch ist. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | Die Ausnahme, die ausgelöst wird, wenn ein Benutzer versucht, ein Dokument mit formatbezogenen Optionen zu öffnen, die mit dem ursprünglichen Dokumentformat inkompatibel sind. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | Die Ausnahme, die ausgelöst wird, wenn ein Benutzer versucht, ein passwortgeschütztes, verschlüsseltes Dokument eines Formats zu öffnen und kein Passwort zum Öffnen dieses Dokuments bereitstellt. |
