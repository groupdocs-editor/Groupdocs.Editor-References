Το **com.groupdocs.editor.formats.abstraction** namespace παρέχει διεπαφές και κλάσεις που περιγράφουν τις υποστηριζόμενες μορφές εγγράφων στη βιβλιοθήκη GroupDocs.Editor.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DocumentFormatBase](../com.groupdocs.editor.formats.abstraction/documentformatbase) | Αντιπροσωπεύει τη βασική κλάση για μορφότυπους εγγράφων, παρέχοντας κοινή λειτουργικότητα για τις περιπτώσεις μορφής. |
| [FormatFamilyBase](../com.groupdocs.editor.formats.abstraction/formatfamilybase) | Αντιπροσωπεύει τη βασική κλάση για οικογένειες μορφότυπων, παρέχοντας κοινή λειτουργικότητα για τις περιπτώσεις οικογένειας μορφότυπου. |

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IDocumentFormat](../com.groupdocs.editor.formats.abstraction/idocumentformat) | Αντιπροσωπεύει τη ριζική διεπαφή για όλα τα υποστηριζόμενα μορφότυπα εγγράφων. |
