Το **com.groupdocs.editor.formats** namespace παρέχει διεπαφές και κλάσεις που περιγράφουν τις υποστηριζόμενες μορφές εγγράφων.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Περιλαμβάνει όλες τις μορφές eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Περιλαμβάνει όλες τις μορφές email. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Περιλαμβάνει όλες τις μορφές σταθερής διάταξης (επίσης γνωστές ως \"fixed-page\"), οι οποίες περιλαμβάνουν PDF και XPS (αυτό δεν περιλαμβάνει εικόνες raster) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Αντιπροσωπεύει τις διαφορετικές οικογένειες μορφών που είναι διαθέσιμες στο σύστημα. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Περιλαμβάνει όλες τις μορφές Presentation. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Περιλαμβάνει όλες τις δυαδικές, XML και κειμενικές μορφές Spreadsheet (εξαιρώντας όλες τις κειμενικές μορφές βασισμένες σε διαχωριστικά με διαχωριστή όπως CSV, TSV, μορφές διαχωρισμένες με ερωτηματικό κ.λπ.), στις οποίες μπορεί να αποθηκευτεί το βιβλίο εργασίας. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Περιλαμβάνει όλες τις κειμενικές (βασισμένες σε κείμενο) μορφές, συμπεριλαμβανομένων των σήμανσης (XML, HTML) και άλλων. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Περιλαμβάνει όλες τις μορφές WordProcessing. |
