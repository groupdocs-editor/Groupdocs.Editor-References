Το **com.groupdocs.editor.htmlcss.css.datatypes** namespace παρέχει κλάσεις που αντιπροσωπεύουν τύπους δεδομένων CSS.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Αντιπροσωπεύει μια τιμή χρώματος σε μορφή ARGB με μετατροπείς και σειριοποιητές |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Περιέχει όλα τα \"γνωστά χρώματα\", που έχουν σταθερό μοναδικό όνομα και τιμή στο πρότυπο CSS |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Αντιπροσωπεύει μια τιμή μήκους CSS σε οποιαδήποτε υποστηριζόμενη μονάδα, συμπεριλαμβανομένου του ποσοστού και του τύπου χωρίς μονάδα. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Όλες οι υποστηριζόμενες μονάδες μήκους |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Αντιπροσωπεύει έναν τύπο δεδομένων CSS \"ratio\", ο οποίος χρησιμοποιείται για την περιγραφή των αναλογιών διαστάσεων σε ερωτήματα μέσων και για εικόνες raster, δηλώνοντας την αναλογία μεταξύ δύο τιμών χωρίς μονάδα που ονομάζονται \"αριθμητής\" και \"παρονομαστής\". |
