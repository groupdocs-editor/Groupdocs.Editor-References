Το **com.groupdocs.editor.htmlcss.exceptions** namespace παρέχει εξαιρέσεις που ρίχνονται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο κάποιο περιεχόμενο.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [InvalidFontFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidfontformatexception) | Η εξαίρεση που ρίχνεται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο κάποιο περιεχόμενο, το οποίο υποτίθεται ότι είναι μια γραμματοσειρά υποστηριζόμενης (γνωστής) μορφής, αλλά στην πραγματικότητα είναι μια γραμματοσειρά μη υποστηριζόμενης ή απροσδόκητης μορφής ή καθόλου δεν είναι γραμματοσειρά. |
| [InvalidImageFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | Η εξαίρεση που ρίχνεται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο κάποιο περιεχόμενο, το οποίο υποτίθεται ότι είναι μια εικόνα (ραστερική ή διανυσματική), αλλά στην πραγματικότητα είναι μια εικόνα απροσδόκητου τύπου ή καθόλου δεν είναι εικόνα. |
