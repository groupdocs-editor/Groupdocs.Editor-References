Το **com.groupdocs.editor.htmlcss.resources.images** namespace παρέχει κλάσεις που αντιπροσωπεύουν πόρους εικόνας όλων των τύπων γενικά.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Αντιπροσωπεύει τις γραμμικές διαστάσεις (πλάτος και ύψος) μιας ραστερικής ορθογώνιας εικόνας σε αυθαίρετη μονάδα. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Αντιπροσωπεύει έναν υποστηριζόμενο τύπο εικόνας (format), υποστηρίζει τόσο ραστερικές όσο και διανυσματικές μορφές. |

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Ο τύπος δεδομένων Image CSS αντιπροσωπεύει μια δισδιάστατη εικόνα. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Αντιπροσωπεύει πόρο εικόνας οποιουδήποτε τύπου, ραστερικό ή διανυσματικό. |
