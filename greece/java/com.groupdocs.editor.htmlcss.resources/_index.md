Το **com.groupdocs.editor.htmlcss.resources** namespace παρέχει κλάσεις που αντιπροσωπεύουν όλα τα είδη των πόρων HTML.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | Στατικές βοηθητικές μεθόδους για την ανίχνευση τύπων πόρων (formats). |

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | Επεκτείνει το τυπικό interface IDisposable, επιτρέπει την απόκτηση της τρέχουσας κατάστασης ενός αντικειμένου και την εγγραφή στο γεγονός διαγραφής. |
| [IHtmlResource](../com.groupdocs.editor.htmlcss.resources/ihtmlresource) | Αντιπροσωπεύει μια παρουσία του άγνωστου πόρου HTML (ραστερική ή διανυσματική εικόνα, stylesheet, γραμματοσειρά, πόρος κειμένου (CSS, XML) κ.λπ.). |
| [IResourceType](../com.groupdocs.editor.htmlcss.resources/iresourcetype) | Αντιπροσωπεύει μια παρουσία του άγνωστου τύπου/μορφής πόρου (εικόνα, γραμματοσειρά, κείμενο). |
