Το **com.groupdocs.editor.metadata** namespace παρέχει κλάσεις για την περιγραφή βασικών ιδιοτήτων εγγράφου που εξαρτώνται από τον τύπο του εγγράφου.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου EBook |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου email οποιασδήποτε υποστηριζόμενης μορφής email |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου με μορφή σταθερής διάταξης όπως PDF ή XPS |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου Markdown |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου Presentation |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου Spreadsheet |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός κειμενικού εγγράφου όπως XML, HTML ή απλό κείμενο (TXT) |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Αντιπροσωπεύει τα μεταδεδομένα ενός εγγράφου WordProcessing |
