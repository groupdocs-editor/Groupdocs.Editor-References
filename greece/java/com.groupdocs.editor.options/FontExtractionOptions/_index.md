### ExtractAllEmbedded {#ExtractAllEmbedded}
```
public static final int ExtractAllEmbedded
```


Εξάγει όλους τους πόρους γραμματοσειρών που είναι ενσωματωμένοι στο εισαγόμενο Word
έγγραφο, ανεξάρτητα από το τι είναι: προσαρμοσμένες ή συστημικές.


*** ** * ** ***

Ο μετατροπέας εντοπίζει και εξάγει όλους τους πόρους γραμματοσειρών 100%, οι οποίοι είναι ενσωματωμένοι στο εισαγόμενο έγγραφο WordProcessing, αλλά δεν καθορίζει εάν είναι συστημικές ή προσαρμοσμένες· δεν αγγίζει καθόλου το Windows Registry ή τους φακέλους του συστήματος.

<br />



### ExtractEmbeddedWithoutSystem {#ExtractEmbeddedWithoutSystem}
```
public static final int ExtractEmbeddedWithoutSystem
```


Εξάγει μόνο εκείνους τους ενσωματωμένους πόρους γραμματοσειρών που είναι προσαρμοσμένοι (όχι
συστημικοί)


*** ** * ** ***

Ο μετατροπέας εντοπίζει και εξάγει όλους τους ενσωματωμένους πόρους γραμματοσειρών, και στη συνέχεια προσπαθεί να καθορίσει ποιες από αυτές τις γραμματοσειρές είναι συστημικές και ποιες όχι. Για να το πετύχει, ο μετατροπέας προσπαθεί να λάβει μια λίστα με όλες τις συστημικές γραμματοσειρές χρησιμοποιώντας το Windows Registry και τους φακέλους του συστήματος, και στη συνέχεια συγκρίνει αυτή τη λίστα με το σύνολο των ενσωματωμένων γραμματοσειρών. Ως αποτέλεσμα, θα επιστραφεί μόνο ένα υποσύνολο των ενσωματωμένων γραμματοσειρών που δεν βρέθηκαν στο σύστημα.

<br />



### ExtractAll {#ExtractAll}
```
public static final int ExtractAll
```


Προσπαθεί να εξάγει όλες τις γραμματοσειρές που χρησιμοποιούνται στην εισαγόμενη WordProcessing
έγγραφο, συμπεριλαμβανομένων των συστημικών γραμματοσειρών.


*** ** * ** ***

Ο μετατροπέας αναλύει ένα εισαγόμενο έγγραφο WordProcessing και εντοπίζει όλες τις γραμματοσειρές που χρησιμοποιούνται. Εάν όλες αυτές οι γραμματοσειρές είναι ενσωματωμένες στο εισαγόμενο έγγραφο, ο μετατροπέας τις εξάγει και τις επιστρέφει. Διαφορετικά, εάν μια συλλογή ενσωματωμένων γραμματοσειρών δεν καλύπτει όλες τις χρησιμοποιημένες γραμματοσειρές στο έγγραφο ή είναι κενή, ο μετατροπέας προσπαθεί να εξάγει αυτούς τους πόρους γραμματοσειρών από το σύστημα, χρησιμοποιώντας το Windows Registry και τους φακέλους του συστήματος.
