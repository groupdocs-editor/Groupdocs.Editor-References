Αναπαριστά τύπους προστασίας φύλλου εργασίας (καρτέλας) Spreadsheet.

## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
|  | [None](#None) | Η προστασία δεν εφαρμόζεται (προεπιλεγμένη τιμή) |
|
|  | [All](#All) | Ο χρήστης δεν μπορεί να τροποποιήσει τίποτα στο φύλλο εργασίας |
|
|  | [Contents](#Contents) | Ο χρήστης δεν μπορεί να εισάγει δεδομένα στο φύλλο εργασίας |
|
|  | [Objects](#Objects) | Ο χρήστης δεν μπορεί να τροποποιήσει αντικείμενα σχεδίασης |
|
|  | [Scenarios](#Scenarios) | Ο χρήστης δεν μπορεί να τροποποιήσει αποθηκευμένα σενάρια |
|
|  | [Structure](#Structure) | Ο χρήστης δεν μπορεί να τροποποιήσει τη δομή |
|
|  | [Window](#Window) | Ο χρήστης δεν μπορεί να τροποποιήσει το παράθυρο |
