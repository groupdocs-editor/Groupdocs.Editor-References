## IImage interface

Ο τύπος δεδομένων Image CSS αντιπροσωπεύει μια δισδιάστατη εικόνα.

```csharp
public interface IImage
```

### Σχόλια

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS reference δηλώνει 4 τύπους εικόνων που μπορούν να διαχειριστούν: 1. Εικόνες με ενδογενείς διαστάσεις (φυσικό μέγεθος) και, συνεπώς, σταθερό λόγο διαστάσεων, που περιλαμβάνουν όλες τις ραστερ εικόνες. 2. Εικόνες με πολλαπλές ενδογενείς διαστάσεις, που υπάρχουν σε πολλαπλές εκδόσεις μέσα σε ένα αρχείο, που περιλαμβάνουν αρχεία ICON (*.ico). Αυτό μπορεί επίσης να είναι TIFF, καθώς υποστηρίζει πολλαπλές εικόνες μέσα σε ένα αρχείο, όμως η μορφή TIFF δεν υποστηρίζεται στο web. 3. Εικόνες χωρίς ενδογενείς διαστάσεις αλλά με ενδογενή λόγο διαστάσεων μεταξύ του πλάτους και του ύψους. Αυτό περιλαμβάνει όλες τις διανυσματικές εικόνες, πρώτα το SVG. 4. Εικόνες χωρίς ούτε ενδογενείς διαστάσεις, ούτε ενδογενή λόγο διαστάσεων. Αυτό περιλαμβάνει όλα τα gradients.
