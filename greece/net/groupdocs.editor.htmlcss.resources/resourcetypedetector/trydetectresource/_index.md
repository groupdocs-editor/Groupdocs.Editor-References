## ResourceTypeDetector.TryDetectResource method

Προσπαθεί να αναλύσει μια ροή εισόδου και δημιουργεί έναν από τους υποστηριζόμενους πόρους HTML από αυτήν, λαμβάνοντας υπόψη έναν καθορισμένο υποθετικό τύπο, εάν δεν είναι null

```csharp
public static IHtmlResource TryDetectResource(Stream inputResourceStream, string name, 
    IResourceType assumptiveFormat)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| inputResourceStream | Ρεύμα | Ροή εισόδου, η οποία υποτίθεται ότι περιέχει έναν πόρο HTML. Εάν είναι άκυρη, θα ριχθεί εξαίρεση. |
| όνομα | String | Όνομα πόρου, το οποίο θα χρησιμοποιηθεί για τον δημιουργηθέντα και επιστρεφόμενο πόρο σε περίπτωση επιτυχίας. Δεν μπορεί να είναι NULL, κενό ή μόνο λευκοί χαρακτήρες. |
| assumptiveFormat | IResourceType | Υποτιθέμενη μορφή του εισερχόμενου πόρου HTML, η οποία είναι χρήσιμη για την επίτευξη της καλύτερης απόδοσης. Εάν είναι εντελώς άγνωστη, χρησιμοποιήστε την τιμή NULL. Μπορεί να είναι λανθασμένη, κάτι που θα μειώσει μόνο την απόδοση. |

### Τιμή Επιστροφής

Στιγμιότυπο, το οποίο υλοποιεί τη διεπαφή 'IHtmlResource' και αντιπροσωπεύει έναν από τους υποστηριζόμενους πόρους HTML σε περίπτωση επιτυχίας, ή NULL σε περίπτωση αποτυχίας.
