## EbookDocumentInfo.PageCount property

Επιστρέφει τον αριθμό των σελίδων σε περίπτωση MOBI ή AZW3 ή τον αριθμό των κεφαλαίων σε περίπτωση ePub.

```csharp
public int PageCount { get; }
```

### Σχόλια

Τα έγγραφα e-Book συνήθως δεν έχουν σταθερές σελίδες και επομένως δεν υπάρχει αριθμός σελίδων. Στην περίπτωση του ePub είναι δυνατόν να υπολογιστεί ο αριθμός των κεφαλαίων. Ωστόσο, οι μορφές MOBI και AZW3 επίσης δεν έχουν κεφάλαια, έτσι αυτός ο αριθμός υπολογίζεται από το τυπικό μέγεθος σελίδας ορισμένο σε A4 σε πορτραίτο προσανατολισμό.
