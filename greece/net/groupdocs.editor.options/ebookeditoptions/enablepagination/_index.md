## EbookEditOptions.EnablePagination property

Επιτρέπει την ενεργοποίηση ή απενεργοποίηση της σελιδοποίησης στο τελικό έγγραφο HTML. Από προεπιλογή είναι απενεργοποιημένη (`false`).

```csharp
public bool EnablePagination { get; set; }
```

### Σχόλια

Στην ουσία, τα περισσότερα φορμά e‑book εσωτερικά είναι μορφή ροής όπως το Office Open XML, όπου το περιεχόμενο είναι συνεχές και χωρίζεται σε κεφάλαια αλλά όχι σε σελίδες. Ωστόσο, περιέχει ορισμένες πληροφορίες ειδικές για τις σελίδες, όπως αριθμούς σελίδων, υποσημειώσεις, κεφαλίδες/υποσέλιδα κ.λπ. Ορισμένοι αναγνώστες e‑book πραγματοποιούν διαίρεση του περιεχομένου σε σελίδες, ενώ άλλοι (ιδιαίτερα σε κινητές συσκευές) — όχι. Αυτή η επιλογή επιτρέπει τον έλεγχο του πώς το περιεχόμενο του e‑book θα πρέπει να εμφανίζεται σε HTML/CSS κατά την επεξεργασία — σε προβολή float (`false`) ή paged (`true`).
