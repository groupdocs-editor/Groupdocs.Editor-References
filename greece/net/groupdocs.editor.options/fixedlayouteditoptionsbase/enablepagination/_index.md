## FixedLayoutEditOptionsBase.EnablePagination property

Επιτρέπει την ενεργοποίηση (true) ή την απενεργοποίηση (false) της σελιδοποίησης στο τελικό έγγραφο HTML. Προεπιλεγμένα είναι απενεργοποιημένη (false).

```csharp
public bool EnablePagination { get; set; }
```

### Σχόλια

Τα έγγραφα μορφής σταθερής διάταξης (PDF και XPS ειδικότερα) στην ουσία τους είναι αυστηρά σελιδοποιημένα, το περιεχόμενό τους έχει σταθερή διάταξη και χωρίζεται σε σελίδες. Ωστόσο το παραγόμενο επεξεργάσιμο HTML μπορεί να εμφανιστεί είτε χωρίς σελίδες (pageless) είτε σε σελιδοποιημένη (paginal) προβολή.
