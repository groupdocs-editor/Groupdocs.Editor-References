## HtmlSaveOptions.SavingCallback property

Διεπαφή, η οποία πρέπει να υλοποιηθεί από τον τελικό χρήστη για την αποθήκευση όλων των εξωτερικών πόρων HTML. Αυτή η ιδιότητα **πρέπει** να μην είναι `null`, διαφορετικά το GroupDocs.Editor θα ρίξει εξαίρεση κατά την αποθήκευση του [`EditableDocument`](../../../groupdocs.editor/editabledocument) σε μορφή HTML.

```csharp
public IHtmlSavingCallback SavingCallback { get; set; }
```

### Σχόλια

Εάν η τιμή της ιδιότητας [`EmbedStylesheetsIntoMarkup`](../embedstylesheetsintomarkup) οριστεί σε `true`, όλα τα stylesheets θα ενσωματωθούν στο HTML markup και έτσι δεν θα περάσουν σε αυτήν την κλήση αποθήκευσης.
