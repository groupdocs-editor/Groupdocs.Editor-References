## MarkdownSaveOptions.ImagesFolder property

public string ImagesFolder { get; set; }

### Σχόλια

Εάν δεν έχει οριστεί ούτε το `ImagesFolder` ούτε το [`ExportImagesAsBase64`](../exportimagesasbase64) από τον χρήστη, τότε το GroupDocs.Editor θα προσπαθήσει να προσδιορίσει το `ImagesFolder` αυτόματα και θα το εφαρμόσει σε περίπτωση επιτυχίας
