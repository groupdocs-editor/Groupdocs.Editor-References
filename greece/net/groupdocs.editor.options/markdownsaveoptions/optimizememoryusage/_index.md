## MarkdownSaveOptions.OptimizeMemoryUsage property

Ενεργοποιεί μηχανισμούς βελτιστοποίησης μνήμης κατά τη δημιουργία εγγράφων από HTML, κάτι που μειώνει την απόδοση ως κόστος μείωσης της χρήσης μνήμης. Ορίζοντας αυτήν την επιλογή σε `true` μπορεί να μειώσει σημαντικά την κατανάλωση μνήμης κατά τη δημιουργία μεγάλων εγγράφων με κόστος πιο αργού χρόνου αποθήκευσης. Η προεπιλογή είναι `false` (η βελτιστοποίηση μνήμης είναι απενεργοποιημένη για την καλύτερη απόδοση).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
