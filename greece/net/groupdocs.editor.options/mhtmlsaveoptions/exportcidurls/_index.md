## MhtmlSaveOptions.ExportCidUrls property

Καθορίζει εάν θα χρησιμοποιηθούν URLs CID (Content-ID) για την αναφορά πόρων (εικόνες, γραμματοσειρές, CSS) που περιλαμβάνονται στα έγγραφα MHTML. Η προεπιλεγμένη τιμή είναι `false`.

```csharp
public bool ExportCidUrls { get; set; }
```

### Σχόλια

Από προεπιλογή, οι πόροι σε έγγραφα MHTML αναφέρονται με το όνομα αρχείου (π.χ., "image.png"), το οποίο ταιριάζει με τις κεφαλίδες "Content-Location" των τμημάτων MIME. Αυτή η επιλογή ενεργοποιεί μια εναλλακτική μέθοδο, όπου οι αναφορές σε αρχεία πόρων γράφονται ως CID (Content-ID) URLs (π.χ., "cid:image.png") και ταιριάζουν με τις κεφαλίδες "Content-ID".

Στη θεωρία, δεν θα πρέπει να υπάρχει διαφορά μεταξύ των δύο μεθόδων αναφοράς και καμία από αυτές δεν πρέπει να παρουσιάζει προβλήματα σε οποιονδήποτε περιηγητή ή πρόγραμμα αλληλογραφίας. Στην πράξη, ωστόσο, ορισμένα προγράμματα αποτυγχάνουν να ανακτήσουν πόρους με βάση το όνομα αρχείου. Εάν ο περιηγητής ή το πρόγραμμα αλληλογραφίας σας αρνείται να φορτώσει πόρους που περιλαμβάνονται σε έγγραφο MTHML (δεν εμφανίζει εικόνες ή δεν φορτώνει στυλ CSS), δοκιμάστε να εξάγετε το έγγραφο με CID URLs.
