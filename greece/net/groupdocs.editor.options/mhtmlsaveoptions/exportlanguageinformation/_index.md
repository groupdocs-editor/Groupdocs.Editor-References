## MhtmlSaveOptions.ExportLanguageInformation property

Καθορίζει εάν θα εξαχθεί η πληροφορία γλώσσας στο MHTML. Η προεπιλεγμένη τιμή είναι `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### Σχόλια

Όταν αυτή η ιδιότητα οριστεί σε `true`, το GroupDocs.Editor εκδίδει το HTML-attribute `lang` στα στοιχεία του εγγράφου που καθορίζουν τη γλώσσα. Αυτό μπορεί να χρειαστεί για τη διατήρηση της σημασιολογίας που σχετίζεται με τη γλώσσα.
