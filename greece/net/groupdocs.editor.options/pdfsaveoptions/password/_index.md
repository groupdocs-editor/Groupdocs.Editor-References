## PdfSaveOptions.Password property

Κωδικός πρόσβασης που θα εφαρμοστεί στο παραγόμενο PDF έγγραφο ως κωδικός χρήστη, απαιτούμενος για άνοιγμα. Εάν είναι NULL ή κενός, δεν θα εφαρμοστεί κωδικός στο έγγραφο. Διαφορετικά, το έγγραφο θα κρυπτογραφηθεί με RC4 (μήκος κλειδιού 128 bit). Προεπιλογή είναι NULL — ο κωδικός δεν εφαρμόζεται.

```csharp
public string Password { get; set; }
```
