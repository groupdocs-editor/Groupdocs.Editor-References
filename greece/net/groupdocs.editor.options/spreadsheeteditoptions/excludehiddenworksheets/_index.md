## SpreadsheetEditOptions.ExcludeHiddenWorksheets property

Επιτρέπει την εξαίρεση κρυφών φύλλων εργασίας στο εισερχόμενο έγγραφο Spreadsheet, ώστε να αγνοηθούν εντελώς. Από προεπιλογή είναι ψευδές — τα κρυφά φύλλα εργασίας είναι διαθέσιμα και επεξεργάζονται κανονικά.

```csharp
public bool ExcludeHiddenWorksheets { get; set; }
```

### Σχόλια

Πολλές δυαδικές μορφές Spreadsheet (όπως το XLSX) υποστηρίζουν την έννοια των κρυφών φύλλων εργασίας (καρτέλες). Ένα έγγραφο τέτοιας μορφής, εάν έχει περισσότερα από ένα φύλλα εργασίας, μπορεί να περιέχει επιπλέον κρυφά φύλλα. Από προεπιλογή, αυτά τα κρυφά φύλλα είναι διαθέσιμα για επεξεργασία, αλλά με αυτήν την επιλογή μπορούν να αγνοηθούν, σαν να δεν υπάρχουν. Όταν αυτή η επιλογή είναι ενεργοποιημένη, δεν μπορείτε να επιλέξετε κρυφό φύλλο εργασίας με την ιδιότητα '[`WorksheetIndex`](../worksheetindex)'.
