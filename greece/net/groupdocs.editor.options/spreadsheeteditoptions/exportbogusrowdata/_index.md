## SpreadsheetEditOptions.ExportBogusRowData property

Όταν είναι ενεργοποιημένο, ο πίνακας HTML στο παραγόμενο έγγραφο HTML περιέχει μια κενή κάτω κρυφή σειρά με μηδενικό ύψος και κενά κελιά, όπου καθορίζεται μόνο το πλάτος. Αυτή η σειρά με κενά κελιά περιέχει ακριβείς τιμές πλάτους για κάθε στήλη και βελτιώνει την αντίστροφη μετατροπή από HTML σε Spreadsheet. Από προεπιλογή είναι ενεργοποιημένο (`true`).

public bool ExportBogusRowData { get; set; }
