## SpreadsheetEditOptions.MergeEmptyAdjacentCells property

Όταν είναι ενεργοποιημένο, τα κενά διπλασιασμένα οριζόντια κελιά από το εισερχόμενο έγγραφο Spreadsheet θα αναπαριστώνται στο επεξεργάσιμο έγγραφο HTML ως συγχωνευμένα σε ένα μόνο κελί με το αντίστοιχο χαρακτηριστικό `colspan`. Από προεπιλογή είναι απενεργοποιημένο (`false`).

```csharp
public bool MergeEmptyAdjacentCells { get; set; }
```

### Σχόλια

Από προεπιλογή, το GroupDocs.Editor μετατρέπει έναν πίνακα από το εισερχόμενο έγγραφο Spreadsheet στο έξοδο HTML διατηρώντας κάθε κελί. Ωστόσο, τα έγγραφα Spreadsheet μπορεί να είναι αραιά — μπορεί να περιέχουν τεράστιες ποσότητες κενών περιοχών, όπου πολλά κελιά είναι κενά. Αυτή η επιλογή, όταν είναι ενεργοποιημένη, συγχωνεύει τέτοια κενά κελιά σε ένα με το χαρακτηριστικό `colspan` στο στοιχείο `TD`, μειώνοντας έτσι σημαντικά το μέγεθος του παραγόμενου κώδικα HTML.
