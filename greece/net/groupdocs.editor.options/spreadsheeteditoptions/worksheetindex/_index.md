## SpreadsheetEditOptions.WorksheetIndex property

Επιτρέπει τον καθορισμό του δείκτη που ξεκινά από το 0 του φύλλου εργασίας (καρτέλας) του εισερχόμενου εγγράφου Spreadsheet, το οποίο πρέπει να μετατραπεί σε HTML (δείτε τις παρατηρήσεις).

```csharp
public int WorksheetIndex { get; set; }
```

### Σχόλια

Τα περισσότερα έγγραφα Spreadsheet υποστηρίζουν την έννοια των καρτελών, δηλαδή μπορούν να έχουν πολλές καρτέλες. Από την άλλη πλευρά, η μορφή HTML δεν υποστηρίζει τέτοια δομή. Γι' αυτό το GroupDocs.Editor μπορεί να μετατρέψει σε HTML μόνο μία συγκεκριμένη καρτέλα του εισερχόμενου εγγράφου, και αυτή η επιλογή επιτρέπει τον καθορισμό της. Ο δείκτης καρτέλας είναι μηδενικής βάσης, οι αρνητικές τιμές απαγορεύονται. Εάν ο καθορισμένος δείκτης υπερβαίνει τον αριθμό όλων των καρτελών, θα προκληθεί εξαίρεση. Εάν το εισερχόμενο έγγραφο Spreadsheet περιέχει μόνο μία καρτέλα, αυτή η επιλογή θα αγνοηθεί. Η προεπιλεγμένη τιμή είναι 0 (πρώτη καρτέλα).
