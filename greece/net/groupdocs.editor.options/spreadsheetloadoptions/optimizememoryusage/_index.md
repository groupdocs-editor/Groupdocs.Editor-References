## SpreadsheetLoadOptions.OptimizeMemoryUsage property

Ενεργοποιεί μηχανισμούς βελτιστοποίησης μνήμης κατά την επεξεργασία του εισερχόμενου εγγράφου, οι οποίοι μπορεί να μειώσουν την απόδοση σε ορισμένες ειδικές περιπτώσεις, αλλά από την άλλη πλευρά μειώνουν τη χρήση μνήμης. Χρήσιμο όταν επεξεργάζεστε τεράστια έγγραφα και αντιμετωπίζετε OutOfMemoryException. Η προεπιλογή είναι false (η βελτιστοποίηση μνήμης είναι απενεργοποιημένη για καλύτερη απόδοση).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
