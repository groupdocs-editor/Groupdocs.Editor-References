## WordProcessingEditOptions.EnableLanguageInformation property

Καθορίζει εάν οι πληροφορίες γλώσσας εξάγονται στο HTML markup με τη μορφή των χαρακτηριστικών 'lang'. Αυτή η επιλογή μπορεί να είναι χρήσιμη για μετατροπή κυκλικής διαδρομής εγγράφων πολλαπλών γλωσσών. Από προεπιλογή είναι απενεργοποιημένη (false).
