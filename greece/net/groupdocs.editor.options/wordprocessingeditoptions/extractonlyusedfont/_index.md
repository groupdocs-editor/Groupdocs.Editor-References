## WordProcessingEditOptions.ExtractOnlyUsedFont property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα εξάγονται μόνο οι πόροι γραμματοσειράς που χρησιμοποιούνται στο κειμενικό περιεχόμενο του εγγράφου.

```csharp
public bool ExtractOnlyUsedFont { get; set; }
```

### Property Value

`true` εάν απαιτείται η εξαγωγή μόνο εκείνων των πόρων γραμματοσειρών που χρησιμοποιούνται στο κείμενο του εγγράφου· διαφορετικά, `false`. Η προεπιλεγμένη τιμή είναι `false`.

### Σχόλια

Δεν χρησιμοποιούνται όλες οι γραμματοσειρές που υπάρχουν στο έγγραφο WordProcessing άμεσα (εφαρμόζονται σε κάποιο κείμενο) στο 100 %. Μπορεί να υπάρξει περίπτωση όπου μια γραμματοσειρά αναφέρεται στο έγγραφο και ακόμη μπορεί να είναι ενσωματωμένη, αλλά δεν εφαρμόζεται σε κανένα τμήμα κειμένου. Για παράδειγμα, κάποια γραμματοσειρά μπορεί να είναι συνδεδεμένη με κάποιο στυλ, αλλά αυτό το στυλ δεν εφαρμόζεται σε κανένα μέρος του κειμένου. Αυτή η επιλογή ελέγχει πώς να επεξεργαστεί τέτοιες περιπτώσεις.
