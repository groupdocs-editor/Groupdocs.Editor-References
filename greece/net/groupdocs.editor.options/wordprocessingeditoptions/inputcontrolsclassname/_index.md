## WordProcessingEditOptions.InputControlsClassName property

Επιτρέπει τον καθορισμό ενός ονόματος κλάσης, το οποίο θα τοποθετηθεί στα χαρακτηριστικά 'class' σε κάθε στοιχείο HTML που αντιπροσωπεύει κάποιο πεδίο στο εισερχόμενο έγγραφο WordProcessing. Από προεπιλογή είναι NULL - τα χαρακτηριστικά 'class' δεν εφαρμόζονται.

```csharp
public string InputControlsClassName { get; set; }
```

### Σχόλια

Σχεδόν όλες οι μορφές της οικογένειας μορφών WordProcessing περιέχουν πεδία — συγκεκριμένες οντότητες εγγράφου που επιτρέπουν τη λήψη δεδομένων εισόδου από τους χρήστες. Υπάρχει μεγάλη ποικιλία πεδίων: πλαίσια κειμένου, πλαίσια ελέγχου, συνδυαστικά πλαίσια, λίστες πτυσσόμενων επιλογών, κουμπιά, επιλογείς ημερομηνίας/ώρας κ.λπ. Όλα αυτά μετατρέπονται στις πιο κατάλληλες δομές και στοιχεία HTML, διατηρώντας τα εισαχθέντα δεδομένα χρήστη, εφόσον υπάρχουν στο εισερχόμενο έγγραφο. Σε συγκεκριμένες περιπτώσεις χρήσης απαιτείται μόνο η συλλογή των εισαχθέντων δεδομένων στην πλευρά του πελάτη αντί για την επεξεργασία ολόκληρου του περιεχομένου του εγγράφου. Για τέτοια περίπτωση απαιτείται η ταυτοποίηση των στοιχείων ελέγχου εισόδου με κάποιον τρόπο ώστε να μπορούν να ανακτηθούν μαζί με τα δεδομένα τους στην πλευρά του πελάτη. Αυτή η ιδιότητα επιτρέπει τον καθορισμό ενός ονόματος κλάσης που θα εφαρμόζεται σε κάθε στοιχείο ελέγχου εισόδου στο σήμανση HTML, ώστε ο κώδικας του πελάτη να μπορεί να διασχίσει τη δομή του εγγράφου HTML και να συλλέξει τα δεδομένα.
