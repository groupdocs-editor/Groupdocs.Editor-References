## WordProcessingSaveOptions.EnablePagination property

Επιτρέπει την ενεργοποίηση ή απενεργοποίηση της σελιδοποίησης που θα χρησιμοποιηθεί για την αποθήκευση του εγγράφου WordProcessing. Εάν το αρχικό έγγραφο ανοίχθηκε και επεξεργάστηκε σε λειτουργία σελιδοποίησης, αυτή η επιλογή πρέπει επίσης να ενεργοποιηθεί. Προεπιλεγμένα είναι απενεργοποιημένη.

public bool EnablePagination { get; set; }
