## WordProcessingSaveOptions.LocaleBi property

Επιτρέπει τον καθορισμό παράκαμψης της τοπικής ρύθμισης (γλώσσας) για το κείμενο RTL (από δεξιά προς αριστερά), η οποία θα εφαρμοστεί κατά τη δημιουργία του. Εάν δεν καθοριστεί (προεπιλεγμένη τιμή), το MS Word (ή άλλο πρόγραμμα) θα εντοπίσει (ή θα επιλέξει) τη RTL τοπική ρύθμιση του εγγράφου σύμφωνα με τις δικές του ρυθμίσεις ή άλλους παράγοντες.

```csharp
public CultureInfo LocaleBi { get; set; }
```

### Σχόλια

Αυτή η επιλογή εφαρμόζει εξαναγκαστικά το καθορισμένο locale σε όλο το κείμενο RTL του εγγράφου. Μην τη χρησιμοποιήσετε εάν το έγγραφο περιέχει διαφορετικά τμήματα κειμένου γραμμένα σε διαφορετικές γλώσσες.
