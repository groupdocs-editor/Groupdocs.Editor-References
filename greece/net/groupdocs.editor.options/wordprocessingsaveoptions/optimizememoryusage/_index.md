## WordProcessingSaveOptions.OptimizeMemoryUsage property

Ενεργοποιεί μηχανισμούς βελτιστοποίησης μνήμης κατά τη δημιουργία εγγράφων από HTML, κάτι που μειώνει την απόδοση ως κόστος μείωσης της χρήσης μνήμης. Ορισμός αυτής της επιλογής σε true μπορεί να μειώσει σημαντικά την κατανάλωση μνήμης κατά τη δημιουργία μεγάλων εγγράφων, με το κόστος του πιο αργού χρόνου αποθήκευσης. Η προεπιλογή είναι false (η βελτιστοποίηση μνήμης είναι απενεργοποιημένη για καλύτερη απόδοση).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
