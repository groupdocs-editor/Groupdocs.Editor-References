## XmlEditOptions.FixIncorrectStructure property

Επιτρέπει την ενεργοποίηση ή απενεργοποίηση του μηχανισμού για τη διόρθωση κατεστραμμένης δομής XML. Προεπιλεγμένα είναι απενεργοποιημένο (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Σχόλια

Από προεπιλογή γίνονται αποδεκτά μόνο σωστά, έγκυρα και καλά δομημένα έγγραφα XML. Όταν αυτή η επιλογή ενεργοποιηθεί, το GroupDocs.Editor θα προσπαθήσει να διορθώσει την κατεστραμμένη δομή XML εφόσον είναι δυνατόν.
