## XmlEditOptions.HighlightOptions property

Επιτρέπει την προσαρμογή της επισήμανσης XML, η οποία θα εφαρμοστεί στη δομή XML όταν αυτή αναπαρίσταται σε HTML. Η προεπιλεγμένη επισήμανση χρησιμοποιείται και είναι ρυθμιζόμενη. Δεν μπορεί να είναι null.
