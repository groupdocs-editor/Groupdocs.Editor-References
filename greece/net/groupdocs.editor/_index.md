Ο ονοματικός χώρος GroupDocs.Editor παρέχει κλάσεις για την επεξεργασία εγγράφων χρησιμοποιώντας εξωτερικούς επεξεργαστές WYSIWYG front-end χωρίς καμία πρόσθετη εφαρμογή.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EditableDocument](./editabledocument) | Ενδιάμεσο έγγραφο, που περιέχει περιεχόμενο πριν και μετά την επεξεργασία |
| [Editor](./editor) | Κύρια κλάση, η οποία ενσωματώνει μεθόδους μετατροπής. Η κλάση Editor παρέχει μεθόδους για τη φόρτωση, την επεξεργασία και την αποθήκευση εγγράφων όλων των υποστηριζόμενων μορφών. Είναι διαχειρίσιμη, επομένως χρησιμοποιήστε την οδηγία 'using' ή απελευθερώστε τους πόρους της χειροκίνητα μέσω της κλήσης της μεθόδου 'Dispose()'. Η φόρτωση εγγράφου εκτελείται μέσω κατασκευαστών. Η επεξεργασία εγγράφου – μέσω της μεθόδου 'Edit', και η αποθήκευση του τελικού εγγράφου μετά την επεξεργασία – μέσω της μεθόδου 'Save'. |
| [EncryptedException](./encryptedexception) | Η εξαίρεση που προκαλείται όταν ο χρήστης προσπαθεί να ανοίξει ένα έγγραφο που κρυπτογραφήθηκε χρησιμοποιώντας τα X509Certificates. |
| [FormFieldManager](./formfieldmanager) | Διαχειριστείτε μια Φόρμα με Παλαιές Πεδία Φόρμας. Τα παλιά πεδία φόρμας είναι οι τύποι πεδίων που ήταν διαθέσιμοι σε προηγούμενες εκδόσεις επεξεργασίας κειμένου. Η ομάδα Legacy Forms (ορατή μετά το κλικ στο εικονίδιο Legacy Tools) περιλαμβάνει τρεις τύπους πεδίων φόρμας που μπορείτε να εισάγετε σε ένα έγγραφο: κείμενο, πλαίσιο ελέγχου, αναπτυσσόμενο μενού, ημερομηνία κ.λπ., δείτε περισσότερα [`FormFieldType`](../groupdocs.editor.words.fieldmanagement/formfieldtype). Κάθε ένα από αυτά τα πεδία φόρμας επιτρέπει στον χρήστη της φόρμας να επιλέξει ή να εισάγει πληροφορίες του τύπου που θεωρείτε κατάλληλο. |
| [IncorrectPasswordException](./incorrectpasswordexception) | Η εξαίρεση που προκαλείται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [InvalidFormatException](./invalidformatexception) | Η εξαίρεση που προκαλείται όταν ο χρήστης προσπαθεί να ανοίξει κάποιο έγγραφο με επιλογές ειδικές για τη μορφή που είναι ασύμβατες με την αρχική μορφή του εγγράφου. |
