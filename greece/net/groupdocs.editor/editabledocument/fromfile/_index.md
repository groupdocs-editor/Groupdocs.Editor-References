## EditableDocument.FromFile method

Στατική κατασκευή, η οποία δημιουργεί ένα αντικείμενο EditableDocument από ένα αρχείο HTML, το οποίο καθορίζεται από τη διαδρομή προς το ίδιο το αρχείο *.html και έναν φάκελο με συνδεδεμένους πόρους

```csharp
public static EditableDocument FromFile(string htmlFilePath, string resourceFolderPath)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| htmlFilePath | String | String, που περιέχει πλήρη διαδρομή προς το αρχείο HTML. Δεν μπορεί να είναι null, πρέπει να είναι έγκυρη διαδρομή αρχείου, και το ίδιο το αρχείο πρέπει να υπάρχει. |
| resourceFolderPath | String | Προαιρετική διαδρομή προς το φάκελο με πόρους HTML. Εάν είναι NULL, άκυρο ή ο φάκελος δεν υπάρχει, ο Editor θα προσπαθήσει να βρει αυτόν τον φάκελο μόνος του, αναλύοντας το σήμανση HTML |

### Τιμή Επιστροφής

New non-null instance of EditableDocument

### Εξαιρέσεις

| εξαίρεση | συνθήκη |
| --- | --- |
| ArgumentException | Η διαδρομή του αρχείου HTML και/ή η διαδρομή του φακέλου πόρων είναι άκυρη |
| FileNotFoundException | Το καθορισμένο αρχείο HTML δεν μπορεί να βρεθεί |
