## FromMarkup(string) {#frommarkup}

Στατική μέθοδος κατασκευής, που δημιουργεί ένα στιγμιότυπο του [`EditableDocument`](../../editabledocument) από το καθορισμένο HTML markup

```csharp
public static EditableDocument FromMarkup(string newHtmlContent)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| newHtmlContent | String | Συμβολοσειρά που περιέχει ακατέργαστο σήμα HTML, το οποίο πρέπει να αναλυθεί. Δεν μπορεί να είναι NULL, κενή ή μη έγκυρη. |

### Τιμή Επιστροφής

### Εξαιρέσεις
