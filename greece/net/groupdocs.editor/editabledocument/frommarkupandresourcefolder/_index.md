## EditableDocument.FromMarkupAndResourceFolder method

Στατική κατασκευή, η οποία δημιουργεί ένα αντικείμενο EditableDocument από το καθορισμένο σήμανση HTML και από πόρους, που βρίσκονται στον φάκελο, καθορισμένο με την πλήρη διαδρομή

```csharp
public static EditableDocument FromMarkupAndResourceFolder(string newHtmlContent, 
    string resourceFolderPath)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| newHtmlContent | String | Συμβολοσειρά που περιέχει ακατέργαστο σήμα HTML, το οποίο πρέπει να αναλυθεί. Δεν μπορεί να είναι NULL, κενή ή μη έγκυρη. |
| resourceFolderPath | String | Υποχρεωτικό μονοπάτι προς το φάκελο με τους πόρους. Όλα τα φύλλα στυλ που βρίσκονται σε αυτόν το φάκελο θα χρησιμοποιηθούν. Δεν μπορεί να είναι NULL ή κενή συμβολοσειρά, και αυτός ο φάκελος πρέπει να υπάρχει. |

### Τιμή Επιστροφής

New non-null instance of EditableDocument

### Σχόλια

Αυτή η στατική μέθοδος κατασκευής είναι χρήσιμη όταν το περιεχόμενο ενός εγγράφου HTML παρουσιάζεται ως συμβολοσειρά, αλλά όλοι οι πόροι βρίσκονται σε κάποιο φάκελο, και συχνά οι σύνδεσμοι προς αυτούς τους πόρους στο σήμα HTML είναι μη έγκυροι ή απουσιάζουν. Κατά την κλήση αυτής της μεθόδου, γίνεται σάρωση του καθορισμένου φακέλου και εφαρμόζονται αυτόματα όλα τα ευρεθέντα φύλλα στυλ στο έγγραφο. Αυτή η μέθοδος είναι πολύ χρήσιμη όταν λαμβάνεται περιεχόμενο από διαφορετικούς επεξεργαστές HTML, οι οποίοι συνήθως αφαιρούν τα μεταδεδομένα του εγγράφου κ.λπ.
