## GetBodyContent() {#getbodycontent}

Επιστρέφει το σώμα του εγγράφου HTML (εσωτερικό περιεχόμενο μεταξύ των ανοίγματος και κλεισίματος ετικετών BODY χωρίς αυτές τις ετικέτες) ως συμβολοσειρά.

```csharp
public string GetBodyContent()
```

### Τιμή Επιστροφής

String, which contains the body of the HTML document (without opening and closing BODY tags)

### Σχόλια

Οι περισσότεροι επεξεργαστές WYSIWYG συνήθως λειτουργούν με το εσωτερικό περιεχόμενο του BODY του εγγράφου και δεν μπορούν να επεξεργαστούν σωστά τις μετα-πληροφορίες του από το μπλοκ HEAD. Αυτή η μέθοδος έχει σχεδιαστεί για τέτοιες περιπτώσεις. Αυτή η υπερφόρτωση δεν επιτρέπει την προσαρμογή των URI για εξωτερικά αιτήματα πόρων.

## GetBodyContent(string) {#getbodycontent_1}

Επιστρέφει το σώμα του εγγράφου HTML (εσωτερικό περιεχόμενο μεταξύ των ανοίγματος και κλεισίματος ετικετών BODY χωρίς αυτές τις ετικέτες) ως συμβολοσειρά, όπου οι σύνδεσμοι προς τους εξωτερικούς πόρους περιέχουν το καθορισμένο πρότυπο με σύμβολα κράτησης θέσης.

```csharp
public string GetBodyContent(string externalImagesTemplate)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| externalImagesTemplate | String | Μέσω αυτής της παραμέτρου μπορεί να καθοριστεί ένα πρότυπο συμβολοσειράς με έναν σύμβολο κράτησης θέσης, το οποίο θα εφαρμοστεί στους συνδέσμους προς όλες τις εξωτερικές εικόνες στα στοιχεία IMG, που θα εμφανιστούν στην τελική συμβολοσειρά HTML. Εάν είναι NULL ή κενό, το πρότυπο δεν θα προστεθεί και θα εμφανίζονται καθαρά ονόματα αρχείων στο τελικό σήμα HTML. Εάν το πρότυπο είναι μη έγκυρο, θα θεωρηθεί ως πρόθεμα, έτσι τα ονόματα αρχείων θα προσαρτηθούν στο τέλος του. |

### Τιμή Επιστροφής

String, which contains the body of the HTML document (without opening and closing BODY tags) with links, adjusted to the external images

### Σχόλια

Οι περισσότεροι επεξεργαστές WYSIWYG συνήθως λειτουργούν με το εσωτερικό περιεχόμενο του BODY του εγγράφου και δεν μπορούν να επεξεργαστούν σωστά τις μετα-πληροφορίες του από το μπλοκ HEAD. Αυτή η μέθοδος έχει σχεδιαστεί για τέτοιες περιπτώσεις. Αυτή η υπερφόρτωση επιτρέπει την προσαρμογή των URI για εξωτερικά αιτήματα πόρων.
