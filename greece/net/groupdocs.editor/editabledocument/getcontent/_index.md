## GetContent(string, string) {#getcontent_1}

Επιστρέφει το συνολικό περιεχόμενο του εγγράφου HTML ως συμβολοσειρά, όπου οι σύνδεσμοι προς τους εξωτερικούς πόρους περιέχουν το καθορισμένο πρότυπο με σύμβολα κράτησης θέσης.

```csharp
public string GetContent(string externalImagesTemplate, string externalCssTemplate)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| externalImagesTemplate | String | Μέσω αυτής της παραμέτρου μπορεί να καθοριστεί ένα πρότυπο συμβολοσειράς με έναν σύμβολο κράτησης θέσης, το οποίο θα εφαρμοστεί στους συνδέσμους προς όλες τις εξωτερικές εικόνες στα στοιχεία IMG, που θα εμφανιστούν στην τελική συμβολοσειρά HTML. Εάν είναι NULL ή κενό, το πρότυπο δεν θα προστεθεί και θα εμφανίζονται καθαρά ονόματα αρχείων στο τελικό σήμα HTML. Εάν το πρότυπο είναι μη έγκυρο, θα θεωρηθεί ως πρόθεμα, έτσι τα ονόματα αρχείων θα προσαρτηθούν στο τέλος του. |
| externalCssTemplate | String | Μέσω αυτού του παραμέτρου μπορεί να καθοριστεί ένα πρότυπο συμβολοσειράς με μία θέση κράτησης, η οποία θα προσαρτηθεί στους συνδέσμους προς όλα τα εξωτερικά φύλλα στυλ στα στοιχεία LINK, που θα εμφανίζονται στην τελική συμβολοσειρά HTML. Εάν είναι NULL ή κενό, το πρότυπο δεν θα προστεθεί και τα καθαρά ονόματα αρχείων θα εμφανιστούν στο τελικό σήμανση HTML. Εάν το πρότυπο είναι άκυρο, θα θεωρηθεί πρόθεμα, έτσι τα ονόματα αρχείων θα προσαρτηθούν στο τέλος του. |

### Τιμή Επιστροφής

String, που περιέχει το περιεχόμενο του εγγράφου HTML με συνδέσμους, προσαρμοσμένο στις εξωτερικές πηγές
