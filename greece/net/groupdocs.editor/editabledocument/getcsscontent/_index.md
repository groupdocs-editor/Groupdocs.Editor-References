## GetCssContent(string, string) {#getcsscontent_1}

Επιστρέφει το περιεχόμενο όλων των εξωτερικών φύλλων στυλ ως λίστα συμβολοσειρών, όπου μια συμβολοσειρά αντιπροσωπεύει ένα φύλλο στυλ. Το καθορισμένο πρόθεμα θα εφαρμοστεί σε κάθε σύνδεσμο προς τον εξωτερικό πόρο σε κάθε παραγόμενο φύλλο στυλ. Επιστρέφει κενή λίστα, εάν δεν υπάρχει CSS για αυτό το έγγραφο.

```csharp
public List<string> GetCssContent(string externalImagesPrefix, string externalFontsPrefix)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| externalImagesPrefix | String | Μέσω αυτής της παραμέτρου μπορεί να καθοριστεί ένα πρόθεμα, το οποίο θα προσαρτηθεί στους συνδέσμους προς όλες τις εξωτερικές εικόνες, που θα εμφανίζονται στις δηλώσεις CSS στα τελικά CSS strings. Εάν είναι NULL ή κενό, τα προθέματα δεν θα προστεθούν. |
| externalFontsPrefix | String | Μέσω αυτής της παραμέτρου μπορεί να καθοριστεί ένα πρόθεμα, το οποίο θα προσαρτηθεί στους συνδέσμους προς όλες τις εξωτερικές γραμματοσειρές στο @font-face at-rules στα τελικά CSS strings. Εάν είναι NULL ή κενό, τα προθέματα δεν θα προστεθούν. |
