## Save(TextWriter, HtmlSaveOptions) {#save}

Αποθηκεύει το περιεχόμενο αυτού του [`EditableDocument`](../../editabledocument) ως έγγραφο HTML στον καθορισμένο text writer, ενώ η δεύτερη παράμετρος options επιτρέπει την προσαρμογή της διαδικασίας αποθήκευσης και τον καθορισμό της callback αποθήκευσης πόρων

```csharp
public void Save(TextWriter htmlMarkup, HtmlSaveOptions saveOptions)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| htmlMarkup | TextWriter | Υλοποίηση του text writer, στον οποίο θα γραφτεί το HTML markup. Δεν μπορεί να είναι null. |
| saveOptions | HtmlSaveOptions | HTML save options, που ελέγχουν τη διαδικασία αποθήκευσης: πώς αποθηκεύεται το HTML-markup (ονόματα ετικετών, τύποι εισαγωγικών) και πώς και πού θα αποθηκευτούν τα CSS και άλλοι πόροι όπως εικόνες ή γραμματοσειρές. Ο χρήστης πρέπει να καθορίσει τον κληρονόμο της διεπαφής στην ιδιότητα [`SavingCallback`](../../../groupdocs.editor.options/htmlsaveoptions/savingcallback) για τον έλεγχο του τρόπου αποθήκευσης και αναφοράς των πόρων από το HTML-markup. |

### Εξαιρέσεις

| --- | --- |
