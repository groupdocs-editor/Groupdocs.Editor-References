## Editor class

Κύρια κλάση, η οποία ενσωματώνει μεθόδους μετατροπής. Η κλάση Editor παρέχει μεθόδους για τη φόρτωση, την επεξεργασία και την αποθήκευση εγγράφων όλων των υποστηριζόμενων μορφών. Είναι διαχειρίσιμη, επομένως χρησιμοποιήστε την οδηγία 'using' ή απελευθερώστε τους πόρους της χειροκίνητα μέσω της κλήσης της μεθόδου 'Dispose()'. Η φόρτωση εγγράφου εκτελείται μέσω κατασκευαστών. Η επεξεργασία εγγράφου – μέσω της μεθόδου 'Edit', και η αποθήκευση του τελικού εγγράφου μετά την επεξεργασία – μέσω της μεθόδου 'Save'.

public sealed class Editor : IAuxDisposable

### Σχόλια

Η κλάση Editor θα πρέπει να θεωρείται ως σημείο εισόδου και το ριζικό αντικείμενο του GroupDocs.Editor. Όλες οι λειτουργίες εκτελούνται χρησιμοποιώντας αυτήν την κλάση. Η τυπική χρήση της κλάσης Editor για την εκτέλεση μιας πλήρους αλυσίδας επεξεργασίας εγγράφου είναι η εξής:

1. Φορτώστε ένα έγγραφο στην παρουσία του Editor μέσω του κατασκευαστή του.
2. Προαιρετικά, εντοπίστε τον τύπο του εγγράφου χρησιμοποιώντας τη μέθοδο [`GetDocumentInfo`](./getdocumentinfo).
3. Ανοίξτε ένα έγγραφο για επεξεργασία καλώντας τη μέθοδο [`Edit`](./edit) και λαμβάνοντας μια παρουσία της κλάσης [`EditableDocument`](../editabledocument) από αυτήν.
4. Επεξεργασία του περιεχομένου του εγγράφου στην πλευρά του πελάτη χρησιμοποιώντας οποιονδήποτε WYSIWYG HTML-editor.
5. Δημιουργία μιας νέας παρουσίασης του [`EditableDocument`](../editabledocument) από το περιεχόμενο του επεξεργασμένου εγγράφου.
6. Αποθήκευση ενός επεξεργασμένου εγγράφου σε κάποια μορφή εξόδου καλώντας τη μέθοδο [`Save`](./save).
7. Καταστροφή ενός αντικειμένου της κλάσης Editor μέσω του τελεστή 'using' ή χειροκίνητα.
