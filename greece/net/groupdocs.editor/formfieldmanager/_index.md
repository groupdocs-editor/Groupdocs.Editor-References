## FormFieldManager class

Διαχειριστείτε μια Φόρμα με Παλαιές Πεδία Φόρμας. Τα παλαιά πεδία φόρμας είναι οι τύποι πεδίων που ήταν διαθέσιμοι σε προηγούμενες εκδόσεις επεξεργασίας Word. Η ομάδα Legacy Forms (ορατή μετά το κλικ στο εικονίδιο Legacy Tools) περιλαμβάνει τρεις τύπους πεδίων φόρμας που μπορείτε να εισάγετε σε ένα έγγραφο: κείμενο, πλαίσιο ελέγχου, αναπτυσσόμενο μενού, ημερομηνία κ.λπ., δείτε περισσότερα [`FormFieldType`](../../groupdocs.editor.words.fieldmanagement/formfieldtype). Κάθε ένα από αυτά τα πεδία φόρμας επιτρέπει στον χρήστη της φόρμας να επιλέξει ή να εισάγει πληροφορίες του τύπου που θεωρείτε κατάλληλο.

### Σχόλια

Η κλάση [`FormFieldManager`](../formfieldmanager) παρέχει λειτουργικότητα για τη διαχείριση πεδίων φόρμας σε ένα έγγραφο. Επιτρέπει στους χρήστες να αποκτούν, να ενημερώνουν, να διορθώνουν, να ελέγχουν την εγκυρότητα και να αφαιρούν πεδία φόρμας από το έγγραφο.
