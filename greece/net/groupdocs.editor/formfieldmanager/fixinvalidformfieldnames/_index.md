## FormFieldManager.FixInvalidFormFieldNames method

Διορθώνει τα μη έγκυρα ονόματα πεδίων φόρμας στο έγγραφο εφαρμόζοντας συγκεκριμένες ενημερώσεις ή δημιουργώντας αυτόματα μοναδικά ονόματα.

```csharp
public void FixInvalidFormFieldNames(IEnumerable<InvalidFormField> updateInvalidFormFieldNames)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| updateInvalidFormFieldNames | IEnumerable`1 | Μια συλλογή ενημερώσεων για μη έγκυρα ονόματα πεδίων φόρμας. Κάθε ενημέρωση περιέχει το αρχικό όνομα του πεδίου φόρμας και το αντίστοιχο νέο του όνομα. Εάν μείνει κενή, τα μη έγκυρα ονόματα πεδίων φόρμας θα μετονομαστούν αυτόματα ώστε να εξασφαλιστεί η μοναδικότητα. |

### Σχόλια

Η μέθοδος `FixInvalidFormFieldNames` επιλύει συγκρούσεις ονοματοδοσίας ή ασυνέπειες εντός των πεδίων φόρμας του εγγράφου εφαρμόζοντας τις ενημερώσεις που καθορίζονται στη συλλογή *updateInvalidFormFieldNames*, ή δημιουργώντας αυτόματα μοναδικά ονόματα εάν η συλλογή είναι κενή. Αυτή η μέθοδος είναι χρήσιμη όταν ορισμένα ονόματα πεδίων φόρμας είναι μη έγκυρα ή συγκρούονται με άλλα στοιχεία στο έγγραφο, και χρειάζεται να διορθωθούν για να εξασφαλιστεί η σωστή λειτουργία. ; ;
