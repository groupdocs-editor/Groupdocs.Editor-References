Το **com.groupdocs.editor.formats** namespace παρέχει διεπαφές και κλάσεις που περιγράφουν τις υποστηριζόμενες μορφές εγγράφων.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Περιλαμβάνει όλες τις μορφές eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Περιλαμβάνει όλες τις μορφές email. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Περιλαμβάνει όλες τις μορφές σταθερής διάταξης (γνωστές επίσης ως "fixed-page"), που περιλαμβάνουν PDF και XPS (αυτό δεν περιλαμβάνει ραστερ εικόνες) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Αντιπροσωπεύει τις διαφορετικές οικογένειες μορφών που είναι διαθέσιμες στο σύστημα. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Περιλαμβάνει όλες τις μορφές Παρουσίασης. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Περιλαμβάνει όλες τις δυαδικές, XML και κειμενικές μορφές Φύλλου Εργασίας (εξαιρώντας όλες τις κειμενικές μορφές βασισμένες σε διαχωριστικά με διαχωριστή όπως CSV, TSV, μορφές διαχωρισμένες με άνω-κάτω τελεία κ.λπ.), στις οποίες μπορεί να αποθηκευτεί το βιβλίο εργασίας. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Περιλαμβάνει όλες τις κειμενικές (βασισμένες σε κείμενο) μορφές, συμπεριλαμβανομένων των γλωσσών σήμανσης (XML, HTML) και άλλων. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Περιλαμβάνει όλες τις μορφές Επεξεργασίας Κειμένου. |
