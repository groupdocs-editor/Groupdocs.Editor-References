### NotExtract {#NotExtract}

```
public static final int NotExtract
```


Δεν εξάγει κανέναν πόρο γραμματοσειράς ούτε από το έγγραφο ούτε από το
σύστημα. Προεπιλεγμένη τιμή.


### ExtractAllEmbedded {#ExtractAllEmbedded}
```
public static final int ExtractAllEmbedded
```


Εξάγει όλους τους πόρους γραμματοσειρών, που είναι ενσωματωμένοι στο εισερχόμενο Word
έγγραφο, ανεξάρτητα από το τι είναι: προσαρμοσμένο ή σύστημα.


*** ** * ** ***

Ο Converter βρίσκει και εξάγει όλους τους πόρους γραμματοσειρών 100%, που είναι ενσωματωμένοι στο εισαγωγικό WordProcessing έγγραφο, αλλά δεν καθορίζει αν είναι σύστημα ή προσαρμοσμένοι· δεν αγγίζει καθόλου το Windows Registry ή τους φακέλους συστήματος.

<br />



### ExtractEmbeddedWithoutSystem {#ExtractEmbeddedWithoutSystem}
```
public static final int ExtractEmbeddedWithoutSystem
```


Εξάγει μόνο εκείνους τους ενσωματωμένους πόρους γραμματοσειρών, που είναι προσαρμοσμένοι (μη
σύστημα)


*** ** * ** ***

Ο Converter βρίσκει και εξάγει όλους τους ενσωματωμένους πόρους γραμματοσειρών, και στη συνέχεια προσπαθεί να καθορίσει ποιες από αυτές τις γραμματοσειρές είναι συστήματος και ποιες - όχι. Για να το επιτύχει, ο converter προσπαθεί να αποκτήσει μια λίστα με όλες τις γραμματοσειρές συστήματος χρησιμοποιώντας το Windows Registry και τους φακέλους συστήματος, και στη συνέχεια συγκρίνει αυτή τη λίστα με ένα σύνολο ενσωματωμένων γραμματοσειρών. Ως αποτέλεσμα, θα επιστραφεί μόνο ένα υποσύνολο των ενσωματωμένων γραμματοσειρών που δεν βρέθηκαν στο σύστημα.

<br />



### ExtractAll {#ExtractAll}
```
public static final int ExtractAll
```


Προσπαθεί να εξάγει όλες τις γραμματοσειρές, που χρησιμοποιούνται στην είσοδο WordProcessing
έγγραφο, συμπεριλαμβανομένων των γραμματοσειρών συστήματος.


*** ** * ** ***

Ο Converter αναλύει ένα εισαγωγικό WordProcessing έγγραφο και βρίσκει όλες τις γραμματοσειρές που χρησιμοποιούνται εκεί. Εάν όλες αυτές οι γραμματοσειρές είναι ενσωματωμένες στο εισαγωγικό έγγραφο, ο converter τις εξάγει και τις επιστρέφει. Διαφορετικά, εάν μια συλλογή ενσωματωμένων γραμματοσειρών δεν καλύπτει όλες τις χρησιμοποιημένες γραμματοσειρές στο έγγραφο, ή είναι κενή, ο converter προσπαθεί να εξάγει αυτούς τους πόρους γραμματοσειρών από το σύστημα, χρησιμοποιώντας το Windows Registry και τους φακέλους συστήματος.
