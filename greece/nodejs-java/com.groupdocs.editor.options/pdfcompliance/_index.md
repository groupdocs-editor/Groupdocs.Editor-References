### PdfA1a {#PdfA1a}
```
public static final int PdfA1a
```


Πρότυπο PDF/A-1a. Αυτό το επίπεδο περιλαμβάνει όλες τις απαιτήσεις του PDF/A-1b και επιπλέον απαιτεί την ένταξη της δομής του εγγράφου
(γνωστό επίσης ως "ετικετοποιημένο"), με στόχο να διασφαλιστεί ότι το περιεχόμενο του εγγράφου μπορεί να αναζητηθεί και να επαναχρησιμοποιηθεί.

<br />

*** ** * ** ***

Σημειώστε ότι η εξαγωγή της δομής του εγγράφου αυξάνει σημαντικά την κατανάλωση μνήμης, ιδιαίτερα για μεγάλα έγγραφα.

<br />

### PdfA2u {#PdfA2u}
```
public static final int PdfA2u
```


Πρότυπο PDF/A-2u (ISO 19005-2). Το PDF/A-2u έχει ως στόχο τη διατήρηση της στατικής οπτικής εμφάνισης του εγγράφου με την πάροδο του χρόνου, ανεξάρτητα από τα εργαλεία και τα συστήματα που χρησιμοποιούνται για τη δημιουργία, αποθήκευση ή απόδοση των αρχείων. Επιπλέον, οποιοδήποτε κείμενο περιέχεται στο έγγραφο μπορεί να εξαχθεί αξιόπιστα ως σειρά κωδικών Unicode.


### PdfUa1 {#PdfUa1}
```
public static final int PdfUa1
```


Πρότυπο PDF/UA-1 (ISO 14289-1). Ο κύριος σκοπός του PDF/UA είναι να ορίσει πώς να αντιπροσωπεύονται τα ηλεκτρονικά έγγραφα σε μορφή PDF με τρόπο που να επιτρέπει την προσβασιμότητα του αρχείου.
