### getExtractOnlyUsedFont() {#getExtractOnlyUsedFont--}
```
public final boolean getExtractOnlyUsedFont()
```


Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν εξάγονται μόνο οι πόροι γραμματοσειράς που
χρησιμοποιούνται στο κειμενικό περιεχόμενο του εγγράφου.
Τιμή:  true  εάν απαιτείται η εξαγωγή μόνο εκείνων των πόρων γραμματοσειράς που χρησιμοποιούνται στο κείμενο του εγγράφου· διαφορετικά,  false . Η προεπιλεγμένη τιμή είναι  false .


*** ** * ** ***

Δεν όλες οι γραμματοσειρές που χρησιμοποιούνται στο έγγραφο WordProcessing χρησιμοποιούνται άμεσα κατά 100% (εφαρμόζονται σε κάποιο κείμενο). Μπορεί να υπάρξει περίπτωση όπου μια γραμματοσειρά αναφέρεται στο έγγραφο και ακόμη μπορεί να είναι ενσωματωμένη, αλλά δεν εφαρμόζεται σε κανένα τμήμα κειμένου. Για παράδειγμα, κάποια γραμματοσειρά μπορεί να είναι συνδεδεμένη με κάποιο στυλ, αλλά αυτό το στυλ δεν εφαρμόζεται σε κανένα μέρος του κειμένου. Αυτή η επιλογή ελέγχει πώς να επεξεργαστεί τέτοιες περιπτώσεις.

### getInputControlsClassName() {#getInputControlsClassName--}
```
public final String getInputControlsClassName()
```


Επιτρέπει τον καθορισμό ενός ονόματος κλάσης, το οποίο θα τοποθετηθεί στο 'class'
χαρακτηριστικά σε κάθε στοιχείο HTML, που αντιπροσωπεύει κάποιο πεδίο στην είσοδο
Έγγραφο WordProcessing. Από προεπιλογή είναι NULL - τα χαρακτηριστικά 'class' δεν είναι
εφαρμοσμένα.


*** ** * ** ***

Σχεδόν όλες οι μορφές από την οικογένεια μορφών WordProcessing περιέχουν πεδία \\u2014 συγκεκριμένες οντότητες εγγράφου που επιτρέπουν τη λήψη δεδομένων εισόδου από τους χρήστες. Υπάρχει μια μεγάλη ποικιλία πεδίων: πλαίσια κειμένου, πλαίσια ελέγχου, συνδυαστικά πλαίσια, λίστες πτυσσόμενες, κουμπιά, επιλογείς ημερομηνίας/ώρας κ.λπ. Όλα αυτά μεταφράζονται στις πιο κατάλληλες δομές και στοιχεία HTML, διατηρώντας τα εισαχθέντα δεδομένα του χρήστη, εφόσον υπάρχουν στο έγγραφο εισόδου. Σε συγκεκριμένες περιπτώσεις χρήσης απαιτείται μόνο η συλλογή των εισαχθέντων δεδομένων στην πλευρά του πελάτη αντί για την επεξεργασία ολόκληρου του περιεχομένου του εγγράφου. Για αυτήν την περίπτωση απαιτείται η αναγνώριση των στοιχείων ελέγχου εισόδου με κάποιον τρόπο ώστε να μπορούν να ανακτηθούν μαζί με τα δεδομένα τους στην πλευρά του πελάτη. Αυτή η ιδιότητα επιτρέπει τον καθορισμό ενός ονόματος κλάσης, το οποίο θα εφαρμοστεί σε κάθε στοιχείο ελέγχου εισόδου στο σήμανση HTML, ώστε ο κώδικας πελάτη να μπορεί να διασχίσει τη δομή του εγγράφου HTML και να συλλέξει τα δεδομένα.
