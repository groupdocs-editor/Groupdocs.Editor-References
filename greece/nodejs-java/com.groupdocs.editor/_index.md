Το **com.groupdocs.editor** namespace είναι ένα ριζικό namespace, το οποίο παρέχει κλάσεις για την επεξεργασία πολλαπλών μορφών εγγράφων στις Java εφαρμογές σας.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Ενδιάμεσο έγγραφο, που περιέχει περιεχόμενο πριν και μετά την επεξεργασία |
| [Editor](../com.groupdocs.editor/editor) | Κύρια κλάση, η οποία ενσωματώνει μεθόδους μετατροπής. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | Η εξαίρεση που ρίχνεται όταν ο χρήστης προσπαθεί να ανοίξει ένα έγγραφο που κρυπτογραφήθηκε χρησιμοποιώντας τα X509Certificates. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | Η εξαίρεση που ρίχνεται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | Η εξαίρεση που ρίχνεται όταν ο χρήστης προσπαθεί να ανοίξει κάποιο έγγραφο με επιλογές ειδικές για μορφή που είναι ασύμβατες με την αρχική μορφή του εγγράφου. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | Η εξαίρεση που ρίχνεται όταν ο χρήστης προσπαθεί να ανοίξει ένα κωδικό-προστατευμένο κρυπτογραφημένο έγγραφο κάποιου τύπου και δεν παρέχει κωδικό πρόσβασης για το άνοιγμα αυτού του εγγράφου. |
