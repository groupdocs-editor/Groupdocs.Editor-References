यह **com.groupdocs.editor.formats.abstraction** नेमस्पेस इंटरफ़ेस और क्लासेस प्रदान करता है जो GroupDocs.Editor लाइब्रेरी में समर्थित दस्तावेज़ फ़ॉर्मेट का वर्णन करते हैं।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [DocumentFormatBase](../com.groupdocs.editor.formats.abstraction/documentformatbase) | दस्तावेज़ फ़ॉर्मेट्स के लिए बेस क्लास को दर्शाता है, जो फ़ॉर्मेट इंस्टेंसेज़ के लिए सामान्य कार्यक्षमता प्रदान करता है। |
| [FormatFamilyBase](../com.groupdocs.editor.formats.abstraction/formatfamilybase) | फ़ॉर्मेट परिवारों के लिए बेस क्लास को दर्शाता है, जो फ़ॉर्मेट फ़ैमिली इंस्टेंसेज़ के लिए सामान्य कार्यक्षमता प्रदान करता है। |
