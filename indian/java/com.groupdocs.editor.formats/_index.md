यह **com.groupdocs.editor.formats** नेमस्पेस इंटरफ़ेस और क्लासेस प्रदान करता है जो समर्थित दस्तावेज़ फ़ॉर्मेट का वर्णन करता है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | सभी ईबुक फ़ॉर्मेट को संलग्न करता है। |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | सभी ईमेल फ़ॉर्मेट को संलग्न करता है। |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | सभी निश्चित-लेआउट (जिसे \"फिक्स्ड-पेज\" भी कहा जाता है) फ़ॉर्मेट को संलग्न करता है, जिसमें PDF और XPS शामिल हैं (यह रास्टर छवियों को शामिल नहीं करता)। |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | सिस्टम में उपलब्ध विभिन्न फ़ॉर्मेट परिवारों का प्रतिनिधित्व करता है। |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | सभी प्रेज़ेंटेशन फ़ॉर्मेट को संलग्न करता है। |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | सभी बाइनरी, XML और पाठ्य स्प्रेडशीट फ़ॉर्मेट को संलग्न करता है (CSV, TSV, सेमीकोलन-डिलिमिटेड आदि जैसे विभाजक-आधारित पाठ्य फ़ॉर्मेट को छोड़कर), जिसमें वर्कबुक को सहेजा जा सकता है। |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | सभी पाठ्य (टेक्स्ट-आधारित) फ़ॉर्मेट को संलग्न करता है, जिसमें मार्कअप (XML, HTML) और अन्य शामिल हैं। |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | सभी वर्डप्रोसेसिंग फ़ॉर्मेट को संलग्न करता है। |
