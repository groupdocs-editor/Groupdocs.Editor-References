यह **com.groupdocs.editor.htmlcss.css.datatypes** नेमस्पेस क्लासेस प्रदान करता है जो CSS डेटा टाइप्स को दर्शाते हैं।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | ARGB फ़ॉर्मेट में एक रंग मान को कनवर्टर्स और सीरियलाइज़र्स के साथ दर्शाता है। |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | सभी "ज्ञात रंगों" को शामिल करता है, जिनके पास CSS मानक में स्थिर अद्वितीय नाम और मान होते हैं। |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | किसी भी समर्थित इकाई में CSS लंबाई मान को दर्शाता है, जिसमें प्रतिशत और बिना इकाई वाला प्रकार शामिल है। |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | सभी समर्थित लंबाई इकाइयाँ |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | एक "अनुपात" CSS डेटा टाइप को दर्शाता है, जिसका उपयोग मीडिया क्वेरीज़ में पहलू अनुपात और रास्टर इमेजेज़ में दो बिना इकाई वाले मानों "न्यूमेरटर" और "डिनॉमिनेटर" के बीच अनुपात दर्शाने के लिए किया जाता है। |
