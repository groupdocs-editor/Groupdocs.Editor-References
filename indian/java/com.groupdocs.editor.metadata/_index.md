यह **com.groupdocs.editor.metadata** नेमस्पेस मूल दस्तावेज़ प्रकार पर निर्भर बुनियादी दस्तावेज़ गुणों का वर्णन करने के लिए क्लासेस प्रदान करता है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | एक ईबुक दस्तावेज़ का मेटाडेटा दर्शाता है |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | किसी भी समर्थित ईमेल फ़ॉर्मेट के एक ईमेल दस्तावेज़ का मेटाडेटा दर्शाता है |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | PDF या XPS जैसे निश्चित लेआउट फ़ॉर्मेट वाले एक दस्तावेज़ का मेटाडेटा दर्शाता है |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | एक मार्कडाउन दस्तावेज़ का मेटाडेटा दर्शाता है |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | एक प्रेज़ेंटेशन दस्तावेज़ का मेटाडेटा दर्शाता है |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | एक स्प्रेडशीट दस्तावेज़ का मेटाडेटा दर्शाता है |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | XML, HTML या साधारण टेक्स्ट (TXT) जैसे एक पाठ्य दस्तावेज़ का मेटाडेटा दर्शाता है |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | एक वर्डप्रोसेसिंग दस्तावेज़ का मेटाडेटा दर्शाता है |
