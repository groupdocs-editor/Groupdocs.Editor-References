GroupDocs.Editor.HtmlCss.Css.DataTypes नेमस्पेस क्लासेज़ प्रदान करता है जो CSS डेटा टाइप्स का प्रतिनिधित्व करते हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ArgbColor.KnownColors](./argbcolor.knowncolors) | सभी "ज्ञात रंगों", जो CSS मानक में स्थिर अद्वितीय नाम और मान रखते हैं, को शामिल करता है |
## Structures

| संरचना | विवरण |
| --- | --- |
| [ArgbColor](./argbcolor) | 32-बिट ARGB प्रारूप (पारदर्शिता सहित प्रत्येक चैनल के 8 बिट) में एक रंग मान का प्रतिनिधित्व करता है, जिसमें परिवर्तक और सीरियलाइज़र शामिल हैं |
| [Length](./length) | किसी भी समर्थित इकाई में CSS लंबाई मान का प्रतिनिधित्व करता है, जिसमें प्रतिशत और बिना इकाई वाला प्रकार शामिल है। मान पूर्णांक या फ्लोट, नकारात्मक, शून्य और सकारात्मक हो सकते हैं। अपरिवर्तनीय संरचना। |
| [Ratio](./ratio) | एक "ratio" CSS डेटा प्रकार का प्रतिनिधित्व करता है, जिसका उपयोग मीडिया क्वेरी में अनुपात वर्णन करने और रास्टर छवियों में दो बिना इकाई वाले मानों "numerator" और "denominator" के बीच अनुपात दर्शाने के लिए किया जाता है। अपरिवर्तनीय संरचना। |
