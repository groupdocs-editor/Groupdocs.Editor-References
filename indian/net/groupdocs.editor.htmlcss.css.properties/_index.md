GroupDocs.Editor.HtmlCss.Css.Properties नेमस्पेस टाइप्स प्रदान करता है जो विभिन्न CSS प्रॉपर्टीज़ (CSS डिक्लेरेशन्स के घटक) का प्रतिनिधित्व करते हैं।

## Structures

| संरचना | विवरण |
| --- | --- |
| [FontSize](./fontsize) | फ़ॉन्ट आकार को एक विशेष इकाई या लंबाई मान के रूप में दर्शाता है, जो फ़ॉन्ट का आकार निर्दिष्ट करता है (ऐतिहासिक रूप से बड़े अक्षर \"M\" की चौड़ाई)। |
| [FontStyle](./fontstyle) | परिभाषित करता है कि फ़ॉन्ट को उसके फ़ॉन्ट-फ़ैमिली से सामान्य, इटैलिक या ऑब्लीक फेस के साथ कैसे स्टाइल किया जाना चाहिए। |
| [FontWeight](./fontweight) | फ़ॉन्ट-वेट प्रॉपर्टी फ़ॉन्ट का वजन (या बोल्डनेस) सेट करती है। उपलब्ध वेट्स वर्तमान में सेट किए गए फ़ॉन्ट-फ़ैमिली पर निर्भर करते हैं। |
| [TextDecorationLineType](./textdecorationlinetype) | पाठ सजावट रेखा के प्रकार को दर्शाता है: रेखांकित (अंडरस्कोर), ओवरलाइन, और स्ट्राइकथ्रू (लाइन-थ्रू) |
