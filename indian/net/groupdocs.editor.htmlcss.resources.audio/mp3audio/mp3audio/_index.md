## Mp3Audio constructor

MP3 सामग्री, जो बाइट स्ट्रीम के रूप में दर्शाई गई है, से नया Mp3Audio क्लास बनाता है, और निर्दिष्ट नाम के साथ

```csharp
public Mp3Audio(string name, Stream binaryContent)
```

| Parameter | Type | विवरण |
| --- | --- | --- |
| name | String | MP3 कंटेंट का नाम। यह null, खाली या whitespace नहीं हो सकता। |
| binaryContent | Stream | सामग्री को बाइट स्ट्रीम के रूप में। पढ़ना मूल स्थिति से शुरू होता है। null नहीं हो सकता। पढ़ने योग्य और सीकएबल होना चाहिए। यदि यह इंस्टेंस डिस्पोज़ किया जाएगा, तो यह स्ट्रीम भी डिस्पोज़ हो जाएगा। |
