GroupDocs.Editor.HtmlCss.Resources.Images.Vector नेमस्पेस क्लासेज़ प्रदान करता है जो केवल वेक्टर इमेज संसाधनों का प्रतिनिधित्व करते हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [EmfImage](./emfimage) | Enhanced metafile फ़ॉर्मेट (EMF) में एक वेक्टर इमेज का प्रतिनिधित्व करता है, साथ में उसका मेटाडेटा और अतिरिक्त मेथड्स। |
| [MetaImageBase](./metaimagebase) | WMF और EMF इमेज फ़ॉर्मेट के लिए बेस एब्स्ट्रैक्ट क्लास |
| [SvgImage](./svgimage) | SVG (Scalable Vector Graphics) फ़ॉर्मेट में एक वेक्टर इमेज का प्रतिनिधित्व करता है, साथ में उसका मेटाडेटा (आकार) और अतिरिक्त मेथड्स (PNG में सहेजना)। |
| [VectorImageResourceBase](./vectorimageresourcebase) | किसी भी समर्थित वेक्टर इमेज के लिए बेस क्लास |
| [WmfImage](./wmfimage) | WMF (Windows MetaFile) फ़ॉर्मेट में एक वेक्टर इमेज का प्रतिनिधित्व करता है, साथ में उसका मेटाडेटा और अतिरिक्त मेथड्स। |
