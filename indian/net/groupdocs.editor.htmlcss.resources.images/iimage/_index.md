## IImage interface

इमेज CSS डेटा टाइप दो‑आयामी छवि का प्रतिनिधित्व करता है।

```csharp
public interface IImage
```

### टिप्पणियाँ

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS संदर्भ 4 प्रकार की छवियों को घोषित करता है, जिन्हें संभाला जा सकता है: 1. अंतर्निहित आयाम (प्राकृतिक आकार) वाली छवियां और इसलिए स्थिर अनुपात, जिसमें सभी रास्टर छवियां शामिल हैं। 2. कई अंतर्निहित आयाम वाली छवियां, जो एक ही फ़ाइल में कई संस्करणों में मौजूद हैं, जिसमें ICON (*.ico) फ़ाइलें शामिल हैं। इसमें TIFF भी हो सकता है, क्योंकि यह एक फ़ाइल में कई छवियों का समर्थन करता है, लेकिन वेब में TIFF फ़ॉर्मेट समर्थित नहीं है। 3. बिना अंतर्निहित आयाम के लेकिन चौड़ाई और ऊँचाई के बीच अंतर्निहित अनुपात वाली छवियां। इसमें सभी वेक्टर छवियां, विशेष रूप से SVG, शामिल हैं। 4. न तो अंतर्निहित आयाम और न ही अंतर्निहित अनुपात वाली छवियां। इसमें सभी ग्रेडिएंट शामिल हैं।
