GroupDocs.Editor.Metadata नेमस्पेस क्लासेज़ प्रदान करता है जो दस्तावेज़ प्रकार पर निर्भर बुनियादी दस्तावेज़ गुणों का वर्णन करने के लिए हैं।

## Structures

| संरचना | विवरण |
| --- | --- |
| [EbookDocumentInfo](./ebookdocumentinfo) | एक e-Book दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [EmailDocumentInfo](./emaildocumentinfo) | किसी भी समर्थित ईमेल प्रारूप के एक ईमेल दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [FixedLayoutDocumentInfo](./fixedlayoutdocumentinfo) | PDF या XPS जैसे स्थिर लेआउट प्रारूप वाले एक दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [MarkdownDocumentInfo](./markdowndocumentinfo) | एक Markdown दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [PresentationDocumentInfo](./presentationdocumentinfo) | एक प्रस्तुति दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [SpreadsheetDocumentInfo](./spreadsheetdocumentinfo) | एक स्प्रेडशीट दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [TextualDocumentInfo](./textualdocumentinfo) | XML, HTML या साधारण पाठ (TXT) जैसे एक पाठ्य दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
| [WordProcessingDocumentInfo](./wordprocessingdocumentinfo) | एक WordProcessing दस्तावेज़ के मेटाडेटा का प्रतिनिधित्व करता है |
