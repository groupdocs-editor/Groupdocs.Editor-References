## DelimitedTextEditOptions.OptimizeMemoryUsage property

इनपुट दस्तावेज़ प्रोसेसिंग के दौरान मेमोरी ऑप्टिमाइज़ेशन मैकेनिज़्म को सक्षम करता है, जो कुछ विशेष मामलों में प्रदर्शन को घटा सकता है, लेकिन दूसरी ओर मेमोरी उपयोग को कम करता है। बड़े दस्तावेज़ों को प्रोसेस करने और OutOfMemoryException का सामना करने पर उपयोगी है। डिफ़ॉल्ट `false` है (बेहतर प्रदर्शन के लिए मेमोरी ऑप्टिमाइज़ेशन अक्षम है)।

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
