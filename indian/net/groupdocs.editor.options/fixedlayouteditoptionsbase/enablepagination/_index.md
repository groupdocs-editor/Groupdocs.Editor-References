## FixedLayoutEditOptionsBase.EnablePagination property

परिणामी HTML दस्तावेज़ में पेजिनेशन को सक्षम (true) या अक्षम (false) करने की अनुमति देता है। डिफ़ॉल्ट रूप से अक्षम (false) है।

```csharp
public bool EnablePagination { get; set; }
```

### टिप्पणियाँ

Fixed-layout फ़ॉर्मेट दस्तावेज़ (विशेष रूप से PDF और XPS) मूल रूप से सख्ती से पृष्ठबद्ध होते हैं, उनका सामग्री स्थिर लेआउट रखती है और पृष्ठों में विभाजित होती है। लेकिन परिणामी संपादन योग्य HTML को पेजलेस या पेजिनल दृश्य में प्रस्तुत किया जा सकता है।
