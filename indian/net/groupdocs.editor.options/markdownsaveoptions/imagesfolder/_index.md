## MarkdownSaveOptions.ImagesFolder property

निर्धारित करता है कि मार्कडाउन फ़ॉर्मेट में दस्तावेज़ निर्यात करते समय छवियों को किस फ़ोल्डर में सहेजा जाए। डिफ़ॉल्ट `null` है।

```csharp
public string ImagesFolder { get; set; }
```

### टिप्पणियाँ

यदि उपयोगकर्ता द्वारा न तो `ImagesFolder` और न ही [`ExportImagesAsBase64`](../exportimagesasbase64) निर्दिष्ट किया गया है, तो GroupDocs.Editor स्वयं `ImagesFolder` निर्धारित करने का प्रयास करेगा और सफलता पर इसे लागू करेगा
