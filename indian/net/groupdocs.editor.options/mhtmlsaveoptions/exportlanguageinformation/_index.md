## MhtmlSaveOptions.ExportLanguageInformation property

निर्दिष्ट करता है कि क्या भाषा जानकारी को MHTML में निर्यात किया जाए। डिफ़ॉल्ट मान `false` है।

```csharp
public bool ExportLanguageInformation { get; set; }
```

### टिप्पणियाँ

जब इस प्रॉपर्टी को `true` पर सेट किया जाता है, तो GroupDocs.Editor दस्तावेज़ तत्वों पर `lang` HTML-एट्रिब्यूट उत्पन्न करता है जो भाषा निर्दिष्ट करते हैं। यह भाषा-संबंधी अर्थ को संरक्षित करने के लिए आवश्यक हो सकता है।
