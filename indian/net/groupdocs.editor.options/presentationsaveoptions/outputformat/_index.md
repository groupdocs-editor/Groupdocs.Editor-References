## PresentationSaveOptions.OutputFormat property

प्रेजेंटेशन फ़ॉर्मेट निर्दिष्ट करने की अनुमति देता है, जिसका उपयोग दस्तावेज़ को सहेजने के लिए किया जाएगा।

```csharp
public PresentationFormats OutputFormat { get; set; }
```

### टिप्पणियाँ

आउटपुट फ़ॉर्मेट आमतौर पर इस क्लास के कंस्ट्रक्टर में सेट किया जाता है, क्योंकि यह अनिवार्य है। यह प्रॉपर्टी बाद में आउटपुट फ़ॉर्मेट प्राप्त करने या संशोधित करने की अनुमति देती है, जब [`PresentationSaveOptions`](../../presentationsaveoptions) क्लास का इंस्टेंस पहले ही बनाया जा चुका हो।
