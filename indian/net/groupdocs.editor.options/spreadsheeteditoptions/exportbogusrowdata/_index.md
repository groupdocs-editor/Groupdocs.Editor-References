## SpreadsheetEditOptions.ExportBogusRowData property

सक्षम होने पर, उत्पन्न HTML दस्तावेज़ में HTML टेबल में नीचे की ओर एक खाली छिपी पंक्ति शून्य ऊँचाई और खाली सेल्स के साथ होती है, जहाँ केवल चौड़ाई निर्दिष्ट की गई है। यह खाली सेल्स वाली पंक्ति प्रत्येक कॉलम के लिए सटीक चौड़ाई मान रखती है और HTML से स्प्रेडशीट में बैकवर्ड रूपांतरण को सुधारती है। डिफ़ॉल्ट रूप से यह सक्षम (`true`) है।

```csharp
public bool ExportBogusRowData { get; set; }
```
