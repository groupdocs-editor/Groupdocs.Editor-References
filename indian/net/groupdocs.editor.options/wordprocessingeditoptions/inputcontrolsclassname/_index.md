## WordProcessingEditOptions.InputControlsClassName property

एक क्लास नाम निर्दिष्ट करने की अनुमति देता है, जो इनपुट WordProcessing दस्तावेज़ में किसी फ़ील्ड का प्रतिनिधित्व करने वाले प्रत्येक HTML तत्व के 'class' एट्रिब्यूट में रखा जाएगा। डिफ़ॉल्ट रूप से यह NULL है - 'class' एट्रिब्यूट लागू नहीं होते।

```csharp
public string InputControlsClassName { get; set; }
```

### टिप्पणियाँ

WordProcessing फ़ॉर्मेट परिवार के लगभग सभी फ़ॉर्मेट में फ़ील्ड होते हैं — विशिष्ट दस्तावेज़ इकाइयाँ, जो उपयोगकर्ताओं से इनपुट डेटा प्राप्त करने की अनुमति देती हैं। फ़ील्ड की विविधता में टेक्स्ट-बॉक्स, चेकबॉक्स, कॉम्बो-बॉक्स, ड्रॉप‑डाउन सूची, बटन, तिथि/समय पिकर आदि शामिल हैं। इन सभी को सबसे उपयुक्त HTML संरचनाओं और तत्वों में अनुवादित किया जाता है, साथ ही यदि इनपुट दस्तावेज़ में मौजूद हों तो दर्ज किए गए उपयोगकर्ता डेटा को संरक्षित रखा जाता है। कुछ विशेष उपयोग मामलों में पूरे दस्तावेज़ की सामग्री को संपादित करने के बजाय केवल क्लाइंट‑साइड पर दर्ज किए गए डेटा को एकत्र करना आवश्यक होता है। ऐसे मामलों में क्लाइंट‑साइड पर डेटा के साथ इनपुट कंट्रोल्स को प्राप्त करने के लिए उन्हें किसी न किसी रूप में पहचानना आवश्यक है। यह प्रॉपर्टी एक क्लास नाम निर्दिष्ट करने की अनुमति देती है, जो HTML मार्कअप में प्रत्येक इनपुट कंट्रोल पर लागू होगा, ताकि क्लाइंट कोड HTML दस्तावेज़ संरचना को पार कर डेटा एकत्र कर सके।
