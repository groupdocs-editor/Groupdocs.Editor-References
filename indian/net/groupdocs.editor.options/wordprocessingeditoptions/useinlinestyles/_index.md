## WordProcessingEditOptions.UseInlineStyles property

इनपुट WordProcessing दस्तावेज़ के स्टाइलिंग और फॉर्मेटिंग डेटा को कहाँ संग्रहीत किया जाए, यह नियंत्रित करता है: बाहरी स्टाइलशीट (`false`) में या HTML मार्कअप में इनलाइन स्टाइल्स (`true`) के रूप में। डिफ़ॉल्ट रूप से बाहरी स्टाइल्स उपयोग किए जाते हैं (`false`).

```csharp
public bool UseInlineStyles { get; set; }
```
