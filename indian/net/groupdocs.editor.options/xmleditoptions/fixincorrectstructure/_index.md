## XmlEditOptions.FixIncorrectStructure property

क्षतिग्रस्त XML संरचना को ठीक करने के तंत्र को सक्षम या अक्षम करने की अनुमति देता है। डिफ़ॉल्ट रूप से यह अक्षम है (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट रूप से केवल सही, मान्य और सुव्यवस्थित XML दस्तावेज़ स्वीकार्य होते हैं। जब यह विकल्प सक्षम किया जाता है, तो GroupDocs.Editor संभव होने पर त्रुटिपूर्ण XML संरचना को ठीक करने का प्रयास करेगा।
