## XpsSaveOptions.OptimizeMemoryUsage property

HTML से दस्तावेज़ जनरेट करने के दौरान मेमोरी ऑप्टिमाइज़ेशन मैकेनिज़्म सक्षम करता है, जो मेमोरी उपयोग कम करने की कीमत पर प्रदर्शन को घटाता है। इस विकल्प को true सेट करने से बड़े दस्तावेज़ जनरेट करते समय मेमोरी खपत में काफी कमी आ सकती है, लेकिन सहेजने के समय धीमा हो जाता है। डिफ़ॉल्ट रूप से false है (बेहतर प्रदर्शन के लिए मेमोरी ऑप्टिमाइज़ेशन अक्षम है)।

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
