## DropDownFormField.HelpText property

फ़ॉर्म फ़ील्ड से संबंधित हेल्प टेक्स्ट को प्राप्त करता है या सेट करता है, वह स्रोत जहाँ टेक्स्ट संदेश बॉक्स में दिखाया जाता है जब फ़ॉर्म फ़ील्ड फोकस में हो और उपयोगकर्ता F1 दबाए।

```csharp
public HelpText HelpText { get; set; }
```

### टिप्पणियाँ

`false` पर सेट करने पर, हेल्प टेक्स्ट लागू नहीं होगा।
