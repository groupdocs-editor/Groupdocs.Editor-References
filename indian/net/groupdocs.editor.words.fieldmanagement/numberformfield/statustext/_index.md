## NumberFormField.StatusText property

फ़ॉर्म फ़ील्ड से संबंधित स्टेटस टेक्स्ट को प्राप्त करता है या सेट करता है, वह स्रोत जहाँ टेक्स्ट स्टेटस बार में दिखाया जाता है जब फ़ॉर्म फ़ील्ड फोकस में हो।

```csharp
public HelpText StatusText { get; set; }
```

### टिप्पणियाँ

`false` पर सेट करने पर, स्टेटस टेक्स्ट लागू नहीं होगा।
