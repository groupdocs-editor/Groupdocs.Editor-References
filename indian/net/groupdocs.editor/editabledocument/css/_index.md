## EditableDocument.Css property

इस HTML दस्तावेज़ द्वारा उपयोग किए जाने वाले स्टाइलशीट (CSS) संसाधनों (बाहरी और एम्बेडेड, लेकिन इनलाइन नहीं) को प्राप्त करने की अनुमति देता है

```csharp
public List<CssText> Css { get; }
```

### टिप्पणियाँ

यह मेथड सभी उपयोग किए गए स्टाइलशीट संसाधनों की एक शैलो कॉपी लौटाता है: `List` प्रत्येक कॉल के लिए एक नया इंस्टेंस है, लेकिन संसाधन इंस्टेंस समान रहते हैं।
