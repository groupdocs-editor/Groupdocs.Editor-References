## Editor class

मुख्य क्लास, जो रूपांतरण विधियों को संलग्न करती है। Editor क्लास सभी समर्थित फ़ॉर्मैट्स के दस्तावेज़ों को लोड करने, संपादित करने और सहेजने के लिए विधियाँ प्रदान करती है। यह डिस्पोजेबल है, इसलिए 'using' निर्देश का उपयोग करें या 'Dispose()' मेथड कॉल के माध्यम से उसके संसाधनों को मैन्युअल रूप से डिस्पोज करें। दस्तावेज़ लोडिंग कंस्ट्रक्टर्स द्वारा की जाती है। दस्तावेज़ संपादन - 'Edit' मेथड के द्वारा, और संपादन के बाद परिणामस्वरूप दस्तावेज़ को सहेजना - 'Save' मेथड के द्वारा।

```csharp
public sealed class Editor : IAuxDisposable
```

### टिप्पणियाँ

Editor क्लास को GroupDocs.Editor का एंट्री पॉइंट और रूट ऑब्जेक्ट माना जाना चाहिए। सभी ऑपरेशन्स इस क्लास का उपयोग करके किए जाते हैं। पूर्ण दस्तावेज़ संपादन पाइपलाइन के लिए Editor क्लास का सामान्य उपयोग निम्नलिखित है:

1. कंस्ट्रक्टर के माध्यम से एक दस्तावेज़ को Editor इंस्टेंस में लोड करें।
2. वैकल्पिक रूप से, एक [`GetDocumentInfo`](./getdocumentinfo) मेथड का उपयोग करके दस्तावेज़ प्रकार का पता लगाएँ।
3. एक दस्तावेज़ को संपादन के लिए खोलने के लिए [`Edit`](./edit) मेथड को कॉल करें और उससे [`EditableDocument`](../editabledocument) क्लास का एक इंस्टेंस प्राप्त करें।
4. क्लाइंट-साइड पर किसी भी WYSIWYG HTML-एडिटर का उपयोग करके दस्तावेज़ की सामग्री को संपादित करना।
5. संपादित दस्तावेज़ सामग्री से एक नया [`EditableDocument`](../editableddocument) इंस्टेंस बनाना।
6. एक [`Save`](./save) मेथड को कॉल करके संपादित दस्तावेज़ को किसी आउटपुट फ़ॉर्मेट में सहेजना।
7. Editor क्लास की एक इंस्टेंस को 'using' ऑपरेटर द्वारा या मैन्युअल रूप से डिस्पोज़ करना।
