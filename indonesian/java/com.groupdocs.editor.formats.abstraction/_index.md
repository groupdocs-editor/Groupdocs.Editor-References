Namespace **com.groupdocs.editor.formats.abstraction** menyediakan antarmuka dan kelas yang menjelaskan format dokumen yang didukung dalam pustaka GroupDocs.Editor.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [DocumentFormatBase](../com.groupdocs.editor.formats.abstraction/documentformatbase) | Mewakili kelas dasar untuk format dokumen, menyediakan fungsionalitas umum untuk instance format. |
| [FormatFamilyBase](../com.groupdocs.editor.formats.abstraction/formatfamilybase) | Mewakili kelas dasar untuk keluarga format, menyediakan fungsionalitas umum untuk instance keluarga format. |

## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IDocumentFormat](../com.groupdocs.editor.formats.abstraction/idocumentformat) | Mewakili antarmuka akar untuk semua format dokumen yang didukung. |
