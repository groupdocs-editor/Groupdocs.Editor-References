Namespace **com.groupdocs.editor.formats** menyediakan antarmuka dan kelas yang menggambarkan format dokumen yang didukung.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Mengkapsulkan semua format eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Mengkapsulkan semua format email. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Mengkapsulkan semua format tata letak tetap (juga dikenal sebagai "fixed-page"), yang mencakup PDF dan XPS (ini tidak termasuk gambar raster) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Mewakili berbagai keluarga format yang tersedia dalam sistem. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Mengkapsulkan semua format Presentasi. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Mengkapsulkan semua format Spreadsheet biner, XML, dan tekstual (mengecualikan semua format berbasis pemisah teks dengan pemisah seperti CSV, TSV, dipisahkan titik koma, dll.), di mana buku kerja dapat disimpan. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Mengkapsulkan semua format tekstual (berbasis teks), termasuk markup (XML, HTML) dan lainnya. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Mengkapsulkan semua format Pengolah Kata. |
