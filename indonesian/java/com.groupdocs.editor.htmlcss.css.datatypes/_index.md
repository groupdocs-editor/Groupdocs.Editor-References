Namespace **com.groupdocs.editor.htmlcss.css.datatypes** menyediakan kelas yang mewakili tipe data CSS.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Mewakili satu nilai warna dalam format ARGB dengan konverter dan serializer. |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Berisi semua \"warna yang dikenal\", yang memiliki nama unik tetap dan nilai dalam standar CSS. |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Mewakili nilai panjang CSS dalam unit apa pun yang didukung, termasuk persentase dan tipe tanpa unit. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Semua unit panjang yang didukung |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Mewakili tipe data CSS \"ratio\", yang digunakan untuk menggambarkan rasio aspek dalam kueri media dan untuk gambar raster dengan menunjukkan proporsi antara dua nilai tanpa unit yang disebut \"numerator\" dan \"denominator\". |
