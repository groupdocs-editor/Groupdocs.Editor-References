Namespace **com.groupdocs.editor.htmlcss.resources.images.raster** menyediakan kelas yang hanya mewakili sumber daya gambar raster.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [BmpImage](../com.groupdocs.editor.htmlcss.resources.images.raster/bmpimage) | Mewakili satu gambar dalam format BMP (BitMap Picture) dengan metadata dan metode tambahan |
| [GifImage](../com.groupdocs.editor.htmlcss.resources.images.raster/gifimage) | Mewakili satu gambar dalam format GIF (Graphics Interchange Format) dengan metadata-nya dan metode tambahan |
| [IconImage](../com.groupdocs.editor.htmlcss.resources.images.raster/iconimage) | Mewakili satu gambar dalam format ICON dengan metadata-nya dan metode tambahan |
| [JpegImage](../com.groupdocs.editor.htmlcss.resources.images.raster/jpegimage) | Mewakili satu gambar dalam format JPEG (Joint Photographic Experts Group) dengan metadata-nya dan metode tambahan |
| [PngImage](../com.groupdocs.editor.htmlcss.resources.images.raster/pngimage) | Mewakili satu gambar dalam format PNG (Portable Network Graphics) dengan metadata-nya dan metode tambahan |
| [RasterImageResourceBase](../com.groupdocs.editor.htmlcss.resources.images.raster/rasterimageresourcebase) | Kelas dasar untuk setiap gambar raster yang didukung dengan nama tetap, dimensi, aspectratio, tipe, ukuran, dan konten. |
| [TiffImage](../com.groupdocs.editor.htmlcss.resources.images.raster/tiffimage) | Mewakili satu gambar dalam format TIFF (Tagged Image File Format) dengan metadata-nya dan metode tambahan |
