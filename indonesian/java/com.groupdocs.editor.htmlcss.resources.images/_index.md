Namespace **com.groupdocs.editor.htmlcss.resources.images** menyediakan kelas yang mewakili sumber daya gambar dari semua jenis secara umum.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Mewakili dimensi linier (lebar dan tinggi) dari satu gambar raster persegi panjang dalam satuan arbitrer. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Mewakili satu tipe gambar yang dapat didukung (format), mendukung baik format raster maupun vektor. |

## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Tipe data CSS gambar mewakili gambar dua dimensi. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Mewakili sumber daya gambar dari jenis apa pun, raster atau vektor. |
