Namespace **com.groupdocs.editor.htmlcss.resources** menyediakan kelas yang mewakili semua jenis sumber daya HTML.

| Kelas | Deskripsi |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | Metode statis utilitas untuk mendeteksi tipe sumber daya (format). |

| Antarmuka | Deskripsi |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | Memperluas antarmuka IDisposable standar, memungkinkan memperoleh status saat ini dari sebuah objek dan berlangganan ke peristiwa pembuangan. |
