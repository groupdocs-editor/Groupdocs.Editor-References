Namespace **com.groupdocs.editor.metadata** menyediakan kelas untuk menggambarkan properti dokumen dasar yang bergantung pada tipe dokumen.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Mewakili metadata satu dokumen EBook |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Mewakili metadata satu dokumen email dalam format email yang didukung apa pun |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Mewakili metadata satu dokumen dengan format tata letak tetap seperti PDF atau XPS |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Mewakili metadata satu dokumen Markdown |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Mewakili metadata satu dokumen Presentasi |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Mewakili metadata satu dokumen Spreadsheet |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Mewakili metadata satu dokumen tekstual seperti XML, HTML, atau teks biasa (TXT) |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Mewakili metadata satu dokumen Pengolah Kata |
