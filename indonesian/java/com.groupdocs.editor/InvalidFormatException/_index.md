```
public final class InvalidFormatException extends RuntimeException
```

Pengecualian yang dilemparkan ketika pengguna mencoba membuka dokumen dengan
opsi format-spesifik yang tidak kompatibel dengan format dokumen asli.


*** ** * ** ***

Sebagai contoh, pengecualian ini akan dilemparkan, jika mencoba membuka dokumen Spreadsheet dengan opsi dokumen WordProcessing.
