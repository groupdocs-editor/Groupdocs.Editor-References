Namespace **com.groupdocs.editor** adalah namespace root, yang menyediakan kelas untuk mengedit berbagai format dokumen dalam aplikasi Java Anda.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Dokumen menengah, yang berisi konten sebelum dan sesudah penyuntingan |
| [Editor](../com.groupdocs.editor/editor) | Kelas utama, yang mengenkapsulasi metode konversi. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | Pengecualian yang dilempar ketika pengguna mencoba membuka dokumen yang dienkripsi menggunakan X509Certificates. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | Pengecualian yang dilempar ketika kata sandi yang ditentukan tidak benar. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | Pengecualian yang dilempar ketika pengguna mencoba membuka dokumen dengan opsi khusus format yang tidak kompatibel dengan format dokumen asli. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | Pengecualian yang dilempar ketika pengguna mencoba membuka dokumen terenkripsi yang dilindungi kata sandi dalam format tertentu dan tidak menyediakan kata sandi untuk membuka dokumen ini. |
