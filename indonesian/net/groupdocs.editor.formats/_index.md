Namespace GroupDocs.Editor.Formats menyediakan antarmuka dan kelas yang menjelaskan format dokumen yang didukung.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [EBookFormats](./ebookformats) | Mewakili semua format eBook. Menyertakan tipe file berikut: [`Mobi`](../groupdocs.editor.formats/ebookformats/mobi), [`Epub`](../groupdocs.editor.formats/ebookformats/epub), [`Azw3`](../groupdocs.editor.formats/ebookformats/azw3). |
| [EmailFormats](./emailformats) | Mewakili semua format email. Menyertakan tipe file berikut: [`Tnef`](../groupdocs.editor.formats/emailformats/tnef), [`Eml`](../groupdocs.editor.formats/emailformats/eml), [`Emlx`](../groupdocs.editor.formats/emailformats/emlx), [`Msg`](../groupdocs.editor.formats/emailformats/msg), [`Html`](../groupdocs.editor.formats/emailformats/html), [`Mhtml`](../groupdocs.editor.formats/emailformats/mhtml). |
| [FixedLayoutFormats](./fixedlayoutformats) | Mewakili format dokumen tata letak tetap (halaman tetap), seperti PDF, tidak termasuk format gambar raster. |
| [FormatFamilies](./formatfamilies) | Mewakili berbagai keluarga format yang tersedia dalam sistem. |
| [PresentationFormats](./presentationformats) | Mewakili semua format Presentasi. Menyertakan format berikut: |
| [SpreadsheetFormats](./spreadsheetformats) | Mewakili semua format Spreadsheet biner, XML, dan tekstual (tidak termasuk semua format berbasis pemisah teks dengan pemisah seperti CSV, TSV, dipisahkan dengan titik koma, dll), di mana buku kerja dapat disimpan. Menyertakan format berikut: [`Xls`](../groupdocs.editor.formats/spreadsheetformats/xls), [`Xlt`](../groupdocs.editor.formats/spreadsheetformats/xlt), [`Xlsx`](../groupdocs.editor.formats/spreadsheetformats/xlsx), [`Xlsm`](../groupdocs.editor.formats/spreadsheetformats/xlsm), [`Xlsb`](../groupdocs.editor.formats/spreadsheetformats/xlsb), [`Xltx`](../groupdocs.editor.formats/spreadsheetformats/xltx), [`Xltm`](../groupdocs.editor.formats/spreadsheetformats/xltm), [`Xlam`](../groupdocs.editor.formats/spreadsheetformats/xlam), [`SpreadsheetML`](../groupdocs.editor.formats/spreadsheetformats/spreadsheetml), [`Ods`](../groupdocs.editor.formats/spreadsheetformats/ods), [`Fods`](../groupdocs.editor.formats/spreadsheetformats/fods), [`Sxc`](../groupdocs.editor.formats/spreadsheetformats/sxc), [`Dif`](../groupdocs.editor.formats/spreadsheetformats/dif), [`Csv`](../groupdocs.editor.formats/spreadsheetformats/csv), [`Tsv`](../groupdocs.editor.formats/spreadsheetformats/tsv). Pelajari lebih lanjut tentang format Spreadsheet [di sini](https://wiki.fileformat.com/spreadsheet). |
| [TextualFormats](./textualformats) | Mewakili semua format tekstual (berbasis teks), termasuk markup (XML, HTML) dan lainnya. Menyertakan format berikut: [`Html`](../groupdocs.editor.formats/textualformats/html), [`Txt`](../groupdocs.editor.formats/textualformats/txt), [`Xml`](../groupdocs.editor.formats/textualformats/xml), [`Md`](../groupdocs.editor.formats/textualformats/md), [`Json`](../groupdocs.editor.formats/textualformats/json), [`Mhtml`](../groupdocs.editor.formats/textualformats/mhtml), [`Chm`](../groupdocs.editor.formats/textualformats/chm). |
