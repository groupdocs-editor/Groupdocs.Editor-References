| --- | --- |
| [ArgbColor](./argbcolor) | Mewakili nilai panjang CSS dalam format 32-bit ARGB (8 bit per kanal termasuk transparansi) dengan konverter dan serializer |
| [Length](./length) | Mewakili nilai panjang CSS dalam unit apa pun yang didukung, termasuk persentase dan tipe tanpa satuan. Nilai dapat berupa integer atau float, negatif, nol, dan positif. Struktur tidak dapat diubah. |
