Namespace GroupDocs.Editor.HtmlCss.Resources.Images.Raster menyediakan kelas yang hanya mewakili sumber daya gambar raster.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [BmpImage](./bmpimage) | Mewakili satu gambar dalam format BMP (BitMap Picture) dengan metadata dan metode tambahan. |
| [GifImage](./gifimage) | Mewakili satu gambar dalam format GIF (Graphics Interchange Format) dengan metadata dan metode tambahan. |
| [IconImage](./iconimage) | Mewakili satu gambar dalam format ICON dengan metadata dan metode tambahan. |
| [JpegImage](./jpegimage) | Mewakili satu gambar dalam format JPEG (Joint Photographic Experts Group) dengan metadata dan metode tambahan. |
| [PngImage](./pngimage) | Mewakili satu gambar dalam format PNG (Portable Network Graphics) dengan metadata dan metode tambahan. |
| [RasterImageResourceBase](./rasterimageresourcebase) | Kelas dasar untuk semua gambar raster yang didukung dengan nama tetap, dimensi, rasio aspek, tipe, ukuran, dan konten. |
| [TiffImage](./tiffimage) | Mewakili satu gambar dalam format TIFF (Tagged Image File Format) dengan metadata dan metode tambahan. |
