## IImage interface

Tipe data CSS gambar mewakili gambar dua dimensi.

```csharp
public interface IImage
```

### Catatan

https://developer.mozilla.org/en-US/docs/Web/CSS/image referensi CSS menyatakan 4 tipe gambar, yang dapat ditangani: 1. Gambar dengan dimensi intrinsik (ukuran alami) dan sehingga rasio aspek tetap, yang mencakup semua gambar raster. 2. Gambar dengan banyak dimensi intrinsik, yang ada dalam beberapa versi di dalam satu file, yang mencakup file ICON (*.ico). Ini juga dapat berupa TIFF, karena mereka mendukung banyak gambar dalam satu file, namun format TIFF tidak didukung di web. 3. Gambar tanpa dimensi intrinsik tetapi dengan rasio aspek intrinsik antara lebar dan tinggi. Ini mencakup semua gambar vektor, terutama SVG. 4. Gambar tanpa dimensi intrinsik maupun rasio aspek intrinsik. Ini mencakup semua gradien.
