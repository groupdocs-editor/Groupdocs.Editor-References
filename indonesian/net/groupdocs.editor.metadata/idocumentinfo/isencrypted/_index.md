## IDocumentInfo.IsEncrypted property

Menunjukkan apakah file tertentu terenkripsi dan memerlukan kata sandi untuk dibuka. Untuk tipe dokumen yang tidak dapat dienkripsi (seperti semua berbasis teks) harus selalu mengembalikan 'false'.
