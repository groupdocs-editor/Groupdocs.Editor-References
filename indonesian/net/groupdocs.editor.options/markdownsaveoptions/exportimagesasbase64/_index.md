## MarkdownSaveOptions.ExportImagesAsBase64 property

Menentukan apakah gambar disimpan dalam format Base64 ke file output. Defaultnya adalah `false`.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### Catatan

Ketika properti ini diatur ke `true`, data gambar diekspor langsung ke elemen gambar ![]() dan file terpisah tidak dibuat. Properti ini, jika diatur ke `true`, memiliki prioritas lebih tinggi daripada properti [`ImagesFolder`](../imagesfolder).
