## MhtmlSaveOptions.ExportLanguageInformation property

Menentukan apakah informasi bahasa diekspor ke MHTML. Nilai default adalah `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### Catatan

Ketika properti ini diatur ke `true`, GroupDocs.Editor menghasilkan atribut HTML `lang` pada elemen dokumen yang menentukan bahasa. Hal ini dapat diperlukan untuk mempertahankan semantik terkait bahasa.
