### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Pdf17 | `0` | Standar PDF 1.7 (ISO 32000-1) |
| Pdf20 | `1` | Standar PDF 2.0 (ISO 32000-2) |
| PdfA1a | `2` | Standar PDF/A-1a. Tingkat ini mencakup semua persyaratan PDF/A-1b dan tambahan mengharuskan struktur dokumen disertakan (juga dikenal sebagai "tagged"), dengan tujuan memastikan konten dokumen dapat dicari dan digunakan kembali. |

| PdfA2a | `4` | Standar PDF/A-2a (ISO 19005-2). Tingkat ini mencakup semua persyaratan PDF/A-2u dan tambahan mengharuskan struktur dokumen disertakan (juga dikenal sebagai "tagged"), dengan tujuan memastikan konten dokumen dapat dicari dan digunakan kembali. |
| PdfA2u | `5` | Standar PDF/A-2u (ISO 19005-2). PDF/A-2u bertujuan mempertahankan tampilan visual statis dokumen seiring waktu, terlepas dari alat dan sistem yang digunakan untuk membuat, menyimpan, atau merender file. Selain itu, teks apa pun yang terdapat dalam dokumen dapat diekstrak secara andal sebagai rangkaian kode Unicode. |
| PdfUa1 | `6` | Standar PDF/UA-1 (ISO 14289-1). Tujuan utama PDF/UA adalah mendefinisikan cara merepresentasikan dokumen elektronik dalam format PDF sehingga file dapat diakses. |
