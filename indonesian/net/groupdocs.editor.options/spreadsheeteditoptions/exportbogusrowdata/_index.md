## SpreadsheetEditOptions.ExportBogusRowData property

Ketika diaktifkan, tabel HTML dalam dokumen HTML yang dihasilkan berisi baris tersembunyi kosong di bagian bawah dengan tinggi nol dan sel kosong, di mana hanya lebar yang ditentukan. Baris dengan sel kosong ini berisi nilai lebar tepat untuk setiap kolom dan meningkatkan konversi balik dari HTML ke Spreadsheet. Secara default diaktifkan (`true`).

public bool ExportBogusRowData { get; set; }
