## WordProcessingSaveOptions.EnablePagination property

Mengizinkan untuk mengaktifkan atau menonaktifkan paginasi yang akan digunakan untuk menyimpan dokumen WordProcessing. Jika dokumen asli dibuka dan diedit dalam mode paginasi, opsi ini juga harus diaktifkan. Secara default dinonaktifkan.

public bool EnablePagination { get; set; }
