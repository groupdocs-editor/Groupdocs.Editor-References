## XmlEditOptions.FixIncorrectStructure property

Mengizinkan untuk mengaktifkan atau menonaktifkan mekanisme perbaikan struktur XML yang rusak. Secara default dinonaktifkan (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Catatan

Secara default hanya dokumen XML yang tepat, valid, dan terstruktur dengan baik yang dapat diterima. Ketika opsi ini diaktifkan, GroupDocs.Editor akan mencoba memperbaiki struktur XML yang rusak jika memungkinkan.
