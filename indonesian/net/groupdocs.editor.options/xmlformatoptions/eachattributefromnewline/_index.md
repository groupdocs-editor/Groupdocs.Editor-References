## XmlFormatOptions.EachAttributeFromNewline property

Ketika diaktifkan, setiap pasangan atribut-nilai dalam setiap elemen XML akan ditempatkan pada baris baru. Secara default bernilai false (dinonaktifkan) — semua pasangan atribut-nilai ditempatkan dalam satu baris.

public bool EachAttributeFromNewline { get; set; }
