## XpsSaveOptions.OptimizeMemoryUsage property

Mengaktifkan mekanisme optimasi memori selama pembuatan dokumen dari HTML, yang mengurangi kinerja sebagai biaya pengurangan penggunaan memori. Mengatur opsi ini ke true dapat secara signifikan mengurangi konsumsi memori saat menghasilkan dokumen besar dengan biaya waktu penyimpanan yang lebih lambat. Nilai default adalah false (optimasi memori dinonaktifkan demi kinerja yang lebih baik).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
