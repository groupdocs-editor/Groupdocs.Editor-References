## EditableDocument.Css property

Memungkinkan memperoleh sumber daya stylesheet (CSS) (baik eksternal maupun tersemat, tetapi tidak inline), yang digunakan oleh dokumen HTML ini

```csharp
public List<CssText> Css { get; }
```

### Catatan

Metode ini mengembalikan salinan dangkal dari semua sumber daya stylesheet yang digunakan: `List` adalah instance baru untuk setiap pemanggilan, tetapi instance sumber daya tetap sama.
