## EditableDocument.Fonts property

Memungkinkan memperoleh sumber daya font eksternal, yang digunakan oleh dokumen HTML ini

```csharp
public List<FontResourceBase> Fonts { get; }
```

### Catatan

Metode ini mengembalikan salinan dangkal dari semua sumber daya font yang digunakan: `List` adalah instance baru untuk setiap pemanggilan, tetapi instance sumber daya tetap sama.
