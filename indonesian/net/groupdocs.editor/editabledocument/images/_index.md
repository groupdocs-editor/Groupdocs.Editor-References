## EditableDocument.Images property

Memungkinkan memperoleh sumber daya gambar eksternal (gambar raster dan vektor), yang digunakan oleh dokumen HTML ini

```csharp
public List<IImageResource> Images { get; }
```

### Catatan

Metode ini mengembalikan salinan dangkal dari semua sumber daya gambar yang digunakan: `List` adalah instance baru untuk setiap pemanggilan, tetapi instance sumber daya tetap sama.
