## Editor.Dispose method

Membuang instance Editor ini, sehingga melepaskan semua sumber daya internal dan menjadi tidak tersedia untuk penggunaan selanjutnya.

```csharp
public void Dispose()
```

### Catatan

Setelah metode ini dipanggil, memanggil semua metode lain dari instansi ini akan melempar ObjectDisposedException. Aman untuk memanggil metode ini berkali-kali — semua panggilan berikutnya diabaikan.
