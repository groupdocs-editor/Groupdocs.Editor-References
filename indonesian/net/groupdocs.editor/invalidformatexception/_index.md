## InvalidFormatException class

Pengecualian yang dilemparkan ketika pengguna mencoba membuka dokumen dengan opsi khusus format yang tidak kompatibel dengan format dokumen asli.

```csharp
public sealed class InvalidFormatException : Exception
```

### Catatan

Sebagai contoh, pengecualian ini akan dilemparkan jika mencoba membuka dokumen Spreadsheet dengan opsi dokumen Pengolah Kata.
