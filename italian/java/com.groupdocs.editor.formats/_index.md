Il namespace **com.groupdocs.editor.formats** fornisce interfacce e classi che descrivono i formati di documento supportati.



## Classi

| Classe | Descrizione |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Incapsula tutti i formati eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Incapsula tutti i formati email. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Incapsula tutti i formati a layout fisso (conosciuti anche come "fixed-page"), che includono PDF e XPS (questo non include le immagini raster) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Rappresenta le diverse famiglie di formati disponibili nel sistema. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Incapsula tutti i formati di Presentazione. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Incapsula tutti i formati binari, XML e testuali di Foglio di calcolo (escludendo tutti i formati testuali basati su delimitatori con separatori come CSV, TSV, delimitati da punto e virgola, ecc.), in cui è possibile salvare la cartella di lavoro. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Incapsula tutti i formati testuali (basati su testo), inclusi markup (XML, HTML) e altri. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Incapsula tutti i formati di elaborazione testi. |
