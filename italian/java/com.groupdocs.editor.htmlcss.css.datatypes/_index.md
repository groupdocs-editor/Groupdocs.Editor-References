Il namespace **com.groupdocs.editor.htmlcss.css.datatypes** fornisce classi che rappresentano i tipi di dati CSS.



## Classi

| Classe | Descrizione |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Rappresenta un valore di colore in formato ARGB con convertitori e serializzatori |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Contiene tutti i \"colori noti\", che hanno un nome unico fisso e un valore nello standard CSS |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Rappresenta un valore di lunghezza CSS in qualsiasi unità supportata, inclusi percentuale e tipo senza unità. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Tutte le unità di lunghezza supportate |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Rappresenta un tipo di dato CSS \"ratio\", utilizzato per descrivere i rapporti d'aspetto nelle query multimediali e per le immagini raster indicando la proporzione tra due valori senza unità chiamati \"numeratore\" e \"denominatore\". |
