Controlla quali parti del messaggio di posta devono essere consegnate all'elaborazione di output

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [None](#None) | Nessuna parte del messaggio email verrà elaborata |
|
|  | [Body](#Body) | Elabora il corpo del messaggio di posta |
|
|  | [Subject](#Subject) | Elabora l'oggetto del messaggio di posta |
|
|  | [Date](#Date) | Elabora la data e l'ora di consegna del messaggio |
|
|  | [To](#To) | Elabora tutti i destinatari del messaggio di posta |
|
|  | [Cc](#Cc) | Elabora tutti i destinatari CC del messaggio di posta |
|
|  | [Bcc](#Bcc) | Elabora tutti i destinatari BCC del messaggio di posta |
|
|  | [From](#From) | Elabora il mittente del messaggio di posta |
|
|  | [Attachments](#Attachments) | Elabora tutti gli allegati del messaggio di posta |
|
|  | [Metadata](#Metadata) | Elabora tutti gli altri metadati tecnici (sensibilità, priorità, codifica, MIME, X-Mailer, ecc.) |
|
|  | [Common](#Common) | Output comune - corpo con tutti i metadati principali |
|
|  | [All](#All) | Output completo - corpo con tutti i metadati |
|
