Consente di specificare l'allineamento del contenuto della tabella da utilizzare quando
esportando in formato Markdown.

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [Auto](#Auto) | L'allineamento sarà preso dal primo paragrafo nella corrispondente |
colonna della tabella.
|
|  | [Left](#Left) | Il contenuto delle tabelle sarà allineato a sinistra. |
|
|  | [Center](#Center) | Il contenuto delle tabelle sarà allineato al centro. |
|
|  | [Right](#Right) | Il contenuto delle tabelle sarà allineato a destra. |
|
