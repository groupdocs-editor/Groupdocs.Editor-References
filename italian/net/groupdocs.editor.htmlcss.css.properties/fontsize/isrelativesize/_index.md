## FontSize.IsRelativeSize property

Indica se questa dimensione del carattere è definita con una dimensione relativa come parola chiave. Il carattere sarà più grande o più piccolo rispetto alla dimensione del carattere dell'elemento genitore, approssimativamente secondo il rapporto usato per separare le parole chiave di dimensione assoluta.
