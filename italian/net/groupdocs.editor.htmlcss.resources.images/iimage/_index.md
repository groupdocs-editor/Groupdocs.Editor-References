## IImage interface

Il tipo di dati CSS Image rappresenta un'immagine bidimensionale.

```csharp
public interface IImage
```

### Osservazioni

https://developer.mozilla.org/en-US/docs/Web/CSS/image Il riferimento CSS dichiara 4 tipi di immagini che possono essere gestiti: 1. Immagini con dimensioni intrinseche (una dimensione naturale) e quindi rapporto d'aspetto fisso, che includono tutte le immagini raster. 2. Immagini con più dimensioni intrinseche, esistenti in più versioni all'interno di un unico file, che includono i file ICON (*.ico). Questo può essere anche TIFF, poiché supporta più immagini in un file, tuttavia il formato TIFF non è supportato sul web. 3. Immagini senza dimensioni intrinseche ma con un rapporto d'aspetto intrinseco tra larghezza e altezza. Questo include tutte le immagini vettoriali, SVG prima di tutto. 4. Immagini senza né dimensioni intrinseche né un rapporto d'aspetto intrinseco. Questo include tutti i gradienti.
