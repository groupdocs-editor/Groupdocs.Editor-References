## EbookDocumentInfo.PageCount property

Restituisce il numero di pagine nel caso di MOBI o AZW3 o il numero di capitoli nel caso di ePub.

```csharp
public int PageCount { get; }
```

### Osservazioni

I documenti e-Book di solito non hanno pagine fisse e quindi conteggio delle pagine. Nel caso di ePub è possibile calcolare il numero di capitoli. Tuttavia, i formati MOBI e AZW3 non hanno nemmeno capitoli, quindi questo numero è calcolato a partire dalla dimensione di pagina standard impostata su A4 in orientamento verticale.
