## HtmlSaveOptions.SavingCallback property

Interfaccia che deve essere implementata dall'utente finale per salvare tutte le risorse HTML esterne. Questa proprietà **deve** non essere `null`, altrimenti GroupDocs.Editor genererà un'eccezione durante il salvataggio di [`EditableDocument`](../../../groupdocs.editor/editabledocument) in formato HTML.

```csharp
public IHtmlSavingCallback SavingCallback { get; set; }
```

### Osservazioni

Se il valore della proprietà [`EmbedStylesheetsIntoMarkup`](../embedstylesheetsintomarkup) è impostato su `true`, tutti i fogli di stile saranno incorporati nel markup HTML e quindi non verranno passati a questa callback di salvataggio.
