## MarkdownSaveOptions.ExportImagesAsBase64 property

Specifica se le immagini vengono salvate in formato Base64 nel file di output. Il valore predefinito è `false`.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### Osservazioni

Quando questa proprietà è impostata su `true`, i dati delle immagini vengono esportati direttamente negli elementi immagine ![]() e non vengono creati file separati. Questa proprietà, se impostata su `true`, ha priorità più alta rispetto alla proprietà [`ImagesFolder`](../imagesfolder).
