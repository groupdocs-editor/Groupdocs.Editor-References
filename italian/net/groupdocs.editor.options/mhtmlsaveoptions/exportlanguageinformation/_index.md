## MhtmlSaveOptions.ExportLanguageInformation property

Specifica se le informazioni sulla lingua sono esportate in MHTML. Il valore predefinito è `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### Osservazioni

Quando questa proprietà è impostata su `true`, GroupDocs.Editor emette l'attributo HTML `lang` sugli elementi del documento che specificano la lingua. Questo può essere necessario per preservare la semantica legata alla lingua.
