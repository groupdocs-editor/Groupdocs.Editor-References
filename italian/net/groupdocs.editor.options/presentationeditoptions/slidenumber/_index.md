## PresentationEditOptions.SlideNumber property

Consente di specificare i numeri delle diapositive che devono essere aperte per la modifica

```csharp
public int SlideNumber { get; set; }
```

### Osservazioni

Il numero della diapositiva è un indice basato su zero che consente di specificare e selezionare una diapositiva particolare da una presentazione da modificare. Se inferiore a 0, verrà selezionata la prima diapositiva (come SlideNumber = 0). Se superiore al numero totale di diapositive nella presentazione, verrà selezionata l'ultima diapositiva. Se la presentazione di input contiene una sola diapositiva, questa opzione verrà ignorata e la singola diapositiva verrà modificata. Se si tenta di aprire per la modifica una diapositiva nascosta, mentre l'opzione [`ShowHiddenSlides`](../showhiddenslides) è impostata su 'false', verrà generata un'eccezione.
