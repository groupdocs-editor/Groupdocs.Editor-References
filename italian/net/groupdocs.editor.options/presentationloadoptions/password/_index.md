## PresentationLoadOptions.Password property

Consente di specificare, modificare e ottenere la password che verrà utilizzata per aprire il documento Presentation, se è codificato. Impostare a NULL o a stringa vuota per rimuovere la password.

```csharp
public string Password { get; set; }
```

### Osservazioni

Per impostazione predefinita questa proprietà ha valore NULL — la password non è impostata. Se il documento Presentation di input è protetto da password, la password è obbligatoria e verrà sollevata un'eccezione se la password non è specificata o è invalida. Se il documento Presentation di input NON è protetto da password, ma la password è impostata, verrà ignorata.
