## PresentationSaveOptions.Password property

Consente di specificare, modificare e ottenere la password che verrà utilizzata per codificare il documento Presentation risultante. Per impostazione predefinita è NULL — la password non verrà impostata. Impostare a NULL o a stringa vuota per rimuovere la password, se era stata impostata in precedenza.
