## Proprietà

| Nome | Descrizione |
| --- | --- |
| [ExcludeHiddenWorksheets](../../groupdocs.editor.options/spreadsheeteditoptions/excludehiddenworksheets) { get; set; } | Consente di escludere i fogli di lavoro nascosti nel documento Spreadsheet di input, in modo che vengano completamente ignorati. L'impostazione predefinita è false — i fogli di lavoro nascosti sono disponibili e vengono elaborati normalmente. |
| [ExportBogusRowData](../../groupdocs.editor.options/spreadsheeteditoptions/exportbogusrowdata) { get; set; } | Quando abilitato, la tabella HTML nel documento HTML prodotto contiene una riga nascosta vuota in fondo con altezza zero e celle vuote, dove è specificata solo la larghezza. Questa riga con celle vuote contiene i valori di larghezza esatti per ciascuna colonna e migliora la conversione inversa da HTML a Spreadsheet. Per impostazione predefinita è abilitata (`true`). |
| [MergeEmptyAdjacentCells](../../groupdocs.editor.options/spreadsheeteditoptions/mergeemptyadjacentcells) { get; set; } | Quando abilitato, le celle orizzontali vuote adiacenti del documento Spreadsheet di input saranno rappresentate nel documento HTML modificabile come unite in un'unica cella con l'attributo `colspan` corrispondente. Per impostazione predefinita è disabilitato (`false`). |
