## SpreadsheetEditOptions.ExcludeHiddenWorksheets property

Consente di escludere i fogli di lavoro nascosti nel documento Spreadsheet di input, in modo che vengano completamente ignorati. L'impostazione predefinita è false — i fogli di lavoro nascosti sono disponibili e vengono elaborati normalmente.

```csharp
public bool ExcludeHiddenWorksheets { get; set; }
```

### Osservazioni

Diversi formati binari di Spreadsheet (come XLSX) supportano il concetto di fogli di lavoro nascosti (schede). Un documento di tale formato, se contiene più di un foglio di lavoro, può includere fogli di lavoro nascosti aggiuntivi. Per impostazione predefinita questi fogli nascosti sono disponibili per l'elaborazione, ma con questa opzione è possibile ignorarli, come se fossero assenti e non esistessero. Quando questa opzione è abilitata, non è possibile selezionare un foglio di lavoro nascosto con la proprietà '[`WorksheetIndex`](../worksheetindex)'.
