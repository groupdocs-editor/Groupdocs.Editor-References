## SpreadsheetEditOptions.ExportBogusRowData property

Quando abilitato, la tabella HTML nel documento HTML prodotto contiene una riga nascosta vuota in fondo con altezza zero e celle vuote, dove è specificata solo la larghezza. Questa riga con celle vuote contiene i valori di larghezza esatti per ciascuna colonna e migliora la conversione inversa da HTML a Spreadsheet. Per impostazione predefinita è abilitata (`true`).

public bool ExportBogusRowData { get; set; }
