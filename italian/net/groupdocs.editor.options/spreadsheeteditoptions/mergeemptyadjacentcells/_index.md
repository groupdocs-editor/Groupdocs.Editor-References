## SpreadsheetEditOptions.MergeEmptyAdjacentCells property

Quando abilitato, le celle orizzontali vuote adiacenti del documento Spreadsheet di input saranno rappresentate nel documento HTML modificabile come unite in un'unica cella con l'attributo `colspan` corrispondente. Per impostazione predefinita è disabilitato (`false`).

```csharp
public bool MergeEmptyAdjacentCells { get; set; }
```

### Osservazioni

Per impostazione predefinita GroupDocs.Editor converte una tabella dal documento Spreadsheet di input al documento HTML di output preservando ogni cella. Tuttavia, i documenti Spreadsheet possono essere sparsi — possono contenere una grande quantità di \"empty areas\", dove molte celle sono vuote. Questa opzione, quando abilitata, unisce tali celle vuote in una sola con l'attributo `colspan` nell'elemento `TD`, riducendo così in modo significativo la dimensione del markup HTML prodotto.
