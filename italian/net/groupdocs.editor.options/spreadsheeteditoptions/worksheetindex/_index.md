## SpreadsheetEditOptions.WorksheetIndex property

Consente di specificare l'indice basato su zero del foglio di lavoro (scheda) del documento Spreadsheet di input, che dovrebbe essere convertito in HTML (vedi note).

```csharp
public int WorksheetIndex { get; set; }
```

### Osservazioni

La maggior parte dei documenti Spreadsheet supporta il concetto di schede, cioè può avere più schede. D'altra parte, il formato HTML non supporta tale struttura. Per questo GroupDocs.Editor può convertire in HTML solo una scheda specifica del documento di input, e questa opzione consente di specificarla. L'indice della scheda è basato su zero, i valori negativi sono proibiti. Se l'indice specificato supera il numero totale di schede, verrà generata un'eccezione. Se il documento Spreadsheet di input contiene una sola scheda, questa opzione verrà ignorata. Il valore predefinito è 0 (prima scheda).
