## SpreadsheetLoadOptions.OptimizeMemoryUsage property

Abilita meccanismi di ottimizzazione della memoria durante l'elaborazione del documento di input, che possono degradare le prestazioni in alcuni casi speciali, ma d'altra parte riducono l'uso della memoria. Utile quando si elaborano documenti di grandi dimensioni e si verifica OutOfMemoryException. Il valore predefinito è false (l'ottimizzazione della memoria è disabilitata per garantire migliori prestazioni).

public bool OptimizeMemoryUsage { get; set; }
