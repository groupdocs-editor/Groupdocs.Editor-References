## Proprietà

| [InsertAsNewWorksheet](../../groupdocs.editor.options/spreadsheetsaveoptions/insertasnewworksheet) { get; set; } | Flag booleano che specifica se il foglio di lavoro modificato deve sostituire il foglio di lavoro esistente nel foglio di calcolo originale nella posizione indicata dalla proprietà [`WorksheetNumber`](./worksheetnumber), oppure se deve essere inserito tra il foglio di lavoro esistente e quello precedente, senza sostituirne il contenuto. Specificare NULL o una stringa vuota per rimuovere (pulire) la password. |
| [WorksheetNumber](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumber) { get; set; } | Consente di inserire il foglio di lavoro modificato in una copia di un foglio di calcolo esistente invece di creare un nuovo foglio di calcolo a foglio unico (comportamento predefinito). WorksheetNumber è un numero basato su 1 che indica il foglio di lavoro nel foglio di calcolo caricato nella classe Editor. Se è 0 (valore predefinito), il nuovo foglio di calcolo verrà creato con un unico foglio di lavoro modificato. Se è maggiore o minore di zero, e esiste un foglio di calcolo valido caricato nella classe Editor, il foglio di lavoro modificato, rappresentato dall'istanza EditableDocument di input, verrà inserito in questo foglio di calcolo. |
| [WorksheetNumbersToDelete](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete) { get; set; } | Consente di specificare un array con numeri basati su 1 dei fogli di lavoro che devono essere eliminati dal foglio di calcolo durante il salvataggio, nel caso in cui il foglio di lavoro modificato venga inserito in un foglio di calcolo esistente |
| [WorksheetProtection](../../groupdocs.editor.options/spreadsheetsaveoptions/worksheetprotection) { get; set; } | Consente di abilitare la protezione del foglio di lavoro per il documento Spreadsheet di output. Per impostazione predefinita è NULL — la protezione non viene applicata. Non tutti i formati supportano la protezione del foglio di lavoro. |
