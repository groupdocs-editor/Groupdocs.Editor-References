## TextEditOptions.RecognizeLists property

Consente di specificare come vengono riconosciuti gli elementi delle liste numerate quando il documento è importato dal formato di testo semplice. Il valore predefinito è true.

```csharp
public bool RecognizeLists { get; set; }
```

### Osservazioni

Se questa opzione è impostata su false, l'algoritmo di riconoscimento delle liste rileva i paragrafi di elenco quando i numeri di lista terminano con un punto, una parentesi chiusa o simboli di puntatura (come "•", "*", "-" o "o"). Se questa opzione è impostata su true, gli spazi bianchi sono utilizzati anche come delimitatori dei numeri di lista: l'algoritmo di riconoscimento delle liste per la numerazione in stile arabo (1., 1.1.2.) utilizza sia gli spazi bianchi sia il punto (".") come simboli.
