## TextLeadingSpacesOptions enumeration

Contiene le opzioni disponibili per la gestione degli spazi iniziali durante l'apertura di un documento di testo semplice (TXT)

```csharp
public enum TextLeadingSpacesOptions
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| ConvertToIndent | `0` | Converti uno o più spazi consecutivi in rientro a sinistra. Valore predefinito. |
| Preserve | `1` | Trasferisci tutti gli spazi iniziali all'HTML di output "as is", senza modificarli |
