## WordProcessingEditOptions.EnableLanguageInformation property

Specifica se le informazioni sulla lingua vengono esportate nel markup HTML sotto forma di attributi HTML 'lang'. Questa opzione può essere utile per la conversione round‑trip dei documenti multilingua. Per impostazione predefinita è disabilitata (false).
