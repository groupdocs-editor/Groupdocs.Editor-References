## WordProcessingEditOptions.ExtractOnlyUsedFont property

Ottiene o imposta un valore che indica se estrarre solo le risorse di carattere utilizzate nel contenuto testuale del documento.

```csharp
public bool ExtractOnlyUsedFont { get; set; }
```

### Property Value

`true` se è necessario estrarre solo quelle risorse di carattere, che sono usate nel contenuto testuale del documento; altrimenti, `false`. Il valore predefinito è `false`.

### Osservazioni

Non tutti i caratteri, utilizzati nel documento WordProcessing, sono usati al 100% direttamente (applicati a del testo). Potrebbe verificarsi una situazione in cui il carattere è referenziato nel documento e può anche essere incorporato, ma non è applicato a nessuna porzione di testo. Ad esempio, un carattere può essere associato a uno stile, ma questo stile non è applicato a nessuna parte del testo. Questa opzione controlla come gestire tali casi.
