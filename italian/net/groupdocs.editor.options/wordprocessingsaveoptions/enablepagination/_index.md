## WordProcessingSaveOptions.EnablePagination property

Consente di abilitare o disabilitare l'impaginazione che verrà utilizzata per il salvataggio del documento WordProcessing. Se il documento originale è stato aperto e modificato in modalità impaginazione, questa opzione dovrebbe essere anch'essa abilitata. Per impostazione predefinita è disabilitata.

public bool EnablePagination { get; set; }
