## WordProcessingSaveOptions.Locale property

Consente di impostare la sovrascrittura della locale predefinita (lingua) per il documento WordProcessing, che verrà applicata durante la sua creazione. Quando non è specificata (valore predefinito), MS Word (o altro programma) rileverà (o sceglierà) la locale del documento in base alle proprie impostazioni o ad altri fattori.

```csharp
public CultureInfo Locale { get; set; }
```

### Osservazioni

Questa opzione applica forzatamente la locale specificata al testo complessivo nel documento. Non usarla se il documento contiene parti di testo scritte in lingue diverse.
