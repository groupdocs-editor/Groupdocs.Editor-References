## WordProcessingSaveOptions.OptimizeMemoryUsage property

Abilita i meccanismi di ottimizzazione della memoria durante la generazione di documenti da HTML, il che degrada le prestazioni come costo della riduzione dell'uso della memoria. Impostare questa opzione su true può ridurre significativamente il consumo di memoria durante la generazione di documenti di grandi dimensioni, a scapito di un tempo di salvataggio più lento. Il valore predefinito è false (l'ottimizzazione della memoria è disabilitata per garantire migliori prestazioni).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
