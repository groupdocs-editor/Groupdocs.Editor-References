## XmlEditOptions.FixIncorrectStructure property

Consente di abilitare o disabilitare il meccanismo per correggere la struttura XML corrotta. Per impostazione predefinita è disabilitato (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Osservazioni

Per impostazione predefinita sono accettati solo documenti XML corretti, validi e ben formati. Quando questa opzione è abilitata, GroupDocs.Editor cercherà di correggere la struttura XML corrotta, se possibile.
