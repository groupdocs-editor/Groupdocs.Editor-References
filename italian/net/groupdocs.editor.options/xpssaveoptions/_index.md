### Osservazioni

Un file XPS rappresenta file di layout di pagina basati su XML Paper Specifications creati da Microsoft. È stato sviluppato come sostituto del formato file EMF ed è simile al formato PDF, ma utilizza XML per le informazioni di layout, aspetto e stampa di un documento.
