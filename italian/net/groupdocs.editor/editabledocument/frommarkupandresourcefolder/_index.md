## EditableDocument.FromMarkupAndResourceFolder method

Factory statica, che crea un'istanza di EditableDocument da un markup HTML specificato e da risorse, situate nella cartella indicata dal percorso completo

```csharp
public static EditableDocument FromMarkupAndResourceFolder(string newHtmlContent, 
    string resourceFolderPath)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| newHtmlContent | String | Stringa che contiene markup HTML grezzo da analizzare. Non può essere NULL, vuota o non valida. |
| resourceFolderPath | String | Percorso obbligatorio alla cartella con le risorse. Tutti i fogli di stile presenti in questa cartella saranno utilizzati. Non può essere NULL o una stringa vuota, e questa cartella deve esistere. |

### Valore restituito

Nuova istanza non nulla di EditableDocument

### Osservazioni

Questa factory statica è utile quando il contenuto del documento HTML è presentato come stringa, ma tutte le risorse si trovano in una cartella, e spesso i collegamenti a queste risorse nel markup HTML sono non validi o assenti. Quando si invoca questo metodo, esso scandisce la cartella specificata e applica automaticamente tutti i fogli di stile trovati al documento. Questo metodo è molto utile quando si ottiene contenuto da diversi editor HTML, che solitamente rimuovono i metadati del documento e così via.
