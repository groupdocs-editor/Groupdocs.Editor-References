## GetBodyContent() {#getbodycontent}

Restituisce il corpo del documento HTML (contenuto interno tra i tag BODY di apertura e chiusura senza questi tag) come stringa.

```csharp
public string GetBodyContent()
```

### Valore restituito

Stringa che contiene il corpo del documento HTML (senza i tag BODY di apertura e chiusura)

### Osservazioni

La maggior parte degli editor WYSIWYG opera solitamente sul contenuto interno del BODY del documento e non può elaborare correttamente le sue informazioni meta dal blocco HEAD. Questo metodo è progettato per tali casi. Questa sovraccarico non consente di regolare gli URI per richieste di risorse esterne.

## GetBodyContent(string) {#getbodycontent_1}

Restituisce il corpo del documento HTML (contenuto interno tra i tag BODY di apertura e chiusura senza questi tag) come stringa, dove i collegamenti alle risorse esterne contengono il modello specificato con segnaposti.

```csharp
public string GetBodyContent(string externalImagesTemplate)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| externalImagesTemplate | String | Attraverso questo parametro è possibile specificare un modello di stringa con un segnaposto, che verrà applicato ai collegamenti a tutte le immagini esterne negli elementi IMG, presenti nella stringa HTML risultante. Se è NULL o vuoto, il modello non verrà aggiunto e saranno presenti solo i nomi file puri nel markup HTML risultante. Se il modello è non valido, verrà trattato come prefisso, quindi i nomi file saranno concatenati alla sua fine. |

### Valore restituito

Stringa che contiene il corpo del documento HTML (senza i tag BODY di apertura e chiusura) con i collegamenti, adeguati alle immagini esterne

### Osservazioni

La maggior parte degli editor WYSIWYG opera solitamente sul contenuto interno del BODY del documento e non può elaborare correttamente le sue informazioni meta dal blocco HEAD. Questo metodo è progettato per tali casi. Questa sovraccarico consente di regolare gli URI per richieste di risorse esterne.
