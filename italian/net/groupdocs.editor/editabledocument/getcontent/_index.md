## GetContent(string, string) {#getcontent_1}

Restituisce il contenuto complessivo del documento HTML come stringa, dove i collegamenti alle risorse esterne contengono il modello specificato con segnaposti.

```csharp
public string GetContent(string externalImagesTemplate, string externalCssTemplate)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| externalImagesTemplate | String | Attraverso questo parametro è possibile specificare un modello di stringa con un segnaposto, che verrà applicato ai collegamenti a tutte le immagini esterne negli elementi IMG, presenti nella stringa HTML risultante. Se è NULL o vuoto, il modello non verrà aggiunto e saranno presenti solo i nomi file puri nel markup HTML risultante. Se il modello è non valido, verrà trattato come prefisso, quindi i nomi file saranno concatenati alla sua fine. |
| externalCssTemplate | String | Attraverso questo parametro è possibile specificare un modello di stringa con un segnaposto, che verrà aggiunto ai collegamenti a tutti i fogli di stile esterni negli elementi LINK, presenti nella stringa HTML risultante. Se NULL o vuoto, il modello non verrà aggiunto e saranno presenti solo i nomi file puri nel markup HTML risultante. Se il modello è non valido, verrà trattato come prefisso, quindi i nomi file saranno concatenati alla sua fine. |

### Valore restituito

Stringa che contiene il contenuto del documento HTML con i collegamenti, adattato alle risorse esterne
