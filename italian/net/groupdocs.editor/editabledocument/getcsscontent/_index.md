## GetCssContent(string, string) {#getcsscontent_1}

Restituisce il contenuto di tutti i fogli di stile esterni come un elenco di stringhe, dove ogni stringa rappresenta un foglio di stile. Il prefisso specificato sarà applicato a ogni collegamento alla risorsa esterna in ciascun foglio di stile risultante. Restituisce un elenco vuoto, se non vi è CSS per questo documento.

```csharp
public List<string> GetCssContent(string externalImagesPrefix, string externalFontsPrefix)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| externalImagesPrefix | String | Attraverso questo parametro è possibile specificare un prefisso, che verrà aggiunto ai collegamenti a tutte le immagini esterne presenti nelle dichiarazioni CSS nelle stringhe CSS risultanti. Se NULL o vuoto, i prefissi non verranno aggiunti. |
| externalFontsPrefix | String | Attraverso questo parametro è possibile specificare un prefisso, che verrà aggiunto ai collegamenti a tutti i font esterni nelle regole @font-face nelle stringhe CSS risultanti. Se NULL o vuoto, i prefissi non verranno aggiunti. |

### Valore restituito

Un elenco di stringhe, dove ogni stringa contiene il contenuto di un documento CSS
