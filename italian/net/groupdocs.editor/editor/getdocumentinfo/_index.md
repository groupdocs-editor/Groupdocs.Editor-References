## Editor.GetDocumentInfo method

Restituisce i metadati sul documento, che è stato caricato in questa istanza di 'Editor'

```csharp
public IDocumentInfo GetDocumentInfo(string password)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| password | String | L'utente può specificare una password per un documento, se questo documento è crittografato con la password. Può essere NULL o una stringa vuota, equivalenti a una password assente. Per quei formati di documento che non supportano la protezione con password, questo argomento verrà ignorato. Se il documento è crittografato e la password non è specificata in questo parametro, ma è stata specificata in precedenza nelle opzioni di caricamento durante la creazione di questa istanza di [`Editor`](../../editor), verrà utilizzata. |

### Valore restituito

Erede specifico del formato dell'interfaccia [`IDocumentInfo`](../../../groupdocs.editor.metadata/idocumentinfo), che indica il formato rilevato con metadati specifici del formato, o NULL, se il documento non è stato riconosciuto come supportato o è corrotto.

### Eccezioni

| eccezione | condizione |
| --- | --- |
| ObjectDisposedException | Viene generato quando l'istanza di Editor è già stata eliminata quando viene invocato "GetDocumentInfo" |
| [PasswordRequiredException](../../passwordrequiredexception) | Viene generato quando il documento caricato è protetto da password, ma la password non è stata specificata nel parametro "*password*" e nelle opzioni di caricamento durante la creazione dell'istanza |
| [IncorrectPasswordException](../../incorrectpasswordexception) | Viene generato quando il documento caricato è protetto da password, la password è specificata ma è errata |
| InvalidOperationException | Viene generato quando si è verificato un errore imprevisto di natura sconosciuta |

### Osservazioni

Il metodo GetDocumentInfo è utile quando non è chiaro quale sia il formato del documento di input, se è protetto da password e/o quante pagine/fogli di lavoro/diapositive contiene. Sulla base di questi metadati, restituiti da GetDocumentInfo, è possibile regolare correttamente le opzioni di caricamento e modifica per la pipeline di elaborazione principale.

Il metodo GetDocumentInfo restituisce sempre dati completi, non è influenzato dalla modalità di prova, il suo utilizzo non consuma i byte o i crediti.
