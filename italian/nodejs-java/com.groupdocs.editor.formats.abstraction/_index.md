Il namespace **com.groupdocs.editor.formats.abstraction** fornisce interfacce e classi che descrivono i formati di documento supportati nella libreria GroupDocs.Editor.



## Classi

| Classe | Descrizione |
| --- | --- |
| [DocumentFormatBase](../com.groupdocs.editor.formats.abstraction/documentformatbase) | Rappresenta la classe base per i formati di documento, fornendo funzionalità comuni per le istanze di formato. |
| [FormatFamilyBase](../com.groupdocs.editor.formats.abstraction/formatfamilybase) | Rappresenta la classe base per le famiglie di formato, fornendo funzionalità comuni per le istanze di famiglia di formato. |

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IDocumentFormat](../com.groupdocs.editor.formats.abstraction/idocumentformat) | Rappresenta l'interfaccia radice per tutti i formati di documento supportati. |
