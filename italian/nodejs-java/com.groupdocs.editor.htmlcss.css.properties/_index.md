## Classi

| Classe | Descrizione |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Rappresenta una dimensione del carattere come unità speciale o valore di lunghezza, che specifica la dimensione del carattere (storicamente la larghezza della lettera maiuscola "M"). |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Definisce come il carattere deve essere stilizzato: normale, corsivo o obliquo dalla sua famiglia di caratteri. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | La proprietà font-weight imposta il peso (o la grassezza) del carattere. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Rappresenta i tipi di linea di decorazione del testo: sottolineatura (underscore), sovralineatura e barratura (strikethrough). |
