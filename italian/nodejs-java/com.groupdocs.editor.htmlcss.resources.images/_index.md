Il namespace **com.groupdocs.editor.htmlcss.resources.images** fornisce classi che rappresentano risorse immagine di tutti i tipi in generale.



## Classi

| Classe | Descrizione |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Rappresenta le dimensioni lineari (larghezza e altezza) di una rectangularimage raster in unità arbitraria. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Rappresenta un tipo di immagine supportabile (formato), supporta sia formati raster che vettoriali. |

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Il tipo di dati CSS Image rappresenta un'immagine bidimensionale. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Rappresenta una risorsa immagine di qualsiasi tipo, raster o vettoriale. |
