Il namespace **com.groupdocs.editor.htmlcss.resources** fornisce classi che rappresentano tutti i tipi di risorse HTML.



## Classi

| Classe | Descrizione |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | Metodi statici di utilità per rilevare i tipi di risorse (formati). |

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | Estende l'interfaccia standard IDisposable, consente di ottenere un currentstate di un oggetto e di iscriversi all'evento disposing. |
| [IHtmlResource](../com.groupdocs.editor.htmlcss.resources/ihtmlresource) | Rappresenta un'istanza di una risorsa HTML sconosciuta (immagine raster o vettoriale, foglio di stile, font, risorsa testuale (CSS, XML) ecc.). |
| [IResourceType](../com.groupdocs.editor.htmlcss.resources/iresourcetype) | Rappresenta un'istanza di un tipo/formato di risorsa sconosciuto (immagine, font, testo). |
