public final class TextLeadingSpacesOptions

Contiene le opzioni disponibili per la gestione degli spazi iniziali durante l'apertura di un semplice
documento di testo (TXT)

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [ConvertToIndent](#ConvertToIndent) | Converti uno o più spazi consecutivi in rientro a sinistra. |
|
|  | [Preserve](#Preserve) | Trasferisci tutti gli spazi iniziali all'HTML di output \"così com'è\", senza modificarli |
|
|  | [Trim](#Trim) | Rimuovi (trunca) tutti gli spazi iniziali completamente |
|
### ConvertToIndent {#ConvertToIndent}
```
public static final int ConvertToIndent
```


Converti uno o più spazi consecutivi in rientro a sinistra. Valore predefinito.


### Preserve {#Preserve}
```
public static final int Preserve
```


Trasferisci tutti gli spazi iniziali all'HTML di output \"così com'è\", senza modificarli


### Trim {#Trim}
```
public static final int Trim
```


Rimuovi (trunca) tutti gli spazi iniziali completamente
