Contiene le opzioni disponibili per la gestione degli spazi finali durante l'apertura di plain
documento di testo (TXT)

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [Trim](#Trim) | Rimuovi (trunca) tutti gli spazi finali completamente. |
|

|

```
public static final int Trim
```

### Preserve {#Preserve}
```
public static final int Preserve
```
