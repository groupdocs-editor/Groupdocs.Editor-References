```
public final class WorksheetProtectionType
```

Rappresenta i tipi di protezione del foglio di lavoro (tab) Spreadsheet

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [None](#None) | La protezione non è applicata (valore predefinito) |
|
|  | [All](#All) | L'utente non può modificare nulla sul foglio di lavoro |
|
|  | [Contents](#Contents) | L'utente non può inserire dati nel foglio di lavoro |
|
|  | [Objects](#Objects) | L'utente non può modificare gli oggetti di disegno |
|
|  | [Scenarios](#Scenarios) | L'utente non può modificare gli scenari salvati |
|
|  | [Structure](#Structure) | L'utente non può modificare la struttura |
|
|  | [Window](#Window) | L'utente non può modificare la finestra |
|
