Il namespace **com.groupdocs.editor** è un namespace radice, che fornisce classi per modificare più formati di documento nelle tue applicazioni Java.



## Classi

| Classe | Descrizione |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Documento intermedio, che contiene contenuti prima e dopo la modifica |
| [Editor](../com.groupdocs.editor/editor) | Classe principale, che incapsula i metodi di conversione. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | L'eccezione che viene lanciata quando l'utente tenta di aprire un documento che è stato crittografato usando X509Certificates. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | L'eccezione che viene lanciata quando la password specificata è errata. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | L'eccezione che viene lanciata quando l'utente tenta di aprire un documento con opzioni specifiche del formato che sono incompatibili con il formato originale del documento. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | L'eccezione che viene lanciata quando l'utente tenta di aprire un documento crittografato protetto da password di qualche formato e non fornisce una password per aprire questo documento. |
