## License class

Gestisce la licenza di GroupDocs.Editor.

Le versioni con licenza sbloccano l'intero set di funzionalità del wrapper a
runtime. Le versioni non licenziate funzionano in modalità di valutazione con la stessa API
interfaccia ma con limiti sulla dimensione dell'output e contenuti con filigrana.

Il tipo License espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [set_license](/editor/python-net/groupdocs.editor/license/set_license/#license_source) | Applica una licenza al processo corrente. |
