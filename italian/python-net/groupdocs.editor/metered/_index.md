## Metered class

Gestisce la licenza a consumo (pay-per-use).

Le licenze Metered fatturano in base al consumo reale (tipicamente pagine o
documenti elaborati). Imposta la coppia di chiavi pubblica/privata una volta a
avvio dell'applicazione; il wrapper riporta l'utilizzo al GroupDocs
server di licenza in background.

Il tipo Metered espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [get_consumption_credit](/editor/python-net/groupdocs.editor/metered/get_consumption_credit/) | Restituisce il credito metered rimanente per la chiave corrente. |
| [get_consumption_quantity](/editor/python-net/groupdocs.editor/metered/get_consumption_quantity/) | Restituisce la quantità metered totale consumata finora. |
| [set_metered_key](/editor/python-net/groupdocs.editor/metered/set_metered_key/#public_key-private_key) | Attiva la fatturazione metered con la coppia di chiavi pubblica/privata fornita. |
