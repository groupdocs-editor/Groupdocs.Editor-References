## FontSize.IsRelativeSize property

この font-size がキーワードとして相対サイズで定義されているかどうかを示します。フォントは親要素のフォントサイズに対して大きくまたは小さくなり、絶対サイズキーワードを分ける際に使用される比率に大まかに従います。
