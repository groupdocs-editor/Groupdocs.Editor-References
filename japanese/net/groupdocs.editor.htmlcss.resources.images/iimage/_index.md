## IImage interface

Image CSS データ型は二次元画像を表します。

```csharp
public interface IImage
```

### 備考

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS リファレンスは、扱える画像のタイプを 4 種類宣言しています: 1. 固有の寸法（自然サイズ）を持ち、したがって固定のアスペクト比を持つ画像で、すべてのラスタ画像が含まれます。 2. 単一ファイル内に複数バージョンが存在する複数の固有寸法を持つ画像で、ICON (*.ico) ファイルが含まれます。これは TIFF でもあり得ますが、TIFF はウェブでサポートされていません。 3. 固有の寸法はないが、幅と高さの間に固有のアスペクト比を持つ画像で、すべてのベクター画像、特に SVG が含まれます。 4. 固有の寸法も固有のアスペクト比も持たない画像で、すべてのグラデーションが含まれます。
