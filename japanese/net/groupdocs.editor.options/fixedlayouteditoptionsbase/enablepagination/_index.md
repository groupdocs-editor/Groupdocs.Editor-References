## FixedLayoutEditOptionsBase.EnablePagination property

生成された HTML ドキュメントでページネーションを有効 (true) または無効 (false) にできます。デフォルトは無効 (false) です。

```csharp
public bool EnablePagination { get; set; }
```

### 備考

固定レイアウト形式のドキュメント（特に PDF と XPS）は本質的にページが厳密に区切られ、コンテンツは固定レイアウトでページに分割されています。しかし、結果として得られる編集可能な HTML は、ページなしビューまたはページ付きビューのいずれかで表現できます。
