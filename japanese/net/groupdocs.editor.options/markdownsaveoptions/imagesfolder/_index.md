## MarkdownSaveOptions.ImagesFolder property

ドキュメントを Markdown 形式でエクスポートする際に画像が保存される物理フォルダーを指定します。デフォルトは null です。

```csharp
public string ImagesFolder { get; set; }
```

### 備考

ユーザーが `ImagesFolder` と [`ExportImagesAsBase64`](../exportimagesasbase64) のいずれも指定しない場合、GroupDocs.Editor は自動的に `ImagesFolder` を判定し、成功すれば適用します。
