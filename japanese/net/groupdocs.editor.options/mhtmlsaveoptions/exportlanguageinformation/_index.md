## MhtmlSaveOptions.ExportLanguageInformation property

言語情報を MHTML にエクスポートするかどうかを指定します。既定値は `false` です。

```csharp
public bool ExportLanguageInformation { get; set; }
```

### 備考

このプロパティが `true` に設定されている場合、GroupDocs.Editor は言語を指定するドキュメント要素に `lang` HTML 属性を出力します。これは言語関連のセマンティクスを保持するために必要になることがあります。
