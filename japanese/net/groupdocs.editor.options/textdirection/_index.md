## TextDirection enumeration

プレーンテキストドキュメントにおけるテキスト方向の扱い方を示す 3 つのバリエーションを表します。

```csharp
public enum TextDirection
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| LeftToRight | `0` | 左から右への方向、通常のテキスト、デフォルト値。 |
| RightToLeft | `1` | 右から左への方向 |
| Auto | `2` | 方向を自動検出します。このオプションが選択され、テキストに RTL スクリプトに属する文字が含まれる場合、文書の方向は自動的に RTL に設定されます。 |
