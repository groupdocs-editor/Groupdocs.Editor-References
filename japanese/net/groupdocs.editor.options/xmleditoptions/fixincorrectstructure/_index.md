## XmlEditOptions.FixIncorrectStructure property

破損した XML 構造を修正するメカニズムを有効または無効にできるようにします。デフォルトは無効 (false) です。

```csharp
public bool FixIncorrectStructure { get; set; }
```

### 備考

デフォルトでは、適切で有効な整形式 XML ドキュメントのみが受け入れられます。このオプションが有効になると、GroupDocs.Editor は可能な限り破損した XML 構造の修正を試みます。
