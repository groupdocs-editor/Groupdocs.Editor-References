## XmlFormatOptions.LeafTextNodesOnNewline property

有効にすると、子を持たない XML 要素内のリーフテキストノード（テキストコンテンツ）は、左インデントを大きくして新しい行にレンダリングされます。デフォルトは false（無効）で、リーフテキストノードは親と同じ行に配置され、インデントは追加されません。

public bool LeafTextNodesOnNewline { get; set; }
