ドキュメント内のフォームフィールドの管理および操作に関連するクラスとインターフェイスを含みます。この名前空間は、テキストフィールド、チェックボックス、ドロップダウンなど、さまざまなタイプのフォームフィールドを操作する機能を提供し、ユーザーがプログラムからフォームフィールドと対話し、変更できるようにします。

## クラス

| クラス | 説明 |
| --- | --- |
| [CheckBoxForm](./checkboxform) | チェックボックスを表示するフォームフィールドを表します。 |
| [CurrentDateFormField](./currentdateformfield) | 現在の日付を表示するフォームフィールドを表します。 |
| [CurrentTimeFormField](./currenttimeformfield) | 現在の時刻を表示するフォームフィールドを表します。 |
| [DateFormField](./dateformfield) | 日付を表示するフォームフィールドを表します。 |
| [DropDownFormField](./dropdownformfield) | ドロップダウンリストを表示するフォームフィールドを表します。 |
| [FormFieldCollection](./formfieldcollection) | フォームフィールドのコレクションを表します。 |
| [HelpText](./helptext) | フォームフィールドのヘルプテキストを表します。 |
| [InvalidFormField](./invalidformfield) | 無効なフォームフィールド名の更新を、[`FixInvalidFormFieldNames`](../groupdocs.editor/formfieldmanager/fixinvalidformfieldnames) 操作中に表します。 |
| [NumberFormField](./numberformfield) | 数値入力を受け付けるフォームフィールドを表します。 |
| [TextFormField](./textformfield) | テキスト入力を受け付けるフォームフィールドを表します。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IFormField](./iformfield) | フォームフィールドを表します。 |
## 列挙

| 列挙 | 説明 |
| --- | --- |
| [FormFieldType](./formfieldtype) | フォームフィールドのタイプを指定します。 |
