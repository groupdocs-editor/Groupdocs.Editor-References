## Editor.FormFieldManager property

ドキュメント内のフォームフィールドを管理する機能へのアクセスを提供します。

```csharp
public FormFieldManager FormFieldManager { get; }
```

### 戻り値

ドキュメント内のフォームフィールドを管理するための `FormFieldManager` インスタンスです。

### 備考

`FormFieldManager` プロパティは、`FormFieldManager` クラスの新しいインスタンスを作成し、ドキュメント内のフォームフィールドを管理するためのメソッドやプロパティへのアクセスを可能にします。フォームフィールドは、ユーザー入力を受け取ったりアクションをトリガーしたりできるインタラクティブな要素です。`FormFieldManager` インスタンスは、無効なフォームフィールドのチェック、フォームフィールドデータの更新、命名問題の修正など、さまざまなフォームフィールド操作のメソッドを提供します。また、フォームフィールド名とそれに関連するデータの取得も容易にします。このプロパティは、プログラムからフォームフィールドと対話し操作する際に役立ち、フォームフィールドの検証、同期、カスタマイズといったタスクを可能にします。
