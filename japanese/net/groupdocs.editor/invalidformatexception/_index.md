## InvalidFormatException class

ユーザーが元のドキュメント形式と互換性のないフォーマット固有オプションを使用してドキュメントを開こうとしたときにスローされる例外です。

```csharp
public sealed class InvalidFormatException : Exception
```

### 備考

例えば、スプレッドシートドキュメントをワードプロセッシングドキュメントのオプションで開こうとすると、この例外がスローされます。
