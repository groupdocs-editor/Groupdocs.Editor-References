**com.groupdocs.editor.formats** 名前空間は、サポートされている文書形式を記述するインターフェイスとクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | すべての eBook 形式をカプセル化します。 |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | すべてのメール形式をカプセル化します。 |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | すべての固定レイアウト（"fixed-page" とも呼ばれる）形式をカプセル化します。これには PDF と XPS が含まれます（ラスタ画像は含まれません） |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | システムで利用可能なさまざまなフォーマットファミリーを表します。 |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | すべてのプレゼンテーション形式をカプセル化します。 |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | バイナリ、XML、テキストのスプレッドシート形式すべてをカプセル化します（CSV、TSV、セミコロン区切りなどのテキスト区切り形式は除外）。これらの形式でワークブックを保存できます。 |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | マークアップ（XML、HTML）やその他を含む、すべてのテキスト（テキストベース）形式をカプセル化します。 |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | すべての WordProcessing 形式をカプセル化します。 |
