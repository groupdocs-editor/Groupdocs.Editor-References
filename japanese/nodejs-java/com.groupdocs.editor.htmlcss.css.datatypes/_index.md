**com.groupdocs.editor.htmlcss.css.datatypes** 名前空間は、CSS データ型を表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | コンバータとシリアライザを備えた ARGB 形式の単一カラー値を表します。 |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | CSS 標準で固定された一意の名前と値を持つすべての \"known colors\" を含みます。 |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | パーセンテージや単位なしタイプを含む、サポートされる任意の単位での CSS 長さ値を表します。 |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | サポートされているすべての長さ単位 |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | メディアクエリのアスペクト比やラスタ画像の比率を表す \"ratio\" CSS データ型で、分子と分母と呼ばれる単位なしの2つの値の比率を示します。 |
