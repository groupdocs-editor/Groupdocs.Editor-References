**com.groupdocs.editor.htmlcss.exceptions** 名前空間は、コンテンツを開く、読み込む、保存する、またはその他の方法で処理しようとしたときにスローされる例外を提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [InvalidFontFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidfontformatexception) | サポートされている（既知の）フォーマットのフォントであると推測されるコンテンツを開く、読み込む、保存する、または何らかの方法で処理しようとしたときにスローされる例外ですが、実際にはサポートされていない、または予期しないフォーマットのフォントであるか、フォント自体でない場合です。 |
| [InvalidImageFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | 開く、読み込む、保存する、または何らかの方法で処理しようとしたときにスローされる例外で、画像（ラスタまたはベクトル）であると推測されるコンテンツですが、実際には予期しないタイプの画像であるか、画像自体でない場合です。 |
