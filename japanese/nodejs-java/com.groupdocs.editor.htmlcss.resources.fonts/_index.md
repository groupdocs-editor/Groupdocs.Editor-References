**com.groupdocs.editor.htmlcss.resources.fonts** 名前空間は、フォントリソースを表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [EotFont](../com.groupdocs.editor.htmlcss.resources.fonts/eotfont) | EOT（Embedded OpenType）フォーマットのフォントを 1 つ表します。 |
| [FontResourceBase](../com.groupdocs.editor.htmlcss.resources.fonts/fontresourcebase) | HTML ドキュメントのリソースとして、すべてのプロパティを持つ任意のサポートされているフォントタイプの基底クラスです。 |
| [FontType](../com.groupdocs.editor.htmlcss.resources.fonts/fonttype) | サポート可能なフォントタイプを 1 つ表します。 |
| [OtfFont](../com.groupdocs.editor.htmlcss.resources.fonts/otffont) | OTF（Open Type Format）フォーマットのフォントを 1 つ表します。 |
| [TtcFont](../com.groupdocs.editor.htmlcss.resources.fonts/ttcfont) | TTC（TrueType Collection）フォーマットのフォントを 1 つ表します。 |
| [TtfFont](../com.groupdocs.editor.htmlcss.resources.fonts/ttffont) | TTF（TrueType Font）フォーマットのフォントを 1 つ表します。 |
| [Woff2Font](../com.groupdocs.editor.htmlcss.resources.fonts/woff2font) | WOFF2（Web Open Font Format）フォーマットのフォントを 1 つ表します。 |
| [WoffFont](../com.groupdocs.editor.htmlcss.resources.fonts/wofffont) | WOFF（Web Open Font Format）フォーマットのフォントを 1 つ表します。 |
