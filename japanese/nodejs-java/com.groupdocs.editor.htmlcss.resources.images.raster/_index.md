**com.groupdocs.editor.htmlcss.resources.images.raster** 名前空間は、ラスタ画像リソースのみを表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [BmpImage](../com.groupdocs.editor.htmlcss.resources.images.raster/bmpimage) | BMP (BitMap Picture) 形式の画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [GifImage](../com.groupdocs.editor.htmlcss.resources.images.raster/gifimage) | GIF (Graphics Interchange Format) 形式の画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [IconImage](../com.groupdocs.editor.htmlcss.resources.images.raster/iconimage) | ICON 形式の画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [JpegImage](../com.groupdocs.editor.htmlcss.resources.images.raster/jpegimage) | JPEG (Joint Photographic Experts Group) 形式の画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [PngImage](../com.groupdocs.editor.htmlcss.resources.images.raster/pngimage) | PNG (Portable Network Graphics) 形式の画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [RasterImageResourceBase](../com.groupdocs.editor.htmlcss.resources.images.raster/rasterimageresourcebase) | サポートされているすべてのラスタ画像の基本クラスで、固定された名前、寸法、アスペクト比、タイプ、サイズ、およびコンテンツを持ちます |
| [TiffImage](../com.groupdocs.editor.htmlcss.resources.images.raster/tiffimage) | TIFF (Tagged Image File Format) 形式の画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
