**com.groupdocs.editor.htmlcss.resources.images.vector** 名前空間は、ベクター画像リソースのみを表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [EmfImage](../com.groupdocs.editor.htmlcss.resources.images.vector/emfimage) | EMF (Enhanced metafile) 形式のベクター画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [MetaImageBase](../com.groupdocs.editor.htmlcss.resources.images.vector/metaimagebase) | WMF および EMF 画像形式の基本抽象クラス |
| [SvgImage](../com.groupdocs.editor.htmlcss.resources.images.vector/svgimage) | SVG (Scalable Vector Graphics) 形式のベクター画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
| [VectorImageResourceBase](../com.groupdocs.editor.htmlcss.resources.images.vector/vectorimageresourcebase) | サポートされているすべてのベクター画像の基本クラス |
| [WmfImage](../com.groupdocs.editor.htmlcss.resources.images.vector/wmfimage) | WMF (Windows MetaFile) 形式のベクター画像を 1 つ表し、そのメタデータと追加のメソッドを提供します |
