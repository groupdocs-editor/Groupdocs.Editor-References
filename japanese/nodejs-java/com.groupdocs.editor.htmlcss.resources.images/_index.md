**com.groupdocs.editor.htmlcss.resources.images** 名前空間は、一般的にすべてのタイプの画像リソースを表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | 任意の単位で、1つのラスタ矩形imageの線形寸法（幅と高さ）を表します。 |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | サポート可能な画像タイプ（フォーマット）を1つ表し、ラスタ形式とベクトル形式の両方をサポートします。 |

## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Image CSS データ型は、2 次元画像を表します。 |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | 任意のタイプ（ラスタまたはベクトル）の画像リソースを表します。 |
