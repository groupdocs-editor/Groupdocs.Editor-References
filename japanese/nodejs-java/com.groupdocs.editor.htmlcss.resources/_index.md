**com.groupdocs.editor.htmlcss.resources** 名前空間は、すべての種類の HTML リソースを表すクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | リソースタイプ（フォーマット）を検出するユーティリティの静的メソッド。 |

## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | 標準の IDisposable インターフェイスを拡張し、オブジェクトの currentstate を取得し、disposing イベントに登録できるようにします。 |
| [IHtmlResource](../com.groupdocs.editor.htmlcss.resources/ihtmlresource) | 未知の HTML リソース（ラスタまたはベクトル画像、スタイルシート、フォント、テキストリソース（CSS、XML）など）のインスタンスを 1 つ表します。 |
| [IResourceType](../com.groupdocs.editor.htmlcss.resources/iresourcetype) | 未知のリソースタイプ/フォーマット（画像、フォント、テキスト）のインスタンスを 1 つ表します。 |
