**com.groupdocs.editor.htmlcss.serialization** 名前空間は、HTML および CSS マークアップのシリアライズプロセスの調整を担当するタイプを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [QuoteType](../com.groupdocs.editor.htmlcss.serialization/quotetype) | シングルクオート (') とダブルクオート (\") の引用文字を表します。 |
| [TagRenderingCase](../com.groupdocs.editor.htmlcss.serialization/tagrenderingcase) | HTML タグ名のシリアライズのさまざまなタイプを表します。 |
