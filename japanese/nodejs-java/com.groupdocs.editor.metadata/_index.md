**com.groupdocs.editor.metadata** 名前空間は、文書タイプに依存する基本的な文書プロパティを記述するクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | EBook ドキュメントのメタデータを表します |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | サポートされている任意のメール形式のメールドキュメントのメタデータを表します |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | PDF や XPS のような固定レイアウト形式のドキュメントのメタデータを表します |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Markdown ドキュメントのメタデータを表します |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | プレゼンテーションドキュメントのメタデータを表します |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | スプレッドシートドキュメントのメタデータを表します |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | XML、HTML、またはプレーンテキスト（TXT）のようなテキストドキュメントのメタデータを表します |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | WordProcessing ドキュメントのメタデータを表します |
