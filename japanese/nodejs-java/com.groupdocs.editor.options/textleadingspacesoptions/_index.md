## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [ConvertToIndent](#ConvertToIndent) | 1 つ以上の連続スペースを左インデントに変換します。 |
|
|  | [Preserve](#Preserve) | 先頭スペースをすべてそのまま出力 HTML に渡し、変更しません |
|
|  | [Trim](#Trim) | 先頭スペースをすべて完全にトリム（切り捨て）します |
|
