Spreadsheetワークシート（タブ）の保護タイプを表します。

## フィールド

| フィールド | 説明 |
| --- | --- |
|  | [None](#None) | 保護は適用されません（デフォルト値） |
|
|  | [All](#All) | ユーザーはワークシート上の何も変更できません |
|
|  | [Contents](#Contents) | ユーザーはワークシートにデータを入力できません |
|
|  | [Objects](#Objects) | ユーザーは描画オブジェクトを変更できません |
|
|  | [Scenarios](#Scenarios) | ユーザーは保存されたシナリオを変更できません |
|
|  | [Structure](#Structure) | ユーザーは構造を変更できません |
|
|  | [Window](#Window) | ユーザーはウィンドウを変更できません |
|
