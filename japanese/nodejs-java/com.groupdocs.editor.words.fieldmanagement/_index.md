**com.groupdocs.editor.words.fieldmanagement** 名前空間には、ドキュメント内のフォームフィールドの管理および操作に関連するクラスとインターフェイスが含まれます。この名前空間は、テキストフィールド、チェックボックス、ドロップダウンなど、さまざまなタイプのフォームフィールドをプログラムで操作および変更できる機能を提供します



## クラス

| クラス | 説明 |
| --- | --- |
| [CheckBoxForm](../com.groupdocs.editor.words.fieldmanagement/checkboxform) | チェックボックスを表示するフォームフィールドを表します |
| [CurrentDateFormField](../com.groupdocs.editor.words.fieldmanagement/currentdateformfield) | 現在の日付を表示するフォームフィールドを表します |
| [CurrentTimeFormField](../com.groupdocs.editor.words.fieldmanagement/currenttimeformfield) | 現在の時刻を表示するフォームフィールドを表します |
| [DateFormField](../com.groupdocs.editor.words.fieldmanagement/dateformfield) | 日付を表示するフォームフィールドを表します |
| [DropDownFormField](../com.groupdocs.editor.words.fieldmanagement/dropdownformfield) | ドロップダウンリストを表示するフォームフィールドを表します |
| [FormFieldCollection](../com.groupdocs.editor.words.fieldmanagement/formfieldcollection) | フォームフィールドのコレクションを表します |
| [FormFieldType](../com.groupdocs.editor.words.fieldmanagement/formfieldtype) | フォームフィールドのタイプを指定します |
| [HelpText](../com.groupdocs.editor.words.fieldmanagement/helptext) | フォームフィールドのヘルプテキストを表します |
| [InvalidFormField](../com.groupdocs.editor.words.fieldmanagement/invalidformfield) | FormFieldManager.FixInvalidFormFieldNames 操作中に無効なフォームフィールド名の更新を表します。 |
| [NumberFormField](../com.groupdocs.editor.words.fieldmanagement/numberformfield) | 数値入力を受け付けるフォームフィールドを表します。 |
| [TextFormField](../com.groupdocs.editor.words.fieldmanagement/textformfield) | テキスト入力を受け付けるフォームフィールドを表します。 |
