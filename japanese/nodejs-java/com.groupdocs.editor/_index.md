**com.groupdocs.editor** 名前空間はルート名前空間であり、Java アプリケーションで複数の文書形式を編集するためのクラスを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | 編集前後のコンテンツを含む中間文書 |
| [Editor](../com.groupdocs.editor/editor) | 変換メソッドをカプセル化するメインクラス。 |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | ユーザーが X509Certificates を使用して暗号化された文書を開こうとしたときにスローされる例外です。 |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | 指定されたパスワードが正しくないときにスローされる例外です。 |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | ユーザーが元の文書形式と互換性のないフォーマット固有オプションで文書を開こうとしたときにスローされる例外です。 |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | ユーザーがパスワードで保護された暗号化文書を開こうとし、開くためのパスワードを提供しなかったときにスローされる例外です。 |
