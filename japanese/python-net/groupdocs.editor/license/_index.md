## License class

GroupDocs.Editor のライセンスを管理します。

ライセンス認証されたビルドは、ラッパーのフル機能セットを次の場所で有効にします
ランタイム。未ライセンスのビルドは、同じ API で評価モードで実行されます
表面ですが、出力サイズと透かし付きコンテンツに制限があります。

License 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [set_license](/editor/python-net/groupdocs.editor/license/set_license/#license_source) | 現在のプロセスにライセンスを適用します。 |
