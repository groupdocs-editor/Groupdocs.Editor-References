**com.groupdocs.editor.formats** 네임스페이스는 지원되는 문서 형식을 설명하는 인터페이스와 클래스를 제공합니다.



## 클래스

| 클래스 | 설명 |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | 모든 eBook 형식을 캡슐화합니다. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | 모든 이메일 형식을 캡슐화합니다. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | 고정 레이아웃(또는 \"fixed-page\"이라고도 함) 형식을 모두 캡슐화하며, 여기에는 PDF와 XPS가 포함됩니다(래스터 이미지는 포함되지 않음). |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | 시스템에서 사용할 수 있는 다양한 형식 패밀리를 나타냅니다. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | 모든 프레젠테이션 형식을 캡슐화합니다. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | 워크북을 저장할 수 있는 모든 이진, XML 및 텍스트 스프레드시트 형식을 캡슐화합니다(CSV, TSV, 세미콜론 구분 등 구분자를 사용하는 모든 텍스트 형식은 제외). |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | 마크업(XML, HTML) 및 기타를 포함한 모든 텍스트(텍스트 기반) 형식을 캡슐화합니다. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | 모든 워드 프로세싱 형식을 캡슐화합니다. |
