```
public static boolean tryFind(String keyword, ArgbColor[] output)
```


문자열 이름으로 색을 찾으려고 시도합니다


**Parameters:**
| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
|  | 키워드 | java.lang.String | 색 이름 |
|
|  | output | [ArgbColor\[\]](../../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | 성공 시 결과 색 값, 실패 시 #Transparent.Transparent 값 |
|

**Returns:**
boolean - 색을 이름으로 성공적으로 찾은 경우 True, 그렇지 않으면 false
