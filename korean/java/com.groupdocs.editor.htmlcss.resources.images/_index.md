**com.groupdocs.editor.htmlcss.resources.images** 네임스페이스는 일반적으로 모든 유형의 이미지 리소스를 나타내는 클래스를 제공합니다.



## 클래스

| 클래스 | 설명 |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | 하나의 래스터 rectangularimage의 선형 차원(너비와 높이)을 임의 단위로 나타냅니다. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | 지원 가능한 이미지 유형(포맷) 하나를 나타내며, 래스터와 벡터 포맷을 모두 지원합니다. |
