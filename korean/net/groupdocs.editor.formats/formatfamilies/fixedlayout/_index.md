## FormatFamilies.FixedLayout field

Fixed Layout 형식 패밀리를 나타냅니다. 다양한 문서 보기 또는 출판 애플리케이션은 사용자가 특정 형식의 문서를 열 수 있게 해줍니다(Adobe Acrobat, XPS Viewer) 및 때때로 편집(Adobe InDesign)할 수 있습니다. 이러한 애플리케이션은 일반적으로 소위 “fixed-page” 형식 문서를 생성합니다. 이러한 문서 형식은 각 페이지에 문서 내용이 정확히 배치되는 위치를 설명합니다. 내부적으로 PDF 또는 XPS 형식은 각 페이지에 대한 설명과 페이지의 내용 레이아웃을 지정하는 그리기 명령을 포함합니다. 이는 이미지 형식과 유사하며, 래스터 또는 벡터 형태로 내용이 표시되는 위치를 설명합니다.

```csharp
public static readonly FormatFamilies FixedLayout;
```
