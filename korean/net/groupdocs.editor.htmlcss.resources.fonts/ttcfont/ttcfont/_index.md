## TtcFont(string, string) {#constructor_1}

콘텐츠를 base64-encoded 문자열로 표현하고 지정된 이름으로 새 TtcFont 클래스를 생성합니다.

```csharp
public TtcFont(string name, string contentInBase64)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 이름 | 문자열 | TTC 폰트의 이름. null, 빈 문자열 또는 공백일 수 없습니다. |
| contentInBase64 | 문자열 | 콘텐츠를 base64 인코딩 문자열로 제공합니다. null, 빈 문자열 또는 공백일 수 없습니다. TTC 콘텐츠가 아니면 예외가 발생합니다. |

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentException | 입력 문자열 중 하나가 `null`이거나 빈 문자열이거나 공백만 있는 경우 |
| [InvalidImageFormatException](../../../groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | *contentInBase64* 매개변수의 콘텐츠를 유효한 TTC 폰트로 인식할 수 없습니다. |
