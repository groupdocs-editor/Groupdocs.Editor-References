## IImage interface

이미지 CSS 데이터 유형은 2차원 이미지를 나타냅니다.

public interface IImage

### 비고

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS 참조는 처리할 수 있는 4가지 이미지 유형을 선언합니다: 1. 고유 차원이 있는 이미지(자연 크기)이며 따라서 고정된 종횡비를 갖습니다. 여기에는 모든 래스터 이미지가 포함됩니다. 2. 단일 파일 내에 여러 버전으로 존재하는 다중 고유 차원을 가진 이미지이며, 여기에는 ICON (*.ico) 파일이 포함됩니다. TIFF도 해당될 수 있는데, 파일 하나에 여러 이미지를 지원하지만 웹에서는 TIFF 형식을 지원하지 않습니다. 3. 고유 차원은 없지만 너비와 높이 사이에 고유 종횡비를 가진 이미지입니다. 여기에는 모든 벡터 이미지, 특히 SVG가 포함됩니다. 4. 고유 차원도 없고 고유 종횡비도 없는 이미지입니다. 여기에는 모든 그라디언트가 포함됩니다.
