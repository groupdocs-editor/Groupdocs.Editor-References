## PresentationDocumentInfo.GeneratePreview method

선택된 슬라이드의 미리보기를 SVG 이미지 형태로 생성하고 반환합니다.

```csharp
public SvgImage GeneratePreview(int slideIndex)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| slideIndex | Int32 | 원하는 슬라이드의 0 기반 인덱스입니다. 0보다 작을 수 없으며, 프레젠테이션의 슬라이드 수를 초과할 수 없습니다. |

### 반환 값

SVG 이미지는 null이 아닌 [`SvgImage`](../../../groupdocs.editor.htmlcss.resources.images.vector/svgimage) 클래스의 인스턴스로 제공합니다.

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentOutOfRangeException | 지정된 *slideIndex*가 0보다 작거나 프레젠테이션의 슬라이드 수보다 큰 경우 |
