## SpreadsheetDocumentInfo.GeneratePreview method

선택된 워크시트의 미리보기를 SVG 이미지 형태로 생성하고 반환합니다.

```csharp
public SvgImage GeneratePreview(int worksheetIndex)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| worksheetIndex | Int32 | 원하는 워크시트의 0 기반 인덱스입니다. 0보다 작을 수 없으며, 이 스프레드시트의 워크시트 수를 초과할 수 없습니다. |

### 반환 값

SVG 이미지는 null이 아닌 [`SvgImage`](../../../groupdocs.editor.htmlcss.resources.images.vector/svgimage) 클래스의 인스턴스로 제공합니다.

| ArgumentOutOfRangeException | 지정된 *worksheetIndex*가 0보다 작거나 이 스프레드시트의 워크시트 수보다 큽니다. |
