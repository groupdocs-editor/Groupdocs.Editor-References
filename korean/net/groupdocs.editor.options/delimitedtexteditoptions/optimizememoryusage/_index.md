## DelimitedTextEditOptions.OptimizeMemoryUsage property

입력 문서 처리 중에 메모리 최적화 메커니즘을 활성화합니다. 이는 일부 특수한 경우에 성능을 저하시킬 수 있지만, 반대로 메모리 사용량을 감소시킵니다. 대용량 문서를 처리하고 OutOfMemoryException에 직면할 때 유용합니다. 기본값은 `false`이며(더 나은 성능을 위해 메모리 최적화가 비활성화됩니다).

public bool OptimizeMemoryUsage { get; set; }
