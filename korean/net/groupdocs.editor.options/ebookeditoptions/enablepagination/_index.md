## EbookEditOptions.EnablePagination property

결과 HTML 문서에서 페이지 매김을 활성화하거나 비활성화할 수 있습니다. 기본값은 비활성화(`false`)입니다.

```csharp
public bool EnablePagination { get; set; }
```

### 비고

본질적으로 대부분의 전자책 형식은 내부적으로 Office Open XML과 같은 흐름 형식이며, 내용은 연속적이고 장으로 분할되지만 페이지로는 나뉘지 않습니다. 그러나 페이지 번호, 각주, 머리글/바닥글 등 페이지별 정보가 포함됩니다. 일부 전자책 리더는 전자책 내용을 페이지로 분할하지만, 다른 리더(특히 모바일)는 그렇지 않습니다. 이 옵션은 편집 중 전자책 내용을 HTML/CSS에서 플로트(`false`) 보기 또는 페이지(`true`) 보기로 어떻게 표시할지 제어합니다.
