## EbookSaveOptions.SplitHeadingLevel property

e-Book 파일을 분할할 최대 제목 수준을 지정합니다. 기본값은 `2`입니다. `0`으로 설정하면 분할이 비활성화되어 e-Book의 모든 내용이 결과 파일 내 단일 패키지에 포함됩니다.

```csharp
public int SplitHeadingLevel { get; set; }
```

### 비고

이 속성을 1에서 9 사이의 값으로 설정하면, 문서는 **Heading 1**, **Heading 2**, **Heading 3** 등 지정된 헤딩 레벨까지의 스타일로 서식이 지정된 단락에서 분할됩니다.

기본적으로 **Heading 1** 및 **Heading 2** 단락만 문서를 분할합니다. 이 속성을 0(또는 0보다 작게)으로 설정하면 헤딩 단락에서 전혀 분할되지 않습니다.
