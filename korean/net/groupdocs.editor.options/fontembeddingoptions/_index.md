## FontEmbeddingOptions enumeration

폰트 임베딩 옵션은 출력 WordProcessing 또는 PDF 문서에 포함시켜야 할 폰트 리소스를 제어합니다.

```csharp
public enum FontEmbeddingOptions
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotEmbed | `0` | EditableDocument 또는 시스템에서 폰트 리소스를 전혀 포함하지 않습니다. 기본값입니다. |
| EmbedAll | `1` | 입력 EditableDocument의 문서 내용을 분석하고 사용된 모든 폰트를 찾아 출력 WordProcessing 또는 PDF 문서에 포함합니다. 먼저 GroupDocs.Editor는 EditableDocument 내부의 폰트 리소스에서 폰트를 가져옵니다. 만약 폰트가 부족하거나 없을 경우, GroupDocs.Editor는 OS에서 폰트를 가져옵니다. |
| EmbedWithoutSystem | `2` | EmbedAll과 동일하지만, OS에서 시스템 폰트로 간주되는 폰트는 제외합니다. |

### 비고

폰트 포함 옵션은 문서를 저장하는 동안(중간 EditableDocument에서 출력 WordProcessing 또는 PDF 형식으로) 적용되며, 이 열거형은 WordProcessingSaveOptions 및 PdfSaveOptions의 속성으로 포함되어 사용됩니다.
