## HtmlSaveOptions.SavingCallback property

외부 HTML 리소스를 모두 저장하기 위해 최종 사용자가 구현해야 하는 인터페이스입니다. 이 속성은 **must** `null`이 아니어야 하며, 그렇지 않으면 GroupDocs.Editor가 [`EditableDocument`](../../../groupdocs.editor/editabledocument)를 HTML 형식으로 저장하는 동안 예외를 발생시킵니다.

public IHtmlSavingCallback SavingCallback { get; set; }
