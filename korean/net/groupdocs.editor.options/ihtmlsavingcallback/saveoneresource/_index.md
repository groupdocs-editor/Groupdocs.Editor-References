## IHtmlSavingCallback.SaveOneResource method

[`Save`](../../../groupdocs.editor/editabledocument/save) 메서드 호출 중에 트리거되는 인스턴스 메서드이며, 제공된 HTML 리소스를 얻고 저장한 뒤 호출자에게 해당 리소스에 대한 링크를 반환하도록 최종 사용자가 구현해야 합니다.

```csharp
public string SaveOneResource(IHtmlResource resource)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 리소스 | IHtmlResource | HTML 마크업에 포함되지 않은 경우 이미지와 폰트, 스타일시트(있을 경우) 등 모든 종류의 HTML 리소스를 GroupDocs.Editor가 이 인터페이스의 사용자 정의 구현에 전달하며, 사용자는 이를 받아 저장, 전송, 변환 등 필요한 모든 절차를 수행할 수 있습니다. GroupDocs.Editor는 이 메서드에 `null` HTML 리소스를 절대 전달하지 않습니다. |

### 반환 값

*resource* 매개변수에서 얻은 리소스에 대한 링크(참조)이며, 사용자는 이를 GroupDocs.Editor에 제공해야 하므로 GroupDocs.Editor는 이 링크를 HTML 마크업에 삽입합니다.

### 비고

GroupDocs.Editor는 이 메서드의 사용자 정의 구현이 실행 중 예외를 발생시키지 않기를 기대합니다. 그러나 예외가 발생하면 [`FilenameWithExtension`](../../../groupdocs.editor.htmlcss.resources/ihtmlresource/filenamewithextension) 속성의 값을 HTML 마크업에 기록합니다.
