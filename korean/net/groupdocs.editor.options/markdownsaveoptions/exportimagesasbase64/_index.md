## MarkdownSaveOptions.ExportImagesAsBase64 property

이미지를 Base64 형식으로 출력 파일에 저장할지 여부를 지정합니다. 기본값은 `false`입니다.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### 비고

이 속성을 `true`로 설정하면 이미지 데이터가 이미지 요소 ![]()에 직접 내보내지고 별도 파일이 생성되지 않습니다. 이 속성이 `true`인 경우 [`ImagesFolder`](../imagesfolder) 속성보다 높은 우선순위를 가집니다.
