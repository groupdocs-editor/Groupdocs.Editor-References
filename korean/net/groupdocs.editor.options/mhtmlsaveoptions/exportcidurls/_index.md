## MhtmlSaveOptions.ExportCidUrls property

MHTML 문서에 포함된 리소스(이미지, 글꼴, CSS)를 참조하기 위해 CID(Content-ID) URL을 사용할지 여부를 지정합니다. 기본값은 `false`입니다.

```csharp
public bool ExportCidUrls { get; set; }
```

### 비고

기본적으로 MHTML 문서의 리소스는 파일 이름(예: "image.png")으로 참조되며, 이는 MIME 파트의 "Content-Location" 헤더와 매핑됩니다. 이 옵션을 사용하면 리소스 파일에 대한 참조를 CID(Content-ID) URL(예: "cid:image.png") 형태로 작성하고, "Content-ID" 헤더와 매핑되는 대체 방법을 사용할 수 있습니다.

이론적으로 두 참조 방식 사이에 차이가 없으며 어느 쪽이든 모든 브라우저나 메일 에이전트에서 정상적으로 작동해야 합니다. 그러나 실제로는 일부 에이전트가 파일 이름으로 리소스를 가져오지 못합니다. 브라우저나 메일 에이전트가 MHTML 문서에 포함된 리소스를 로드하지 못하는 경우(이미지가 표시되지 않거나 CSS 스타일이 로드되지 않음) CID URL로 문서를 내보내 보세요.
