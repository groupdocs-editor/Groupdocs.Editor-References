## PageRange.FromStartPageTillEndPage method

지정된 페이지 번호(포함)에서 시작하여 지정된 페이지 번호(제외)까지 계속되는 페이지 범위를 생성합니다.

```csharp
public static PageRange FromStartPageTillEndPage(ushort startPageNumber, ushort endPageNumber)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| startPageNumber | UInt16 | 페이지 번호, 페이지 범위가 시작되는 포함 시작 번호입니다. 페이지 번호는 1부터 시작하므로 0보다 크게 엄격히 지정되어야 합니다. |
| endPageNumber | UInt16 | 페이지 번호, 페이지 범위가 독점적으로 종료되는 번호입니다. 페이지 번호는 1부터 시작하므로 0보다 크게 엄격히 지정되어야 하며, 또한 *startPageNumber*보다 엄격히 커야 합니다. |
