## PresentationEditOptions.SlideNumber property

편집을 위해 열어야 할 슬라이드 번호를 지정할 수 있습니다.

```csharp
public int SlideNumber { get; set; }
```

### 비고

슬라이드 번호는 슬라이드의 0부터 시작하는 인덱스로, 프레젠테이션에서 특정 슬라이드를 지정하고 선택하여 편집할 수 있게 합니다. 0보다 작으면 첫 번째 슬라이드가 선택됩니다(SlideNumber = 0과 동일). 프레젠테이션의 전체 슬라이드 수보다 크면 마지막 슬라이드가 선택됩니다. 입력 프레젠테이션에 슬라이드가 하나만 있는 경우 이 옵션은 무시되고 해당 단일 슬라이드가 편집됩니다. 숨겨진 슬라이드를 편집하려고 시도할 때 [`ShowHiddenSlides`](../showhiddenslides) 옵션이 'false'로 설정되어 있으면 예외가 발생합니다.
