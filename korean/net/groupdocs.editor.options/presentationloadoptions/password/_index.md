## PresentationLoadOptions.Password property

Presentation 문서가 암호화된 경우 열 때 사용할 비밀번호를 지정, 수정 및 가져올 수 있습니다. 비밀번호를 제거하려면 NULL 또는 빈 문자열로 설정합니다.

```csharp
public string Password { get; set; }
```

### 비고

기본적으로 이 속성은 NULL 값을 가지며—비밀번호가 설정되지 않습니다. 입력 프레젠테이션 문서가 비밀번호로 보호된 경우 비밀번호가 필수이며, 비밀번호가 지정되지 않거나 잘못된 경우 예외가 발생합니다. 입력 프레젠테이션 문서가 비밀번호로 보호되지 않았지만 비밀번호가 설정된 경우 무시됩니다.
