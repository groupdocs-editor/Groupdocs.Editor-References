## PresentationSaveOptions.InsertAsNewSlide property

편집된 슬라이드가 원본 프레젠테이션에서 [`SlideNumber`](../slidenumber) 속성으로 지정된 위치에 기존 슬라이드를 교체할지, 아니면 기존 슬라이드와 이전 슬라이드 사이에 삽입하여 내용을 교체하지 않을지를 지정하는 Boolean 플래그입니다. 기본값은 `false` — 기존 슬라이드가 교체됩니다. 이 속성은 [`SlideNumber`](../slidenumber) 속성 값이 `'0'`으로 설정된 경우 무시됩니다.

```csharp
public bool InsertAsNewSlide { get; set; }
```

### 비고

기본적으로 슬라이드는 교체됩니다. 이는 주어진 프레젠테이션에 슬라이드가 5개 있고 [`SlideNumber`](../slidenumber)=4인 경우, 4번째 슬라이드가 새로운 편집된 슬라이드로 교체되며 프레젠테이션의 전체 슬라이드 수(5)는 변하지 않음을 의미합니다. 그러나 이 속성 값이 true로 설정되면 새로운 편집된 슬라이드가 4번째 슬라이드로 삽입되고, 이후 모든 슬라이드가 끝쪽으로 이동합니다: \"old\" 4번째 슬라이드가 5번째가 되고, 5번째가 6번째가 되며, 프레젠테이션의 전체 슬라이드 수가 하나 증가하여 6이 됩니다.
