## PresentationSaveOptions.SlideNumber property

새 단일 슬라이드 프레젠테이션을 생성하는 대신(기본 동작) 편집된 슬라이드를 기존 프레젠테이션에 삽입할 수 있습니다. 슬라이드 번호는 Editor 클래스에 로드된 프레젠테이션에서 슬라이드의 1부터 시작하는 번호입니다. 0(기본값)인 경우 새 프레젠테이션은 단일 편집 슬라이드로 생성됩니다. 0보다 크거나 작고 Editor 클래스에 유효한 프레젠테이션이 로드된 경우, 입력 EditableDocument 인스턴스에 저장된 편집 슬라이드가 해당 프레젠테이션에 삽입됩니다.

```csharp
public int SlideNumber { get; set; }
```

### 비고

SlideNumber 정수 속성은 기본 상태(예약 값 '0')가 아니면 슬라이드 번호를 나타내며, 0이 아니라 1부터 시작하고 최대값은 프레젠테이션에 존재하는 모든 슬라이드 수입니다. 지정된 값이 전체 슬라이드 수보다 크면 GroupDocs.Editor가 마지막 슬라이드로 조정합니다. 음수 값도 허용되며 끝에서부터 슬라이드를 셉니다. 예를 들어 \"-1\"은 마지막 슬라이드, \"-2\"는 마지막에서 두 번째 슬라이드 등을 의미합니다. 양수와 마찬가지로 음수 슬라이드 번호가 프레젠테이션의 총 슬라이드 수를 초과하면 첫 번째 슬라이드로 조정됩니다. [`InsertAsNewSlide`](../insertasnewslide) 부울 속성은 이 속성과 밀접하게 연결되어 있습니다.

### 예시

주어진 프레젠테이션에 슬라이드가 5개 있습니다: SlideNumber = 0; — 주어진 프레젠테이션을 무시하고 새 프레젠테이션을 만든 뒤 편집된 슬라이드를 넣습니다. SlideNumber = 1; — 첫 번째 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = 2; — 두 번째 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = 5; — 마지막(5번째) 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = 6; — 마지막(5번째) 슬라이드를 편집된 슬라이드로 교체합니다(6이 5보다 커서 마지막 슬라이드로 조정됨). SlideNumber = -1; — 마지막(5번째) 슬라이드를 편집된 슬라이드로 교체합니다(\"-1\"은 \"마지막 존재 슬라이드\"를 의미). SlideNumber = -2; — 네 번째 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = -3; — 세 번째 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = -4; — 두 번째 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = -5; — 첫 번째 슬라이드를 편집된 슬라이드로 교체합니다. SlideNumber = -6; — 첫 번째 슬라이드를 편집된 슬라이드로 교체합니다(\"-6\"이 5보다 커서 첫 슬라이드로 조정됨).
