## PresentationSaveOptions.SlideNumbersToDelete property

편집된 슬라이드가 기존 프레젠테이션에 삽입될 경우 저장 중에 프레젠테이션에서 삭제할 슬라이드의 1부터 시작하는 번호 배열을 지정할 수 있습니다.

```csharp
public int[] SlideNumbersToDelete { get; set; }
```

### 비고

편집된 슬라이드가 새 단일 슬라이드 프레젠테이션(기본 동작)으로 저장되지 않고, 기존 프레젠테이션에 저장될 때([`SlideNumber`](../slidenumber) 속성을 사용), 이 배열에 번호를 지정하여 해당 프레젠테이션의 특정 슬라이드를 삭제할 수도 있습니다.

기본적으로 이 배열은 `null`이며 슬라이드가 삭제되지 않습니다. 그러나 배열이 null이 아니고 비어 있지 않으며 하나 이상의 유효한 슬라이드 번호를 포함하는 경우, 편집된 슬라이드 내용으로 출력 프레젠테이션 문서가 생성된 후, 지정된 번호의 슬라이드가 출력 스트림이나 파일에 쓰기 직전에 프레젠테이션에서 삭제됩니다.

이 배열의 슬라이드 번호는 1부터 시작하며 0부터 시작하지 않습니다. 유효하지 않은 번호(1보다 작거나 전체 슬라이드 수보다 큰)는 무시됩니다.
