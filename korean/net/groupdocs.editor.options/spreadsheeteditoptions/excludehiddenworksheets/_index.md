## SpreadsheetEditOptions.ExcludeHiddenWorksheets property

입력 스프레드시트 문서에서 숨겨진 워크시트를 제외하도록 할 수 있으며, 이렇게 하면 완전히 무시됩니다. 기본값은 false이며, 숨겨진 워크시트는 정상적으로 사용 및 처리됩니다.

```csharp
public bool ExcludeHiddenWorksheets { get; set; }
```

### 비고

XLSX와 같은 일부 바이너리 Spreadsheet 형식은 숨겨진 워크시트(탭) 개념을 지원합니다. 이러한 형식의 문서는 워크시트가 두 개 이상인 경우 추가 숨겨진 워크시트를 포함할 수 있습니다. 기본적으로 이러한 숨겨진 워크시트는 처리 가능하지만, 이 옵션을 사용하면 숨겨진 워크시트를 무시하여 마치 존재하지 않는 것처럼 동작합니다. 이 옵션이 활성화되면 '[`WorksheetIndex`](../worksheetindex)' 속성을 사용하여 숨겨진 워크시트를 선택할 수 없습니다.
