## SpreadsheetEditOptions.ExportBogusRowData property

활성화하면 생성된 HTML 문서의 HTML 테이블에 높이가 0이고 셀은 비어 있으나 너비만 지정된 빈 하단 숨김 행이 포함됩니다. 이 빈 셀 행은 각 열의 정확한 너비 값을 포함하여 HTML에서 스프레드시트로의 역변환을 개선합니다. 기본값은 활성화(`true`)입니다.

```csharp
public bool ExportBogusRowData { get; set; }
```
