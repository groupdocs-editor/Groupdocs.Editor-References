## SpreadsheetEditOptions.MergeEmptyAdjacentCells property

활성화하면 입력 스프레드시트 문서의 인접한 빈 가로 셀들이 편집 가능한 HTML 문서에서 해당 `colspan` 속성을 가진 단일 셀로 병합되어 표시됩니다. 기본값은 비활성화(`false`)입니다.

```csharp
public bool MergeEmptyAdjacentCells { get; set; }
```

### 비고

기본적으로 GroupDocs.Editor는 입력 Spreadsheet 문서의 테이블을 각 셀을 보존한 채 출력 HTML 문서로 변환합니다. 그러나 Spreadsheet 문서는 희소할 수 있으며, 많은 셀이 비어 있는 "빈 영역"이 대량으로 존재할 수 있습니다. 이 옵션을 활성화하면 이러한 빈 셀들을 `TD` 요소의 `colspan` 속성을 사용해 하나의 셀로 병합하여 생성된 HTML 마크업의 크기를 크게 줄일 수 있습니다.
