## SpreadsheetSaveOptions.InsertAsNewWorksheet property

편집된 워크시트가 원본 스프레드시트의 기존 워크시트를 [`WorksheetNumber`](../worksheetnumber) 속성으로 지정된 위치에 교체할지, 기존 워크시트와 이전 워크시트 사이에 삽입하여 내용을 교체하지 않을지를 지정하는 부울 플래그입니다. 기본값은 false — 기존 워크시트가 교체됩니다. [`WorksheetNumber`](../worksheetnumber) 속성 값이 '0'으로 설정된 경우 이 속성은 무시됩니다.

```csharp
public bool InsertAsNewWorksheet { get; set; }
```

### 비고

기본적으로 워크시트가 교체됩니다. 이는 주어진 스프레드시트에 워크시트가 5개 있고 [`WorksheetNumber`](../worksheetnumber)=4인 경우, 4번째 워크시트가 새 편집된 워크시트로 교체되며 스프레드시트의 전체 워크시트 수(5)는 변경되지 않음을 의미합니다. 그러나 이 속성값을 true로 설정하면 새 편집된 워크시트가 4번째 워크시트로 삽입되고 이후의 모든 워크시트가 끝으로 이동합니다: \"old\" 4번째 워크시트가 5번째가 되고, 5번째가 6번째가 되며, 스프레드시트의 전체 워크시트 수가 하나 증가하여 6이 됩니다.
