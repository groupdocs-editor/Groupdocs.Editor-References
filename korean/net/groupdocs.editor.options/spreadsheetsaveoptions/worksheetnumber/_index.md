## SpreadsheetSaveOptions.WorksheetNumber property

새 단일 워크시트 스프레드시트를 생성하는 대신 기존 스프레드시트 복사본에 편집된 워크시트를 삽입할 수 있습니다 (기본 동작). WorksheetNumber는 Editor 클래스에 로드된 스프레드시트에서 워크시트의 1 기반 번호입니다. 값이 0(기본값)인 경우 새 스프레드시트가 단일 편집 워크시트와 함께 생성됩니다. 값이 0보다 크거나 작고, Editor 클래스에 로드된 유효한 스프레드시트가 있는 경우, 입력 EditableDocument 인스턴스로 표시되는 편집 워크시트가 해당 스프레드시트에 삽입됩니다.

```csharp
public int WorksheetNumber { get; set; }
```

### 비고

WorksheetNumber 정수 속성은 기본 상태(예약 값 '0')가 아니면 워크시트 번호를 나타내며, 0이 아닌 1부터 시작하고 최대값은 프레젠테이션에 존재하는 모든 슬라이드 수와 같습니다. 그러나 지정된 값이 전체 슬라이드 수보다 크면 GroupDocs.Editor는 이를 마지막 워크시트로 조정합니다. 음수 값도 허용되며 끝에서부터 워크시트를 셉니다. 예를 들어 "-1"은 스프레드시트의 마지막 워크시트를 의미하고, "-2"는 그 전 워크시트를 의미합니다. 양수 값과 마찬가지로 음수 워크시트 번호가 해당 스프레드시트의 전체 워크시트 수를 초과하면 첫 번째 워크시트로 조정됩니다. [`InsertAsNewWorksheet`](../insertasnewworksheet) 부울 속성은 이 속성과 밀접하게 연결되어 있습니다.

### 예시

주어진 스프레드시트에 5개의 워크시트가 있습니다: WorksheetNumber = 0; — 주어진 스프레드시트를 무시하고 새 스프레드시트를 생성하여 편집된 워크시트를 넣습니다. WorksheetNumber = 1; — 첫 번째 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = 2; — 두 번째 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = 5; — 마지막(5번째) 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = 6; — 6이 5보다 크므로 마지막(5번째) 워크시트를 교체하고 조정됩니다. WorksheetNumber = -1; — "-1"은 마지막 기존 워크시트를 의미하므로 마지막(5번째) 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = -2; — 네 번째 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = -3; — 세 번째 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = -4; — 두 번째 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = -5; — 첫 번째 워크시트를 편집된 워크시트로 교체합니다. WorksheetNumber = -6; — "-6"이 5보다 크므로 첫 번째 워크시트를 교체하고 조정됩니다.
