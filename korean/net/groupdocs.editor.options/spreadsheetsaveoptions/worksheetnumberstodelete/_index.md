## SpreadsheetSaveOptions.WorksheetNumbersToDelete property

편집된 워크시트가 기존 스프레드시트에 삽입되는 경우, 저장 중에 스프레드시트에서 삭제해야 하는 워크시트의 1 기반 번호 배열을 지정할 수 있습니다.

```csharp
public int[] WorksheetNumbersToDelete { get; set; }
```

### 비고

편집된 워크시트가 새 단일 워크시트 스프레드시트로 저장되지 않고(기본 동작) 대신 기존 스프레드시트에 저장될 때([`WorksheetNumber`](../worksheetnumber) 속성을 사용), 이 배열에 번호를 지정하여 해당 스프레드시트에서 특정 워크시트를 삭제할 수도 있습니다.

기본적으로 이 배열은 `null`이며 워크시트가 삭제되지 않습니다. 그러나 배열이 null이 아니고 비어 있지 않으며 하나 이상의 유효한 워크시트 번호를 포함하는 경우, 편집된 워크시트의 내용으로 출력 스프레드시트 문서가 생성된 후 지정된 번호의 워크시트가 출력 스트림이나 파일에 내용을 쓰기 직전에 스프레드시트에서 삭제됩니다.

이 배열의 워크시트 번호는 0이 아닌 1부터 시작합니다. 1보다 작거나 워크시트 총 수보다 큰 잘못된 번호는 무시됩니다.
