## TextEditOptions.RecognizeLists property

문서를 일반 텍스트 형식에서 가져올 때 번호 매기기 목록 항목을 인식하는 방식을 지정할 수 있습니다. 기본값은 true입니다.

```csharp
public bool RecognizeLists { get; set; }
```

### 비고

이 옵션이 false로 설정되면 목록 번호가 점, 오른쪽 괄호 또는 글머리 기호(예: \"•\", \"*\", \"-\", \"o\")로 끝나는 경우 목록 인식 알고리즘은 목록 단락을 감지합니다. 옵션이 true로 설정되면 공백도 목록 번호 구분자로 사용됩니다: 아라비아식 번호 매기기(1., 1.1.2.)에 대한 목록 인식 알고리즘은 공백과 점(\".\") 기호를 모두 사용합니다.
