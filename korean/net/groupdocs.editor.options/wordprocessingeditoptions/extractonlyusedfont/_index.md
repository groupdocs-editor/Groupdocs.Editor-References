## WordProcessingEditOptions.ExtractOnlyUsedFont property

문서의 텍스트 내용에 사용된 글꼴 리소스만 추출할지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool ExtractOnlyUsedFont { get; set; }
```

### Property Value

`true`이면 문서의 텍스트 내용에 사용된 폰트 리소스만 추출하도록 요구됩니다; 그렇지 않으면 `false`입니다. 기본값은 `false`입니다.

### 비고

WordProcessing 문서에서 사용되는 모든 폰트가 100% 직접 사용(텍스트에 적용)되는 것은 아닙니다. 문서에 폰트가 참조되고 포함될 수도 있지만 텍스트에 적용되지 않는 경우가 있을 수 있습니다. 예를 들어, 어떤 폰트가 스타일에 연결되어 있지만 해당 스타일이 텍스트의 어느 부분에도 적용되지 않을 수 있습니다. 이 옵션은 이러한 경우를 어떻게 처리할지 제어합니다.
