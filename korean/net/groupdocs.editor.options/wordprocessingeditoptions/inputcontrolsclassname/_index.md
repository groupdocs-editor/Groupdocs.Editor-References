## WordProcessingEditOptions.InputControlsClassName property

입력 WordProcessing 문서의 일부 필드를 나타내는 모든 HTML 요소에 'class' 속성으로 배치될 클래스 이름을 지정할 수 있습니다. 기본값은 NULL이며, 'class' 속성이 적용되지 않습니다.

```csharp
public string InputControlsClassName { get; set; }
```

### 비고

WordProcessing 형식군의 거의 모든 형식에는 필드가 포함되어 있습니다 — 사용자로부터 입력 데이터를 얻을 수 있는 특정 문서 엔터티입니다. 텍스트 박스, 체크박스, 콤보 박스, 드롭다운 목록, 버튼, 날짜/시간 선택기 등 다양한 필드가 있습니다. 이러한 모든 필드는 입력 문서에 존재하는 경우 입력된 사용자 데이터를 보존하면서 가장 적절한 HTML 구조와 요소로 변환됩니다. 특정 사용 사례에서는 전체 문서 내용을 편집하는 대신 클라이언트 측에서 입력된 데이터만 수집해야 합니다. 이러한 경우 클라이언트 측에서 데이터를 가져오기 위해 입력 컨트롤을 어떤 방식으로든 식별해야 합니다. 이 속성은 HTML 마크업의 모든 입력 컨트롤에 적용될 클래스 이름을 지정할 수 있게 하여, 클라이언트 코드가 HTML 문서 구조를 순회하며 데이터를 수집할 수 있도록 합니다.
