## WordProcessingSaveOptions.LocaleBi property

RTL(오른쪽에서 왼쪽) 텍스트용 WordProcessing 문서의 로케일(언어)을 재정의하도록 설정할 수 있습니다. 이는 문서 생성 시 적용됩니다. 지정되지 않은 경우(기본값), MS Word(또는 다른 프로그램)가 자체 설정이나 기타 요인에 따라 문서 RTL 로케일을 감지(또는 선택)합니다.

```csharp
public CultureInfo LocaleBi { get; set; }
```

### 비고

이 옵션은 지정된 로케일을 문서 전체의 RTL 텍스트에 강제로 적용합니다. 문서에 서로 다른 언어로 작성된 텍스트 부분이 포함된 경우 사용하지 마십시오.
