## EditableDocument.FromFile method

HTML 파일(*.html 파일 자체 경로)과 연결된 리소스 폴더를 지정하여 EditableDocument 인스턴스를 생성하는 정적 팩터리

```csharp
public static EditableDocument FromFile(string htmlFilePath, string resourceFolderPath)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| htmlFilePath | 문자열 | HTML 파일에 대한 전체 경로를 포함하는 문자열입니다. null일 수 없으며, 유효한 파일 경로여야 하고 파일 자체가 존재해야 합니다. |
| resourceFolderPath | 문자열 | HTML 리소스가 있는 폴더에 대한 선택적 경로입니다. NULL이거나 유효하지 않거나 폴더가 존재하지 않을 경우, Editor는 HTML 마크업을 분석하여 해당 폴더를 스스로 찾으려고 시도합니다. |

### 반환 값

새로운 null이 아닌 EditableDocument 인스턴스

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentException | HTML 파일 경로 및/또는 리소스 폴더 경로가 유효하지 않습니다. |
| FileNotFoundException | 지정된 HTML 파일을 찾을 수 없습니다. |
