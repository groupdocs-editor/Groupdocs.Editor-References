## FromMarkup(string) {#frommarkup}

지정된 HTML 마크업에서 [`EditableDocument`](../../editabledocument) 인스턴스를 생성하는 정적 팩터리

```csharp
public static EditableDocument FromMarkup(string newHtmlContent)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| newHtmlContent | 문자열 | 구문 분석해야 하는 원시 HTML 마크업을 포함하는 문자열. NULL이거나 비어 있거나 유효하지 않아서는 안 됩니다. |

### 반환 값

새로운 null이 아닌 EditableDocument 인스턴스

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentException | 입력 원시 HTML 마크업 문자열은 null이거나 비어 있을 수 없습니다. |

### 비고

이 정적 메서드는 단일 문자열 HTML 마크업에서 모든 리소스가 base64 인코딩으로 삽입된 [`EditableDocument`](../../editabledocument) 인스턴스를 만드는 데 유용합니다.
