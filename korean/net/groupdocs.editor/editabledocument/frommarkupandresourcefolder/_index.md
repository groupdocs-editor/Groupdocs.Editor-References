## EditableDocument.FromMarkupAndResourceFolder method

```csharp
public static EditableDocument FromMarkupAndResourceFolder(string newHtmlContent, 
    string resourceFolderPath)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| newHtmlContent | 문자열 | 구문 분석해야 하는 원시 HTML 마크업을 포함하는 문자열. NULL이거나 비어 있거나 유효하지 않아서는 안 됩니다. |
| resourceFolderPath | 문자열 | 리소스가 포함된 폴더에 대한 필수 경로. 이 폴더에 있는 모든 스타일시트가 사용됩니다. NULL이거나 빈 문자열이면 안 되며, 해당 폴더가 존재해야 합니다. |

### 반환 값

### 비고

이 정적 팩터리는 HTML 문서의 내용이 문자열로 제공되지만 모든 리소스가 특정 폴더에 위치하고, HTML 마크업 내의 해당 리소스 링크가 잘못되었거나 없을 때 유용합니다. 이 메서드를 호출하면 지정된 폴더를 스캔하고 발견된 모든 스타일시트를 문서에 자동으로 적용합니다. 이 메서드는 일반적으로 문서 메타데이터 등을 잘라내는 다양한 HTML 편집기에서 콘텐츠를 가져올 때 매우 유용합니다.
