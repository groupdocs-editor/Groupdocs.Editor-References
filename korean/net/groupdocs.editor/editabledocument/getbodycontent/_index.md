## GetBodyContent() {#getbodycontent}

HTML 문서의 본문(열고 닫는 BODY 태그 사이의 내부 내용, 태그 자체 제외)을 문자열로 반환합니다.

```csharp
public string GetBodyContent()
```

### 반환 값

HTML 문서의 본문(시작 및 종료 BODY 태그 없이)을 포함하는 문자열

### 비고

대부분의 WYSIWYG 편집기는 문서의 BODY 내부 콘텐츠를 주로 다루며 HEAD 블록의 메타 정보를 올바르게 처리하지 못합니다. 이 메서드는 이러한 경우를 위해 설계되었습니다. 이 오버로드는 외부 리소스 요청을 위한 URI 조정을 허용하지 않습니다.

## GetBodyContent(string) {#getbodycontent_1}

HTML 문서의 본문(열고 닫는 BODY 태그 사이의 내부 내용, 태그 자체 제외)을 문자열로 반환하며, 외부 리소스에 대한 링크는 지정된 템플릿과 플레이스홀더를 포함합니다.

```csharp
public string GetBodyContent(string externalImagesTemplate)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| externalImagesTemplate | 문자열 | 이 매개변수를 통해 하나의 자리표시자를 가진 문자열 템플릿을 지정할 수 있으며, 이는 결과 HTML 문자열에 포함될 IMG 요소의 모든 외부 이미지 링크에 적용됩니다. NULL이거나 비어 있으면 템플릿이 추가되지 않고 순수 파일 이름만 결과 HTML 마크업에 표시됩니다. 템플릿이 유효하지 않으면 접두사로 처리되어 파일 이름이 그 뒤에 연결됩니다. |

### 반환 값

외부 이미지에 맞게 조정된 링크가 포함된 HTML 문서의 본문(시작 및 종료 BODY 태그 없이)을 포함하는 문자열

### 비고

대부분의 WYSIWYG 편집기는 일반적으로 문서의 BODY 내부 콘텐츠를 대상으로 작업하며 HEAD 블록의 메타 정보를 올바르게 처리하지 못합니다. 이 메서드는 이러한 경우를 위해 설계되었습니다. 이 오버로드는 외부 리소스 요청을 위한 URI를 조정할 수 있게 합니다.
