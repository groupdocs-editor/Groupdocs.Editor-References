## GetContent(string, string) {#getcontent_1}

HTML 문서의 전체 내용을 문자열로 반환하며, 외부 리소스에 대한 링크는 지정된 템플릿과 플레이스홀더를 포함합니다.

```csharp
public string GetContent(string externalImagesTemplate, string externalCssTemplate)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| externalImagesTemplate | 문자열 | 이 매개변수를 통해 하나의 자리표시자를 가진 문자열 템플릿을 지정할 수 있으며, 이는 결과 HTML 문자열에 포함될 IMG 요소의 모든 외부 이미지 링크에 적용됩니다. NULL이거나 비어 있으면 템플릿이 추가되지 않고 순수 파일 이름만 결과 HTML 마크업에 표시됩니다. 템플릿이 유효하지 않으면 접두사로 처리되어 파일 이름이 그 뒤에 연결됩니다. |
| externalCssTemplate | 문자열 | 이 매개변수를 사용하면 하나의 자리표시자를 포함하는 문자열 템플릿을 지정할 수 있으며, 이는 결과 HTML 문자열에 포함될 LINK 요소의 모든 외부 스타일시트 링크에 추가됩니다. NULL이거나 비어 있으면 템플릿이 추가되지 않고 순수 파일 이름만 결과 HTML 마크업에 표시됩니다. 템플릿이 유효하지 않은 경우 접두사로 처리되어 파일 이름이 템플릿 끝에 연결됩니다. |

### 반환 값

외부 리소스에 맞게 조정된 링크가 포함된 HTML 문서의 내용을 포함하는 문자열
