```csharp
public List<string> GetCssContent(string externalImagesPrefix, string externalFontsPrefix)
```

| --- | --- | --- |
| externalImagesPrefix | 문자열 | 이 매개변수를 사용하여 모든 외부 이미지 링크에 추가될 접두사를 지정할 수 있습니다. 해당 접두사는 결과 CSS 문자열의 CSS 선언에 포함된 외부 이미지 링크에 추가됩니다. NULL이거나 비어 있으면 접두사가 추가되지 않습니다. |
