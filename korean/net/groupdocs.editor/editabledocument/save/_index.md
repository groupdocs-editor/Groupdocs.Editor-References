## Save(TextWriter, HtmlSaveOptions) {#save}

이 [`EditableDocument`](../../editabledocument)의 내용을 HTML 문서로 지정된 텍스트 라이터에 저장하며, 두 번째 옵션 매개변수를 사용하여 저장 절차를 사용자 정의하고 리소스 저장 콜백을 지정할 수 있습니다.

```csharp
public void Save(TextWriter htmlMarkup, HtmlSaveOptions saveOptions)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| htmlMarkup | TextWriter | HTML 마크업이 기록될 텍스트 라이터의 구현입니다. null일 수 없습니다. |
| saveOptions | HtmlSaveOptions | HTML 저장 옵션은 저장 절차를 제어합니다: HTML 마크업이 어떻게 저장되는지(태그 이름, 인용 부호 유형)와 CSS 및 이미지, 폰트와 같은 기타 리소스가 언제, 어디에 저장되는지. 사용자는 리소스가 어떻게 저장되고 HTML 마크업에서 참조되는지를 제어하기 위해 [`SavingCallback`](../../../groupdocs.editor.options/htmlsaveoptions/savingcallback) 속성의 인터페이스 구현자를 지정해야 합니다. |

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentNullException | 지정된 인수 중 하나 또는 *saveOptions*의 `SavingCallback` 속성이 `null`입니다. |
