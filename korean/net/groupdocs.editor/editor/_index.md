## Editor class

변환 메서드를 캡슐화하는 메인 클래스입니다. Editor 클래스는 모든 지원 형식의 문서를 로드, 편집 및 저장하는 메서드를 제공합니다. 이 클래스는 disposable이므로 'using' 지시문을 사용하거나 'Dispose()' 메서드 호출을 통해 리소스를 수동으로 해제하십시오. 문서 로드는 생성자를 통해 수행됩니다. 문서 편집은 'Edit' 메서드를 통해, 편집 후 결과 문서 저장은 'Save' 메서드를 통해 이루어집니다.

```csharp
public sealed class Editor : IAuxDisposable
```

### 비고

Editor 클래스는 GroupDocs.Editor의 진입점이자 루트 객체로 간주되어야 합니다. 모든 작업은 이 클래스를 사용하여 수행됩니다. 전체 문서 편집 파이프라인을 수행하기 위한 Editor 클래스의 일반적인 사용 방법은 다음과 같습니다:

1. 생성자를 통해 문서를 Editor 인스턴스로 로드합니다.
2. 선택적으로, [`GetDocumentInfo`](./getdocumentinfo) 메서드를 사용하여 문서 유형을 감지합니다.
3. [`Edit`](./edit) 메서드를 호출하여 문서를 편집용으로 열고, [`EditableDocument`](../editabledocument) 클래스의 인스턴스를 얻습니다.
4. 원하는 WYSIWYG HTML 편집기를 사용하여 클라이언트 측에서 문서 내용을 편집합니다.
5. 편집된 문서 내용으로부터 새로운 [`EditableDocument`](../editableddocument) 인스턴스를 생성합니다.
6. [`Save`](./save) 메서드를 호출하여 편집된 문서를 특정 출력 형식으로 저장합니다.
7. 'using' 연산자 또는 수동으로 Editor 클래스 인스턴스를 해제합니다.
