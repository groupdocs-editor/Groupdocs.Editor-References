## Edit(IEditOptions) {#edit_1}

지정된 형식별 옵션을 사용하여 이전에 로드된 문서를 편집하기 위해 열고, HTML 마크업 및 관련 리소스를 생성하는 메서드를 포함하는 '[`EditableDocument`](../../editabledocument)' 클래스의 인스턴스를 생성하여 반환합니다.

```csharp
public EditableDocument Edit(IEditOptions editOptions)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| editOptions | IEditOptions | 형식별 문서 옵션으로, 변환 프로세스를 조정할 수 있습니다. NULL일 수 있으며, 이 경우 GroupDocs.Editor는 이전에 로드된 문서의 형식을 감지하고 해당 형식의 기본 옵션을 적용합니다. 이전에 적용된 로드 옵션과 충돌하지 않아야 합니다. |

### 반환 값

'[`EditableDocument`](../../editabledocument)' 클래스의 인스턴스로, 중간 형식으로 모든 리소스를 포함한 전체 입력 문서를 캡슐화합니다. 이 메서드는 성공적으로 완료되면 NULL을 반환하지 않습니다.

### 비고

입력 원본 문서가 생성자를 통해 'Editor' 인스턴스로 로드될 때, 이 메서드는 문서를 중간 형식으로 변환하여 'EditableDocument' 클래스 인스턴스에 캡슐화함으로써 편집을 위해 엽니다. '[`EditableDocument`](../../editabledocument)'는 HTML 마크업 및 해당 리소스(이미지, 글꼴 및 스타일시트 등)를 생성하기 위한 모든 필요한 메서드와 속성을 포함하며, 이후 어떤 WYSIWYG HTML‑editor에든 전달할 수 있는 모든 구성에서 사용할 수 있습니다. 이 오버로드는 패밀리 형식에 특정한 편집 옵션을 얻습니다. **Learn more**
