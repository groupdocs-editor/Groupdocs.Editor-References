## Editor.GetDocumentInfo method

이 'Editor' 인스턴스에 로드된 문서에 대한 메타데이터를 반환합니다.

```csharp
public IDocumentInfo GetDocumentInfo(string password)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| password | String | 문서가 비밀번호로 암호화된 경우 사용자는 문서에 대한 비밀번호를 지정할 수 있습니다. NULL이거나 빈 문자열일 경우 비밀번호가 없는 것과 동일하게 취급됩니다. 비밀번호 보호 기능이 없는 문서 형식에 대해서는 이 인수가 무시됩니다. 문서가 암호화되어 있고 이 매개변수에 비밀번호가 지정되지 않았지만, [`Editor`](../../editor) 인스턴스를 생성할 때 로드 옵션에서 이미 지정된 경우 해당 비밀번호가 사용됩니다. |

### 반환 값

감지된 형식과 형식별 메타데이터를 나타내는 [`IDocumentInfo`](../../../groupdocs.editor.metadata/idocumentinfo) 인터페이스의 형식별 구현체이며, 문서가 지원 가능한 형식으로 인식되지 않거나 손상된 경우 NULL을 반환합니다.

### 예외

| 예외 | 조건 |
| --- | --- |
| ObjectDisposedException | Editor 인스턴스가 이미 폐기된 상태에서 "GetDocumentInfo"가 호출될 때 발생합니다. |
| [PasswordRequiredException](../../passwordrequiredexception) | 로드된 문서가 비밀번호로 보호되어 있지만 매개변수 "*password*"와 인스턴스 생성 시 로드 옵션 모두에 비밀번호가 지정되지 않은 경우 발생합니다. |
| [IncorrectPasswordException](../../incorrectpasswordexception) | 로드된 문서가 비밀번호로 보호되어 있고 비밀번호가 지정되었지만 올바르지 않은 경우 발생합니다. |
| InvalidOperationException | 알 수 없는 성격의 예상치 못한 오류가 발생했을 때 발생합니다. |

### 비고

GetDocumentInfo 메서드는 입력 문서의 형식이 무엇인지, 비밀번호로 보호되어 있는지 및/또는 페이지/워크시트/슬라이드가 몇 개인지 명확하지 않을 때 유용합니다. GetDocumentInfo가 반환하는 이 메타데이터를 기반으로 주요 처리 파이프라인에 대한 로드 및 편집 옵션을 올바르게 조정할 수 있습니다.

GetDocumentInfo 메서드는 항상 전체 데이터를 반환하며, 평가판 모드의 영향을 받지 않고, 사용 시 소모된 바이트나 크레딧을 차감하지 않습니다.
