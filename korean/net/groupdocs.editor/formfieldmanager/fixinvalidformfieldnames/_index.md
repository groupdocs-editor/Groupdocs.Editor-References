## FormFieldManager.FixInvalidFormFieldNames method

지정된 업데이트를 적용하거나 자동으로 고유한 이름을 생성하여 문서의 잘못된 양식 필드 이름을 수정합니다.


| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| updateInvalidFormFieldNames | IEnumerable`1 | 잘못된 폼 필드 이름에 대한 업데이트 컬렉션입니다. 각 업데이트는 폼 필드의 원래 이름과 해당하는 새 이름을 포함합니다. 비워두면, 잘못된 폼 필드 이름은 고유성을 보장하기 위해 자동으로 이름이 변경됩니다. |

### 비고

이 `FixInvalidFormFieldNames` 메서드는 *updateInvalidFormFieldNames* 컬렉션에 지정된 업데이트를 적용하거나 컬렉션이 비어 있을 경우 자동으로 고유한 이름을 생성하여 문서의 폼 필드 내 이름 충돌 또는 불일치를 해결합니다. 이 메서드는 특정 폼 필드 이름이 잘못되었거나 문서의 다른 요소와 충돌할 때, 올바른 기능을 보장하기 위해 수정이 필요할 경우 유용합니다. ; ;
