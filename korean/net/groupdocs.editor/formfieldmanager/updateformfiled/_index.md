
| 매개변수 | 형식 | 설명 |

### 비고

`UpdateFormFiled` 메서드는 제공된 *formFieldCollection*을 기반으로 문서의 양식 필드를 업데이트합니다. 컬렉션의 각 양식 필드는 문서의 양식 필드와 대응되며, 컬렉션에 지정된 업데이트가 적절히 적용됩니다. 이 메서드는 사용자 인터페이스나 데이터베이스와 같은 외부 소스와 문서 간의 양식 필드 데이터를 동기화하는 데 유용합니다.
