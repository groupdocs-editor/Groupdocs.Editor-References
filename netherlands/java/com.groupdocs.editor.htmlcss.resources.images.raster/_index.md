De **com.groupdocs.editor.htmlcss.resources.images.raster** namespace biedt klassen die alleen rasterafbeeldingsresources vertegenwoordigen.



## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [BmpImage](../com.groupdocs.editor.htmlcss.resources.images.raster/bmpimage) | Stelt één afbeelding in BMP (BitMap Picture)-formaat voor met zijn metadata en extra methoden. |
| [GifImage](../com.groupdocs.editor.htmlcss.resources.images.raster/gifimage) | Stelt één afbeelding in GIF (Graphics Interchange Format)-formaat voor met zijn metadata en extra methoden. |
| [IconImage](../com.groupdocs.editor.htmlcss.resources.images.raster/iconimage) | Stelt één afbeelding in ICON-formaat voor met zijn metadata en extra methoden. |
| [JpegImage](../com.groupdocs.editor.htmlcss.resources.images.raster/jpegimage) | Stelt één afbeelding in JPEG (Joint Photographic Experts Group)-formaat voor met zijn metadata en extra methoden. |
| [PngImage](../com.groupdocs.editor.htmlcss.resources.images.raster/pngimage) | Stelt één afbeelding in PNG (Portable Network Graphics)-formaat voor met zijn metadata en extra methoden. |
| [RasterImageResourceBase](../com.groupdocs.editor.htmlcss.resources.images.raster/rasterimageresourcebase) | Basisklasse voor elke ondersteunde rasterafbeelding met vaste naam, afmetingen, beeldverhouding, type, grootte en inhoud. |
| [TiffImage](../com.groupdocs.editor.htmlcss.resources.images.raster/tiffimage) | Stelt één afbeelding in TIFF (Tagged Image File Format)-formaat voor met zijn metadata en extra methoden. |
