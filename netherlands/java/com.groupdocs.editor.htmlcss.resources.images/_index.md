De **com.groupdocs.editor.htmlcss.resources.images** namespace biedt klassen die afbeeldingsresources van alle soorten in het algemeen vertegenwoordigen.



## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Stelt de lineaire afmetingen (breedte en hoogte) van één raster rectangularimage in een willekeurige eenheid voor. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Stelt één ondersteund afbeeldings type (formaat) voor, ondersteunt zowel raster- als vectorformaten. |

## Interfaces

| Interface | Beschrijving |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Het Image CSS datatype stelt een tweedimensionale afbeelding voor. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Stelt een afbeeldingsbron van elk type voor, raster of vector. |
