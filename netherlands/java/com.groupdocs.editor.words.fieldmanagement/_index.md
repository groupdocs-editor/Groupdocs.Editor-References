De **com.groupdocs.editor.words.fieldmanagement** namespace bevat klassen en interfaces die verband houden met het beheer en de manipulatie van formuliervelden binnen documenten. Deze namespace biedt functionaliteit om met verschillende soorten formuliervelden te werken, zoals tekstvelden, selectievakjes, vervolgkeuzelijsten, enz., waardoor gebruikers programmeerbaar met formuliervelden kunnen communiceren en deze kunnen aanpassen.



## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [CheckBoxForm](../com.groupdocs.editor.words.fieldmanagement/checkboxform) | Stelt een formulierveld voor dat een selectievakje weergeeft. |
| [CurrentDateFormField](../com.groupdocs.editor.words.fieldmanagement/currentdateformfield) | Stelt een formulierveld voor dat de huidige datum weergeeft. |
| [CurrentTimeFormField](../com.groupdocs.editor.words.fieldmanagement/currenttimeformfield) | Stelt een formulierveld voor dat de huidige tijd weergeeft. |
| [DateFormField](../com.groupdocs.editor.words.fieldmanagement/dateformfield) | Stelt een formulierveld voor dat een datum weergeeft. |
| [DropDownFormField](../com.groupdocs.editor.words.fieldmanagement/dropdownformfield) | Stelt een formulierveld voor dat een vervolgkeuzelijst weergeeft. |
| [FormFieldCollection](../com.groupdocs.editor.words.fieldmanagement/formfieldcollection) | Stelt een verzameling formuliervelden voor. |
| [FormFieldType](../com.groupdocs.editor.words.fieldmanagement/formfieldtype) | Specificeert het type formulierveld. |
| [HelpText](../com.groupdocs.editor.words.fieldmanagement/helptext) | Stelt helptekst voor een formulierveld voor. |
| [InvalidFormField](../com.groupdocs.editor.words.fieldmanagement/invalidformfield) | Stelt de bijwerking van ongeldige formulierveldnamen voor tijdens de FormFieldManager.FixInvalidFormFieldNames operatie. |
| [NumberFormField](../com.groupdocs.editor.words.fieldmanagement/numberformfield) | Stelt een formulierveld voor dat een numerieke invoer accepteert. |
| [TextFormField](../com.groupdocs.editor.words.fieldmanagement/textformfield) | Stelt een formulierveld voor dat tekstinvoer accepteert. |
