Retourneert een hashcode voor het huidige object.

```csharp
public override int GetHashCode()
```

### Retourwaarde

Een hashcode voor het huidige object, geschikt voor gebruik in hash-algoritmen en datastructuren zoals een hashtabel.

### Opmerkingen

Deze methode overschrijft GetHashCode. De hashcode wordt berekend met behulp van de `Id`- en `Name`-eigenschappen van het object. De `unchecked`-context staat overflow toe, wat acceptabel is in een hashcode-berekeningscontext.
