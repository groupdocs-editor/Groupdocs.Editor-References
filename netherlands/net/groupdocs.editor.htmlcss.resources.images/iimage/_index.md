## IImage interface

Het CSS-gegevenstype Image stelt een tweedimensionale afbeelding voor.

```csharp
public interface IImage
```

### Opmerkingen

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS-referentie verklaart 4 soorten afbeeldingen die kunnen worden verwerkt: 1. Afbeeldingen met intrinsieke afmetingen (een natuurlijke grootte) en dus een vaste beeldverhouding, die alle rasterafbeeldingen omvatten. 2. Afbeeldingen met meerdere intrinsieke afmetingen, die in meerdere versies binnen één bestand bestaan, die ICON (*.ico)-bestanden omvatten. Dit kan ook TIFF zijn, omdat ze meerdere afbeeldingen binnen één bestand ondersteunen, echter wordt het TIFF-formaat niet ondersteund op het web. 3. Afbeeldingen zonder intrinsieke afmetingen maar met een intrinsieke beeldverhouding tussen breedte en hoogte. Dit omvat alle vectorafbeeldingen, SVG bovenal. 4. Afbeeldingen zonder zowel intrinsieke afmetingen als een intrinsieke beeldverhouding. Dit omvat alle verlopen.
