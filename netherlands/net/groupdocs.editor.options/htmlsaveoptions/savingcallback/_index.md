## HtmlSaveOptions.SavingCallback property

Interface, die moet worden geïmplementeerd door de eindgebruiker voor het opslaan van alle externe HTML-bronnen. Deze eigenschap **moet** niet `null` zijn, anders zal GroupDocs.Editor een uitzondering werpen tijdens het opslaan van [`EditableDocument`](../../../groupdocs.editor/editabledocument) naar HTML-indeling.

```csharp
public IHtmlSavingCallback SavingCallback { get; set; }
```

### Opmerkingen

Als de waarde van de eigenschap [`EmbedStylesheetsIntoMarkup`](../embedstylesheetsintomarkup) is ingesteld op `true`, worden alle stylesheets ingesloten in de HTML-markup en worden ze dus niet doorgegeven aan deze opslaan-callback.
