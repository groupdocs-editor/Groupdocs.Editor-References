## MarkdownSaveOptions.ExportImagesAsBase64 property

Geeft aan of afbeeldingen in Base64‑formaat naar het uitvoerbestand worden opgeslagen. Standaard is `false`.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### Opmerkingen

Wanneer deze eigenschap is ingesteld op `true`, worden afbeeldingsgegevens rechtstreeks geëxporteerd naar de afbeeldingselementen ![]() en worden er geen afzonderlijke bestanden aangemaakt. Deze eigenschap, indien ingesteld op `true`, heeft een hogere prioriteit dan de eigenschap [`ImagesFolder`](../imagesfolder).
