## MarkdownSaveOptions.OptimizeMemoryUsage property

Schakelt geheugenoptimalisatiemechanismen in tijdens het genereren van documenten vanuit HTML, wat de prestaties vermindert als prijs voor minder geheugengebruik. Als u deze optie instelt op `true`, kan het geheugengebruik aanzienlijk dalen bij het genereren van grote documenten, ten koste van een tragere opslagtijd. Standaard is `false` (geheugenoptimalisatie is uitgeschakeld voor betere prestaties).

public bool OptimizeMemoryUsage { get; set; }
