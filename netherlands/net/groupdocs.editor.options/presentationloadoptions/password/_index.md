## PresentationLoadOptions.Password property

Staat toe om het wachtwoord op te geven, te wijzigen en op te halen, dat wordt gebruikt voor het openen van het Presentatie‑document, indien het versleuteld is. Stel in op NULL of een lege tekenreeks om het wachtwoord te verwijderen.

```csharp
public string Password { get; set; }
```

### Opmerkingen

Standaard heeft deze eigenschap de waarde NULL — wachtwoord is niet ingesteld. Als het invoer‑Presentation‑document met een wachtwoord is beveiligd, is het wachtwoord verplicht en wordt er een uitzondering gegooid als het wachtwoord niet is opgegeven of ongeldig is. Als het invoer‑Presentation‑document NIET met een wachtwoord is beveiligd, maar er wel een wachtwoord is ingesteld, wordt het genegeerd.
