## SpreadsheetEditOptions.MergeEmptyAdjacentCells property

Wanneer ingeschakeld, worden de lege aangrenzende horizontale cellen uit het invoer‑Spreadsheet‑document in het bewerkbare HTML‑document weergegeven als samengevoegd tot één cel met het overeenkomstige `colspan`‑attribuut. Standaard is uitgeschakeld (`false`).

```csharp
public bool MergeEmptyAdjacentCells { get; set; }
```

### Opmerkingen

Standaard converteert de GroupDocs.Editor een tabel uit het invoer‑Spreadsheet‑document naar het uitvoer‑HTML‑document door elke cel te behouden. Spreadsheet‑documenten kunnen echter spaarzaam zijn — ze kunnen enorme hoeveelheden "lege gebieden" bevatten, waar veel cellen leeg zijn. Deze optie, wanneer ingeschakeld, voegt dergelijke lege cellen samen tot één cel met het `colspan`‑attribuut in het `TD`‑element, en kan zo de grootte van de geproduceerde HTML‑markup aanzienlijk verkleinen.
