## SpreadsheetEditOptions.WorksheetIndex property

Staat toe de 0-gebaseerde index van het werkblad (tabblad) van het invoer Spreadsheet‑document op te geven, dat naar HTML moet worden geconverteerd (zie opmerkingen).

```csharp
public int WorksheetIndex { get; set; }
```

### Opmerkingen

De meeste Spreadsheet‑documenten ondersteunen het concept van tabbladen, d.w.z. ze kunnen meerdere tabbladen hebben. Daarentegen ondersteunt het HTML‑formaat zo’n structuur niet. Hierdoor kan de GroupDocs.Editor bij het converteren naar HTML slechts één specifiek tabblad van het invoer‑document omzetten, en deze optie maakt het mogelijk om dat tabblad op te geven. De tabblad‑index is 0‑gebaseerd, negatieve waarden zijn verboden. Als de opgegeven index groter is dan het aantal tabbladen, wordt een uitzondering gegooid. Als het invoer‑Spreadsheet‑document slechts één tabblad bevat, wordt deze optie genegeerd. Standaardwaarde is 0 (eerste tabblad).
