## SpreadsheetSaveOptions.WorksheetNumbersToDelete property

Staat toe om een array met 1-gebaseerde nummers van werkbladen op te geven die tijdens het opslaan uit de spreadsheet moeten worden verwijderd, voor het geval het bewerkte werkblad wordt ingevoegd in een bestaande spreadsheet

```csharp
public int[] WorksheetNumbersToDelete { get; set; }
```

### Opmerkingen

Wanneer het bewerkte werkblad niet wordt opgeslagen als een nieuwe enkel-werkblad spreadsheet (standaardgedrag), maar in plaats daarvan wordt opgeslagen in een bestaande spreadsheet (met behulp van de [`WorksheetNumber`](../worksheetnumber) eigenschap), is het ook mogelijk om bepaalde werkbladen uit deze spreadsheet te verwijderen door hun nummers in deze array op te geven.

Standaard is deze array `null` — er worden geen werkbladen verwijderd. Wanneer deze array echter niet null en niet leeg is, en ten minste één geldig werkbladnummer bevat, worden de werkbladen met de opgegeven nummers verwijderd uit de spreadsheet vlak voordat de inhoud wordt weggeschreven naar de uitvoerstroom of het bestand, nadat het uitvoer‑spreadsheet‑document is gegenereerd met de inhoud van het bewerkte werkblad.

Werkbladnummers in deze array zijn 1‑gebaseerd, niet 0‑gebaseerd; ongeldige nummers (kleiner dan 1 of groter dan het totale aantal werkbladen) worden genegeerd.
