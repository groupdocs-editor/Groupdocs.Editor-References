## EditableDocument.FromMarkupAndResourceFolder method

Statische fabriek die een instantie van EditableDocument maakt vanuit opgegeven HTML‑markup en vanuit bronnen, gelegen in de map die is gespecificeerd door het volledige pad

```csharp
public static EditableDocument FromMarkupAndResourceFolder(string newHtmlContent, 
    string resourceFolderPath)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| newHtmlContent | String | String, die ruwe HTML-markup bevat die geparseerd moet worden. Mag niet NULL, leeg of ongeldig zijn. |
| resourceFolderPath | String | Verplichte pad naar de map met bronnen. Alle stylesheets die zich in deze map bevinden, worden gebruikt. Mag niet NULL of een lege tekenreeks zijn, en deze map moet bestaan. |

### Retourwaarde

Nieuwe niet-nul instantie van EditableDocument

### Opmerkingen

Deze statische fabriek is handig wanneer de inhoud van een HTML-document wordt gepresenteerd als een string, maar alle bronnen zich bevinden in een map, en vaak zijn de links naar deze bronnen in de HTML-markup ongeldig en afwezig. Bij het aanroepen van deze methode scant deze de opgegeven map en past automatisch alle gevonden stylesheets toe op het document. Deze methode is zeer nuttig bij het verkrijgen van inhoud uit verschillende HTML-editors, die meestal de documentmetadata wegsnijden, enzovoort.
