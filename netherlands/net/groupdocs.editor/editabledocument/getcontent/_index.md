## GetContent(string, string) {#getcontent_1}

Retourneert de volledige inhoud van het HTML‑document als een string, waarbij links naar de externe bronnen een opgegeven sjabloon met plaatsaanduidingen bevatten.

```csharp
public string GetContent(string externalImagesTemplate, string externalCssTemplate)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| externalImagesTemplate | String | Via deze parameter kan een string‑sjabloon met één plaatshouder worden opgegeven, dat zal worden toegepast op de links naar alle externe afbeeldingen in IMG‑elementen die in de resulterende HTML‑string aanwezig zullen zijn. Als NULL of leeg, wordt het sjabloon niet toegevoegd en zullen zuivere bestandsnamen in de resulterende HTML‑markup aanwezig zijn. Als het sjabloon ongeldig is, wordt het behandeld als een prefix, zodat bestandsnamen aan het einde ervan worden gekoppeld. |
| externalCssTemplate | String | Via deze parameter kan een string‑sjabloon met één placeholder worden opgegeven, dat aan de links naar alle externe stylesheets in LINK‑elementen wordt toegevoegd, die aanwezig zullen zijn in de resulterende HTML‑string. Als NULL of leeg, wordt het sjabloon niet toegevoegd en zullen alleen bestandsnamen aanwezig zijn in de resulterende HTML‑markup. Is het sjabloon ongeldig, dan wordt het behandeld als een prefix, zodat bestandsnamen aan het einde ervan worden gekoppeld. |

### Retourwaarde

String die de inhoud van het HTML-document met links bevat, aangepast aan de externe bronnen.
