## EditableDocument.GetEmbeddedHtml method

Retourneert alle inhoud van dit HTML‑document met alle gerelateerde bronnen in de vorm van één string, waarbij alle bronnen zijn ingebed in de HTML‑markup in base64‑gecodeerde vorm.

```csharp
public string GetEmbeddedHtml()
```

### Retourwaarde

String die in geen geval NULL of leeg is.

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| ObjectDisposedException | Deze EditableDocument-instantie is al vrijgegeven |

### Opmerkingen

Deze methode converteert deze EditableDocument naar HTML en serialiseert deze naar een enkele string, waarbij alle bronnen in de string zijn ingebed samen met de HTML-markup:

* All images from HTML-&gt;BODY are converted to base64 format and are located in the IMG 'src' attribute
* All stylesheets are stored in the STYLE elements inside HTML-&gt;HEAD sections
* All images from stylesheets are converted to base64 format and located in the appropriate CSS declarations
* All fonts from stylesheets are converted to base64 format and located in the appropriate @font-face at-rules
