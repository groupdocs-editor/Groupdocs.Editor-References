## Editor.GetDocumentInfo method

Retourneert metadata over het document dat in dit 'Editor'‑exemplaar is geladen.

```csharp
public IDocumentInfo GetDocumentInfo(string password)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| password | String | De gebruiker kan een wachtwoord opgeven voor een document, als dit document versleuteld is met een wachtwoord. Mag NULL of een lege string zijn, wat gelijk staat aan het ontbreken van een wachtwoord. Voor die documentformaten die geen wachtwoordbeveiligingsfunctie hebben, wordt dit argument genegeerd. Als het document versleuteld is en het wachtwoord niet is opgegeven in deze parameter "*password*", maar het eerder is opgegeven in de laadopties bij het maken van deze [`Editor`](../../editor)‑instantie, wordt het gebruikt. |

### Retourwaarde

Formaat‑specifieke afstammeling van de [`IDocumentInfo`](../../../groupdocs.editor.metadata/idocumentinfo)‑interface, die het gedetecteerde formaat aangeeft met formaat‑specifieke metadata, of NULL, als het document niet werd herkend als ondersteund of corrupt is.

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| ObjectDisposedException | Wordt gegooid wanneer de Editor‑instantie al is vrijgegeven op het moment dat "GetDocumentInfo" wordt aangeroepen. |
| [PasswordRequiredException](../../passwordrequiredexception) | Wordt gegooid wanneer het geladen document met een wachtwoord is beveiligd, maar het wachtwoord niet is opgegeven in de parameter "*password*" en in de laadopties tijdens het maken van de instantie. |
| [IncorrectPasswordException](../../incorrectpasswordexception) | Wordt gegooid wanneer het geladen document met een wachtwoord is beveiligd, het wachtwoord is opgegeven, maar onjuist is. |
| InvalidOperationException | Wordt gegooid wanneer een onverwachte fout van onbekende aard is opgetreden. |

### Opmerkingen

De GetDocumentInfo‑methode is nuttig wanneer onduidelijk is welk formaat het invoerdocument heeft, of het met een wachtwoord is beveiligd en/of hoeveel pagina's/werkbladen/diapresentaties het bevat. Op basis van deze metadata, geretourneerd door GetDocumentInfo, is het mogelijk om de laad‑ en bewerkingsopties voor de hoofd‑verwerkingspipeline correct aan te passen.

De GetDocumentInfo‑methode retourneert altijd volledige gegevens, wordt niet beïnvloed door de proefmodus, en het gebruik schrijft de verbruikte bytes of credits niet af.
