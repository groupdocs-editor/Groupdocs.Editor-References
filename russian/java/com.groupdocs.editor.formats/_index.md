Пространство имен **com.groupdocs.editor.formats** предоставляет интерфейсы и классы, описывающие поддерживаемые форматы документов.



## Классы

| Класс | Описание |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Инкапсулирует все форматы eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Инкапсулирует все форматы электронной почты. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Инкапсулирует все форматы фиксированного макета (также известный как "fixed-page"), которые включают PDF и XPS (это не включает растровые изображения) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Представляет различные семейства форматов, доступные в системе. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Инкапсулирует все форматы Presentation. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Инкапсулирует все бинарные, XML и текстовые форматы Spreadsheet (исключая все текстовые форматы, основанные на разделителях, такие как CSV, TSV, форматы с разделителем‑точка с запятой и т.д.), в которые можно сохранить книгу. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Инкапсулирует все текстовые (основанные на тексте) форматы, включая разметку (XML, HTML) и другие. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Инкапсулирует все форматы WordProcessing. |
