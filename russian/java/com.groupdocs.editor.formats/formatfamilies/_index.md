### FixedLayout {#FixedLayout}
```
public static final FormatFamilies FixedLayout
```


Представляет семейство форматов Fixed Layout.
Различные приложения для просмотра или публикации документов позволяют пользователям открывать (Adobe Acrobat, XPS Viewer), а иногда редактировать (Adobe InDesign) документы определённых форматов.
Эти приложения обычно создают так называемые «fixed-page» документы.
Такой формат документа точно описывает, где размещается содержимое документа на каждой странице.
Внутри форматы PDF или XPS содержат описание каждой страницы, а также инструкции по рисованию, указывающие расположение содержимого на странице.
Это аналогично форматам изображений, описывающим, где отображается содержимое в растровой или векторной форме.
