```
public static boolean tryFind(String keyword, ArgbColor[] output)
```


Пытается найти цвет по его строковому имени


**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
|  | ключевое слово | java.lang.String | Имя цвета |
|
|  | output | [ArgbColor\[\]](../../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Полученное значение цвета при успехе или значение #Transparent.Transparent при неудаче |
|

**Returns:**
boolean - true, если цвет был успешно найден по имени, иначе false
