## Классы

| Класс | Описание |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Представляет размер шрифта как специальную единицу или значение длины, которое определяет размер шрифта (исторически — ширина заглавной буквы "M"). |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Определяет, как шрифт должен быть оформлен: обычный, курсивный или наклонный стиль из его семейства шрифтов. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | Свойство font-weight задает толщину (или жирность) шрифта. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Представляет типы линии текстового декора: подчеркивание (underscore), надчеркивание и зачеркивание (strikethrough). |
