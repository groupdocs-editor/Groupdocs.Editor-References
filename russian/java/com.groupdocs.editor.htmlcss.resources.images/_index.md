Пространство имен **com.groupdocs.editor.htmlcss.resources.images** предоставляет классы, представляющие графические ресурсы всех типов в целом.



## Классы

| Класс | Описание |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Представляет линейные размеры (ширину и высоту) одного растрового прямоугольного изображения в произвольных единицах. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Представляет один поддерживаемый тип изображения (формат), поддерживает как растровые, так и векторные форматы. |

## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IImage](../com.groupdocs.editor.htmlcss.resources.images/iimage) | Тип данных Image CSS представляет двумерное изображение. |
| [IImageResource](../com.groupdocs.editor.htmlcss.resources.images/iimageresource) | Представляет ресурс изображения любого типа, растровый или векторный. |
