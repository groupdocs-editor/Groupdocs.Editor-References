Определяет, какие части почтового сообщения должны быть переданы в выходную обработку.

## Поля

| Поле | Описание |
| --- | --- |
|  | [None](#None) | Никакие части электронного сообщения не будут обрабатываться |
|
|  | [Body](#Body) | Обработать тело сообщения |
|
|  | [Subject](#Subject) | Обработать тему сообщения |
|
|  | [Date](#Date) | Обработать дату и время доставки сообщения |
|
|  | [To](#To) | Обработать всех получателей сообщения |
|
|  | [Cc](#Cc) | Обработать всех получателей в копии (CC) сообщения |
|
|  | [Bcc](#Bcc) | Обработать всех получателей в скрытой копии (BCC) сообщения |
|
|  | [From](#From) | Обработать отправителя сообщения |
|
|  | [Attachments](#Attachments) | Обработать все вложения сообщения |
|
|  | [Metadata](#Metadata) | Обработать все остальные технические метаданные (чувствительность, приоритет, кодировка, MIME, X-Mailer и т.д.) |
|
|  | [Common](#Common) | Общий вывод — тело с основной метаинформацией |
|
|  | [All](#All) | Полный вывод — тело со всеми метаданными |
|
