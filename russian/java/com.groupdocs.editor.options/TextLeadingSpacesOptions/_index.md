Содержит доступные параметры обработки начальных пробелов при открытии простого
текстовый документ (TXT)

## Поля

| Поле | Описание |
| --- | --- |
|  | [ConvertToIndent](#ConvertToIndent) | Преобразовать один или несколько последовательных пробелов в левый отступ. |
|
|  | [Preserve](#Preserve) | Pass all leading spaces to the output HTML "as is", without touching them |
|
|  | [Trim](#Trim) | Обрезать (усечь) все начальные пробелы полностью |
|
