Пространство имён GroupDocs.Editor.Formats предоставляет интерфейсы и классы, описывающие поддерживаемые форматы документов.

## Классы

| Класс | Описание |
| --- | --- |
| [EBookFormats](./ebookformats) | Инкапсулирует все форматы электронных книг. Включает следующие типы файлов: [`Mobi`](../groupdocs.editor.formats/ebookformats/mobi), [`Epub`](../groupdocs.editor.formats/ebookformats/epub), [`Azw3`](../groupdocs.editor.formats/ebookformats/azw3). |
| [EmailFormats](./emailformats) | Инкапсулирует все форматы электронной почты. Включает следующие типы файлов: [`Tnef`](../groupdocs.editor.formats/emailformats/tnef), [`Eml`](../groupdocs.editor.formats/emailformats/eml), [`Emlx`](../groupdocs.editor.formats/emailformats/emlx), [`Msg`](../groupdocs.editor.formats/emailformats/msg), [`Html`](../groupdocs.editor.formats/emailformats/html), [`Mhtml`](../groupdocs.editor.formats/emailformats/mhtml). |
| [FixedLayoutFormats](./fixedlayoutformats) | Представляет форматы документов с фиксированным макетом (фиксированная страница), такие как PDF, за исключением растровых форматов изображений. |
| [FormatFamilies](./formatfamilies) | Представляет различные семейства форматов, доступные в системе. |

Включает следующие форматы: [`Xls`](../groupdocs.editor.formats/spreadsheetformats/xls), [`Xlt`](../groupdocs.editor.formats/spreadsheetformats/xlt), [`Xlsx`](../groupdocs.editor.formats/spreadsheetformats/xlsx), [`Xlsm`](../groupdocs.editor.formats/spreadsheetformats/xlsm), [`Xlsb`](../groupdocs.editor.formats/spreadsheetformats/xlsb), [`Xltx`](../groupdocs.editor.formats/spreadsheetformats/xltx), [`Xltm`](../groupdocs.editor.formats/spreadsheetformats/xltm), [`Xlam`](../groupdocs.editor.formats/spreadsheetformats/xlam), [`SpreadsheetML`](../groupdocs.editor.formats/spreadsheetformats/spreadsheetml), [`Ods`](../groupdocs.editor.formats/spreadsheetformats/ods), [`Fods`](../groupdocs.editor.formats/spreadsheetformats/fods), [`Sxc`](../groupdocs.editor.formats/spreadsheetformats/sxc), [`Dif`](../groupdocs.editor.formats/spreadsheetformats/dif), [`Csv`](../groupdocs.editor.formats/spreadsheetformats/csv), [`Tsv`](../groupdocs.editor.formats/spreadsheetformats/tsv). Узнайте больше о форматах электронных таблиц [здесь](https://wiki.fileformat.com/spreadsheet). |
| [TextualFormats](./textualformats) | Инкапсулирует все текстовые (основанные на тексте) форматы, включая разметку (XML, HTML) и другие.
