Пространство имён GroupDocs.Editor.HtmlCss.Css.DataTypes предоставляет классы, представляющие типы данных CSS.

## Классы

| Класс | Описание |
| --- | --- |
| [ArgbColor.KnownColors](./argbcolor.knowncolors) | Содержит все "известные цвета", которые имеют фиксированное уникальное имя и значение в стандарте CSS |
## Structures

| Структура | Описание |
| --- | --- |
| [ArgbColor](./argbcolor) | Представляет одно значение цвета в 32-битном формате ARGB (8 бит на канал, включая прозрачность) с конвертерами и сериализаторами |
| [Length](./length) | Представляет значение длины CSS в любой поддерживаемой единице, включая проценты и тип без единицы. Значения могут быть целыми или с плавающей точкой, отрицательными, нулевыми и положительными. Неизменяемая структура. |
| [Ratio](./ratio) | Представляет тип данных CSS "ratio", который используется для описания соотношений сторон в медиа‑запросах и для растровых изображений, обозначая пропорцию между двумя безразмерными значениями, называемыми "numerator" и "denominator". Неизменяемая структура. |
