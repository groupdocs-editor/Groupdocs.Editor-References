## Length.Unit enumeration

Все поддерживаемые единицы длины

```csharp
public enum Unit
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Unitless | `0` | Без единицы измерения — не определена единица длины. Значение по умолчанию. |
| Px | `1` | Пиксель. Относительно просматривающего устройства. Для экранного отображения обычно один пиксель (точка) дисплея. |
| Em | `2` | Em. Эта единица представляет вычисленный размер шрифта элемента. |
| Ex | `3` | Ex (x‑длина). Эта единица представляет x‑высоту шрифта элемента. В шрифтах с буквой «x» это обычно высота строчных букв; 1ex ≈ 0,5em во многих шрифтах. |
| Cm | `4` | Cm. Один сантиметр (10 миллиметров). |
| Mm | `5` | Mm. Один миллиметр. |
| In | `6` | In. Один дюйм (2,54 сантиметра). |
| Pt | `7` | Pt. Один пункт равен 1/72 дюйма или 0,353 мм. |
| Pc | `8` | Pc. Одна пики (12 пунктов). |
| Ch | `9` | Ch. Эта единица представляет ширину, а точнее измерение продвижения, глифа '0' (ноль, символ Unicode U+0030) в шрифте элемента. |
| Rem | `10` | Rem. Эта единица представляет размер шрифта корневого элемента (например, размер шрифта элемента &lt;html&gt;). При использовании в свойстве font-size этого корневого элемента она представляет его начальное значение. |
| Vw | `11` | Vw - ширина области просмотра. 1/100 ширины области просмотра. |
| Vh | `12` | Vh - высота области просмотра. 1/100 высоты области просмотра. |
| Vmin | `13` | Vmin. 1/100 от минимального значения между высотой и шириной области просмотра. |
| Vmax | `14` | Vmax. 1/100 от максимального значения между высотой и шириной области просмотра. |
| Percent | `15` | Значение относительно фиксированного (внешнего) значения, зависящего от контекста. 1% = 1/100 внешнего значения. |
