## Length.GetUnitFromName method

Пытается разобрать указанное название единицы и вернуть соответствующее значение перечисления Unit. Возвращает Unit.Unitless, если не удаётся найти подходящую единицу.

```csharp
public static Unit GetUnitFromName(string unitName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| unitName | String | Строка, представляющая название единицы измерения |

### Возвращаемое значение

Значение перечисления Unit в любом случае, Unit.Unitless, если не удалось найти подходящую единицу
