Пространство имён GroupDocs.Editor.HtmlCss.Css.Properties предоставляет типы, представляющие различные свойства CSS (компоненты объявлений CSS).

## Structures

| Структура | Описание |
| --- | --- |
| [FontSize](./fontsize) | Представляет размер шрифта как специальную единицу или значение длины, которое определяет размер шрифта (исторически — ширина заглавной буквы \"M\"). |
| [FontStyle](./fontstyle) | Определяет, как шрифт должен быть оформлен: обычный, курсивный или наклонный начертание из его семейства шрифтов. |
| [FontWeight](./fontweight) | Свойство font-weight задаёт толщину (или жирность) шрифта. Доступные толщины зависят от текущего семейства шрифтов. |
| [TextDecorationLineType](./textdecorationlinetype) | Представляет типы линии текстового декора: подчеркивание (нижнее подчеркивание), надчеркивание и зачеркивание (перечёркивание) |
