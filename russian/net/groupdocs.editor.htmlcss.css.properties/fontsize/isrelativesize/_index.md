## FontSize.IsRelativeSize property

Указывает, определён ли этот размер шрифта относительным размером в виде ключевого слова. Шрифт будет больше или меньше относительно размера шрифта родительского элемента, примерно по соотношению, используемому для разделения абсолютных ключевых слов.

public bool IsRelativeSize { get; }
