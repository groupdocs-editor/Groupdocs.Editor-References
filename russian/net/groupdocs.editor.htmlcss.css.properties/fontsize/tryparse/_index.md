## FontSize.TryParse method

Пытается распознать указанное ключевое слово как корректное значение ключевого слова свойства 'font-size' и возвращает его при успехе или NULL при неудаче.

```csharp
public static bool TryParse(string keyword, out FontSize result)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| keyword | String | Ключевое слово для разбора |
| result | FontSize& | Результат, парсинга был успешным, или [`Medium`](../medium) в противном случае |

### Возвращаемое значение

true, если разбор был успешным, иначе false
