## FontStyle.Italic field

Выбирает шрифт, классифицированный как курсивный. Если курсивная версия шрифта недоступна, используется версия, классифицированная как наклонная. Если ни одна из них недоступна, стиль имитируется искусственно.

```csharp
public static readonly FontStyle Italic;
```
