## FontStyle.Oblique field

Выбирает шрифт, классифицированный как наклонный. Если наклонная версия шрифта недоступна, используется версия, классифицированная как курсивная. Если ни одна из них недоступна, стиль имитируется искусственно.

```csharp
public static readonly FontStyle Oblique;
```
