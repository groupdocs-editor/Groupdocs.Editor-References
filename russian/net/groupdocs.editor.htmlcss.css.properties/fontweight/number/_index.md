## FontWeight.Number property

Возвращает число — целое значение от 1 до 1000 включительно, описывающее жирность шрифта, или генерирует исключение, если текущая жирность не абсолютна, а относительна.

```csharp
public ushort Number { get; }
```

### Исключения

| исключение | условие |
| --- | --- |
| InvalidOperationException | Брасывается, если текущий font-weight содержит относительное значение толщины шрифта |
