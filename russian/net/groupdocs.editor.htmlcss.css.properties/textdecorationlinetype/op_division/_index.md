## TextDecorationLineType Division operator

Возвращает пересечение между первым и вторым типами линий, где включены только те флаги, которые одновременно включены в обоих операндах. Имеет наивысший приоритет среди всех операторов (выше, чем union и difference)

public static TextDecorationLineType operator /(TextDecorationLineType first,
