## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток действительным шрифтом EOT

```csharp
public static bool IsValid(Stream eotBinaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| eotBinaryContent | Stream | Поток байтов, который предположительно содержит ресурс EOT |

### Возвращаемое значение

True, если указанный поток содержит действительный шрифт EOT, иначе false
