## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток допустимым шрифтом OTF

```csharp
public static bool IsValid(Stream binaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| binaryContent | Stream | Поток байтов, который предположительно содержит ресурс OTF |

### Возвращаемое значение

True, если указанный поток содержит действительный шрифт OTF, иначе false
