## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток действительным шрифтом TTC

```csharp
public static bool IsValid(Stream binaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| binaryContent | Stream | Поток байтов, который предположительно содержит ресурс TTC |

### Возвращаемое значение

True, если указанный поток содержит действительный шрифт TTC, иначе false
