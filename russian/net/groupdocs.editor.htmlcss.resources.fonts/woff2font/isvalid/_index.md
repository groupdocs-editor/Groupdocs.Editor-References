## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток действительным шрифтом WOFF2

```csharp
public static bool IsValid(Stream binaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| binaryContent | Stream | Поток байтов, который, предположительно, содержит ресурс WOFF2 |

### Возвращаемое значение

True, если указанный поток содержит действительный шрифт WOFF2, иначе false
