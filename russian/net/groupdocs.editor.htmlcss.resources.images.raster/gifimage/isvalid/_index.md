## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток действительным изображением GIF

```csharp
public static bool IsValid(Stream binaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| binaryContent | Stream | Поток байтов, предположительно содержащий GIF‑изображение |
