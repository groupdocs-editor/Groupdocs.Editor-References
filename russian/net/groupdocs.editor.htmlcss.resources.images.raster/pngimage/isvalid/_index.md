## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток действительным изображением PNG

```csharp
public static bool IsValid(Stream binaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| binaryContent | Stream | Поток байтов, который, предположительно, содержит PNG‑изображение. |

### Возвращаемое значение

True, если указанный поток содержит корректное PNG‑изображение, иначе false.
