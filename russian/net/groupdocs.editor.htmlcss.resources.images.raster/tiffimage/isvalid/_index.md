## IsValid(Stream) {#isvalid}

Проверяет, является ли указанный поток действительным изображением TIFF

```csharp
public static bool IsValid(Stream binaryContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| binaryContent | Stream | Поток байтов, который, предположительно, содержит TIFF‑изображение. |

### Возвращаемое значение

True, если указанный поток содержит корректное TIFF‑изображение, иначе false.
