## MetaImageBase.SaveToSvg method

При реализации типа WMF или EMF следует сохранять текущий векторный мета‑изображение в векторный формат SVG в указанный поток байтов

```csharp
public abstract void SaveToSvg(Stream outputSvgContent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| outputSvgContent | Stream | Поток байтов, в который будет сохранена версия SVG этого векторного мета‑изображения. Не должен быть NULL и должен поддерживать запись. |
