## SvgImage.IsValid method

Выполняет поверхностную проверку, является ли указанное текстовое содержимое, соответствующее XML, представлением SVG‑изображения

```csharp
public static bool IsValid(string content)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| содержимое | String | XML‑содержимое изображения SVG в виде простого текста, а не закодированного base64 содержимого. |

### Возвращаемое значение

True, если указанную строку можно считать корректным SVG с первого взгляда, false, если это точно не SVG.
