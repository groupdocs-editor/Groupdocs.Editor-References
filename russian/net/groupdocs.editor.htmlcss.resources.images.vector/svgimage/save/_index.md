## SvgImage.Save method

Сохраняет это SVG‑изображение в файл

```csharp
public override void Save(string fullPathToFile)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| fullPathToFile | String | Полный путь к файлу, который будет создан (если он не существует) или перезаписан (если существует) содержимым этого SVG‑изображения |

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentException | Выбрасывается, когда указанный путь к файлу недействителен |
| ObjectDisposedException | Выбрасывается, когда этот экземпляр уже был освобождён |
