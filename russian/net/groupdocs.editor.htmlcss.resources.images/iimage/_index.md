## IImage interface

Тип данных CSS Image представляет двумерное изображение

```csharp
public interface IImage
```

### Замечания

https://developer.mozilla.org/en-US/docs/Web/CSS/image CSS reference объявляет 4 типа изображений, которые могут обрабатываться: 1. Изображения с внутренними размерами (естественный размер) и фиксированным соотношением сторон, включающие все растровые изображения. 2. Изображения с несколькими внутренними размерами, существующие в нескольких версиях внутри одного файла, включающие файлы ICON (*.ico). Это могут быть также TIFF, так как они поддерживают несколько изображений в одном файле, однако формат TIFF не поддерживается в вебе. 3. Изображения без внутренних размеров, но с внутренним соотношением сторон между шириной и высотой. Это включает все векторные изображения, прежде всего SVG. 4. Изображения без внутренних размеров и без внутреннего соотношения сторон. Это включает все градиенты.
