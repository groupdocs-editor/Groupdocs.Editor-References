## TextType.ParseFromFilenameWithExtension method

Возвращает значение TextType, которое эквивалентно расширению имени файла, полученному из указанного имени файла с расширением или из чистого расширения

```csharp
public static TextType ParseFromFilenameWithExtension(string filename)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| filename | String | Имя файла с расширением, может быть относительным или абсолютным путём, либо самим чистым расширением |

### Возвращаемое значение

Разобранный экземпляр TextType при успехе или TextType.Undefined при неудаче
