Пространство имён GroupDocs.Editor.Metadata предоставляет классы для описания основных свойств документа, зависящих от типа документа.

## Structures

| Структура | Описание |
| --- | --- |
| [EbookDocumentInfo](./ebookdocumentinfo) | Представляет метаданные одного e‑Book документа |
| [EmailDocumentInfo](./emaildocumentinfo) | Представляет метаданные одного email‑документа любого поддерживаемого формата электронной почты |
| [FixedLayoutDocumentInfo](./fixedlayoutdocumentinfo) | Представляет метаданные одного документа с фиксированным макетом, например PDF или XPS |
| [MarkdownDocumentInfo](./markdowndocumentinfo) | Представляет метаданные одного Markdown‑документа |
| [PresentationDocumentInfo](./presentationdocumentinfo) | Представляет метаданные одного документа презентации |
| [SpreadsheetDocumentInfo](./spreadsheetdocumentinfo) | Представляет метаданные одного документа электронной таблицы |
| [TextualDocumentInfo](./textualdocumentinfo) | Представляет метаданные одного текстового документа, например XML, HTML или обычного текста (TXT) |
| [WordProcessingDocumentInfo](./wordprocessingdocumentinfo) | Представляет метаданные одного документа обработки текста |
