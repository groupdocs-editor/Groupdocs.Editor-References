## IDocumentInfo.IsEncrypted property

Указывает, зашифрован ли конкретный файл и требует ли пароль для открытия. Для типов документов, которые нельзя зашифровать (например, все текстовые), всегда должно возвращаться 'false'.

```csharp
public bool IsEncrypted { get; }
```
