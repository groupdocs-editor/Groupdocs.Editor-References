## MarkdownDocumentInfo.PageCount property

Возвращает количество страниц. У Markdown‑документов обычно нет фиксированных страниц и, соответственно, количества страниц, поэтому это число рассчитывается исходя из стандартного размера страницы, установленного как A4 в портретной ориентации.

public int PageCount { get; }
