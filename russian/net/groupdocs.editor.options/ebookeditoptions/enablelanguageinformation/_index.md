## EbookEditOptions.EnableLanguageInformation property

Указывает, экспортируется ли информация о языке в разметку HTML в виде атрибутов 'lang'. Этот параметр может быть полезен для обратного преобразования многоязычных документов. По умолчанию отключён (`false`).

```csharp
public bool EnableLanguageInformation { get; set; }
```
