## FixedLayoutEditOptionsBase.EnablePagination property

Позволяет включить (true) или отключить (false) разбиение на страницы в результирующем HTML‑документе. По умолчанию отключено (false).

```csharp
public bool EnablePagination { get; set; }
```

### Замечания

Документы фиксированного макета (в частности PDF и XPS) по своей сути строго постраничны, их содержимое имеет фиксированный макет и разделено на страницы. Однако результирующий редактируемый HTML может быть представлен как безстраничный, так и постраничный вид.
