## MailMessageOutput enumeration

Определяет, какие части почтового сообщения должны быть переданы в выходную обработку

```csharp
[Flags]
public enum MailMessageOutput
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Ни одна часть электронного сообщения не будет обработана. |
| Body | `1` | Обрабатывать тело почтового сообщения. |
| Subject | `2` | Обрабатывать тему почтового сообщения. |
| Date | `4` | Обрабатывать дату и время доставки сообщения. |
| To | `8` | Обработать всех получателей почтового сообщения |
| Cc | `10` | Обработать всех получателей в копии (CC) почтового сообщения |
| Bcc | `20` | Обработать всех получателей в скрытой копии (BCC) почтового сообщения |
| From | `40` | Обработать отправителя почтового сообщения |
| Attachments | `80` | Обработать все вложения почтового сообщения |
| Metadata | `100` | Обработать все остальные технические метаданные (чувствительность, приоритет, кодировка, MIME, X-Mailer и т.д.) |
| Common | `7B` | Общий вывод — тело с основными метаданными |
| All | `1FF` | Полный вывод — тело со всеми метаданными |
