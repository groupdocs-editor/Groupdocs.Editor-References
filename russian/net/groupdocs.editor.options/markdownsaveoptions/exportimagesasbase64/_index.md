## MarkdownSaveOptions.ExportImagesAsBase64 property

Указывает, сохраняются ли изображения в формате Base64 в выходном файле. По умолчанию — `false`.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### Замечания

Когда это свойство установлено в `true`, данные изображений экспортируются непосредственно в элементы изображения ![]() и отдельные файлы не создаются. Это свойство, если установлено в `true`, имеет более высокий приоритет, чем свойство [`ImagesFolder`](../imagesfolder).
