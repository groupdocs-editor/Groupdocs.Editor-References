## MarkdownSaveOptions.ImagesFolder property

Указывает физическую папку, в которой сохраняются изображения при экспорте документа в формат Markdown. По умолчанию — null.

```csharp
public string ImagesFolder { get; set; }
```

### Замечания

Если пользователь не указывает ни `ImagesFolder`, ни [`ExportImagesAsBase64`](../exportimagesasbase64), то GroupDocs.Editor попытается определить `ImagesFolder` самостоятельно и применит его при успешном определении
