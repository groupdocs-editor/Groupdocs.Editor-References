## MarkdownTableContentAlignment enumeration

Позволяет задать выравнивание содержимого таблицы, используемое при экспорте в формат Markdown

```csharp
public enum MarkdownTableContentAlignment
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Выравнивание будет взято из первого абзаца в соответствующей колонке таблицы |
| Left | `1` | Содержимое таблиц будет выровнено по левому краю |
| Center | `2` | Содержимое таблиц будет выровнено по центру |
| Right | `3` | Содержимое таблиц будет выровнено по правому краю |
