## MhtmlSaveOptions.ExportLanguageInformation property

Указывает, экспортировать ли информацию о языке в MHTML. Значение по умолчанию — `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### Замечания

Когда это свойство установлено в `true`, GroupDocs.Editor добавляет атрибут `lang` в HTML‑элементы документа, указывающие язык. Это может потребоваться для сохранения семантики, связанной с языком.
