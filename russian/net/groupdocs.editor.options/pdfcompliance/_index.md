## PdfCompliance enumeration

Указывает уровень соответствия стандартам PDF

```csharp
public enum PdfCompliance
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Pdf17 | `0` | Стандарт PDF 1.7 (ISO 32000-1) |
| Pdf20 | `1` | Стандарт PDF 2.0 (ISO 32000-2) |
| PdfA1a | `2` | Стандарт PDF/A-1a. Этот уровень включает все требования PDF/A-1b и дополнительно требует включения структуры документа (известной как \"tagged\"), с целью обеспечения возможности поиска и повторного использования содержимого документа. |
| PdfA1b | `3` | PDF/A-1b (ISO 19005-1). Цель PDF/A-1b — обеспечить надёжное воспроизведение визуального вида документа. |
| PdfA2a | `4` | Стандарт PDF/A-2a (ISO 19005-2). Этот уровень включает все требования PDF/A-2u и дополнительно требует включения структуры документа (известной как \"tagged\"), с целью обеспечения возможности поиска и повторного использования содержимого документа. |
| PdfA2u | `5` | Стандарт PDF/A-2u (ISO 19005-2). Цель PDF/A-2u — сохранять статический визуальный вид документа во времени, независимо от используемых инструментов и систем создания, хранения или отображения файлов. Кроме того, любой текст в документе может быть надёжно извлечён как последовательность кодовых точек Unicode. |
| PdfUa1 | `6` | Стандарт PDF/UA-1 (ISO 14289-1). Основная цель PDF/UA — определить способ представления электронных документов в формате PDF таким образом, чтобы файл был доступным. |
