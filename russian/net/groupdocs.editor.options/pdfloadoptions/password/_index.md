## PdfLoadOptions.Password property

Позволяет указывать, изменять и получать пароль, который будет использоваться для открытия PDF‑документа, если он зашифрован. Установите NULL или пустую строку, чтобы не использовать пароль (значение по умолчанию).

public string Password { get; set; }
