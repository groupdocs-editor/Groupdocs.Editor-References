## PdfSaveOptions.OptimizeMemoryUsage property

Включает механизмы оптимизации памяти при генерации документа из HTML, что снижает производительность в качестве цены за уменьшение использования памяти. Установка этой опции в true может значительно снизить потребление памяти при генерации больших документов за счёт более медленного времени сохранения. По умолчанию false (оптимизация памяти отключена ради лучшей производительности).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
