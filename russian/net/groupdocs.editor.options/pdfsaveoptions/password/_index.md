## PdfSaveOptions.Password property

Пароль, который будет применён к созданному PDF‑документу как пользовательский пароль, требуемый для открытия. Если NULL или пустой, пароль к документу применён не будет. В противном случае документ будет зашифрован с помощью RC4 (длина ключа 128 бит). По умолчанию — NULL — пароль не применяется.

public string Password { get; set; }
