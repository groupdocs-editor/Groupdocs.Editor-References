## PresentationEditOptions.ShowHiddenSlides property

Указывает, следует ли включать скрытые слайды или нет. По умолчанию false — скрытые слайды не отображаются, и при попытке их редактировать будет выброшено исключение.

```csharp
public bool ShowHiddenSlides { get; set; }
```
