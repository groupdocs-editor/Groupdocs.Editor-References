## PresentationSaveOptions.OutputFormat property

Позволяет указать формат презентации, который будет использоваться для сохранения документа.

```csharp
public PresentationFormats OutputFormat { get; set; }
```

### Замечания

Формат вывода обычно задаётся в конструкторе этого класса, поскольку он обязателен. Это свойство позволяет получить или изменить формат вывода позже, когда экземпляр класса [`PresentationSaveOptions`](../../presentationsaveoptions) уже создан.
