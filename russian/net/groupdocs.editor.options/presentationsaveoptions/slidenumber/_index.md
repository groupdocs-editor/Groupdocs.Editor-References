## PresentationSaveOptions.SlideNumber property

Позволяет вставлять отредактированный слайд в существующую презентацию вместо создания новой одно‑слайдовой презентации (поведение по умолчанию). Номер слайда — это нумерация, начинающаяся с 1, слайда в презентации, загруженной в классе Editor. Если он равен 0 (значение по умолчанию), будет создана новая презентация с одним отредактированным слайдом. Если он больше или меньше нуля, и существует корректная презентация, загруженная в классе Editor, отредактированный слайд, хранящийся во входном экземпляре EditableDocument, будет вставлен в эту презентацию.

```csharp
public int SlideNumber { get; set; }
```

### Замечания

Свойство SlideNumber типа integer, если оно не находится в состоянии по умолчанию (зарезервированное значение '0'), представляет номер слайда, то есть начинается с 1, а не с нуля, а его максимальное значение — количество всех существующих слайдов в презентации. Однако если указанное значение превышает количество всех слайдов, GroupDocs.Editor скорректирует его, пометив последний слайд. Отрицательные значения также допускаются и считаются от конца. Например, \"-1\" означает последний слайд в презентации, \"-2\" — предпоследний и т.д. Как и в случае положительных значений, когда отрицательный номер слайда превышает общее количество слайдов в данной презентации, он будет скорректирован до первого слайда. Булево свойство [`InsertAsNewSlide`](../insertasnewslide) тесно связано с этим.

### Примеры

У данной презентации 5 слайдов: SlideNumber = 0; — игнорировать данную презентацию, создать новую презентацию и поместить в неё отредактированный слайд. SlideNumber = 1; — заменить первый слайд отредактированным. SlideNumber = 2; — заменить второй слайд отредактированным. SlideNumber = 5; — заменить последний (5‑й) слайд отредактированным. SlideNumber = 6; — заменить последний (5‑й) слайд отредактированным, потому что 6 больше чем 5, и поэтому значение будет скорректировано. SlideNumber = -1; — заменить последний (5‑й) слайд отредактированным, потому что \"-1\" означает \"последний существующий\". SlideNumber = -2; — заменить 4‑й слайд отредактированным. SlideNumber = -3; — заменить 3‑й слайд отредактированным. SlideNumber = -4; — заменить 2‑й слайд отредактированным. SlideNumber = -5; — заменить первый слайд отредактированным. SlideNumber = -6; — заменить первый слайд отредактированным, потому что \"-6\" больше чем 5, и поэтому значение будет скорректировано.
