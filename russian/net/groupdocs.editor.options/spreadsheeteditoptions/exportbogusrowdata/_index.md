## SpreadsheetEditOptions.ExportBogusRowData property

Если включено, HTML‑таблица в создаваемом HTML‑документе содержит пустую скрытую нижнюю строку нулевой высоты с пустыми ячейками, где указана только ширина. Эта строка с пустыми ячейками содержит точные значения ширины для каждого столбца и улучшает обратное преобразование из HTML в таблицу. По умолчанию включено (`true`).

```csharp
public bool ExportBogusRowData { get; set; }
```
