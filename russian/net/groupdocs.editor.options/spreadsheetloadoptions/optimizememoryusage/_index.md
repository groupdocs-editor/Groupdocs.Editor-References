## SpreadsheetLoadOptions.OptimizeMemoryUsage property

Включает механизмы оптимизации памяти во время обработки входного документа, что может ухудшить производительность в некоторых особых случаях, но, с другой стороны, уменьшить использование памяти. Полезно при обработке огромных документов и возникновении OutOfMemoryException. По умолчанию - false (оптимизация памяти отключена ради лучшей производительности).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
