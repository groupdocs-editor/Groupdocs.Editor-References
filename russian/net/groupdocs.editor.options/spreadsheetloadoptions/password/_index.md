## SpreadsheetLoadOptions.Password property

Позволяет указать, изменить и получить пароль, который будет использоваться для открытия документа Spreadsheet, если он зашифрован. Установите NULL или пустую строку, чтобы не использовать пароль (значение по умолчанию).

public string Password { get; set; }
