## SpreadsheetSaveOptions.Password property

Позволяет указать, изменить, получить или удалить пароль, который будет использоваться для шифрования сгенерированного документа Spreadsheet, если данный формат документа поддерживает защиту паролем. Укажите NULL или пустую строку для удаления (очистки) пароля.

```csharp
public string Password { get; set; }
```
