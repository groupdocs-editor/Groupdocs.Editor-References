## SpreadsheetSaveOptions.WorksheetNumber property

Позволяет вставить отредактированный рабочий лист в копию существующей таблицы вместо создания новой таблицы с одним листом (поведение по умолчанию). WorksheetNumber — это номер листа, начинающийся с 1, в таблице, загруженной в класс Editor. Если он равен 0 (значение по умолчанию), будет создана новая таблица с единственным отредактированным листом. Если он больше или меньше нуля, и существует действительная таблица, загруженная в класс Editor, отредактированный рабочий лист, представленный экземпляром EditableDocument, будет вставлен в эту таблицу.

```csharp
public int WorksheetNumber { get; set; }
```

### Замечания

Свойство WorksheetNumber типа integer, если оно не находится в состоянии по умолчанию (зарезервированное значение '0'), представляет номер листа, то есть нумерация начинается с 1, а не с нуля, а его максимальное значение равно количеству всех существующих слайдов в презентации. Однако, если указанное значение превышает количество всех слайдов, GroupDocs.Editor скорректирует его, чтобы указать последний лист. Отрицательные значения также допускаются и считаются от конца. Например, "-1" означает последний лист в таблице, "-2" — предпоследний и т.д. Как и в случае с положительными значениями, когда отрицательный номер листа превышает общее количество листов в данной таблице, он будет скорректирован до первого листа. Булево свойство [`InsertAsNewWorksheet`](../insertasnewworksheet) тесно связано с этим.

### Примеры

В заданной таблице 5 листов: WorksheetNumber = 0; — игнорировать заданную таблицу, создать новую таблицу и поместить в неё отредактированный лист. WorksheetNumber = 1; — заменить первый лист отредактированным. WorksheetNumber = 2; — заменить второй лист отредактированным. WorksheetNumber = 5; — заменить последний (5‑й) лист отредактированным. WorksheetNumber = 6; — заменить последний (5‑й) лист отредактированным, потому что 6 больше, чем 5, и поэтому корректируется. WorksheetNumber = -1; — заменить последний (5‑й) лист отредактированным, потому что «-1» означает «последний существующий». WorksheetNumber = -2; — заменить 4‑й лист отредактированным. WorksheetNumber = -3; — заменить 3‑й лист отредактированным. WorksheetNumber = -4; — заменить 2‑й лист отредактированным. WorksheetNumber = -5; — заменить первый лист отредактированным. WorksheetNumber = -6; — заменить первый лист отредактированным, потому что «-6» больше, чем 5, и поэтому корректируется.
