## SpreadsheetSaveOptions.WorksheetProtection property

Позволяет включить защиту листа для выходного документа Spreadsheet. По умолчанию NULL — защита не применяется. Не все форматы поддерживают защиту листа.

```csharp
public WorksheetProtection WorksheetProtection { get; set; }
```
