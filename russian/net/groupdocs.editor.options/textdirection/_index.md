## TextDirection enumeration

Представляет 3 возможных варианта обработки направления текста в простых текстовых документах

```csharp
public enum TextDirection
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| LeftToRight | `0` | Направление слева направо, обычный текст, значение по умолчанию. |
| RightToLeft | `1` | Направление справа налево |
| Auto | `2` | Автоматическое определение направления. Когда эта опция выбрана и текст содержит символы, принадлежащие RTL‑скриптам, направление документа будет автоматически установлено в RTL. |
