## TextLeadingSpacesOptions enumeration

Содержит доступные параметры обработки начальных пробелов при открытии простого текстового документа (TXT)

```csharp
public enum TextLeadingSpacesOptions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ConvertToIndent | `0` | Преобразовать один или несколько последовательных пробелов в левый отступ. Значение по умолчанию. |
| Preserve | `1` | Передать все начальные пробелы в вывод HTML "as is", не изменяя их |
| Trim | `2` | Полностью обрезать (усечь) все начальные пробелы |
