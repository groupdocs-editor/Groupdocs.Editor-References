## TextSaveOptions.AddBidiMarks property

Указывает, следует ли добавлять двунаправленные метки перед каждым BiDi‑блоком при экспорте в формат простого текста. По умолчанию 'false' — не добавлять BiDi‑метки.

```csharp
public bool AddBidiMarks { get; set; }
```
