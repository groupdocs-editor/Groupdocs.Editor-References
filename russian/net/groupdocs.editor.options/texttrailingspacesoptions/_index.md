## TextTrailingSpacesOptions enumeration

Содержит доступные параметры обработки конечных пробелов при открытии простого текстового документа (TXT)

```csharp
public enum TextTrailingSpacesOptions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Trim | `0` | Обрезать (усечь) все конечные пробелы полностью. Значение по умолчанию. |
| Preserve | `1` | Передать все конечные пробелы в выходной HTML \"как есть\", не изменяя их |
