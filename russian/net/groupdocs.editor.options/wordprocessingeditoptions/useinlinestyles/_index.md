## WordProcessingEditOptions.UseInlineStyles property

Определяет, где хранить данные стилей и форматирования входного документа WordProcessing: во внешней таблице стилей (`false`) или как встроенные стили в разметке HTML (`true`). По умолчанию используются внешние стили (`false`).

```csharp
public bool UseInlineStyles { get; set; }
```
