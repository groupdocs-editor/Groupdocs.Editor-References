## WordProcessingProtectionType enumeration

Представляет все доступные типы защиты документа WordProcessing

```csharp
public enum WordProcessingProtectionType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| NoProtection | `0` | Документ не защищён. Значение по умолчанию. |
| AllowOnlyRevisions | `1` | Пользователь может только добавлять метки правок в документ. |
| AllowOnlyComments | `2` | Пользователь может только изменять комментарии в документе. |
| AllowOnlyFormFields | `3` | Пользователь может только вводить данные в поля формы в документе. |
| ReadOnly | `4` | Изменения в документе не допускаются. |
