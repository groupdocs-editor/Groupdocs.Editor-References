## XmlEditOptions.FixIncorrectStructure property

Позволяет включать или отключать механизм исправления повреждённой структуры XML. По умолчанию отключено (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Замечания

По умолчанию допускаются только корректные, валидные, хорошо сформированные XML‑документы. Когда эта опция включена, GroupDocs.Editor попытается исправить повреждённую структуру XML, если это возможно.
