## XmlEditOptions.HighlightOptions property

Позволяет настроить подсветку XML, которая будет применена к структуре XML при её представлении в HTML. По умолчанию используется подсветка, которую можно изменить. Не может быть null.

public XmlHighlightOptions HighlightOptions { get; }
