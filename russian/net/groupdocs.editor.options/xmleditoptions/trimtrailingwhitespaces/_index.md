## XmlEditOptions.TrimTrailingWhitespaces property

Позволяет включить усечение конечных пробелов во внутреннем тексте тега. По умолчанию отключено (false) — конечные пробелы будут сохранены.

```csharp
public bool TrimTrailingWhitespaces { get; set; }
```
