## XmlFormatOptions.EachAttributeFromNewline property

Если включено, каждая пара атрибут‑значение в каждом XML‑элементе будет размещена на новой строке. По умолчанию значение false (отключено) — все пары атрибут‑значение размещаются в одной строке.

```csharp
public bool EachAttributeFromNewline { get; set; }
```
