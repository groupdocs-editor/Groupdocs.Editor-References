## XmlFormatOptions.LeftIndent property

Позволяет задать смещение левого отступа для каждой новой строки. Не может быть безразмерным ненулевым значением. По умолчанию — 10 pt.

```csharp
public Length LeftIndent { get; set; }
```

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentOutOfRangeException | Указанное значение длины безразмерно и не нулевое. |
