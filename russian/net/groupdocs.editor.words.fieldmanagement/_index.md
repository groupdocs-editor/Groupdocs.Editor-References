Содержит классы и интерфейсы, связанные с управлением и манипуляцией полями форм в документах. Это пространство имён предоставляет функциональность для работы с различными типами полей форм, такими как текстовые поля, флажки, выпадающие списки и т.д., позволяя пользователям взаимодействовать с полями форм и изменять их программно.

| Класс | Описание |
| --- | --- |
| [CheckBoxForm](./checkboxform) | Представляет поле формы, отображающее флажок. |
| [CurrentDateFormField](./currentdateformfield) | Представляет поле формы, отображающее текущую дату. |
| [CurrentTimeFormField](./currenttimeformfield) | Представляет поле формы, отображающее текущее время. |
| [DateFormField](./dateformfield) | Представляет поле формы, отображающее дату. |
| [DropDownFormField](./dropdownformfield) | Представляет поле формы, отображающее выпадающий список. |
| [FormFieldCollection](./formfieldcollection) | Представляет коллекцию полей формы. |
| [HelpText](./helptext) | Представляет справочный текст для поля формы. |
| [InvalidFormField](./invalidformfield) | Представляет обновление недействительных имён полей формы во время операции [`FixInvalidFormFieldNames`](../groupdocs.editor/formfieldmanager/fixinvalidformfieldnames). |
| [NumberFormField](./numberformfield) | Представляет поле формы, принимающее числовой ввод. |
| [TextFormField](./textformfield) | Представляет поле формы, принимающее текстовый ввод. |
