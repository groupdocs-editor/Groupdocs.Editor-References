## CurrentTimeFormField.StatusText property

Получает или задает текст статуса, связанный с полем формы, источник текста, отображаемого в строке состояния, когда поле формы имеет фокус.

```csharp
public HelpText StatusText { get; set; }
```

### Замечания

Если установлено `false`, текст статуса не будет применён.
