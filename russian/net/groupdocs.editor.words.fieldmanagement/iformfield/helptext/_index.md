## IFormField.HelpText property

Получает или задает вспомогательный текст, связанный с полем формы, источник текста, отображаемого в диалоговом окне, когда поле формы имеет фокус и пользователь нажимает F1.

```csharp
public HelpText HelpText { get; set; }
```

### Замечания

Если установлено `false`, справочный текст не будет применён.
