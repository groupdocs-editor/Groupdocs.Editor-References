Пространство имён GroupDocs.Editor предоставляет классы для редактирования документов с использованием сторонних фронтенд‑редакторов WYSIWYG без каких‑либо дополнительных приложений.

## Классы

| Класс | Описание |
| --- | --- |
| [EditableDocument](./editabledocument) | Промежуточный документ, содержащий содержимое до и после редактирования |
| [Editor](./editor) | Основной класс, который инкапсулирует методы конвертации. Класс Editor предоставляет методы загрузки, редактирования и сохранения документов всех поддерживаемых форматов. Он реализует интерфейс IDisposable, поэтому используйте директиву `using` или освобождайте его ресурсы вручную вызовом метода `Dispose()`. Загрузка документа выполняется через конструкторы. Редактирование документа — через метод `Edit`, а сохранение полученного документа после редактирования — через метод `Save`. |
| [EncryptedException](./encryptedexception) | Исключение, которое выбрасывается, когда пользователь пытается открыть документ, зашифрованный с использованием X509Certificates. |
| [FormFieldManager](./formfieldmanager) | Управляйте формой с устаревшими полями формы. Устаревшие поля формы — это типы полей, которые были доступны в более ранних версиях обработки Word. Группа Legacy Forms (видна после щелчка по значку Legacy Tools) включает три типа полей формы, которые можно вставить в документ: текст, флажок, раскрывающийся список, дата и т.д., см. подробнее [`FormFieldType`](../groupdocs.editor.words.fieldmanagement/formfieldtype). Каждое из этих полей формы позволяет пользователю формы выбирать или вводить информацию того типа, который вы считаете подходящим. |
| [IncorrectPasswordException](./incorrectpasswordexception) | Исключение, которое выбрасывается, когда указанный пароль неверен. |
| [InvalidFormatException](./invalidformatexception) | Исключение, которое выбрасывается, когда пользователь пытается открыть документ с параметрами, специфичными для формата, которые несовместимы с оригинальным форматом документа. |
| [License](./license) | Предоставляет методы лицензирования компонента. Узнайте больше о лицензировании [здесь](https://purchase.groupdocs.com/faqs/licensing). |
| [Metered](./metered) | Предоставляет методы применения [Metered](https://purchase.groupdocs.com/faqs/licensing/metered) лицензии. |
| [PasswordRequiredException](./passwordrequiredexception) | Исключение, которое выбрасывается, когда пользователь пытается открыть защищённый паролем зашифрованный документ какого-либо формата и не предоставляет пароль для его открытия. |
