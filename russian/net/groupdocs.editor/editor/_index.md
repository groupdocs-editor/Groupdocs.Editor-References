## Editor class

Основной класс, который инкапсулирует методы конвертации. Класс Editor предоставляет методы загрузки, редактирования и сохранения документов всех поддерживаемых форматов. Он реализует интерфейс IDisposable, поэтому используйте директиву `using` или освобождайте его ресурсы вручную вызовом метода `Dispose()`. Загрузка документа выполняется через конструкторы. Редактирование документа — через метод `Edit`, а сохранение полученного документа после редактирования — через метод `Save`.

```csharp
public sealed class Editor : IAuxDisposable
```

### Замечания

Класс Editor следует рассматривать как точку входа и корневой объект GroupDocs.Editor. Все операции выполняются с использованием этого класса. Типичное использование класса Editor для выполнения полного конвейера редактирования документа выглядит следующим образом:

1. Загрузите документ в экземпляр Editor через его конструктор.
2. При необходимости определите тип документа с помощью метода [`GetDocumentInfo`](./getdocumentinfo).
3. Откройте документ для редактирования, вызвав метод [`Edit`](./edit) и получив из него экземпляр класса [`EditableDocument`](../editabledocument).
4. Отредактируйте содержимое документа на клиентской стороне, используя любой WYSIWYG HTML‑редактор.
5. Создайте новый экземпляр [`EditableDocument`](../editabledocument) из отредактированного содержимого документа.
6. Сохраните отредактированный документ в нужный выходной формат, вызвав метод [`Save`](./save).
7. Удаление экземпляра класса Editor с помощью оператора 'using' или вручную.
