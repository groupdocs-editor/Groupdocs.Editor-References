## Editor.Dispose method

Освобождает этот экземпляр Editor, освобождая все внутренние ресурсы и делая его недоступным для дальнейшего использования.

```csharp
public void Dispose()
```

### Замечания

После вызова этого метода вызов любых других методов этого экземпляра вызовет ObjectDisposedException. Безопасно вызывать этот метод многократно — все последующие вызовы игнорируются.
