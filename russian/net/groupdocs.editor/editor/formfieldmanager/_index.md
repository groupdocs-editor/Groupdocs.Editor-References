## Editor.FormFieldManager property

Предоставляет доступ к функционалу управления полями формы в документе.

```csharp
public FormFieldManager FormFieldManager { get; }
```

### Возвращаемое значение

Экземпляр `FormFieldManager` для управления полями формы в документе.

### Замечания

Свойство `FormFieldManager` создает новый экземпляр класса `FormFieldManager`, который предоставляет доступ к методам и свойствам для управления полями формы в документе. Поля формы — это интерактивные элементы документа, способные принимать ввод пользователя или инициировать действия. Экземпляр `FormFieldManager` предоставляет методы для различных операций с полями формы, включая проверку недействительных полей формы, обновление данных полей формы и исправление проблем с именованием. Он также облегчает получение имен полей формы и связанных с ними данных. Это свойство полезно для программного взаимодействия и манипулирования полями формы, позволяя выполнять такие задачи, как проверка валидности полей формы, синхронизация и настройка.
