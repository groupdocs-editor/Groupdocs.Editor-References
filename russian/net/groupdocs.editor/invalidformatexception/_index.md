## InvalidFormatException class

Исключение, которое выбрасывается, когда пользователь пытается открыть документ с параметрами, специфичными для формата, которые несовместимы с оригинальным форматом документа.

```csharp
public sealed class InvalidFormatException : Exception
```

### Замечания

Например, это исключение будет выброшено, если попытаться открыть документ электронной таблицы с параметрами документа обработки текста.
