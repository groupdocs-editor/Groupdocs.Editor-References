Пространство имен **com.groupdocs.editor.htmlcss.css.datatypes** предоставляет классы, представляющие типы данных CSS.



## Классы

| Класс | Описание |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Представляет одно значение цвета в формате ARGB с конвертерами и сериализаторами |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Содержит все «известные цвета», имеющие фиксированное уникальное имя и значение в стандарте CSS |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Представляет значение длины CSS в любой поддерживаемой единице, включая процентные и безразмерные типы. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Все поддерживаемые единицы длины |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Представляет тип данных CSS "ratio", который используется для описания соотношений сторон в медиазапросах и для растровых изображений, обозначая пропорцию между двумя безразмерными значениями, называемыми "numerator" и "denominator". |
