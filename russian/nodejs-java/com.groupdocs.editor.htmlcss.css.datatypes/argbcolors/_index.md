### tryFind(String keyword, ArgbColor[] output) {#tryFind-java.lang.String-com.groupdocs.editor.htmlcss.css.datatypes.ArgbColor---}
```
public static boolean tryFind(String keyword, ArgbColor[] output)
```


Пытается найти цвет по его строковому названию


**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
|  | keyword | java.lang.String | Название цвета |
|
|  | output | [ArgbColor\[\]](../../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Полученное значение цвета при успехе или значение #Transparent.Transparent при неудаче |
|

**Returns:**
boolean — True, если цвет был успешно найден по его имени, иначе false
