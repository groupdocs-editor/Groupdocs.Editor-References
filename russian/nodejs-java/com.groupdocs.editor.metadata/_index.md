Пространство имен **com.groupdocs.editor.metadata** предоставляет классы для описания основных свойств документа, зависящих от типа документа.



## Классы

| Класс | Описание |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Представляет метаданные одного документа EBook |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Представляет метаданные одного почтового документа любого поддерживаемого формата электронной почты |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Представляет метаданные одного документа с фиксированным макетом, например PDF или XPS |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Представляет метаданные одного документа Markdown |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Представляет метаданные одного документа презентации |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Представляет метаданные одного документа электронной таблицы |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Представляет метаданные одного текстового документа, такого как XML, HTML или простой текст (TXT) |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Представляет метаданные одного документа обработки текста |
