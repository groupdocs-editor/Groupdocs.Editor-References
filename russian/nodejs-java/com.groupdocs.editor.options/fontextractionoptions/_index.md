### NotExtract {#NotExtract}
```
public static final int NotExtract
```


Не извлекает ни один ресурс шрифта ни из документа, ни из
система. Значение по умолчанию.


### ExtractAllEmbedded {#ExtractAllEmbedded}
```
public static final int ExtractAllEmbedded
```


Извлекает все ресурсы шрифтов, которые встроены во входной документ Word
документ, независимо от того, что это: пользовательский или системный.


*** ** * ** ***

Конвертер находит и извлекает все 100% ресурсы шрифтов, которые встроены во входной документ WordProcessing, но не определяет, являются ли они системными или пользовательскими; он вовсе не взаимодействует с реестром Windows или системными папками.

<br />



### ExtractEmbeddedWithoutSystem {#ExtractEmbeddedWithoutSystem}
```
public static final int ExtractEmbeddedWithoutSystem
```


Извлекает только те встроенные ресурсы шрифтов, которые являются пользовательскими (не
системными)


*** ** * ** ***

Конвертер находит и извлекает все встроенные ресурсы шрифтов, а затем пытается определить, какие из этих шрифтов являются системными, а какие — нет. Для этого конвертер пытается получить список всех системных шрифтов, используя реестр Windows и системные папки, а затем сравнивает этот список с набором встроенных шрифтов. В результате будет возвращён только подмножество тех встроенных шрифтов, которые не найдены в системе.

<br />



### ExtractAll {#ExtractAll}
```
public static final int ExtractAll
```


Пытается извлечь все шрифты, которые используются во входном документе WordProcessing
документе, включая системные шрифты.


*** ** * ** ***

Конвертер анализирует входной документ WordProcessing и находит все используемые в нём шрифты. Если все эти шрифты встроены во входной документ, конвертер извлекает их и возвращает. В противном случае, если набор встроенных шрифтов не покрывает все используемые шрифты в документе или пуст, конвертер пытается извлечь эти ресурсы шрифтов из системы, используя реестр Windows и системные папки.

<br />
