java.lang.Object
```
public final class MailMessageOutput
```

Управляет тем, какие части почтового сообщения должны быть переданы в выходную обработку.

## Поля

| Поле | Описание |
| --- | --- |
|  | [None](#None) | Никакие части электронного сообщения не будут обрабатываться |
|
|  | [Body](#Body) | Обрабатывать тело сообщения |
|
|  | [Subject](#Subject) | Обрабатывать тему сообщения |
|
|  | [Date](#Date) | Обрабатывать дату и время доставки сообщения |
|
|  | [To](#To) | Обрабатывать всех получателей сообщения |
|
|  | [Cc](#Cc) | Обрабатывать всех получателей в копии (CC) сообщения |
|
|  | [Bcc](#Bcc) | Обрабатывать всех получателей в скрытой копии (BCC) сообщения |
|
|  | [From](#From) | Обрабатывать отправителя сообщения |
|
|  | [Attachments](#Attachments) | Обрабатывать все вложения сообщения |
|
|  | [Metadata](#Metadata) | Обрабатывать все остальные технические метаданные (чувствительность, приоритет, кодировка, MIME, X-Mailer и т.д.) |
|
|  | [Common](#Common) | Общий вывод — тело со всеми основными метаданными |
|
|  | [All](#All) | Полный вывод — тело со всеми метаданными |
|
