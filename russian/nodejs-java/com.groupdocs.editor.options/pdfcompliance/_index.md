### PdfA1a {#PdfA1a}
```
public static final int PdfA1a
```


Стандарт PDF/A-1a. Этот уровень включает все требования PDF/A-1b и дополнительно требует включения структуры документа
(также известный как «тегированный»), с целью обеспечения возможности поиска и повторного использования содержимого документа.

<br />

*** ** * ** ***

Обратите внимание, что экспорт структуры документа значительно увеличивает потребление памяти, особенно для больших документов.

<br />

public static final int PdfA1b

PDF/A-1b (ISO 19005-1). Цель PDF/A-1b — обеспечить надёжное воспроизведение визуального вида документа.


### PdfA2a {#PdfA2a}
```
public static final int PdfA2a
```


Стандарт PDF/A-2a (ISO 19005-2). Этот уровень включает все требования PDF/A-2u и дополнительно требует включения структуры документа (также известной как «тегированный»), с целью обеспечения возможности поиска и повторного использования содержимого документа.

<br />

*** ** * ** ***

Обратите внимание, что экспорт структуры документа значительно увеличивает потребление памяти, особенно для больших документов.

<br />



### PdfA2u {#PdfA2u}
```
public static final int PdfA2u
```


Стандарт PDF/A-2u (ISO 19005-2). Цель PDF/A-2u — сохранять статический визуальный вид документа во времени, независимо от инструментов и систем, используемых для создания, хранения или отображения файлов. Кроме того, любой текст в документе может быть надёжно извлечён в виде последовательности кодовых точек Unicode.


### PdfUa1 {#PdfUa1}
```
public static final int PdfUa1
```


Стандарт PDF/UA-1 (ISO 14289-1). Основная цель PDF/UA — определить способ представления электронных документов в формате PDF таким образом, чтобы файл был доступным.
