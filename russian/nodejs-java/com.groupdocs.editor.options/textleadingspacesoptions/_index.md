Содержит доступные параметры обработки начальных пробелов при открытии обычного
текстовый документ (TXT)

## Поля

| Поле | Описание |
| --- | --- |
|  | [ConvertToIndent](#ConvertToIndent) | Преобразовать один или несколько последовательных пробелов в левый отступ. |
|
|  | [Preserve](#Preserve) | Передать все начальные пробелы в вывод HTML "as is", не изменяя их |
|
|  | [Trim](#Trim) | Обрезать (усечь) все начальные пробелы полностью |
|
