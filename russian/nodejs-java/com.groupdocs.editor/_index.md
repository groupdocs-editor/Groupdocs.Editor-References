Пространство имен **com.groupdocs.editor** является корневым пространством имен, которое предоставляет классы для редактирования множества форматов документов в ваших Java‑приложениях.



## Классы

| Класс | Описание |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Промежуточный документ, содержащий содержимое до и после редактирования |
| [Editor](../com.groupdocs.editor/editor) | Основной класс, инкапсулирующий методы конвертации. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | Исключение, которое выбрасывается, когда пользователь пытается открыть документ, зашифрованный с использованием X509Certificates. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | Исключение, которое выбрасывается, когда указан пароль неверен. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | Исключение, которое выбрасывается, когда пользователь пытается открыть документ с параметрами, специфичными для формата, несовместимыми с оригинальным форматом документа. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | Исключение, которое выбрасывается, когда пользователь пытается открыть защищённый паролем зашифрованный документ какого-либо формата и не предоставляет пароль для открытия этого документа. |
