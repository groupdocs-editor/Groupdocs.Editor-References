## License class

Управляет лицензированием GroupDocs.Editor.

Лицензированные сборки открывают полный набор функций оболочки по адресу
время выполнения. Нелицензированные сборки работают в режиме оценки с тем же API
поверхность, но с ограничениями на размер вывода и содержимое с водяным знаком.
