## Metered class

Управляет измеряемым (по‑использованию) лицензированием.

Лицензии Metered выставляются по фактическому потреблению (обычно страниц или
обработанных документов). Установите пару открытого/закрытого ключа один раз при
запуске приложения; обертка отправляет данные об использовании обратно в GroupDocs
лицензионный сервер в фоновом режиме.

Тип Metered раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [get_consumption_credit](/editor/python-net/groupdocs.editor/metered/get_consumption_credit/) | Возвращает оставшийся кредит Metered для текущего ключа. |
| [get_consumption_quantity](/editor/python-net/groupdocs.editor/metered/get_consumption_quantity/) | Возвращает общее количество потреблённого Metered до текущего момента. |
| [set_metered_key](/editor/python-net/groupdocs.editor/metered/set_metered_key/#public_key-private_key) | Активировать оплату по Metered с указанной парой открытого/закрытого ключа. |
