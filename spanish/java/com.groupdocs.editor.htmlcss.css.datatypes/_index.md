El **com.groupdocs.editor.htmlcss.css.datatypes** namespace proporciona clases que representan tipos de datos CSS.



## Clases

| Clase | Descripción |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Representa un valor de color en formato ARGB con convertidores y serializadores |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Contiene todos los "colores conocidos", que tienen un nombre y valor único fijo en el estándar CSS |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Representa un valor de longitud CSS en cualquier unidad soportada, incluyendo tipo porcentaje y sin unidad. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Todas las unidades de longitud soportadas |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Representa un tipo de dato CSS "ratio", que se utiliza para describir relaciones de aspecto en consultas de medios y para imágenes rasterizadas al denotar la proporción entre dos valores sin unidad llamados "numerador" y "denominador". |
