Contiene opciones disponibles para el manejo de espacios iniciales al abrir texto plano
documento de texto (TXT)

## Campos

| Campo | Descripción |
| --- | --- |
|  | [ConvertToIndent](#ConvertToIndent) | Convertir uno o más espacios consecutivos en sangría izquierda. |
|
|  | [Preserve](#Preserve) | Pasar todos los espacios iniciales al HTML de salida "as is", sin modificarlos |
|
|  | [Trim](#Trim) | Recortar (truncar) todos los espacios iniciales por completo |
|
### ConvertToIndent {#ConvertToIndent}
```
public static final int ConvertToIndent
```


Convertir uno o más espacios consecutivos en sangría izquierda. Valor predeterminado.


### Preserve {#Preserve}
```
public static final int Preserve
```


Pasar todos los espacios iniciales al HTML de salida "as is", sin modificarlos


### Trim {#Trim}
```
public static final int Trim
```


Recortar (truncar) todos los espacios iniciales por completo
