Representa tipos de protección de Spreadsheet worksheet (tab)

## Campos

| Campo | Descripción |
| --- | --- |
|  | [None](#None) | La protección no se aplica (valor predeterminado) |
|
|  | [All](#All) | El usuario no puede modificar nada en la hoja de cálculo |
|
|  | [Contents](#Contents) | El usuario no puede ingresar datos en la hoja de cálculo |
|
|  | [Objects](#Objects) | El usuario no puede modificar objetos de dibujo |
|
|  | [Scenarios](#Scenarios) | El usuario no puede modificar escenarios guardados |
|
|  | [Structure](#Structure) | El usuario no puede modificar la estructura |
|
|  | [Window](#Window) | El usuario no puede modificar la ventana |
|
