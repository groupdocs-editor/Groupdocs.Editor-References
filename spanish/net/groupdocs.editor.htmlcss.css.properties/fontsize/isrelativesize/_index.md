## FontSize.IsRelativeSize property

Indica si este font-size está definido con un tamaño relativo como una palabra clave. La fuente será mayor o menor en relación al tamaño de fuente del elemento padre, aproximadamente según la proporción utilizada para separar las palabras clave de tamaño absoluto.
