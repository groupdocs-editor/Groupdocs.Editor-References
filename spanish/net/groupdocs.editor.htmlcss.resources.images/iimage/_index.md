## IImage interface

El tipo de datos CSS de imagen representa una imagen bidimensional.

```csharp
public interface IImage
```

### Observaciones

https://developer.mozilla.org/en-US/docs/Web/CSS/image la referencia CSS declara 4 tipos de imágenes que pueden ser manejados: 1. Imágenes con dimensiones intrínsecas (un tamaño natural) y, por lo tanto, relación de aspecto fija, que incluye todas las imágenes raster. 2. Imágenes con múltiples dimensiones intrínsecas, existentes en varias versiones dentro de un solo archivo, que incluye archivos ICON (*.ico). Esto también puede ser TIFF, ya que soporta múltiples imágenes dentro de un archivo, sin embargo el formato TIFF no es compatible en la web. 3. Imágenes sin dimensiones intrínsecas pero con una relación de aspecto intrínseca entre su ancho y alto. Esto incluye todas las imágenes vectoriales, SVG primero. 4. Imágenes sin dimensiones intrínsecas ni relación de aspecto intrínseca. Esto incluye todos los degradados.
