## PdfSaveOptions.Password property

Contraseña que se aplicará al documento PDF generado como contraseña de usuario, requerida para abrirlo. Si es NULL o está vacía, no se aplicará ninguna contraseña al documento. De lo contrario, el documento se cifrará con RC4 (longitud de clave de 128 bits). Por defecto es NULL — no se aplica contraseña.

public string Password { get; set; }
