## PresentationSaveOptions.OutputFormat property

Permite especificar un formato de presentación que se utilizará para guardar el documento.

```csharp
public PresentationFormats OutputFormat { get; set; }
```

### Observaciones

El formato de salida suele establecerse en el constructor de esta clase, porque es obligatorio. Esta propiedad permite obtener o modificar el formato de salida más tarde, cuando ya se ha creado una instancia de la clase [`PresentationSaveOptions`](../../presentationsaveoptions).
