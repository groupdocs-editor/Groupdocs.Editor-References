## WordProcessingEditOptions.EnableLanguageInformation property

Especifica si la información de idioma se exporta al marcado HTML en forma de atributos HTML 'lang'. Esta opción puede ser útil para la conversión de ida y vuelta de documentos multilingües. Por defecto está desactivada (false).
