## WordProcessingSaveOptions.EnablePagination property

Permite habilitar o deshabilitar la paginación que se utilizará al guardar el documento WordProcessing. Si el documento original se abrió y editó en modo de paginación, esta opción también debe estar habilitada. Por defecto está deshabilitada.

public bool EnablePagination { get; set; }
