## XmlEditOptions.FixIncorrectStructure property

Permite habilitar o deshabilitar el mecanismo para corregir la estructura XML corrupta. Por defecto está deshabilitado (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Observaciones

Por defecto solo se aceptan documentos XML correctos, válidos y bien formados. Cuando esta opción está habilitada, GroupDocs.Editor intentará corregir la estructura XML dañada si es posible.
