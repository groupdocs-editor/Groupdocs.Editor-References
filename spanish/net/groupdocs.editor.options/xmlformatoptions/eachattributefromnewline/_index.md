## XmlFormatOptions.EachAttributeFromNewline property

Cuando está habilitado, cada par atributo-valor en cada elemento XML se colocará en una nueva línea. Por defecto es falso (deshabilitado) — todos los pares atributo-valor se colocan en una sola línea.

public bool EachAttributeFromNewline { get; set; }
