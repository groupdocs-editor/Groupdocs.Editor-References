## XmlFormatOptions.LeafTextNodesOnNewline property

Cuando está habilitado, los nodos de texto hoja (contenido textual dentro de los elementos XML que no tienen hijos) se renderizarán en una nueva línea con una sangría izquierda mayor. Por defecto es falso (deshabilitado) — los nodos de texto hoja se colocan en la misma línea que sus padres, sin nueva sangría.

public bool LeafTextNodesOnNewline { get; set; }
