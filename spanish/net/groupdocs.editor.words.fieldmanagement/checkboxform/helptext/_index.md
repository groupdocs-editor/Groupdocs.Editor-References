## CheckBoxForm.HelpText property

Obtiene o establece el texto de ayuda asociado al campo de formulario, la fuente del texto que se muestra en un cuadro de mensaje cuando un campo de formulario tiene el foco y el usuario presiona F1.

```csharp
public HelpText HelpText { get; set; }
```

### Observaciones

Si se establece en `false`, el texto de ayuda no se aplicará.
