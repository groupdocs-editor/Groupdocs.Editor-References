## Editor.FormFieldManager property

Proporciona acceso a la funcionalidad para gestionar campos de formulario dentro del documento.

```csharp
public FormFieldManager FormFieldManager { get; }
```

### Valor devuelto

Una instancia de `FormFieldManager` para gestionar los campos de formulario dentro del documento.

### Observaciones

La propiedad `FormFieldManager` crea una nueva instancia de la clase `FormFieldManager`, que permite el acceso a métodos y propiedades para gestionar los campos de formulario dentro del documento. Los campos de formulario son elementos interactivos dentro del documento que pueden capturar la entrada del usuario o desencadenar acciones. La instancia `FormFieldManager` proporciona métodos para diversas operaciones de campos de formulario, incluyendo la verificación de campos de formulario inválidos, la actualización de datos de campos de formulario y la corrección de problemas de nomenclatura. También facilita la recuperación de los nombres de los campos de formulario y sus datos asociados. Esta propiedad es útil para interactuar y manipular los campos de formulario programáticamente, permitiendo tareas como la validación de campos de formulario, la sincronización y la personalización.
