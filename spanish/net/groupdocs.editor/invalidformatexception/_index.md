## InvalidFormatException class

La excepción que se lanza cuando el usuario intenta abrir un documento con opciones específicas de formato que son incompatibles con el formato original del documento.

```csharp
public sealed class InvalidFormatException : Exception
```

### Observaciones

Por ejemplo, esta excepción se lanzará si se intenta abrir un documento de Hoja de cálculo con opciones de documento de procesamiento de texto.
