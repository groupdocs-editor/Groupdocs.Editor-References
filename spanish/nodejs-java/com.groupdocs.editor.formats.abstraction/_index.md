El espacio de nombres **com.groupdocs.editor.formats.abstraction** proporciona interfaces y clases que describen los formatos de documento compatibles en la biblioteca GroupDocs.Editor.



## Clases

| Clase | Descripción |
| --- | --- |
| [DocumentFormatBase](../com.groupdocs.editor.formats.abstraction/documentformatbase) | Representa la clase base para formatos de documento, proporcionando funcionalidad común para instancias de formato. |
| [FormatFamilyBase](../com.groupdocs.editor.formats.abstraction/formatfamilybase) | Representa la clase base para familias de formatos, proporcionando funcionalidad común para instancias de familia de formato. |

## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IDocumentFormat](../com.groupdocs.editor.formats.abstraction/idocumentformat) | Representa la interfaz raíz para todos los formatos de documento compatibles. |
