El espacio de nombres **com.groupdocs.editor.formats** proporciona interfaces y clases que describen los formatos de documento compatibles.



## Clases

| Clase | Descripción |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Encapsula todos los formatos de eBook. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Encapsula todos los formatos de correo electrónico. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Encapsula todos los formatos de diseño fijo (también conocido como "fixed-page"), que incluyen PDF y XPS (esto no incluye imágenes rasterizadas) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Representa las diferentes familias de formatos disponibles en el sistema. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Encapsula todos los formatos de presentación. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Encapsula todos los formatos binarios, XML y textuales de hojas de cálculo (excluyendo todos los formatos basados en delimitadores textuales con separadores como CSV, TSV, delimitados por punto y coma, etc.), en los que se puede guardar el libro de trabajo. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Encapsula todos los formatos textuales (basados en texto), incluidos los de marcado (XML, HTML) y otros. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Encapsula todos los formatos de procesamiento de texto. |
