El espacio de nombres **com.groupdocs.editor.htmlcss.exceptions** proporciona excepciones que se lanzan al intentar abrir, cargar, guardar o procesar de alguna otra forma algún contenido.



## Clases

| Clase | Descripción |
| --- | --- |
| [InvalidFontFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidfontformatexception) | La excepción que se lanza al intentar abrir, cargar, guardar o procesar de alguna manera algún contenido, que presumiblemente es una fuente de formato soportado (conocido), pero que en realidad es una fuente de formato no soportado o inesperado o no es una fuente en absoluto. |
| [InvalidImageFormatException](../com.groupdocs.editor.htmlcss.exceptions/invalidimageformatexception) | La excepción que se lanza al intentar abrir, cargar, guardar o procesar de alguna manera algún contenido, que presumiblemente es una imagen (raster o vector), pero que en realidad es una imagen de tipo inesperado o no es una imagen en absoluto. |
