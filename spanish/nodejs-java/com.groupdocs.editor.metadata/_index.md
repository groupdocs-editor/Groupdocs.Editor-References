El espacio de nombres **com.groupdocs.editor.metadata** proporciona clases para describir las propiedades básicas del documento según el tipo de documento.



## Clases

| Clase | Descripción |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Representa los metadatos de un documento EBook |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Representa los metadatos de un documento de correo electrónico de cualquier formato de correo admitido |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Representa los metadatos de un documento con formato de diseño fijo como PDF o XPS |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Representa los metadatos de un documento Markdown |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Representa los metadatos de un documento de presentación |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Representa los metadatos de un documento de hoja de cálculo |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Representa los metadatos de un documento textual como XML, HTML o texto plano (TXT) |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Representa los metadatos de un documento de procesamiento de texto |
