Controla qué partes del mensaje de correo deben entregarse al procesamiento de salida

## Campos

| Campo | Descripción |
| --- | --- |
|  | [None](#None) | Ninguna de las partes del mensaje de correo electrónico será procesada |
|
|  | [Body](#Body) | Procesar el cuerpo del mensaje de correo |
|
|  | [Subject](#Subject) | Procesar el asunto del mensaje de correo |
|
|  | [Date](#Date) | Procesar la fecha y hora en que se entregó el mensaje |
|
|  | [To](#To) | Procesar todos los destinatarios del mensaje de correo |
|
|  | [Cc](#Cc) | Procesar todos los destinatarios CC del mensaje de correo |
|
|  | [Bcc](#Bcc) | Procesar todos los destinatarios BCC del mensaje de correo |
|
|  | [From](#From) | Procesar el remitente del mensaje de correo |
|
|  | [Attachments](#Attachments) | Procesar todos los archivos adjuntos del mensaje de correo |
|
|  | [Metadata](#Metadata) | Procesar todos los demás metadatos técnicos (sensibilidad, prioridad, codificación, MIME, X-Mailer, etc) |
|
|  | [Common](#Common) | Salida común - cuerpo con todos los metadatos principales |
|
|  | [All](#All) | Salida completa - cuerpo con todos los metadatos |
|
