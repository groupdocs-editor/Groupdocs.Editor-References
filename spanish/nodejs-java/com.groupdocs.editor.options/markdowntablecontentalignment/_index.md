Permite especificar la alineación del contenido de la tabla que se usará cuando
exportar al formato Markdown.

## Campos

| Campo | Descripción |
| --- | --- |
|  | [Auto](#Auto) | La alineación se tomará del primer párrafo en la correspondiente |
columna de tabla.
|
|  | [Left](#Left) | El contenido de las tablas se alineará a la Izquierda. |
|
|  | [Center](#Center) | El contenido de las tablas se alineará al Centro. |
|
|  | [Right](#Right) | El contenido de las tablas se alineará a la Derecha. |
|
