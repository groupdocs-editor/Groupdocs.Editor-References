El espacio de nombres **com.groupdocs.editor.words.fieldmanagement** contiene clases e interfaces relacionadas con la gestión y manipulación de campos de formulario dentro de documentos. Este espacio de nombres proporciona funcionalidad para trabajar con varios tipos de campos de formulario, como campos de texto, casillas de verificación, listas desplegables, etc., permitiendo a los usuarios interactuar y modificar los campos de formulario programáticamente.



## Clases

| Clase | Descripción |
| --- | --- |
| [CheckBoxForm](../com.groupdocs.editor.words.fieldmanagement/checkboxform) | Representa un campo de formulario que muestra una casilla de verificación. |
| [CurrentDateFormField](../com.groupdocs.editor.words.fieldmanagement/currentdateformfield) | Representa un campo de formulario que muestra la fecha actual. |
| [CurrentTimeFormField](../com.groupdocs.editor.words.fieldmanagement/currenttimeformfield) | Representa un campo de formulario que muestra la hora actual. |
| [DateFormField](../com.groupdocs.editor.words.fieldmanagement/dateformfield) | Representa un campo de formulario que muestra una fecha. |
| [DropDownFormField](../com.groupdocs.editor.words.fieldmanagement/dropdownformfield) | Representa un campo de formulario que muestra una lista desplegable. |
| [FormFieldCollection](../com.groupdocs.editor.words.fieldmanagement/formfieldcollection) | Representa una colección de campos de formulario. |
| [FormFieldType](../com.groupdocs.editor.words.fieldmanagement/formfieldtype) | Especifica el tipo de campo de formulario. |
| [HelpText](../com.groupdocs.editor.words.fieldmanagement/helptext) | Representa texto de ayuda para un campo de formulario. |
| [InvalidFormField](../com.groupdocs.editor.words.fieldmanagement/invalidformfield) | Representa la actualización de nombres de campos de formulario no válidos durante la operación FormFieldManager.FixInvalidFormFieldNames. |
| [NumberFormField](../com.groupdocs.editor.words.fieldmanagement/numberformfield) | Representa un campo de formulario que acepta una entrada numérica. |
| [TextFormField](../com.groupdocs.editor.words.fieldmanagement/textformfield) | Representa un campo de formulario que acepta una entrada de texto. |
