Den **com.groupdocs.editor.formats** namnrymden tillhandahåller gränssnitt och klasser som beskriver de stödda dokumentformaten.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Inkapslar alla eBook-format. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Inkapslar alla e‑postformat. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Inkapslar alla fast‑layout (även kända som \"fixed-page\")‑format, som inkluderar PDF och XPS (detta inkluderar inte rasterbilder). |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Representerar de olika formatfamiljerna som finns tillgängliga i systemet. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Inkapslar alla presentationsformat. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Inkapslar alla binära, XML- och textbaserade kalkylbladsformat (exklusive alla textbaserade format med avgränsare som CSV, TSV, semikolonavgränsade etc.), i vilka arbetsboken kan sparas. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Inkapslar alla textbaserade (text‑baserade) format, inklusive markup (XML, HTML) och andra. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Inkapslar alla ordbehandlingsformat. |
