Den **com.groupdocs.editor.htmlcss.css.datatypes** namnrymden tillhandahåller klasser som representerar CSS-datatyper.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ArgbColor](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolor) | Representerar ett färgvärde i ARGB‑format med konverterare och serialiserare. |
| [ArgbColors](../com.groupdocs.editor.htmlcss.css.datatypes/argbcolors) | Innehåller alla \"kända färger\" som har ett fast unikt namn och värde i CSS‑standarden. |
| [Length](../com.groupdocs.editor.htmlcss.css.datatypes/length) | Representerar ett CSS‑längdvärde i någon stödjande enhet, inklusive procent‑ och enhetlösa typer. |
| [LengthUnit](../com.groupdocs.editor.htmlcss.css.datatypes/lengthunit) | Alla stödjade längdenheter. |
| [Ratio](../com.groupdocs.editor.htmlcss.css.datatypes/ratio) | Representerar en \"ratio\"‑CSS‑datatyp som används för att beskriva bildförhållanden i media‑queries och för rasterbilder genom att ange förhållandet mellan två enhetlösa värden som kallas \"numerator\" och \"denominator\". |
