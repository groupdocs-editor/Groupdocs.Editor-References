## Klasser

| Klass | Beskrivning |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Representerar en teckenstorlek som en speciell enhet eller ett längdvärde, vilket specificerar storleken på teckensnittet (historiskt bredden på den stora "M"). |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Definierar hur teckensnittet ska stiliseras med: ett normalt, kursivt eller snett teckensnitt från dess font-family. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | Font-weight-egenskapen sätter vikten (eller fetstil) på teckensnittet. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Representerar typer av textdekoration: understrykning (underscore), överstrykning och genomstrykning (strikethrough). |
