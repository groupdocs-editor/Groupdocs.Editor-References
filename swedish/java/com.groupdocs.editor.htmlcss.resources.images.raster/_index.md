Den **com.groupdocs.editor.htmlcss.resources.images.raster** namnrymden tillhandahåller klasser som endast representerar rasterbildresurser.

| --- | --- |

| [GifImage](../com.groupdocs.editor.htmlcss.resources.images.raster/gifimage) | Representerar en bild i GIF (Graphics Interchange Format)-format med dess metadata och ytterligare metoder. |
| [IconImage](../com.groupdocs.editor.htmlcss.resources.images.raster/iconimage) | Representerar en bild i ICON-format med dess metadata och ytterligare metoder. |
| [JpegImage](../com.groupdocs.editor.htmlcss.resources.images.raster/jpegimage) | Representerar en bild i JPEG (Joint Photographic Experts Group)-format med dess metadata och ytterligare metoder. |
| [PngImage](../com.groupdocs.editor.htmlcss.resources.images.raster/pngimage) | Representerar en bild i PNG (Portable Network Graphics)-format med dess metadata och ytterligare metoder. |
| [RasterImageResourceBase](../com.groupdocs.editor.htmlcss.resources.images.raster/rasterimageresourcebase) | Basisklass för alla stödda rasterbilder med fast namn, dimensioner, bildförhållande, typ, storlek och innehåll. |
| [TiffImage](../com.groupdocs.editor.htmlcss.resources.images.raster/tiffimage) | Representerar en bild i TIFF (Tagged Image File Format)-format med dess metadata och ytterligare metoder. |
