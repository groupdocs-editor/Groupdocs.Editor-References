Den **com.groupdocs.editor.metadata** namnrymden tillhandahåller klasser för att beskriva grundläggande dokumentegenskaper beroende på dokumenttyp.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EbookDocumentInfo](../com.groupdocs.editor.metadata/ebookdocumentinfo) | Representerar metadata för ett EBook-dokument |
| [EmailDocumentInfo](../com.groupdocs.editor.metadata/emaildocumentinfo) | Representerar metadata för ett e‑postdokument i vilket som helst stödd e‑postformat. |
| [FixedLayoutDocumentInfo](../com.groupdocs.editor.metadata/fixedlayoutdocumentinfo) | Representerar metadata för ett dokument med fast layoutformat som PDF eller XPS. |
| [MarkdownDocumentInfo](../com.groupdocs.editor.metadata/markdowndocumentinfo) | Representerar metadata för ett Markdown-dokument. |
| [PresentationDocumentInfo](../com.groupdocs.editor.metadata/presentationdocumentinfo) | Representerar metadata för ett presentationsdokument. |
| [SpreadsheetDocumentInfo](../com.groupdocs.editor.metadata/spreadsheetdocumentinfo) | Representerar metadata för ett kalkylbladsdokument. |
| [TextualDocumentInfo](../com.groupdocs.editor.metadata/textualdocumentinfo) | Representerar metadata för ett textdokument som XML, HTML eller vanlig text (TXT). |
| [WordProcessingDocumentInfo](../com.groupdocs.editor.metadata/wordprocessingdocumentinfo) | Representerar metadata för ett ordbehandlingsdokument. |
