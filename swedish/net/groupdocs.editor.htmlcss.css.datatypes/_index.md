## Structures

| Struktur | Beskrivning |
| --- | --- |
| [ArgbColor](./argbcolor) | Representerar ett färgvärde i 32-bitars ARGB-format (8 bitar per kanal inklusive transparens) med konverterare och serialiserare |
| [Length](./length) | Representerar ett CSS-längdvärde i någon stödbar enhet, inklusive procent och enhetstyp utan enhet. Värden kan vara heltal eller flyttal, negativa, noll och positiva. Oföränderlig struktur. |
| [Ratio](./ratio) | Representerar en \"ratio\" CSS-datatyp, som används för att beskriva bildförhållanden i media queries och för rasterbilder genom att ange förhållandet mellan två enhetslösa värden som kallas \"numerator\" och \"denominator\". Oföränderlig struktur. |
