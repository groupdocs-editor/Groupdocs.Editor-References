GroupDocs.Editor.HtmlCss.Css.Properties-namnrymden tillhandahåller typer som representerar olika CSS-egenskaper (komponenter i CSS-deklarationer).

## Structures

| Struktur | Beskrivning |
| --- | --- |
| [FontSize](./fontsize) | Representerar en teckenstorlek som en speciell enhet eller ett längdvärde, vilket specificerar teckenstorleken (historiskt bredden på den stora \"M\"). |
| [FontStyle](./fontstyle) | Definierar hur teckensnittet ska stiliseras med: en normal, kursiv eller sned (oblique) stil från dess font-family. |
| [FontWeight](./fontweight) | Font-weight‑egenskapen anger vikten (eller fetheten) på teckensnittet. Tillgängliga vikter beror på den font-family som för närvarande är inställd. |
| [TextDecorationLineType](./textdecorationlinetype) | Representerar typer av textdekorationens linje: understrykning (underscore), överlinje och genomstrykning (strikethrough) |
