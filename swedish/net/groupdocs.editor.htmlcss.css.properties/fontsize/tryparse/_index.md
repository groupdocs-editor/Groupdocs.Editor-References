```csharp
public static bool TryParse(string keyword, out FontSize result)
```

| Parameter | Type | Beskrivning |
| --- | --- | --- |
| keyword | String | Ett nyckelord att tolka |
| result | FontSize& | Resultatet, av parsning var framgångsrikt, eller [`Medium`](../medium) annars |

### Returvärde
