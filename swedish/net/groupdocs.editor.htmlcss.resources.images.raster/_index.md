GroupDocs.Editor.HtmlCss.Resources.Images.Raster-namnrymden tillhandahåller klasser som endast representerar rasterbildresurser.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [BmpImage](./bmpimage) | Representerar en bild i BMP (BitMap Picture)-format med dess metadata och ytterligare metoder. |
| [GifImage](./gifimage) | Representerar en bild i GIF (Graphics Interchange Format)-format med dess metadata och ytterligare metoder. |
| [IconImage](./iconimage) | Representerar en bild i ICON-format med dess metadata och ytterligare metoder. |
| [JpegImage](./jpegimage) | Representerar en bild i JPEG (Joint Photographic Experts Group)-format med dess metadata och ytterligare metoder. |
| [PngImage](./pngimage) | Representerar en bild i PNG (Portable Network Graphics)-format med dess metadata och ytterligare metoder. |
| [RasterImageResourceBase](./rasterimageresourcebase) | Basklass för alla stödjade rasterbilder med fast namn, dimensioner, bildförhållande, typ, storlek och innehåll. |
| [TiffImage](./tiffimage) | Representerar en bild i TIFF (Tagged Image File Format)-format med dess metadata och ytterligare metoder. |
