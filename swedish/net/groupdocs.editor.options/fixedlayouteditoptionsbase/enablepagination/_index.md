## FixedLayoutEditOptionsBase.EnablePagination property

Tillåter att aktivera (true) eller inaktivera (false) paginering i det resulterande HTML-dokumentet. Som standard är den inaktiverad (false).

```csharp
public bool EnablePagination { get; set; }
```

### Anmärkningar

Dokument i fast layout-format (PDF och XPS i synnerhet) är i sin essens strikt paginerade, deras innehåll har en fast layout och är delat på sidor. Men den resulterande redigerbara HTML:n kan visas antingen utan sidor eller i paginerad vy.
