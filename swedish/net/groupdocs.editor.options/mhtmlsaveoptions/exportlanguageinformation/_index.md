## MhtmlSaveOptions.ExportLanguageInformation property

Anger om språkinformation ska exporteras till MHTML. Standardvärdet är `false`.

```csharp
public bool ExportLanguageInformation { get; set; }
```

### Anmärkningar

När den här egenskapen är satt till `true` skickar GroupDocs.Editor `lang`‑HTML‑attributet på dokumentelementen som specificerar språk. Detta kan behövas för att bevara språkrelaterad semantik.
