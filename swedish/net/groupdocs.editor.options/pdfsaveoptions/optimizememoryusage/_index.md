## PdfSaveOptions.OptimizeMemoryUsage property

Aktiverar minnesoptimeringsmekanismer under dokumentgenerering från HTML, vilket försämrar prestandan som en kostnad för minskat minnesanvändning. Att sätta detta alternativ till true kan avsevärt minska minnesförbrukningen vid generering av stora dokument på bekostnad av långsammare sparningstid. Standard är false (minnesoptimering är inaktiverad för bättre prestanda).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
