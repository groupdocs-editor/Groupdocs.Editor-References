## PdfSaveOptions.Password property

Lösenord som kommer att tillämpas på det genererade PDF‑dokumentet som användarlösenord, krävs för att öppna det. Om NULL eller tomt kommer inget lösenord att tillämpas på dokumentet. Annars krypteras dokumentet med RC4 (nyckellängd 128 bit). Som standard är NULL – lösenordet tillämpas inte.

public string Password { get; set; }
