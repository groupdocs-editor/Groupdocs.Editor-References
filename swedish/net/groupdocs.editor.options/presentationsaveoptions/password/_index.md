## PresentationSaveOptions.Password property

Tillåter att ange, ändra och hämta lösenordet som kommer att användas för att koda det resulterande Presentation‑dokumentet. Standardvärdet är NULL – lösenordet kommer inte att sättas. Sätt till NULL eller en tom sträng för att ta bort lösenordet om det tidigare har satts.

public string Password { get; set; }
