## SpreadsheetEditOptions.ExportBogusRowData property

När den är aktiverad innehåller HTML‑tabellen i det genererade HTML‑dokumentet en tom dold rad längst ner med nollhöjd och tomma celler, där endast bredd anges. Denna rad med tomma celler innehåller exakta breddvärden för varje kolumn och förbättrar bakåtkonvertering från HTML till Spreadsheet. Som standard är den aktiverad (`true`).

```csharp
public bool ExportBogusRowData { get; set; }
```
