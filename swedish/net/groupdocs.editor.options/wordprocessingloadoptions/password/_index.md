## WordProcessingLoadOptions.Password property

Tillåter att ange, ändra och hämta lösenordet som kommer att användas för att öppna WordProcessing-dokumentet om det är krypterat. Sätt till NULL eller en tom sträng för att inte använda lösenordet (standardvärde).
