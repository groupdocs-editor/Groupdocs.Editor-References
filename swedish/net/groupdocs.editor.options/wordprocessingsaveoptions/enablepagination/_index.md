## WordProcessingSaveOptions.EnablePagination property

Tillåter att aktivera eller inaktivera paginering som kommer att användas för att spara WordProcessing-dokumentet. Om det ursprungliga dokumentet öppnades och redigerades i pagineringsläge bör detta alternativ också aktiveras. Som standard är det inaktiverat.

```csharp
public bool EnablePagination { get; set; }
```
