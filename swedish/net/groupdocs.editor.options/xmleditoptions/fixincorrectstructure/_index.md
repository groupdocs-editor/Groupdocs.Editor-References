## XmlEditOptions.FixIncorrectStructure property

Tillåter att aktivera eller inaktivera mekanismen för att reparera korrupt XML-struktur. Som standard är den inaktiverad (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Anmärkningar

Som standard är endast korrekta, giltiga och välformade XML-dokument acceptabla. När det här alternativet är aktiverat kommer GroupDocs.Editor att försöka reparera korrupt XML-struktur om möjligt.
