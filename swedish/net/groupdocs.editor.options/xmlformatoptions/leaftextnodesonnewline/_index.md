## XmlFormatOptions.LeafTextNodesOnNewline property

När den är aktiverad kommer lövtextnoder (textinnehåll inuti XML-element som inte har några barn) att renderas på en ny rad med större vänsterindrag. Som standard är false (inaktiverad) — lövtextnoder placeras på samma rad som sina föräldrar, utan nytt indrag.

public bool LeafTextNodesOnNewline { get; set; }
