Innehåller klasser och gränssnitt relaterade till hantering och manipulation av formulärfält i dokument. Denna namnrymd tillhandahåller funktionalitet för att arbeta med olika typer av formulärfält, såsom textfält, kryssrutor, rullgardinsmenyer osv., vilket möjliggör för användare att interagera med och modifiera formulärfält programatiskt.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [CheckBoxForm](./checkboxform) | Representerar ett formulärfält som visar en kryssruta. |
| [CurrentDateFormField](./currentdateformfield) | Representerar ett formulärfält som visar det aktuella datumet. |
| [CurrentTimeFormField](./currenttimeformfield) | Representerar ett formulärfält som visar den aktuella tiden. |
| [DateFormField](./dateformfield) | Representerar ett formulärfält som visar ett datum. |
| [DropDownFormField](./dropdownformfield) | Representerar ett formulärfält som visar en rullgardinslista. |
| [FormFieldCollection](./formfieldcollection) | Representerar en samling av formulärfält. |
| [HelpText](./helptext) | Representerar hjälptext för ett formulärfält. |
| [InvalidFormField](./invalidformfield) | Representerar uppdateringen av ogiltiga formulärfältsnamn under [`FixInvalidFormFieldNames`](../groupdocs.editor/formfieldmanager/fixinvalidformfieldnames)-operationen. |
| [NumberFormField](./numberformfield) | Representerar ett formulärfält som accepterar en numerisk inmatning. |
| [TextFormField](./textformfield) | Representerar ett formulärfält som accepterar textinmatning. |
