## Editor.FormFieldManager property

Tillhandahåller åtkomst till funktionalitet för att hantera formulärfält i dokumentet.

```csharp
public FormFieldManager FormFieldManager { get; }
```

### Returvärde

En `FormFieldManager`-instans för att hantera formulärfält inom dokumentet.

### Anmärkningar

Egenskapen `FormFieldManager` skapar en ny instans av klassen `FormFieldManager`, vilket ger åtkomst till metoder och egenskaper för att hantera formulärfält inom dokumentet. Formulärfält är interaktiva element i dokumentet som kan fånga användarinmatning eller utlösa åtgärder. `FormFieldManager`-instansen tillhandahåller metoder för olika formulärfältsoperationer, inklusive kontroll av ogiltiga formulärfält, uppdatering av formulärfältsdata och åtgärdande av namnproblem. Den underlättar också hämtning av formulärfältnamn och deras associerade data. Egenskapen är användbar för att interagera med och manipulera formulärfält programatiskt, vilket möjliggör uppgifter såsom formulärfältvalidering, synkronisering och anpassning.
