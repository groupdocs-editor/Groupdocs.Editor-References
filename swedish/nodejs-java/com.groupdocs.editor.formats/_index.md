Den **com.groupdocs.editor.formats**-namnutrymmet tillhandahåller gränssnitt och klasser som beskriver de stödjade dokumentformaten.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Innesluter alla eBook-format. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Innesluter alla e‑postformat. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | Innesluter alla fast‑layout (även känt som \"fixed-page\")-format, som inkluderar PDF och XPS (detta inkluderar inte rasterbilder). |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Representerar de olika formatfamiljerna som finns tillgängliga i systemet. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Innesluter alla presentationsformat. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Innesluter alla binära, XML‑ och textbaserade kalkylbladsformat (exklusive alla textbaserade format med avgränsare som CSV, TSV, semikolon‑avgränsade etc.), i vilka arbetsboken kan sparas. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | Innesluter alla textbaserade (text‑baserade) format, inklusive markup (XML, HTML) och andra. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Innesluter alla ordbehandlingsformat. |
