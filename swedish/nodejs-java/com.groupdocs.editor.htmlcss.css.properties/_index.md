## Klasser

| Klass | Beskrivning |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Representerar en teckenstorlek som en speciell enhet eller ett längdvärde, vilket specificerar storleken på teckensnittet (historiskt bredden på den stora "M"). |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Definierar hur teckensnittet ska stylas med: en normal, kursiv eller snedställd stil från dess font-family. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | Font-weight-egenskapen anger vikten (eller fetstil) för teckensnittet. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Representerar typer av textdekoration: underline (understrykning), overline och line-through (genomstrykning) |
