Den **com.groupdocs.editor.htmlcss.resources.images**-namnutrymmet tillhandahåller klasser som representerar bildresurser av alla typer i allmänhet.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Dimensions](../com.groupdocs.editor.htmlcss.resources.images/dimensions) | Representerar de linjära dimensionerna (bredd och höjd) för en raster rectangularimage i godtycklig enhet. |
| [ImageType](../com.groupdocs.editor.htmlcss.resources.images/imagetype) | Representerar en stödbar bildtyp (format), stöder både raster- och vektorformat. |
