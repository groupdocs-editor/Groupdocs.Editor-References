Namnutrymmet **com.groupdocs.editor.words.fieldmanagement** innehåller klasser och gränssnitt relaterade till hantering och manipulation av formulärfält i dokument. Detta namnutrymme tillhandahåller funktionalitet för att arbeta med olika typer av formulärfält, såsom textfält, kryssrutor, rullgardinsmenyer osv., vilket möjliggör för användare att interagera med och modifiera formulärfält programatiskt.

| Klass | Beskrivning |
| --- | --- |
| [CheckBoxForm](../com.groupdocs.editor.words.fieldmanagement/checkboxform) | Representerar ett formulärfält som visar en kryssruta. |
| [CurrentDateFormField](../com.groupdocs.editor.words.fieldmanagement/currentdateformfield) | Representerar ett formulärfält som visar det aktuella datumet. |
| [CurrentTimeFormField](../com.groupdocs.editor.words.fieldmanagement/currenttimeformfield) | Representerar ett formulärfält som visar den aktuella tiden. |
| [DateFormField](../com.groupdocs.editor.words.fieldmanagement/dateformfield) | Representerar ett formulärfält som visar ett datum. |
| [DropDownFormField](../com.groupdocs.editor.words.fieldmanagement/dropdownformfield) | Representerar ett formulärfält som visar en rullgardinslista. |
| [FormFieldCollection](../com.groupdocs.editor.words.fieldmanagement/formfieldcollection) | Representerar en samling av formulärfält. |
| [FormFieldType](../com.groupdocs.editor.words.fieldmanagement/formfieldtype) | Anger typen av formulärfält. |
| [HelpText](../com.groupdocs.editor.words.fieldmanagement/helptext) | Representerar hjälptext för ett formulärfält. |
| [InvalidFormField](../com.groupdocs.editor.words.fieldmanagement/invalidformfield) | Representerar uppdateringen av ogiltiga formulärfältsnamn under FormFieldManager.FixInvalidFormFieldNames‑operationen. |
| [NumberFormField](../com.groupdocs.editor.words.fieldmanagement/numberformfield) | Representerar ett formulärfält som accepterar numerisk inmatning. |
| [TextFormField](../com.groupdocs.editor.words.fieldmanagement/textformfield) | Representerar ett formulärfält som accepterar textinmatning. |
