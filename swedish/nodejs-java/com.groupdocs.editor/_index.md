Den **com.groupdocs.editor**-namnutrymmet är ett rot‑namnutrymme som tillhandahåller klasser för att redigera flera dokumentformat i dina Java‑applikationer.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Mellanliggande dokument som innehåller innehåll före och efter redigering |
| [Editor](../com.groupdocs.editor/editor) | Huvudklass som kapslar in konverteringsmetoder. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | Undantaget som kastas när en användare försöker öppna ett dokument som krypterades med X509Certificates. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | Undantaget som kastas när det angivna lösenordet är felaktigt. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | Undantaget som kastas när en användare försöker öppna ett dokument med format‑specifika alternativ som är inkompatibla med det ursprungliga dokumentformatet. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | Undantaget som kastas när en användare försöker öppna ett lösenordsskyddat krypterat dokument av något format och inte anger ett lösenord för att öppna detta dokument. |
