## License class

Hantera licensiering för GroupDocs.Editor.

Licensierade byggen låser upp hela funktionsuppsättningen för omslaget på
körningstid. Olicensierade byggen körs i evalueringsläge med samma API
yta men med begränsningar för utskriftsstorlek och vattenstämplat innehåll.

Typen License visar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [set_license](/editor/python-net/groupdocs.editor/license/set_license/#license_source) | Applicera en licens på den aktuella processen. |
