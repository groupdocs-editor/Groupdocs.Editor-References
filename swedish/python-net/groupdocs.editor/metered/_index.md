## Metered class

Hantera mätbaserad (betala per användning) licensiering.

Metered-licenser faktureras baserat på faktisk förbrukning (vanligtvis sidor eller
dokument som bearbetas). Ställ in det offentliga/privata nyckelparet en gång vid
programstart; omslaget rapporterar användning tillbaka till GroupDocs
licensserver i bakgrunden.

Metered-typen visar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_consumption_credit](/editor/python-net/groupdocs.editor/metered/get_consumption_credit/) | Returnera den återstående meterade krediten för den aktuella nyckeln. |
| [get_consumption_quantity](/editor/python-net/groupdocs.editor/metered/get_consumption_quantity/) | Returnera den totala meterade mängden som har förbrukats hittills. |
| [set_metered_key](/editor/python-net/groupdocs.editor/metered/set_metered_key/#public_key-private_key) | Aktivera meterad fakturering med det angivna offentliga/privata nyckelparet. |
