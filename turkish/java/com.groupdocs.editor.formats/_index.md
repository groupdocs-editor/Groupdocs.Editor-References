Bu **com.groupdocs.editor.formats** ad alanı, desteklenen belge formatlarını tanımlayan arabirimler ve sınıflar sağlar.



## Sınıflar

| Sınıf | Açıklama |
| --- | --- |
| [EBookFormats](../com.groupdocs.editor.formats/ebookformats) | Tüm eBook formatlarını kapsar. |
| [EmailFormats](../com.groupdocs.editor.formats/emailformats) | Tüm e-posta formatlarını kapsar. |
| [FixedLayoutFormats](../com.groupdocs.editor.formats/fixedlayoutformats) | PDF ve XPS'yi içeren tüm sabit düzen (\"fixed-page\" olarak da bilinir) formatlarını kapsar (bu, raster görüntüleri içermez) |
| [FormatFamilies](../com.groupdocs.editor.formats/formatfamilies) | Sistemde mevcut farklı format ailelerini temsil eder. |
| [PresentationFormats](../com.groupdocs.editor.formats/presentationformats) | Tüm Sunum formatlarını kapsar. |
| [SpreadsheetFormats](../com.groupdocs.editor.formats/spreadsheetformats) | Çalışma kitabının kaydedilebileceği tüm ikili, XML ve metin tabanlı Elektronik Tablo formatlarını (CSV, TSV, noktalı virgül gibi ayırıcılarla kullanılan metin tabanlı ayırıcı formatları hariç) kapsar. |
| [TextualFormats](../com.groupdocs.editor.formats/textualformats) | İşaretleme (XML, HTML) ve diğerlerini içeren tüm metin (metin tabanlı) formatlarını kapsar. |
| [WordProcessingFormats](../com.groupdocs.editor.formats/wordprocessingformats) | Tüm Kelime İşleme formatlarını kapsar. |
