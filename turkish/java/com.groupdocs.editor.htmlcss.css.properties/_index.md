## Sınıflar

| Sınıf | Açıklama |
| --- | --- |
| [FontSize](../com.groupdocs.editor.htmlcss.css.properties/fontsize) | Bir yazı tipi boyutunu özel bir birim veya uzunluk değeri olarak temsil eder, bu değer yazı tipinin boyutunu (tarihsel olarak büyük "M" harfinin genişliği) belirtir. |
| [FontStyle](../com.groupdocs.editor.htmlcss.css.properties/fontstyle) | Yazı tipinin nasıl stillenmesi gerektiğini tanımlar: normal, italik veya eğik bir yüz, font-family'sinden. |
| [FontWeight](../com.groupdocs.editor.htmlcss.css.properties/fontweight) | Font-weight özelliği, yazı tipinin ağırlığını (veya kalınlığını) ayarlar. |
| [TextDecorationLineType](../com.groupdocs.editor.htmlcss.css.properties/textdecorationlinetype) | Metin süslemesi çizgi türlerini temsil eder: alt çizgi (underscore), üst çizgi ve üstten çizgi (strikethrough). |
