GroupDocs.Editor.HtmlCss.Css.Properties namespace'i, farklı CSS özelliklerini (CSS bildirimlerinin bileşenleri) temsil eden tipler sağlar.

## Structures

| Yapı | Açıklama |
| --- | --- |
| [FontSize](./fontsize) | Bir yazı tipi boyutunu özel bir birim veya uzunluk değeri olarak temsil eder; bu, yazı tipinin boyutunu (tarihsel olarak büyük "M" harfinin genişliği) belirtir. |
| [FontStyle](./fontstyle) | Yazı tipinin font-family'sinden normal, italik veya eğik bir yüz ile nasıl stilleneceğini tanımlar. |
| [FontWeight](./fontweight) | Font-weight özelliği, yazı tipinin ağırlığını (veya kalınlığını) ayarlar. Mevcut ayarlı font-family'ye bağlı olarak kullanılabilir ağırlıklar değişir. |
| [TextDecorationLineType](./textdecorationlinetype) | Metin süsleme çizgi türlerini temsil eder: alt çizgi (alt tire), üst çizgi ve üstü çizili (çizgi üzeri) |
