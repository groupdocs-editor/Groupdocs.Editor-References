## MarkdownSaveOptions.ExportImagesAsBase64 property

Görüntülerin çıktı dosyasına Base64 formatında kaydedilip kaydedilmeyeceğini belirtir. Varsayılan `false`.

```csharp
public bool ExportImagesAsBase64 { get; set; }
```

### Açıklamalar

`true` olarak ayarlandığında, görüntü verileri doğrudan görüntü öğelerine ![]() aktarılır ve ayrı dosyalar oluşturulmaz. Bu özellik, `true` ise, [`ImagesFolder`](../imagesfolder) özelliğine göre daha yüksek önceliğe sahiptir.
