## MarkdownSaveOptions.OptimizeMemoryUsage property

HTML'den belge oluşturulurken bellek optimizasyon mekanizmalarını etkinleştirir; bu, bellek kullanımını azaltma karşılığında performansı düşürür. Bu seçeneği `true` olarak ayarlamak, büyük belgeler oluşturulurken bellek tüketimini önemli ölçüde azaltabilir, ancak kaydetme süresini yavaşlatır. Varsayılan `false` (daha iyi performans için bellek optimizasyonu devre dışıdır).

```csharp
public bool OptimizeMemoryUsage { get; set; }
```
