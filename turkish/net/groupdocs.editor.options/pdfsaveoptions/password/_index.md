## PdfSaveOptions.Password property

Oluşturulan PDF belgesine kullanıcı şifresi olarak uygulanacak şifre, açmak için gereklidir. NULL veya boş ise belgeye şifre uygulanmaz. Aksi takdirde belge RC4 (128 bit anahtar uzunluğu) ile şifrelenir. Varsayılan olarak NULL — şifre uygulanmaz.
