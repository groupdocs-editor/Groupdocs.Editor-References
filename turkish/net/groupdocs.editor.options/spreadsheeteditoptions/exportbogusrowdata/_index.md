## SpreadsheetEditOptions.ExportBogusRowData property

Etkinleştirildiğinde, üretilen HTML belgesindeki HTML tablosu, yalnızca genişliğin belirtildiği boş hücrelere sahip, sıfır yüksekliğinde ve gizli bir alt satır içerir. Bu boş hücreli satır, her sütun için kesin genişlik değerlerini içerir ve HTML'den Elektronik Tabloya geri dönüşümü iyileştirir. Varsayılan olarak etkindir (`true`).

```csharp
public bool ExportBogusRowData { get; set; }
```
