## WordProcessingEditOptions.EnableLanguageInformation property

Dil bilgisinin HTML işaretlemesine 'lang' HTML öznitelikleri şeklinde dışa aktarılıp aktarılmayacağını belirtir. Bu seçenek çok dilli belgelerin çift yönlü dönüşümünde faydalı olabilir. Varsayılan olarak devre dışıdır (false).

public bool EnableLanguageInformation { get; set; }
