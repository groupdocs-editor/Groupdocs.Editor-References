## WordProcessingSaveOptions.LocaleFarEast property

WordProcessing belgesinin Doğu Asya metinleri için yerel ayarını (dil) geçersiz kılmanıza olanak tanır; bu ayar oluşturma sırasında uygulanır. Belirtilmezse (varsayılan değer), MS Word (veya başka bir program) belge Doğu Asya yerel ayarını kendi ayarları veya diğer faktörlere göre algılar (veya seçer).

```csharp
public CultureInfo LocaleFarEast { get; set; }
```

### Açıklamalar

Bu seçenek, belirtilen yereli belgedeki tüm Doğu Asya metnine zorla uygular. Belge farklı dillerde yazılmış farklı metin bölümleri içeriyorsa kullanmayın.
