## XmlEditOptions.FixIncorrectStructure property

Bozuk XML yapısını düzeltmek için mekanizmayı etkinleştirmenize veya devre dışı bırakmanıza olanak tanır. Varsayılan olarak devredışı bırakılmıştır (false).

```csharp
public bool FixIncorrectStructure { get; set; }
```

### Açıklamalar

Varsayılan olarak yalnızca doğru, geçerli ve iyi biçimlendirilmiş XML belgeleri kabul edilir. Bu seçenek etkinleştirildiğinde, GroupDocs.Editor mümkünse bozuk XML yapısını düzeltmeye çalışır.
