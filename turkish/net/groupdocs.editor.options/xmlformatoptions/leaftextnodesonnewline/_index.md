## XmlFormatOptions.LeafTextNodesOnNewline property

Etkinleştirildiğinde, yaprak metin düğümleri (çocukları olmayan XML öğeleri içindeki metin içeriği) daha büyük sol girinti ile yeni bir satıra yerleştirilecektir. Varsayılan olarak yanlıştır (devre dışı) — yaprak metin düğümleri ebeveynleriyle aynı satıra, yeni girinti olmadan yerleştirilir.

public bool LeafTextNodesOnNewline { get; set; }
