Bu **com.groupdocs.editor.htmlcss.resources** ad alanı, tüm HTML kaynaklarını temsil eden sınıflar sağlar.



## Sınıflar

| Sınıf | Açıklama |
| --- | --- |
| [ResourceTypeDetector](../com.groupdocs.editor.htmlcss.resources/resourcetypedetector) | Kaynak türlerini (formatları) tespit etmek için yardımcı statik yöntemler. |

## Arabirimler

| Arabirim | Açıklama |
| --- | --- |
| [IAuxDisposable](../com.groupdocs.editor.htmlcss.resources/iauxdisposable) | Standart IDisposable arayüzünü genişletir, bir nesnenin mevcut durumunu elde etmeye ve disposing (yok etme) olayına abone olmaya olanak tanır. |
| [IHtmlResource](../com.groupdocs.editor.htmlcss.resources/ihtmlresource) | Bilinmeyen bir HTML kaynağının (raster veya vektör görüntü, stil sayfası, yazı tipi, metin kaynağı (CSS, XML) vb.) bir örneğini temsil eder. |
| [IResourceType](../com.groupdocs.editor.htmlcss.resources/iresourcetype) | Bilinmeyen kaynak türünün/formatının (görüntü, yazı tipi, metin) bir örneğini temsil eder. |
