Bu **com.groupdocs.editor** ad alanı, Java uygulamalarınızda birden çok belge formatını düzenlemek için sınıflar sağlayan bir kök ad alanıdır.



## Sınıflar

| Sınıf | Açıklama |
| --- | --- |
| [EditableDocument](../com.groupdocs.editor/editabledocument) | Düzenlemeden önce ve sonra içeriği içeren ara belge |
| [Editor](../com.groupdocs.editor/editor) | Dönüştürme yöntemlerini kapsülleyen ana sınıf. |
| [EncryptedException](../com.groupdocs.editor/encryptedexception) | Kullanıcı, X509Certificates kullanılarak şifrelenmiş bir belgeyi açmaya çalıştığında atılan istisna. |
| [FormFieldManager](../com.groupdocs.editor/formfieldmanager) |  |
| [IncorrectPasswordException](../com.groupdocs.editor/incorrectpasswordexception) | Belirtilen şifre yanlış olduğunda atılan istisna. |
| [InvalidFormatException](../com.groupdocs.editor/invalidformatexception) | Kullanıcı, özgün belge formatıyla uyumsuz format‑spesifik seçeneklerle bir belgeyi açmaya çalıştığında atılan istisna. |
| [PasswordRequiredException](../com.groupdocs.editor/passwordrequiredexception) | Kullanıcı, bazı formatlarda şifre korumalı şifrelenmiş bir belgeyi açmaya çalıştığında ve bu belgeyi açmak için şifre sağlamadığında atılan istisna. |
